Les incontournables

Sept savoir-faire à maîtriser le jour J

  1. Réciter les définitions du QCMTension = différence de potentiels, courant = déplacement ordonné de charges, branche = entre deux nœuds consécutifs, série = même courant, parallèle = même tension.
    QCM →
  2. Compter nœuds, branches et maillesColorie les fils, compte les nœuds (3 fils ou plus), les branches, puis toutes les boucles : les corrigés comptent toutes les mailles.
    Cours →
  3. Flécher et enchaîner les tensionsConvention récepteur sur les résistances, UAB = VA − VB, loi des mailles avec + et −, résultats négatifs assumés.
    Exercices →
  4. Réduire un réseau de résistancesDepuis le bout le plus loin, en redessinant ; réflexes 4R // 4R = 2R, 3R // 6R = 2R, fractions sans calculatrice.
    Exercices →
  5. Appliquer les diviseursTension : la même résistance en haut. Courant : l’autre résistance en haut. Ils finissent tous les exercices de Thévenin.
    Cours →
  6. Transformer Thévenin ⇄ Norton en chaîneParallèle → Norton pour additionner les courants, série → Thévenin pour additionner les tensions, un schéma par étape, flèches vers le +.
    Méthode →
  7. Vérifier sans calculatriceRth en éteignant les sources (tension → fil, courant → trou), unités, un cas limite, ou Millman en une ligne.
    Méthode →
