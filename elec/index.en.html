The essentials

Seven skills to master on exam day

  1. Know the MCQ definitions by heartVoltage = potential difference, current = orderly displacement of charges, branch = between two consecutive nodes, series = same current, parallel = same voltage.
    MCQ →
  2. Count nodes, branches and loopsColor the wires, count the nodes (3 wires or more), the branches, then every loop: the answer keys count all the loops.
    Course →
  3. Draw the arrows and chain the voltagesReceiver convention on resistors, UAB = VA − VB, KVL with + and −, negative results are fine.
    Exercises →
  4. Reduce a resistor networkStart from the far end and redraw as you go; reflexes 4R // 4R = 2R, 3R // 6R = 2R, fractions without a calculator.
    Exercises →
  5. Apply the dividersVoltage: the same resistor on top. Current: the other resistor on top. They finish every Thévenin exercise.
    Course →
  6. Chain Thévenin ⇄ Norton transformationsParallel → Norton to add the currents, series → Thévenin to add the voltages, one diagram per step, arrows toward the +.
    Method →
  7. Check without a calculatorRth by turning off the sources (voltage → wire, current → gap), units, a limiting case, or Millman in one line.
    Method →
