Detailed methods

Quantities

I in A = C/s · U in V = J/C · R in Ω · P in W · G = 1/R in S

UAB = VA − VB (head = A) · UAC = UAB + UBC

Ground = chosen reference (0 V), earth = the soil. Current arrow drawn at random: negative = other direction.

Conventions and Ohm’s law

Receiver: opposite arrows, U = RI, P = UI received.

Generator: arrows in the same direction, on a resistor U = −RI, P supplied.

P = UI = RI² = U²/R · kΩ × mA = V

Wire or gap

Wire: closed switch (U = 0), ammeter (in series).

Gap: open switch (I = 0), voltmeter (in parallel).

Wire across a resistor = short circuit: 0 V, 0 A through it. Open loop: the whole voltage across the gap.

Sources

Voltage source: sets U, line along the wire. Current source: sets I, line across it.

Turn off: voltage → wire; current → gap (remove the branch).

Real: u = E − ri (r in series, small) · i = I − u/r (r in parallel, large)

Nodes, branches, loops

Node: ≥ 3 wires. Branch: between two consecutive nodes, same current. Loop: closed path.

Independent: b − n + 1. The answer keys count every loop.

Kirchhoff

KCL: Σ Iin = Σ Iout

KVL: Σ ± U = 0 (+ if the arrow follows the direction of travel)

Series, parallel

Series = same current. Parallel = same voltage (same two nodes). Often neither.

Req = ΣRk · 1/Req = Σ 1/Rk · R₁R₂/(R₁ + R₂)

R // R = R/2R // 2R = 2R/3
3R // 6R = 2R2R // 4R = 4R/3
n × R: R/n2R // 3R = 6R/5

Reduce from the far end, redraw after each merge.

Dividers

Voltage (series): U₂ = E·R₂/(R₁ + R₂) — the same one on top

Current (parallel): I₂ = I·R₁/(R₁ + R₂) — the other one on top

Large resistor: large voltage, small current.

Thévenin and Norton · 11 pts

Eth = no-load voltage between A and B. Rth = resistance seen, sources off, load disconnected.

IN = short-circuit current, RN = Rth, Eth = R·IN.

U = Eth·2R/(Rth + 2R)

Chained transformations

(E series R) ⇄ (E/R parallel R)

  1. Disconnect the 2R load.
  2. Branches in parallel → Norton, add the currents.
  3. Elements in series (I // R block on a line) → Thévenin RI, add the emfs.
  4. One source + one resistor → reconnect 2R, divider.
  5. Check Rth by turning off the sources.

Norton current arrow toward the +; emf in the direction of the current. A source leaving A counts as a minus.

Millman

VA = [Σ (Vk ± Ek)/Rk + ΣIin − ΣIout] / Σ 1/Rk

+ if the emf points toward A. Current source in series: numerator only.

Superposition

One source at a time (the others off: voltage → wire, current → gap), then add up the contributions. Ideal for checking.

Traps

  • Negative result = right answer if the arrow is reversed.
  • Disconnect the 2R load before Eth, Rth.
  • Current source turned off = gap, not wire.
  • Read every source arrow (2E pointing down in 2024).
  • Current enters and leaves a generator unchanged.
  • 6R // 6R = 3R, not 12R.
  • Ammeter in series, voltmeter in parallel.
