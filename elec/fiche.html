Méthodes détaillées

Grandeurs

I en A = C/s · U en V = J/C · R en Ω · P en W · G = 1/R en S

UAB = VA − VB (pointe = A) · UAC = UAB + UBC

Masse = référence choisie (0 V), terre = sol. Courant fléché au hasard : négatif = autre sens.

Conventions et loi d’Ohm

Récepteur : flèches opposées, U = RI, P = UI reçue.

Générateur : flèches même sens, sur une résistance U = −RI, P fournie.

P = UI = RI² = U²/R · kΩ × mA = V

Fil ou trou

Fil : interrupteur fermé (U = 0), ampèremètre (en série).

Trou : interrupteur ouvert (I = 0), voltmètre (en parallèle).

Fil aux bornes d’une résistance = court-circuit : 0 V, 0 A dedans. Boucle ouverte : toute la tension sur le trou.

Générateurs

Source de tension : impose U, trait dans l’axe du fil. Source de courant : impose I, trait en travers.

Éteindre : tension → fil ; courant → trou (on enlève la branche).

Réels : u = E − ri (r série, faible) · i = I − u/r (r parallèle, forte)

Nœuds, branches, mailles

Nœud : ≥ 3 fils. Branche : entre deux nœuds consécutifs, même courant. Maille : contour fermé.

Indépendantes : b − n + 1. Les corrigés comptent toutes les mailles.

Kirchhoff

Nœuds : Σ Ientrants = Σ Isortants

Mailles : Σ ± U = 0 (+ si la flèche suit le sens de parcours)

Série, parallèle

Série = même courant. Parallèle = même tension (mêmes deux nœuds). Souvent ni l’un ni l’autre.

Req = ΣRk · 1/Req = Σ 1/Rk · R₁R₂/(R₁ + R₂)

R // R = R/2R // 2R = 2R/3
3R // 6R = 2R2R // 4R = 4R/3
n × R : R/n2R // 3R = 6R/5

Réduire depuis le bout le plus loin, redessiner à chaque fusion.

Diviseurs

Tension (série) : U₂ = E·R₂/(R₁ + R₂) — la même en haut

Courant (parallèle) : I₂ = I·R₁/(R₁ + R₂) — l’autre en haut

Grosse résistance : grosse tension, petit courant.

Thévenin et Norton · 11 pts

Eth = tension à vide entre A et B. Rth = résistance vue, sources éteintes, charge débranchée.

IN = courant de court-circuit, RN = Rth, Eth = R·IN.

U = Eth·2R/(Rth + 2R)

Transformations en chaîne

(E série R) ⇄ (E/R parallèle R)

  1. Débrancher la charge 2R.
  2. Branches en parallèle → Norton, additionner les courants.
  3. Éléments en série (bloc I // R sur une ligne) → Thévenin RI, additionner les fém.
  4. Une source + une résistance → rebrancher 2R, diviseur.
  5. Vérifier Rth en éteignant les sources.

Flèche du courant de Norton vers le + ; fém dans le sens du courant. Une source qui sort de A compte en moins.

Millman

VA = [Σ (Vk ± Ek)/Rk + ΣIentrants − ΣIsortants] / Σ 1/Rk

+ si la fém pointe vers A. Source de courant en série : numérateur seulement.

Superposition

Une source à la fois (les autres éteintes : tension → fil, courant → trou), puis on additionne les contributions. Idéal pour vérifier.

Pièges

  • Résultat négatif = bonne réponse si la flèche est à l’envers.
  • Charge 2R à débrancher avant Eth, Rth.
  • Source de courant éteinte = trou, pas fil.
  • Lire chaque flèche de source (2E vers le bas en 2024).
  • Le courant entre et ressort d’un générateur sans changer.
  • 6R // 6R = 3R, pas 12R.
  • Ampèremètre en série, voltmètre en parallèle.
