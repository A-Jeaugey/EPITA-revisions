Detailed methods

The exam

No calculator or documents, answers on the paper. A course MCQ (5 to 8 points, whole semester), then two or three theorem exercises. 45% of the ECUE grade.

The title of the exercise names the theorem: use that one.

Turning off a source

Voltage → wire (U = 0). Current → gap (I = 0, remove the branch).

Do not count: a resistor in series with a current source, a resistor in parallel with a voltage source.

Thévenin

  1. Disconnect the load, mark A and B.
  2. Eth = open-circuit voltage between A and B.
  3. Rth = resistance seen from A and B, sources turned off.

U = Eth·RL/(Rth + RL)

Norton

IN = short-circuit current between A and B (wire in place of the load). RN = Rth.

I = IN·RN/(RN + RL) — the other one on top

Eth = RN·IN

Chained transformations

(E series R) ⇄ (E/R parallel R)

  1. Disconnect the load, remove what does not matter.
  2. Branches in parallel → Norton, add the currents.
  3. Elements in series (I // R block on a line) → Thévenin RI, add the emfs.
  4. One source + one resistor → reconnect the load, divider.
  5. Check Rth by turning off the sources.

Norton current arrow toward the +; emf in the direction of the current. A source leaving A counts negatively. One diagram per step.

Millman

VA = [Σ (Vk ± Ek)/Rk + ΣIin − ΣIout] / Σ 1/Rk

Ground at the foot of the sources. + if the emf points toward A. Current-source branch: numerator only, its resistance does not count.

Superposition

  1. One state per source, the others turned off (voltage → wire, current → gap).
  2. Each contribution through a divider, with its sign.
  3. Add, then the numerical application.

Never powers. A source can disappear from the result: that is allowed.

B1 reminders

Voltage: U₂ = E·R₂/(R₁ + R₂) — the same one on top

Current: I₂ = I·R₁/(R₁ + R₂) — the other one on top

R // R = R/2R // 2R = 2R/3
3R // 6R = 2R2R // 3R = 6R/5

kΩ × mA = V · V / kΩ = mA

Traps

  • Disconnect the load before Eth, Rth.
  • Current source turned off = gap, not wire.
  • Current divider: the other resistor on top.
  • Read every source arrow before writing a sign.
  • A resistor on the bottom wire is easy to forget.
  • Millman: no 1/R for a current-source branch.
  • Answer U loaded, not Eth.
  • Negative result = right answer if the arrow is reversed.

On your paper

  • Name the theorem and the step.
  • One diagram per transformation, per state.
  • Symbolic, then numerical with the unit.
  • A single fraction bar, result boxed.
  • Check the units and Rth twice.
