Partie 1 cours § III.5.1

Sommes de produits, produits de sommes

En algèbre de Boole, le résultat d’un OU s’appelle une somme et le résultat d’un ET un produit. Deux écritures reviennent sans cesse :

  • une somme de produits : des produits reliés par des OU, comme A.B.C + B.C.D + A.~B.C.~D.E ;
  • un produit de sommes : des sommes reliées par des ET, comme (A + ~B).(B + C + D).

Dans les deux cas, les barres ne portent que sur des variables seules. Un terme réduit à une variable compte comme un produit (dans une somme de produits) ou comme une somme (dans un produit de sommes).

Sommes de produits (cours)

A + A.B + B.~A + ~B + ~A.C.D + B.C.D

~B + A.C + ~A.B + B.~C + ~A.~B.C

Produits de sommes (cours)

(A + ~B + C).(~A + D + ~E).(C + D + ~E)

A.(B + C + ~D).(A + ~C).(A + D)

À retenir

« Le résultat ne devra pas contenir de parenthèses » : c’est une somme de produits. Toute expression peut s’écrire ainsi (De Morgan, puis développement), et c’est la forme que donne un tableau de Karnaugh.

Piège : une barre sur un groupe

A.~(B.C) + D n’est pas une somme de produits au sens strict : la barre couvre deux variables. Casse-la d’abord : A.(~B + ~C) + D = A.~B + A.~C + D.

Partie 2 cours § III.5.2.1

Mintermes et première forme canonique

Un minterme est un produit qui contient toutes les variables de l’expression, chacune une fois, complémentée ou non. Avec A, B, C, D : A.~B.C.D est un minterme, A.~B.C n’en est pas un (il manque D).

Une fonction peut s’écrire de bien des façons, mais elle n’a qu’une seule somme de mintermes : c’est la somme canonique de produits, ou première forme canonique.

Exemple du cours, avec cinq variables A, B, C, D, E :

ProduitMinterme ?
A.B.Cnon : D et E n’apparaissent pas
B.C.Dnon : A et E n’apparaissent pas
A.~B.C.~D.Eoui
A.B.C.~D.~Eoui

En revanche, A.B.C.D + ~A.~B.~C.D + ~A.B.C.~D + ~A.B.~C.~D + ~A.~B.~C.~D est une somme de mintermes : c’est une première forme canonique.

Le numéro d’un minterme

Remplace chaque variable par 1 et chaque variable barrée par 0, et lis le nombre binaire obtenu (dans l’ordre des variables) : A.~B.C → 101 → minterme 5. Un minterme vaut 1 sur une seule ligne de la table de vérité : celle qui porte son numéro.

Piège : quelles variables ?

Les variables sont celles de l’expression, toutes. Dans A + ~B, il y en a deux : la première forme a trois mintermes, A.B + A.~B + ~A.~B (examen 2025-2026). N’en invente pas de troisième.

Partie 3 cours § III.5.2.2

Compléter les produits

On obtient la première forme à partir de n’importe quelle somme de produits en complétant chaque produit. S’il manque la variable D, on multiplie par (D + ~D), qui vaut 1, puis on développe.

Exemple du cours : X = ~A.B.C + A.~B + A.B.~C.~D, quatre variables.

~A.B.Cil manque D
~A.B.C.(D + ~D)
~A.B.C.D + ~A.B.C.~Ddeux mintermes
A.~Bil manque C et D
A.~B.(C + ~C).(D + ~D)
A.~B.C.D + A.~B.C.~D + A.~B.~C.D + A.~B.~C.~Dquatre mintermes

Le dernier produit, A.B.~C.~D, est déjà un minterme. Résultat :

X = ~A.B.C.D + ~A.B.C.~D + A.~B.C.D + A.~B.C.~D + A.~B.~C.D + A.~B.~C.~D + A.B.~C.~D
Combien de mintermes ?

Un produit auquel il manque k variables donne 2k mintermes. Si deux produits donnent le même minterme, on ne l’écrit qu’une fois (X + X = X).

Piège : les doublons

Avec A.B + B.C (variables A, B, C), compléter donne A.B.C + A.B.~C + A.B.C + ~A.B.C : le minterme A.B.C apparaît deux fois. La première forme n’en garde qu’un : trois mintermes.

Partie 4 cours § III.5.2.3

Première forme et table de vérité

La première forme se lit directement sur la table de vérité : chaque ligne où la sortie vaut 1 donne un minterme. On remplace les 1 par les variables et les 0 par les variables complémentées.

X = ~A.~B.C + ~A.B.C + A.B.~C + A.B.Clignes 001, 011, 110, 111

Et inversement : à partir d’une première forme, on remplit la table en mettant un 1 sur la ligne de chaque minterme, et 0 ailleurs.

Une méthode rapide pour l’examen

Pour la première forme d’une expression compliquée, il est souvent plus sûr de passer par la table : calcule la sortie ligne par ligne (ou remplis directement un tableau de Karnaugh, chapitre 4), puis écris un minterme par 1. Exemple : (A + ~C).(~A + C + ~D).B.~C vaut 1 seulement si B = 1 et C = 0 ; il reste à tester les quatre valeurs de A et D.

Piège : l’ordre des variables

Écris les variables de chaque minterme dans le même ordre, celui de la table (A, B, C, D) : c’est plus lisible, et c’est ainsi que les corrigés les écrivent. L’ordre des mintermes entre eux, lui, n’a pas d’importance.

Partie 5 cours § III.5.3.1

Maxtermes et seconde forme canonique

Un maxterme est une somme qui contient toutes les variables de l’expression, chacune une fois, complémentée ou non : (A + ~B + C + D). Une fonction n’a qu’un seul produit de maxtermes : le produit canonique de sommes, ou seconde forme canonique.

Exemple du cours, variables A, B, C, D, E
SommeMaxterme ?
A + B + Cnon : D et E n’apparaissent pas
B + C + Dnon : A et E n’apparaissent pas
A + ~B + C + ~D + Eoui
A + B + C + ~D + ~Eoui
Minterme

Un produit, qui vaut 1 sur une seule ligne de la table.

Maxterme

Une somme, qui vaut 0 sur une seule ligne de la table.

La ligne d’un maxterme

Un maxterme vaut 0 quand chacune de ses variables vaut 0 : la variable seule vaut 0, la variable barrée vaut 1. (A + ~B + C) vaut 0 seulement pour A = 0, B = 1, C = 0 : la ligne 010 = 2. C’est l’inverse de la règle des mintermes.

Piège : les barres à l’envers

La ligne 101 donne le minterme A.~B.C mais le maxterme (~A + B + ~C) : dans un maxterme, on barre les variables qui valent 1.

Partie 6 cours § III.5.3.2

Compléter les sommes

Pour passer d’un produit de sommes à la seconde forme, on complète chaque somme. S’il manque B, on ajoute B.~B, qui vaut 0, puis on applique la distributivité du OU (X + Y.Z = (X + Y).(X + Z)).

Exemple du cours : X = (~A + C).B, trois variables.

(~A + C)il manque B
(~A + B.~B + C)
(~A + B + C).(~A + ~B + C)distributivité
Bil manque A et C
A.~A + B + C.~C
(A + B + C.~C).(~A + B + C.~C)distributivité
(A + B + C).(A + B + ~C).(~A + B + C).(~A + B + ~C)distributivité

Le maxterme (~A + B + C) apparaît deux fois : on le garde une seule fois. Seconde forme :

X = (~A + B + C).(~A + ~B + C).(A + B + C).(A + B + ~C).(~A + B + ~C)
Piège : partir d’une somme de produits

Pour la seconde forme de A + B.C, il faut d’abord un produit de sommes : A + B.C = (A + B).(A + C), puis compléter. Ou bien passer par la table : les lignes où la sortie vaut 0 (partie suivante).

Partie 7 cours § III.5.3.3

Seconde forme et table de vérité

La seconde forme se lit aussi sur la table, mais sur les 0 : chaque ligne où la sortie vaut 0 donne un maxterme, en remplaçant les 0 par les variables et les 1 par les variables complémentées.

X = (A + B + C).(A + ~B + C).(~A + B + C).(~A + B + ~C)lignes 000, 010, 100, 101

Les deux formes décrivent la même fonction : quatre mintermes (les 1) d’un côté, quatre maxtermes (les 0) de l’autre. Avec 3 variables, il y a 8 lignes : le nombre de mintermes plus le nombre de maxtermes vaut toujours 8.

Piège : lire les 1 au lieu des 0

La seconde forme vient des lignes à 0. Un maxterme écrit pour une ligne à 1 donne une fonction fausse ; c’est l’erreur la plus fréquente sur cette question.

Partie 8 cours § III.5.4

D’une forme à l’autre, et l’examen

Pour passer d’une forme canonique à l’autre, on liste les combinaisons binaires présentes dans une forme ; les combinaisons manquantes donnent l’autre forme.

  1. Première forme du cours : ~A.~B.C + ~A.B.~C + ~A.B.C + A.~B.C + A.B.~C.

  2. Combinaisons présentes (les 1) : 001, 010, 011, 101, 110.

  3. Combinaisons manquantes (les 0) : 000, 100, 111.

  4. Seconde forme : (A + B + C).(~A + B + C).(~A + ~B + ~C).

À l’examen
  • Un exercice de formes canoniques à chaque examen 2 (2023-2024, 2024-2025, 2025-2026 : 4 ou 5 points) : deux ou trois expressions pour la première forme, deux pour la seconde. Avant, la question venait dans un exercice d’expressions (« donnez la première forme canonique de S1 »).
  • Les expressions sont courtes : 2 à 4 variables, un produit et une somme. Exemples tombés : A + ~B, A.B.C + A.~B, (A + ~B).(~B + C), A + B.~C.
  • Le TD 1 (exercice 3) reprend des expressions des anciens sujets : (a + c).(~a + b + c) est celle de l’examen 2 de 2023-2024.
Piège : simplifier la forme canonique

Une forme canonique ne se simplifie pas : c’est justement la forme développée au maximum. Si ta réponse a moins de termes que de 1 (ou de 0) dans la table, ce n’est pas une forme canonique.
