The two-input gates

  • AND A.B: 1 if all inputs are 1. OR A + B: 1 if at least one input is 1.
  • NAND ~(A.B): 0 only if all inputs are 1. NOR ~(A + B): 1 only if all inputs are 0.
  • XOR A ^ B: 1 if an odd number of inputs are 1; XNOR: 1 if A = B.
  • A bubble = a NOT. n inputs → 2n rows, counting in binary.

Precedence and axioms

  • Precedence: NOT, then AND, then OR. A bar over a group works like parentheses.
  • A.0 = 0 ; A.1 = A ; A.A = A ; A.~A = 0
  • A + 1 = 1 ; A + 0 = A ; A + A = A ; A + ~A = 1 ; ~~A = A

Distributivity, De Morgan, absorption

  • A.(B + C) = A.B + A.C and also A + B.C = (A + B).(A + C)
  • De Morgan: ~(A.B) = ~A + ~B; ~(A + B) = ~A.~B (and for 3 or more variables)
  • Absorption: A + A.B = A; A + ~A.B = A + B
  • Combining: A.B + A.~B = A
  • Duality: swapping AND and OR, 0 and 1 gives another true rule.

EXCLUSIVE-OR

  • A ^ B = A.~B + ~A.B ; ~(A ^ B) = A.B + ~A.~B
  • A ^ 0 = A ; A ^ 1 = ~A ; A ^ A = 0 ; A ^ ~A = 1
  • Making it appear: factor until you reach X.~Y + ~X.Y, where X or Y can be products (~D.B + ~C.B + D.C.~B = B ^ (C.D)).
  • In a Karnaugh map: 1s in a checkerboard.

Simplify without parentheses

  1. De Morgan on the long bars, from the outside in.
  2. Expand; remove X.~X; X.X = X.
  3. Combine, absorb, until you reach the shortest sum of products.
  4. Check with a Karnaugh map.

Canonical forms

  • Minterm form: sum of minterms, one per row with output 1; variable at 0 → complemented.
  • Maxterm form: product of maxterms, one per row with output 0; variable at 1 → complemented.
  • Each term contains all the variables of the expression, once. Minterms + maxterms = 2n.
  • Completing: X = X.Y + X.~Y (minterm form); X = (X + Y).(X + ~Y) (maxterm form); no duplicates.

  • Gray order 00, 01, 11, 10: two neighbouring cells differ by only one bit. With 3 variables: a row C = 0 (0 1 3 2), a row C = 1 (4 5 7 6).

Karnaugh: groups and Φ

  • Rectangles of 1, 2, 4, 8 cells, as large as possible, as few as possible; opposite edges touch, and so do the 4 corners.
  • Reading: variable that changes → absent; always 0 → complemented; always 1 → written as is.
  • Φ (undefined): in a group if it makes it larger, never a group of Φ alone.
  • A single cell = a minterm.

NAND gates only

  • NOT: ~(A.A) = ~A (1 gate).
  • AND: A.B = ~~(A.B) (2 gates).
  • OR: A + B = ~(~A.~B) (3 gates).
  • XOR: A ^ B = ~(~(A.~B).~(~A.B)) (5 gates; 4 when sharing ~(A.B)).

A problem

  1. Name the inputs and outputs, in the order of the paper (the first = most significant).
  2. Truth table row by row; Φ only for impossible cases.
  3. One Karnaugh map per output; an EXCLUSIVE-OR if asked.

Circuits of the course

  • 1-bit comparator: A > B: A.~B; A = B: ~(A ^ B); A < B: ~A.B.
  • 2-bit adder: S0 = B0 ^ A0, S1 = A1 ^ B1 ^ (A0.B0).
  • Decoder: one output at 1, the one for the input number. Multiplexer: copies the selected input. Demultiplexer: sends D to the selected output.

Traps

  • ~(A + B) is not ~A + ~B; De Morgan also changes the operator.
  • Result with parentheses, or not the shortest.
  • Maxterm written like a minterm; maxterm form taken from the rows at 1.
  • Karnaugh map in binary order; edges forgotten; group of 3 or 6 cells; a Φ circled alone.
  • EXCLUSIVE-OR used where the paper forbids it.
  • Φ put on a row that the statement defines.
