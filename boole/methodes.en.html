Method 1 exercise 1 · sheet 2, parts 4, 5 and 8

Simplify as much as possible, without parentheses

  1. Break the long bars with De Morgan, from the outside in: ~(X.Y) = ~X + ~Y, ~(X + Y) = ~X.~Y. Keep parentheses as long as you need them.

  2. Expand into a sum of products, and immediately remove the null products (X.~X = 0) and the repetitions (X.X = X).

  3. Reduce: two products that differ by only one variable combine (X.Y + X.~Y = X); a product absorbs a longer one (X + X.Y = X); X + ~X.Y = X + Y.

  4. Check on scratch paper with a Karnaugh map: only the result is graded, and the map reliably gives the simplest form.

Example · B2 exam 2025-2026, exercise 1 (and Tutorial 1, S5)

(A + ~B.~C).~(A.B)
(A + ~B.~C).(~A + ~B)De Morgan
A.~A + A.~B + ~A.~B.~C + ~B.~Cexpansion
A.~B + ~A.~B.~C + ~B.~CA.~A = 0
A.~B + ~B.~C~B.~C absorbs ~A.~B.~C

Same paper: the sum under the bar

~(A.B + ~A.~B + ~A.B)
~(A.B + ~A)~A.~B + ~A.B = ~A
~(~A + B)~A + A.B = ~A + B
A.~BDe Morgan
On the paper

The result alone, in the box: A.~B + ~B.~C. A sum of products, with no parentheses at all: “The result must not contain parentheses.” An expression that equals 0 or 1 is written 0 or 1 (2023 paper: ~((C + D) + (B + ~D)) = 0).

Traps
  • Half a De Morgan: ~(X.Y) becomes ~X + ~Y; the AND becomes OR, it is not enough to put a bar on each letter.
  • Stopping too early: A + B.C + ~B.C can still be reduced, to A + C.
  • Leaving a factored parenthesis (B.(C + ~A)): the result is correct, but the instruction is not followed.
Method 2 exercise 2 · sheet 3, parts 2 to 7

Minterm and maxterm canonical forms

  1. List the variables of the expression, in alphabetical order, and only those: A + ~B has only A and B.

  2. Find the rows: output 1 for the minterm form, output 0 for the maxterm form. Read them from the shape of the expression (a product imposes its values) or build the truth table.

  3. Minterm form: one minterm per row with output 1, a product of all the variables, complemented if it is 0. Maxterm form: one maxterm per row with output 0, a sum of all the variables, complemented if it is 1.

  4. Count: minterms + maxterms = 2n. No duplicate term.

Example · B2 exam 2025-2026: A + B.~C, maxterm form

S = (A + B + C).(A + B + ~C).(A + ~B + ~C)one maxterm per row at 0

Completing the terms · exam 2 2023-2024 and Tutorial 1: (A + C).(~A + B + C)

(A + C).(~A + B + C)
(A + B.~B + C).(~A + B + C)B is missing: B.~B = 0
(A + B + C).(A + ~B + C).(~A + B + C)X + Y.Z = (X + Y).(X + Z)
On the paper

Each term contains all the variables, in the same order; minterms separated by +, maxterms in parentheses and separated by dots. The answer keys list the terms in any order: only the content counts.

Traps
  • Mixing up the conventions: in a maxterm, a variable at 0 is written without a bar.
  • Adding a variable that is not in the expression.
  • Keeping a duplicate term after completing two products (Tutorial 1, ex. 3.1, S3: two duplicates).
Method 3 exercise 3 · sheet 4

Karnaugh maps, with undefined cells

  1. Copy the header of the paper: rows DC, columns BA, in Gray order 00, 01, 11, 10. The cell numbers: 0 1 3 2 / 4 5 7 6 / 12 13 15 14 / 8 9 11 10.

  2. Fill in: 1 at the given numbers, Φ at the undefined cells, 0 everywhere else. The map is graded: check every cell.

  3. Circle the largest rectangles of 1, 2, 4 or 8 cells, opposite edges being neighbours, with as few circles as possible. A Φ goes into a circle if it enlarges it, never alone.

  4. Read each circle: the variable that changes disappears; at 0, it is complemented; at 1, written as is. The expression is the sum of the products.

Example · B2 exam 2025-2026, exercise 3: S2 = 1 iff N = 0, 4, 6, 8, 12, 14; undefined iff N = 3, 5, 7, 10, 13, 15

On the paper

The completed map (0, 1 and Φ), the circles drawn, then the expression: S2 = C + ~B.~A. “No points will be given to an expression if its Karnaugh map is wrong”: the map counts as much as the expression.

Traps
  • Binary order instead of Gray order (00, 01, 10, 11): the map is wrong.
  • Forgetting the edges: column 10 touches column 00, row 10 touches row 00, and the four corners form a circle.
  • A circle of 3 or 6 cells: only powers of 2 are allowed.
  • A circle that contains only Φ cells, or a Φ left at 0 when it would have doubled a circle.

Method 4 exercises 3 and 5 · sheet 2, part 7

Making an EXCLUSIVE-OR appear

  1. Start from the simplest form without EXCLUSIVE-OR (Karnaugh or algebra).

  2. Look for the pattern X.~Y + ~X.Y = X ^ Y (or X.Y + ~X.~Y = ~(X ^ Y)), where X and Y can be products. Factor to make it appear, with De Morgan’s help.

  3. Spot the checkerboard: in a Karnaugh map, 1s that never touch, every other cell, signal an EXCLUSIVE-OR.

Example · B2 exam 2025-2026, exercise 3, question 2

~D.B + ~C.B + D.C.~B
B.(~D + ~C) + ~B.(C.D)factoring
B.~(C.D) + ~B.(C.D)De Morgan
B ^ (C.D)X.~Y + ~X.Y = X ^ Y
On the paper

S1 = B ^ (C.D), with parentheses around the product: B ^ C.D reads the same (AND comes first), but the answer keys write them.

Trap

Using EXCLUSIVE-OR when the paper forbids it: “Do not simplify by using the EXCLUSIVE-OR operator” (2025, question 1). The form with ⊕ goes only where it is asked for.

Method 5 exercise 5 (2025) · sheet 2, part 9

NAND gates only

  1. NOT: a NAND with both inputs tied together, ~(A.A) = ~A. 1 gate.

  2. AND: a NAND, then an inverter, A.B = ~~(A.B). 2 gates.

  3. OR: an inverter on each input, then a NAND, A + B = ~(~A.~B). 3 gates.

  4. XOR: A ^ B = ~(~(A.~B).~(~A.B)). Two inverters, two NANDs, a final NAND: 5 gates.

Example · B2 exam 2025-2026, exercise 5: the XOR in 5 gates

On the paper

A clean schematic: inputs on the left, output on the right, one NAND gate per symbol, and the imposed number of gates respected (AND: 2, OR: 3, XOR: 5 in 2025-2026).

Trap

Translating each gate of A.~B + ~A.B into NAND, one by one: 9 gates. The double bar and De Morgan bring it down to 5 (4 when sharing ~(A.B), see Tutorial 1, ex. 2).

Method 6 exercise 4 · sheet 5, parts 1 and 2

A problem: from the statement to the equations

  1. Name the inputs and outputs, in the order of the paper (the first input is the most significant of the table).

  2. Fill in the truth table row by row, translating the statement. A row that the statement declares impossible or “does not matter” gets Φ; a row that it defines (an error, an alarm) gets its value.

  3. One Karnaugh map per output, unless a single row is 1: it is then a minterm. Simplify, then look for an EXCLUSIVE-OR if it is asked for.

Example · B2 exam 2025-2026, exercise 4: the tank with three sensors

C1, C2 and C3 are at 250, 500 and 750 liters. A sensor can have liquid in front of it only if the ones below it do: only 000, 001, 011 and 111 are normal, and each one lights a level light. The four other rows are errors: L0.

On the paper

The complete table, then L1 = ~C3.~C2.~C1, L2 = ~C3.~C2.C1, L3 = ~C3.C2.C1, L4 = C3.C2.C1, and the map of L0 with its circles: L0 = C3.~C2 + C2.~C1.

Trap

Putting Φ on a row that the statement defines. Here, the errors are not “impossible”: they light L0 and switch off L1 to L4. Simplifying L1 to ~C3 would be wrong on row 010.

!To reread the day before

The traps, exercise by exercise

Algebra
  • ~(A + B) is not ~A + ~B: it is ~A.~B.
  • A + ~A.B = A + B, not A.B or A.
  • (A + B).(A + C) = A + B.C: distributivity of OR over AND does not exist in arithmetic, but it does in Boolean algebra.
Canonical forms
  • Minterm: variable at 0 → complemented. Maxterm: variable at 0 → no bar.
  • The maxterm form comes from the rows at 0, not the rows at 1.
Karnaugh
  • Gray order, neighbouring edges, circles of 1, 2, 4, 8 cells.
  • Rows and columns swapped compared to the paper: the cell numbers change.
  • Φ: a help, never an obligation.
Problems
  • Order of the inputs: the first one named is the most significant of the table (C3 before C2 before C1 in the tank).
  • A row defined by the statement is never a Φ.
