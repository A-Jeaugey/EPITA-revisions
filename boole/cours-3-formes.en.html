Part 1 course § III.5.1

Sums of products, products of sums

In Boolean algebra, the result of an OR is called a sum and the result of an AND a product. Two forms come up again and again:

  • a sum of products: products joined by ORs, such as A.B.C + B.C.D + A.~B.C.~D.E ;
  • a product of sums: sums joined by ANDs, such as (A + ~B).(B + C + D).

In both cases, the bars apply only to single variables. A term reduced to one variable counts as a product (in a sum of products) or as a sum (in a product of sums).

Sums of products (course)

A + A.B + B.~A + ~B + ~A.C.D + B.C.D

~B + A.C + ~A.B + B.~C + ~A.~B.C

Products of sums (course)

(A + ~B + C).(~A + D + ~E).(C + D + ~E)

A.(B + C + ~D).(A + ~C).(A + D)

Key points

“The result must not contain parentheses”: this means a sum of products. Any expression can be written this way (De Morgan, then expansion), and it is the form a Karnaugh map gives.

Pitfall: a bar over a group

A.~(B.C) + D is not a sum of products in the strict sense: the bar covers two variables. Break it first: A.(~B + ~C) + D = A.~B + A.~C + D.

Part 2 course § III.5.2.1

Minterms and the minterm canonical form

A minterm is a product that contains all the variables of the expression, each once, complemented or not. With A, B, C, D: A.~B.C.D is a minterm, A.~B.C is not (D is missing).

A function can be written in many ways, but it has only one sum of minterms: the canonical sum of products, or minterm canonical form (the first canonical form).

Example from the course, with five variables A, B, C, D, E :

ProductMinterm?
A.B.Cno: D and E do not appear
B.C.Dno: A and E do not appear
A.~B.C.~D.Eyes
A.B.C.~D.~Eyes

On the other hand, A.B.C.D + ~A.~B.~C.D + ~A.B.C.~D + ~A.B.~C.~D + ~A.~B.~C.~D is a sum of minterms: it is a minterm canonical form.

The number of a minterm

Replace each variable by 1 and each barred variable by 0, and read the binary number you get (in the order of the variables): A.~B.C → 101 → minterm 5. A minterm is 1 on a single row of the truth table: the one that carries its number.

Pitfall: which variables?

The variables are those of the expression, all of them. In A + ~B there are two: the minterm canonical form has three minterms, A.B + A.~B + ~A.~B (2025-2026 exam). Do not invent a third one.

Part 3 course § III.5.2.2

Completing the products

You get the minterm canonical form from any sum of products by completing each product. If the variable D is missing, you multiply by (D + ~D), which is 1, then expand.

Example from the course: X = ~A.B.C + A.~B + A.B.~C.~D, four variables.

~A.B.CD is missing
~A.B.C.(D + ~D)
~A.B.C.D + ~A.B.C.~Dtwo minterms
A.~BC and D are missing
A.~B.(C + ~C).(D + ~D)
A.~B.C.D + A.~B.C.~D + A.~B.~C.D + A.~B.~C.~Dfour minterms

The last product, A.B.~C.~D, is already a minterm. Result:

X = ~A.B.C.D + ~A.B.C.~D + A.~B.C.D + A.~B.C.~D + A.~B.~C.D + A.~B.~C.~D + A.B.~C.~D
How many minterms?

A product that is missing k variables gives 2k minterms. If two products give the same minterm, you write it only once (X + X = X).

Pitfall: duplicates

With A.B + B.C (variables A, B, C), completing gives A.B.C + A.B.~C + A.B.C + ~A.B.C: the minterm A.B.C appears twice. The minterm canonical form keeps only one: three minterms.

Part 4 course § III.5.2.3

Minterm canonical form and truth table

The minterm canonical form can be read directly from the truth table: each row where the output is 1 gives a minterm. Replace the 1s by the variables and the 0s by the complemented variables.

X = ~A.~B.C + ~A.B.C + A.B.~C + A.B.Crows 001, 011, 110, 111

And conversely: from a minterm canonical form, you fill in the table by putting a 1 on the row of each minterm, and 0 elsewhere.

A quick method for the exam

For the minterm canonical form of a complicated expression, it is often safer to go through the table: compute the output row by row (or fill in a Karnaugh map directly, chapter 4), then write one minterm per 1. Example: (A + ~C).(~A + C + ~D).B.~C is 1 only if B = 1 and C = 0; you just have to test the four values of A and D.

Pitfall: the order of the variables

Write the variables of each minterm in the same order, that of the table (A, B, C, D): it is more readable, and it is how the official solutions write them. The order of the minterms among themselves does not matter.

Part 5 course § III.5.3.1

Maxterms and the maxterm canonical form

A maxterm is a sum that contains all the variables of the expression, each once, complemented or not: (A + ~B + C + D). A function has only one product of maxterms: the canonical product of sums, or maxterm canonical form (the second canonical form).

Example from the course, variables A, B, C, D, E
SumMaxterm?
A + B + Cno: D and E do not appear
B + C + Dno: A and E do not appear
A + ~B + C + ~D + Eyes
A + B + C + ~D + ~Eyes
Minterm

A product, which is 1 on a single row of the table.

Maxterm

A sum, which is 0 on a single row of the table.

The row of a maxterm

A maxterm is 0 when each of its variables is 0: a plain variable is 0, a barred variable is 1. (A + ~B + C) is 0 only for A = 0, B = 1, C = 0: row 010 = 2. This is the opposite of the minterm rule.

Pitfall: the bars the wrong way round

Row 101 gives the minterm A.~B.C but the maxterm (~A + B + ~C): in a maxterm, you bar the variables that are 1.

Part 6 course § III.5.3.2

Completing the sums

To go from a product of sums to the maxterm canonical form, you complete each sum. If B is missing, you add B.~B, which is 0, then apply the distributivity of OR (X + Y.Z = (X + Y).(X + Z)).

Example from the course: X = (~A + C).B, three variables.

(~A + C)B is missing
(~A + B.~B + C)
(~A + B + C).(~A + ~B + C)distributivity
BA and C are missing
A.~A + B + C.~C
(A + B + C.~C).(~A + B + C.~C)distributivity
(A + B + C).(A + B + ~C).(~A + B + C).(~A + B + ~C)distributivity

The maxterm (~A + B + C) appears twice: you keep it only once. Maxterm canonical form:

X = (~A + B + C).(~A + ~B + C).(A + B + C).(A + B + ~C).(~A + B + ~C)
Pitfall: starting from a sum of products

For the maxterm canonical form of A + B.C, you first need a product of sums: A + B.C = (A + B).(A + C), then complete. Or go through the table: the rows where the output is 0 (next part).

Part 7 course § III.5.3.3

Maxterm canonical form and truth table

The maxterm canonical form is also read from the table, but on the 0s: each row where the output is 0 gives a maxterm, replacing the 0s by the variables and the 1s by the complemented variables.

X = (A + B + C).(A + ~B + C).(~A + B + C).(~A + B + ~C)rows 000, 010, 100, 101

Les deux formes décrivent la même fonction : four minterms (les 1) d’un côté, quatre maxtermes (les 0) de l’autre. Avec 3 variables, il y a 8 lignes : le nombre de mintermes plus le nombre de maxtermes vaut toujours 8.

Pitfall: reading the 1s instead of the 0s

The maxterm canonical form comes from the rows with a 0. A maxterm written for a row with a 1 gives a wrong function; this is the most frequent mistake on this question.

Part 8 course § III.5.4

From one form to the other, and the exam

To go from one canonical form to the other, list the binary combinations present in one form; the missing combinations give the other form.

  1. Minterm canonical form from the course: ~A.~B.C + ~A.B.~C + ~A.B.C + A.~B.C + A.B.~C.

  2. Combinations present (the 1s): 001, 010, 011, 101, 110.

  3. Missing combinations (the 0s): 000, 100, 111.

  4. Maxterm canonical form: (A + B + C).(~A + B + C).(~A + ~B + ~C).

In the exam
  • An exercise on canonical forms in every Exam 2 (2023-2024, 2024-2025, 2025-2026: 4 or 5 points): two or three expressions for the minterm form, two for the maxterm form. Before that, the question came inside an exercise on expressions (“give the minterm canonical form of S1”).
  • The expressions are short: 2 to 4 variables, one product and one sum. Examples that came up: A + ~B, A.B.C + A.~B, (A + ~B).(~B + C), A + B.~C.
  • Tutorial 1 (exercise 3) reuses expressions from past exams: (a + c).(~a + b + c) is the one from the 2023-2024 Exam 2.
Pitfall: simplifying the canonical form

A canonical form is not simplified: it is precisely the fully expanded form. If your answer has fewer terms than there are 1s (or 0s) in the table, it is not a canonical form.
