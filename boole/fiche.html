  • ET A.B : 1 si toutes à 1. OU A + B : 1 si au moins une à 1.
  • NON-ET ~(A.B) : 0 seulement si toutes à 1. NON-OU ~(A + B) : 1 seulement si toutes à 0.
  • OU exclusif A ^ B : 1 si un nombre impair d’entrées à 1 ; NON-OU exclusif : 1 si A = B.
  • Une bulle = un NON. n entrées → 2n lignes, en comptant en binaire.

Priorités et axiomes

  • Priorités : NON, puis ET, puis OU. Une barre sur un groupe vaut des parenthèses.
  • A.0 = 0 ; A.1 = A ; A.A = A ; A.~A = 0
  • A + 1 = 1 ; A + 0 = A ; A + A = A ; A + ~A = 1 ; ~~A = A

Distributivité, De Morgan, absorption

  • A.(B + C) = A.B + A.C et aussi A + B.C = (A + B).(A + C)
  • De Morgan : ~(A.B) = ~A + ~B ; ~(A + B) = ~A.~B (et pour 3 variables ou plus)
  • Absorption : A + A.B = A ; A + ~A.B = A + B
  • Regroupement : A.B + A.~B = A
  • Dualité : échanger ET et OU, 0 et 1 donne une autre règle vraie.

OU exclusif

  • A ^ B = A.~B + ~A.B ; ~(A ^ B) = A.B + ~A.~B
  • A ^ 0 = A ; A ^ 1 = ~A ; A ^ A = 0 ; A ^ ~A = 1
  • Faire apparaître : factoriser jusqu’à X.~Y + ~X.Y, avec X ou Y produits (~D.B + ~C.B + D.C.~B = B ^ (C.D)).
  • Dans un tableau : des 1 en damier.

Simplifier sans parenthèses

  1. De Morgan sur les grandes barres, de l’extérieur vers l’intérieur.
  2. Développer ; supprimer X.~X ; X.X = X.
  3. Regrouper, absorber, jusqu’à la somme de produits la plus courte.
  4. Contrôler avec un tableau de Karnaugh.

Formes canoniques

  • 1re forme : somme de mintermes, un par ligne à 1 ; variable à 0 → barrée.
  • 2e forme : produit de maxtermes, un par ligne à 0 ; variable à 1 → barrée.
  • Chaque terme contient toutes les variables de l’expression, une fois. Mintermes + maxtermes = 2n.
  • Compléter : X = X.Y + X.~Y (1re) ; X = (X + Y).(X + ~Y) (2e) ; pas de doublon.

  • Ordre de Gray 00, 01, 11, 10 : deux cases voisines ne diffèrent que d’un bit. À 3 variables : une ligne C = 0 (0 1 3 2), une ligne C = 1 (4 5 7 6).

Karnaugh : cercles et Φ

  • Rectangles de 1, 2, 4, 8 cases, les plus grands possible, le moins possible ; les bords opposés se touchent, les 4 coins aussi.
  • Lire : variable qui varie → absente ; toujours 0 → barrée ; toujours 1 → écrite.
  • Φ (indéfinie) : dans un cercle s’il l’agrandit, jamais un cercle de Φ seuls.
  • Une case seule = un minterme.

Portes NON-ET seules

  • NON : ~(A.A) = ~A (1 porte).
  • ET : A.B = ~~(A.B) (2 portes).
  • OU : A + B = ~(~A.~B) (3 portes).
  • OU exclusif : A ^ B = ~(~(A.~B).~(~A.B)) (5 portes ; 4 en partageant ~(A.B)).

Un problème

  1. Nommer entrées et sorties, dans l’ordre du sujet (la première = poids fort).
  2. Table de vérité ligne par ligne ; Φ seulement pour les cas impossibles.
  3. Un tableau de Karnaugh par sortie ; un OU exclusif si demandé.

Circuits du cours

  • Comparateur 1 bit : A > B : A.~B ; A = B : ~(A ^ B) ; A < B : ~A.B.
  • Additionneur 2 bits : S0 = B0 ^ A0, S1 = A1 ^ B1 ^ (A0.B0).
  • Décodeur : une sortie à 1, celle du nombre en entrée. Multiplexeur : recopie l’entrée choisie. Démultiplexeur : envoie D sur la sortie choisie.

Pièges

  • ~(A + B) n’est pas ~A + ~B ; De Morgan change aussi l’opérateur.
  • Résultat avec parenthèses, ou pas le plus court.
  • Maxterme écrit comme un minterme ; 2e forme prise sur les lignes à 1.
  • Karnaugh en ordre binaire ; bords oubliés ; cercle de 3 ou 6 cases ; un Φ seul encerclé.
  • OU exclusif utilisé là où le sujet l’interdit.
  • Φ mis sur une ligne que l’énoncé définit.
