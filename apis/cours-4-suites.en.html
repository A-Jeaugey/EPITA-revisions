Part 1 “Introduction” sheet § 1

Defining a sequence

Definition numerical sequence

A numerical sequence is a function from \(\N\) to \(\mathbb{K}\), where \(\mathbb{K} = \R\) or \(\mathbb{C}\):

\[u : \N \to \mathbb{K},\qquad n \mapsto u(n) = u_n.\]

\(u_n\) is the term of index \(n\). The sequence is written \(u\), \((u_n)\) or \((u_n)_{n \in \N}\). If \(\mathbb{K} = \R\), it is a real sequence; if \(\mathbb{K} = \mathbb{C}\), a complex sequence.

Two ways to define a sequence:

  • explicitly, as a function of \(n\): \(\forall n \in \N,\ u_n = f(n)\). Example: \(u_n = \dfrac{n}{n + 3}\). You compute any term directly: \(u_{100} = \frac{100}{103}\).
  • by recurrence: a first term and a relation that gives each term from the previous one (or ones). Example: \(u_0 = 0\) and \(u_{n+1} = \sqrt{1 + u_n}\). To get \(u_3\), you need \(u_1\) and \(u_2\): \(u_1 = 1\), \(u_2 = \sqrt{2}\), \(u_3 = \sqrt{1 + \sqrt{2}}\).

A sequence may be defined only from some rank on: \(\left(\frac{1}{n}\right)_{n \in \N^*}\) starts at \(n = 1\).

Model answer Moodle model exercise 3: the sequence is well defined

Let \(u_0 = 0\) and \(u_{n+1} = \sqrt{1 + u_n}\). Show that \((u_n)\) is well defined and that \(\forall n \in \N,\ 0 \leq u_n \leq 2\).

By induction, with \(\mathcal{P}_n\): “\(u_n\) is defined and \(0 \leq u_n \leq 2\)”.the statement includes “is defined”

Base case. \(u_0 = 0\): \(\mathcal{P}_0\) is true.

Inductive step. Suppose \(\mathcal{P}_n\) is true for some \(n \in \N\). Then \(1 \leq 1 + u_n \leq 3\), so \(1 + u_n \geq 0\): \(\sqrt{1 + u_n}\) exists, that is, \(u_{n+1}\) is defined. Moreover \(\sqrt{1} \leq u_{n+1} \leq \sqrt{3}\), and since \(0 \leq 1\) and \(\sqrt{3} \leq 2\): \(0 \leq u_{n+1} \leq 2\). \(\mathcal{P}_{n+1}\) is true.

Conclusion. For every \(n \in \N\), \(u_n\) is defined and \(0 \leq u_n \leq 2\).

Traps
  • \((u_n)\) is the sequence, \(u_n\) is a number. “\(u_n\) is increasing” is said of the sequence: \((u_n)\) is increasing.
  • \(u_{n+1}\) (the next term) is not \(u_n + 1\).
  • For an explicit sequence, \(u_{n+1}\) is obtained by replacing every \(n\) with \(n + 1\): if \(u_n = \frac{n}{n + 3}\), then \(u_{n+1} = \frac{n + 1}{n + 4}\).

Sequence bounded above, bounded below, bounded

Definitions with quantifiers
  1. \((u_n)\) is bounded above if \(\exists M \in \R,\ \forall n \in \N,\ u_n \leq M\).
  2. \((u_n)\) is bounded below if \(\exists m \in \R,\ \forall n \in \N,\ m \leq u_n\).
  3. \((u_n)\) is bounded if it is bounded below and bounded above.

The order of the quantifiers matters: \(M\) is chosen before \(n\), it does not depend on \(n\). An upper bound is not unique: if 1 is an upper bound of the sequence, so is 2. The negation, useful for counterexamples: \((u_n)\) is not bounded above if \(\forall M \in \R,\ \exists n \in \N,\ u_n \gt M\).

Proposition bounded sequence
\[(u_n) \text{ bounded} \iff \exists M \in \R,\ \forall n \in \N,\ |u_n| \leq M.\]
Proof the “Proofs to know” sheet

Reminder: for \(M \in \R_+\), \(|a| \leq M \iff -M \leq a \leq M\).

\(\Leftarrow\) Suppose there exists \(M \in \R\) such that \(\forall n \in \N,\ |u_n| \leq M\). Then \(\forall n \in \N,\ -M \leq u_n \leq M\): \((u_n)\) is bounded below by \(-M\) and bounded above by \(M\), hence bounded.

\(\Rightarrow\) Suppose \((u_n)\) is bounded: there exists \((m, K) \in \R^2\) such that \(\forall n \in \N,\ m \leq u_n \leq K\). Now \(K \leq |K|\) and \(-|m| \leq m\), hence \(-|m| \leq u_n \leq |K|\).

Set \(M = \max(|m|, |K|)\). We have \(|K| \leq M\) and \(-M \leq -|m|\), hence \(\forall n \in \N,\ -M \leq u_n \leq M\), that is, \(|u_n| \leq M\).

Method bounding above, bounding below
  1. Compute a few terms to guess an upper bound and a lower bound.
  2. Start from safe inequalities: \(n \geq 0\), \(-1 \leq \cos(n) \leq 1\), \(-1 \leq (-1)^n \leq 1\), \(n \lt n + 3\).
  3. For a quotient of positive terms: bound the numerator above, bound the denominator below.
  4. For a sequence defined by recurrence: proof by induction.
Model answer Moodle model exercise 1

Let \(u_n = \dfrac{n}{n + 3}\) for \(n \in \N\). Upper bound, lower bound? Is the sequence bounded?

Let \(n \in \N\). \(n \geq 0\) and \(n + 3 \gt 0\), so \(u_n \geq 0\): the sequence is bounded below by 0.

Moreover \(n \lt n + 3\) and \(n + 3 \gt 0\), hence \(\dfrac{n}{n + 3} \leq 1\): the sequence is bounded above by 1.we divide by a positive number

Bounded below and above: \((u_n)\) is bounded.

Model exercise 2. \(u_n = \dfrac{n - 4}{7n - 22}\). The denominator never vanishes (\(\frac{22}{7}\) is not an integer). First terms: \(u_0 = \frac{2}{11}\), \(u_1 = \frac{1}{5}\), \(u_2 = \frac{1}{4}\), \(u_3 = 1\), \(u_4 = 0\). For \(n \geq 4\): \(n - 4 \geq 0\) and \(7n - 22 \geq 6\), so \(u_n \geq 0\); and \(7(n - 4) = 7n - 28 \lt 7n - 22\), so \(u_n \leq \frac{1}{7}\). With the first four terms: the sequence is bounded below by 0 and above by 1, hence bounded. You handle the first terms separately, then “from rank 4 on”.

Traps
  • Writing “\(\forall n,\ \exists M,\ u_n \leq M\)”: it is true for every sequence (take \(M = u_n\)). The upper bound comes first.
  • “Bounded above by 3” does not mean that 3 is reached, nor that the limit is 3.
  • \((-1)^n n\) is neither bounded above nor bounded below; \((-1)^n\) is bounded: \(|(-1)^n| \leq 1\).

Monotonicity

Definitions
  • \((u_n)\) is increasing if \(\forall n \in \N,\ u_{n+1} \geq u_n\); decreasing if \(\forall n \in \N,\ u_{n+1} \leq u_n\).
  • \((u_n)\) is strictly increasing if \(\forall n \in \N,\ u_{n+1} \gt u_n\); strictly decreasing if \(\forall n \in \N,\ u_{n+1} \lt u_n\).
  • \((u_n)\) is monotonic if it is increasing or decreasing (strictly monotonic: strictly increasing or strictly decreasing).
  • \((u_n)\) is constant if \(\exists C \in \R,\ \forall n \in \N,\ u_n = C\).
  • \((u_n)\) is stationary if it is constant from some rank on: \(\exists N \in \N,\ \forall n \geq N,\ u_n = u_N\).

Compare \(\dfrac{u_{n+1}}{u_n}\) with 1only if \(u_n \gt 0\); products, powers, factorials\(\geq 1\) for every \(n\): increasing
Variations of \(f\)explicit \(u_n = f(n)\)\(f\) increasing on \([0, +\infty[\): \((u_n)\) increasing

Model answer model exercise 1: \(u_n = \frac{n}{n+3}\)

Let \(n \in \N\). \(u_{n+1} - u_n = \dfrac{n + 1}{n + 4} - \dfrac{n}{n + 3} = \dfrac{(n + 1)(n + 3) - n(n + 4)}{(n + 4)(n + 3)} = \dfrac{3}{(n + 4)(n + 3)}\).same denominator, we expand

For every \(n \in \N\), \(u_{n+1} - u_n \gt 0\): the sequence is strictly increasing.

Model answer model exercise 3: increasing, by induction

\(u_0 = 0\), \(u_{n+1} = \sqrt{1 + u_n}\). Let \(\mathcal{P}_n\): “\(u_n \lt u_{n+1}\)”.

Base case. \(u_1 = 1 \gt 0 = u_0\): \(\mathcal{P}_0\) is true.

Inductive step. Suppose \(u_n \lt u_{n+1}\). Then \(1 + u_n \lt 1 + u_{n+1}\), and since the square root is strictly increasing, \(\sqrt{1 + u_n} \lt \sqrt{1 + u_{n+1}}\), that is, \(u_{n+1} \lt u_{n+2}\).we apply an increasing function

Conclusion. The sequence is strictly increasing.

Monotonic from some rank on. In model exercise 2, \(u_n = \frac{n - 4}{7n - 22}\): for \(n \geq 5\), \(u_n \gt 0\) and \(\dfrac{u_{n+1}}{u_n} = \dfrac{7n^2 - 43n + 66}{7n^2 - 43n + 60} \gt 1\), so the sequence is strictly increasing from rank 5 on. But \(u_3 = 1 \gt u_4 = 0\): it is not increasing on \(\N\), hence not monotonic.

Traps
  • The quotient can be compared with 1 only if the terms are strictly positive. With \(u_n = -\frac{1}{n}\), the quotient is less than 1 and the sequence is increasing.
  • A constant sequence is both increasing and decreasing (in the weak sense).
  • A sequence can be neither increasing nor decreasing: \(((-1)^n)\).
  • Two or three terms do not prove monotonicity; a single counterexample is enough to refute it.

Limit of a sequence: finite, infinite, or no limit

Definition finite limit

Let \((u_n)\) be a real sequence. We say that \((u_n)\) converges to \(\ell \in \R\) if

\[\forall \varepsilon \gt 0,\ \exists n_\varepsilon \in \N,\ \forall n \in \N,\ \left(n \geq n_\varepsilon \Rightarrow |u_n - \ell| \lt \varepsilon\right).\]

We write \(u_n \to \ell\) or \(\displaystyle\lim_{n \to +\infty} u_n = \ell\).

\(|u_n - \ell| \lt \varepsilon\) is equivalent to \(\ell - \varepsilon \lt u_n \lt \ell + \varepsilon\), that is, \(u_n \in\ ]\ell - \varepsilon, \ell + \varepsilon[\). The definition says: for every band around \(\ell\), however narrow, there is a rank from which all the terms are in the band. The rank depends on \(\varepsilon\).

Figure 2 — Reduce \(\varepsilon\): the rank moves back, but it always exists. For \((-1)^n\), no narrow band works.

Model answer model exercise 1: \(u_n = \frac{1}{n^2}\) converges, by the definition

Let us show that \((u_n)_{n \in \N^*}\) converges to 0. Let \(\varepsilon \gt 0\).ε is fixed, arbitrary

\(|u_n - 0| = \dfrac{1}{n^2}\), and \(\dfrac{1}{n^2} \leq \varepsilon \iff n^2 \geq \dfrac{1}{\varepsilon} \iff n \geq \dfrac{1}{\sqrt{\varepsilon}}\).we look for the n from which it holds

Let \(N\) be an integer greater than \(\dfrac{1}{\sqrt{\varepsilon}}\), for example \(N = E\left(\dfrac{1}{\sqrt{\varepsilon}}\right) + 1\). Then \(n \geq N \Rightarrow |u_n - 0| \leq \varepsilon\).E: integer part

So \((u_n)\) converges to 0.

Propositions convergent sequence
  • Uniqueness. The limit of a convergent real sequence is unique.
  • \(\displaystyle\lim_{n \to +\infty} u_n = \ell \iff \lim_{n \to +\infty} (u_n - \ell) = 0\).
  • If \(\ell \neq 0\), then \(\exists n_0 \in \N,\ \forall n \geq n_0,\ u_n \neq 0\).
  • If \(\forall n \in \N,\ u_n \gt 0\), then \(\ell \geq 0\): the strict inequality becomes weak in the limit.
  • If \(u_n \to \ell\), then \(|u_n| \to |\ell|\). And \(u_n \to 0 \iff |u_n| \to 0\).
Definitions divergent sequence, infinite limit

A sequence is divergent if it does not converge.

\((u_n)\) tends to \(+\infty\) if \(\forall A \in \R,\ \exists n_0 \in \N,\ \forall n \in \N,\ \left(n \geq n_0 \Rightarrow u_n \gt A\right)\).

\((u_n)\) tends to \(-\infty\) if \(\forall A \in \R,\ \exists n_0 \in \N,\ \forall n \in \N,\ \left(n \geq n_0 \Rightarrow u_n \lt A\right)\).

BehaviourVocabularyExample
finite limit \(\ell\)convergent\(1 + \frac{1}{n} \to 1\)
limit \(+\infty\) or \(-\infty\)divergent (it has a limit, an infinite one)\(n^2 \to +\infty\), \(\ln(n^2 + n) \to +\infty\)

Traps
  • “Divergent” does not mean “tends to infinity”: \(((-1)^n)\) diverges while staying bounded.
  • In the definition, \(\varepsilon\) comes before the rank. “\(\exists N,\ \forall \varepsilon \gt 0\)” describes a stationary sequence.
  • \(\frac{1}{n} \gt 0\) for every \(n\), and yet the limit is 0: you only keep \(\ell \geq 0\).
  • A sequence that tends to \(+\infty\) is not necessarily increasing (part 8).

Operations on limits, indeterminate forms

Proposition finite limits

Let \((u_n)\) and \((v_n)\) be convergent, with limits \(\ell\) and \(\ell'\), and \(\lambda \in \R\). Then:

  1. \((\lambda u_n + v_n)\) converges to \(\lambda\ell + \ell'\);
  2. \((u_n v_n)\) converges to \(\ell\ell'\);
  3. if \(\forall n \in \N,\ v_n \neq 0\) and \(\ell' \neq 0\), then \(\left(\dfrac{1}{v_n}\right)\) converges to \(\dfrac{1}{\ell'}\).

The four indeterminate forms
\[\infty - \infty,\qquad 0 \times \infty,\qquad \frac{\infty}{\infty},\qquad \frac{0}{0}.\]

“Indeterminate” does not mean “no limit”: you must transform the expression before concluding.

Method resolving an indeterminate form
  1. Factor out the dominant term in the numerator and the denominator, then simplify.
  2. Comparative growth: \(\displaystyle\lim_{n \to +\infty} \frac{\ln(n)}{n} = 0\), \(\displaystyle\lim_{n \to +\infty} \frac{n^2}{e^n} = 0\), \(\displaystyle\lim_{n \to +\infty} \frac{e^n}{n} = +\infty\). The exponential beats the powers, which beat the logarithm.
  3. Conjugate expression for a difference of roots: \(\sqrt{n + 1} - \sqrt{n} = \dfrac{1}{\sqrt{n + 1} + \sqrt{n}} \to 0\).
  4. Otherwise: bounding and the squeeze theorem (part 6).
Model answer Moodle model exercise 2

Limit of \(u_n = \dfrac{2 + n - n^2}{n^2 + 3n + 4}\)?

\(u_n = \dfrac{n^2\left(\frac{2}{n^2} + \frac{1}{n} - 1\right)}{n^2\left(1 + \frac{3}{n} + \frac{4}{n^2}\right)} = \dfrac{\frac{2}{n^2} + \frac{1}{n} - 1}{1 + \frac{3}{n} + \frac{4}{n^2}}\).we factor out n², the dominant term

Now \(\displaystyle\lim_{n \to +\infty} \left(\frac{2}{n^2} + \frac{1}{n} - 1\right) = -1\) and \(\displaystyle\lim_{n \to +\infty} \left(1 + \frac{3}{n} + \frac{4}{n^2}\right) = 1\). By the quotient rule, \(\displaystyle\lim_{n \to +\infty} u_n = -1\).

Model answer Moodle model exercise 3

Limit of \(u_n = \dfrac{e^n - n^2}{n + \ln(n)}\)?

\(u_n = \dfrac{e^n\left(1 - \frac{n^2}{e^n}\right)}{n\left(1 + \frac{\ln(n)}{n}\right)} = \dfrac{e^n}{n} \times \dfrac{1 - \frac{n^2}{e^n}}{1 + \frac{\ln(n)}{n}}\).eⁿ dominates on top, n on the bottom

By comparative growth, \(\dfrac{n^2}{e^n} \to 0\), \(\dfrac{\ln(n)}{n} \to 0\) and \(\dfrac{e^n}{n} \to +\infty\). So \(\displaystyle\lim_{n \to +\infty} u_n = +\infty\).

Shortcut to know. A quotient of polynomials in \(n\) has the limit of the quotient of their highest-degree terms: \(\dfrac{3n^2 + 1}{2n^2 - n} \to \dfrac{3}{2}\), \(\dfrac{n + 1}{n^2} \to 0\), \(\dfrac{n^3}{n^2 + 1} \to +\infty\). In your answer, write the factorisation.

Traps
  • “\(\infty - \infty = 0\)” and “\(0 \times \infty = 0\)” are false: \(n^2 - n \to +\infty\), \(\frac{1}{n} \times n^2 \to +\infty\), \(\frac{1}{n} \times n \to 1\).
  • The operations assume that both limits exist: \((-1)^n + (-1)^{n+1} = 0\) converges although neither of the two terms has a limit.
  • \(\ln(n^2 + n) \to +\infty\): the sequence diverges, even though it grows slowly.

Comparison, squeeze theorem, convergent hence bounded

Theorem comparison

Let \((u_n)\) and \((v_n)\) be such that \(\forall n \in \N,\ u_n \leq v_n\).

  1. If \(\lim u_n = +\infty\), then \(\lim v_n = +\infty\).
  2. If \(\lim v_n = -\infty\), then \(\lim u_n = -\infty\).
Theorem squeeze theorem

Let \((u_n)\), \((v_n)\) and \((w_n)\) be three real sequences such that:

  1. from some rank on, \(u_n \leq v_n \leq w_n\);
  2. \((u_n)\) and \((w_n)\) converge to the same limit \(\ell \in \R\).

Then \((v_n)\) converges to \(\ell\).

Proof the “Proofs to know” sheet; January 2024 exam, 5 points

Let \(\varepsilon \gt 0\) be fixed.

\((u_n)\) converges to \(\ell\): \(\exists N_1 \in \N,\ \forall n \geq N_1,\ \ell - \varepsilon \lt u_n \lt \ell + \varepsilon\).

\((w_n)\) converges to \(\ell\): \(\exists N_2 \in \N,\ \forall n \geq N_2,\ \ell - \varepsilon \lt w_n \lt \ell + \varepsilon\).

Set \(N = \max(N_1, N_2)\) and let \(n \geq N\). Then \(n \geq N_1\) and \(n \geq N_2\), so \(\ell - \varepsilon \lt u_n \leq v_n \leq w_n \lt \ell + \varepsilon\).

We have shown: \(\forall \varepsilon \gt 0\), there is a rank \(N\) from which \(|v_n - \ell| \lt \varepsilon\). So \((v_n)\) converges to \(\ell\).

Model answer Moodle model exercise 4

Limit of \(u_n = \dfrac{2n + (-1)^n}{n^2 + \cos(n)}\)?

\((-1)^n = \pm 1\), so \(2n - 1 \leq 2n + (-1)^n \leq 2n + 1\). And \(\cos(n) \in [-1, 1]\), so \(n^2 - 1 \leq n^2 + \cos(n) \leq n^2 + 1\).

For \(n \geq 2\), everything is strictly positive: \(\dfrac{2n - 1}{n^2 + 1} \leq u_n \leq \dfrac{2n + 1}{n^2 - 1}\).small numerator over large denominator, and the reverse

Now \(\dfrac{2n - 1}{n^2 + 1} = \dfrac{2 - \frac{1}{n}}{n + \frac{1}{n}} \to 0\) and \(\dfrac{2n + 1}{n^2 - 1} \to 0\). By the squeeze theorem, \(\displaystyle\lim_{n \to +\infty} u_n = 0\).

Practical consequence. If \((u_n)\) is bounded and \(v_n \to 0\), then \(u_n v_n \to 0\): \(|u_n v_n| \leq M|v_n|\). Examples: \(\dfrac{\sin(n)}{n} \to 0\), \(\dfrac{(-1)^n}{n} \to 0\).

Comparison towards infinity (model exercise 5). \(u_n = \sqrt{n}\) if \(n\) is even, \(n^2\) if \(n\) is odd. In both cases \(u_n \geq \sqrt{n}\), and \(\sqrt{n} \to +\infty\): by comparison, \(u_n \to +\infty\). The sequence is nevertheless not monotonic: for \(n\) odd, \(n \geq 3\), \(u_n = n^2 \gt \sqrt{n + 1} = u_{n+1}\).

Tutorial 4, exercise 3.6. \(u_n = \displaystyle\sum_{k=1}^{n} \frac{1}{n^2 + k}\): each term is between \(\frac{1}{n^2 + n}\) and \(\frac{1}{n^2 + 1}\), and there are \(n\) of them, so \(\dfrac{n}{n^2 + n} \leq u_n \leq \dfrac{n}{n^2 + 1}\). The two bounding sequences tend to 0: \(u_n \to 0\). Likewise \(\dfrac{n^2}{n^2 + n} \leq n\,u_n \leq \dfrac{n^2}{n^2 + 1}\): \(n\,u_n \to 1\).

Proposition property of a convergent sequence
\[(u_n) \text{ converges} \implies (u_n) \text{ bounded}.\]
Proof the “Proofs to know” sheet

Suppose that \((u_n)\) converges and denote its limit by \(\ell \in \R\): \(\forall \varepsilon \gt 0,\ \exists N \in \N,\ \forall n \geq N,\ |u_n - \ell| \lt \varepsilon\).

This is true for every \(\varepsilon \gt 0\), so for \(\varepsilon = 1\): there is a rank \(N\) from which \(|u_n - \ell| \lt 1\). For \(n \geq N\), by the triangle inequality:

\[|u_n| = |(u_n - \ell) + \ell| \leq |u_n - \ell| + |\ell| \lt 1 + |\ell|.\]

The sequence is bounded from rank \(N\) on. Set \(M = \max\left(|u_0|, |u_1|, \ldots, |u_{N-1}|, 1 + |\ell|\right)\). Alors \(\forall n \in \N,\ |u_n| \leq M\): \((u_n)\) is bounded.

The converse is false: \(((-1)^n)\) is bounded and does not converge. The contrapositive, true and useful: an unbounded sequence does not converge. The January 2025 exam asked for all four: the definition of “bounded”, the proof, the converse (with a counterexample) and the contrapositive.

In the course test and the exam

The “Proofs to know” sheet is a separate Moodle module, which is not named in the course test syllabus. Its first three proofs (bounded \(\iff |u_n| \leq M\), convergent \(\Rightarrow\) bounded, squeeze theorem) are nevertheless about the modules on the syllabus, and a course test may ask for a proof (IBP in October 2022). Learn them now: they are required for the final exam anyway.

Traps
  • Squeeze theorem: the two bounding sequences must have the same limit. \(-1 \leq (-1)^n \leq 1\) gives nothing.
  • Dividing an inequality: by a positive number, and taking the inverse reverses the inequalities.
  • Passing to the limit in an inequality without knowing that the limit exists.

Geometric and arithmetic-geometric sequences

Definition geometric sequence

\((u_n)\) is geometric if there is a real number \(q\) such that \(\forall n \in \N,\ u_{n+1} = q\,u_n\). The number \(q\) is the common ratio.

Theorems general term, sum

Let \((u_n)\) be geometric with first term \(u_0\) and common ratio \(q\).

\[\forall n \in \N,\ u_n = u_0\,q^n \qquad\text{and, for } n \geq n_0,\quad u_n = u_{n_0}\,q^{n - n_0}.\]
\[u_0 + u_1 + \cdots + u_n = \begin{cases} u_0 \times \dfrac{1 - q^{n+1}}{1 - q} & \text{if } q \neq 1,\\[2mm] (n + 1)\,u_0 & \text{if } q = 1. \end{cases}\]

From rank \(n_0\) on: \(u_{n_0} + \cdots + u_n = u_{n_0}\dfrac{1 - q^{n - n_0 + 1}}{1 - q}\) for \(q \neq 1\). To remember: first term \(\times \dfrac{1 - q^{\text{number of terms}}}{1 - q}\).

Common ratio \(q\)\(\displaystyle\lim_{n \to +\infty} q^n\)\((q^n)\)

\(q = 1\)\(1\)converges (constant)

 So \((q^n)\) converges if and only if \(-1 \lt q \leq 1\): this is the “necessary and sufficient condition” asked for in the December 2022 course test.

Sign (Tutorial 4, ex. 2.3). If \(q \gt 0\), all the terms have the sign of \(u_0\). If \(q \lt 0\), the terms change sign at every rank. If \(q = 0\), the sequence is zero from rank 1 on.

Reminder: arithmetic sequence. \(u_{n+1} = u_n + r\), so \(u_n = u_0 + nr\) and \(u_0 + \cdots + u_n = (n + 1)\dfrac{u_0 + u_n}{2}\). It diverges, unless \(r = 0\).

Method arithmetic-geometric sequence \(u_{n+1} = a\,u_n + b\), \(a \neq 1\)
  1. Fixed point: solve \(\ell = a\ell + b\). It is the value of \(u_0\) for which the sequence is constant.
  2. Set \(v_n = u_n - \ell\) and show that \((v_n)\) is geometric with common ratio \(a\): \(v_{n+1} = u_{n+1} - \ell = a\,u_n + b - (a\ell + b) = a(u_n - \ell) = a\,v_n\).
  3. Write \(v_n = v_0\,a^n\), then \(u_n = \ell + (u_0 - \ell)\,a^n\).
  4. Conclude: if \(|a| \lt 1\), \(u_n \to \ell\).

\(u_0 \in \R\) and \(\forall n \in \N,\ u_{n+1} = \dfrac{u_n + 4}{5}\).

Traps
  • Sum: the exponent is the number of terms, \(n + 1\) from \(u_0\) to \(u_n\), not \(n\).
  • \(q = 1\): the sum formula does not apply (division by 0), the sum is \((n + 1)u_0\).
  • \(q = -1\): \(((-1)^n)\) has no limit. \(q = 1\): the sequence converges. Do not write “converges \(\iff |q| \lt 1\)”.
  • The limit of \(q^n\) is not that of \(u_0 q^n\) when \(u_0 \lt 0\) and \(q \gt 1\): \(-2^n \to -\infty\).

Ratio criterion, examples and counterexamples

Theorem sequences such that \(\left|\frac{u_{n+1}}{u_n}\right| \lt \ell \lt 1\)

Let \((u_n)\) be a sequence of nonzero reals. Assume there is a real number \(\ell\) such that, for every \(n\) (or only from some rank on):

\[\left|\frac{u_{n+1}}{u_n}\right| \lt \ell \lt 1.\]

Then \(\displaystyle\lim_{n \to +\infty} u_n = 0\).

Corollary. If \(\displaystyle\lim_{n \to +\infty} \frac{u_{n+1}}{u_n} = 0\), then \(\displaystyle\lim_{n \to +\infty} u_n = 0\).

The idea: \(|u_n|\) is then smaller than a geometric sequence with common ratio \(\ell \lt 1\), which tends to 0. The real number \(\ell\) is fixed, strictly between the quotient and 1: “the quotient is less than 1” is not enough. With \(u_n = 1 + \frac{1}{n}\), the quotient is always less than 1 and the sequence tends to 1, not to 0.

Why a sequence that is neither bounded above nor bounded below has no limit (Tutorial 4, ex. 1.2). If it converged, it would be bounded. If it tended to \(+\infty\), it would be greater than 0 from some rank \(n_0\) on, hence bounded below by the smallest of the numbers \(u_0, \ldots, u_{n_0 - 1}, 0\). Likewise, if it tended to \(-\infty\), it would be bounded above.

In the course test

The two course tests on sequences that we found (December 2022 and November 2023) ask only this type of question: a definition with quantifiers, then “give an example of a sequence…”. A sequence given without justification is accepted when it is correct, but a line of checking protects you.
