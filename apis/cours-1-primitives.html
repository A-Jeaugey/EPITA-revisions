Trouver une primitive, c’est dériver à l’envers.

Une primitive de \(f\) est une fonction dont la dérivée est \(f\). Deux tableaux suffisent : celui des fonctions usuelles, et celui des fonctions composées \(u' \times g(u)\). Tout le travail consiste à reconnaître la bonne ligne et à ajuster une constante. Ce cours est la base des intégrales (cours 2) et de tout le reste de l’ECUE.

Partie 1 polycopié § 1.1 · fiche § 1

Primitive d’une fonction : définition, existence, constante

Définition primitive

Soit \(f\) une fonction continue sur un intervalle \(I\) de \(\R\). Une primitive de \(f\) sur \(I\) est une fonction \(F\) dérivable sur \(I\) telle que \(F' = f\), c’est-à-dire :

\[\forall x \in I,\quad F'(x) = f(x).\]

On note souvent \(F(x) = \displaystyle\int f(x)\,dx\).

Exemples. Une primitive de \(x \mapsto \frac{1}{x}\) sur \(]0, +\infty[\) est \(x \mapsto \ln(x)\). Une primitive de \(x \mapsto x\) sur \(\R\) est \(x \mapsto \frac{x^2}{2}\). Pour vérifier une primitive, on la dérive : c’est le contrôle à faire à chaque fois.

Théorème existence, et toutes les primitives

Soit \(I\) un intervalle de \(\R\).

  1. Toute fonction continue sur \(I\) admet une primitive sur \(I\).
  2. Si \(F\) est une primitive de \(f\) sur \(I\), alors les primitives de \(f\) sur \(I\) sont exactement les fonctions \(F + c\), où \(c\) est une constante réelle.
Pourquoi

\((F + c)' = F' = f\) : ajouter une constante donne encore une primitive. Dans l’autre sens, si \(G\) est une autre primitive, \((G - F)' = f - f = 0\) sur l’intervalle \(I\), donc \(G - F\) est constante.

Une fonction continue a donc une infinité de primitives, qui diffèrent d’une constante : \(x \mapsto 2x\) et \(x \mapsto 2x + \pi\) sont deux primitives de \(x \mapsto 2\). On dit « une primitive », jamais « la primitive », sauf si une condition fixe la constante.

Rédaction modèle la primitive qui vaut 3 en 4 (polycopié)

Déterminer la primitive \(F\) de \(x \mapsto \frac{1}{\sqrt{x}}\) sur \(]0, +\infty[\) telle que \(F(4) = 3\).

Les primitives de \(x \mapsto \frac{1}{\sqrt{x}}\) sur \(]0, +\infty[\) sont les fonctions \(F(x) = 2\sqrt{x} + c\), \(c \in \R\).la forme générale d’abord

\(F(4) = 3 \iff 2\sqrt{4} + c = 3 \iff c = -1\).la condition fixe c

Donc \(F(x) = 2\sqrt{x} - 1\).

Pièges
  • Confondre primitive et dérivée : la primitive de \(x^2\) est \(\frac{x^3}{3}\), pas \(2x\). En cas de doute, dérive ta réponse.
  • Sur un ensemble qui n’est pas un intervalle (comme \(\R^*\)), deux primitives peuvent différer d’une constante différente sur chaque morceau. On travaille toujours sur un intervalle.

Méthode les puissances : une seule formule
  1. Écris la fonction sous la forme \(x^\alpha\) : \(\sqrt{x} = x^{1/2}\), \(\frac{1}{x^3} = x^{-3}\), \(x\sqrt{x} = x^{3/2}\).
  2. Ajoute 1 à l’exposant, divise par le nouvel exposant : \(\frac{x^{\alpha+1}}{\alpha+1}\).
  3. Si \(\alpha = -1\), la formule ne marche pas (division par 0) : c’est \(\ln|x|\).

Applications du TD 3 (exercice 1.2). Sur \(\R_+\) : \(x\sqrt{x} = x^{3/2}\) a pour primitive \(\frac{x^{5/2}}{5/2} = \frac{2}{5}x^{5/2}\). Sur \(\R\) : \(-3\sin(x) + 2e^x\) a pour primitive \(3\cos(x) + 2e^x\).

D’où viennent tan et arctan

TD 3, exercice 1.1 : \(\tan = \frac{\sin}{\cos}\), donc \(\tan' = \frac{\cos^2 + \sin^2}{\cos^2} = \frac{1}{\cos^2} = 1 + \tan^2\). Pour arctan : si \(y = \tan(x)\), alors \(\arctan(y) = x\) ; en dérivant \(\arctan(\tan(x)) = x\), on obtient \(\arctan'(\tan x) \times (1 + \tan^2 x) = 1\), d’où \(\arctan'(y) = \frac{1}{1 + y^2}\).

Pièges
  • Le signe : une primitive de \(\sin\) est \(-\cos\) ; une primitive de \(\cos\) est \(+\sin\).
  • \(\frac{1}{x^2}\) n’a pas pour primitive \(\ln(x^2)\) : le logarithme, c’est seulement pour l’exposant \(-1\).
  • Diviser par l’ancien exposant : \(\frac{x^{\alpha+1}}{\alpha}\) est faux.

Sommes et multiplications par un réel

Théorème linéarité

Soient \(f\) et \(g\) continues sur un intervalle \(I\), \(F\) une primitive de \(f\) et \(G\) une primitive de \(g\) sur \(I\). Pour tout \((\alpha, \beta) \in \R^2\), une primitive de \(\alpha f + \beta g\) sur \(I\) est \(\alpha F + \beta G\).

Démonstration

\((\alpha F + \beta G)' = \alpha F' + \beta G' = \alpha f + \beta g\).

Exemples du polycopié. Sur \(\R\), une primitive de \(x + 3x^2 + 6x^5\) est \(\frac{x^2}{2} + 3 \times \frac{x^3}{3} + 6 \times \frac{x^6}{6} = \frac{x^2}{2} + x^3 + x^6\). Une primitive de \(\cos(x) + 6e^x\) est \(\sin(x) + 6e^x\). Sur \(\left]-\frac{\pi}{2}, \frac{\pi}{2}\right[\), une primitive de \(\frac{3}{\cos^2(x)} + 2\) est \(3\tan(x) + 2x\) (le polycopié ajoute la constante 42 : n’importe laquelle convient).

TD 3. Sur \(]0, +\infty[\), \(g(x) = \frac{3}{x} - 5x + 6x^4\) a pour primitive \(3\ln(x) - \frac{5}{2}x^2 + \frac{6}{5}x^5\).

Piège : le produit
  • La linéarité ne dit rien du produit : une primitive de \(f \times g\) n’est pas \(F \times G\), car \((FG)' = fG + Fg\).
  • Pour un produit, deux pistes seulement : reconnaître une forme \(u' \times g(u)\) (partie 4), ou intégrer par parties (cours 3).

Primitives des fonctions composées : la forme \(u' \times g(u)\)

La dérivée d’une composée est \((G \circ u)' = u' \times (G' \circ u)\). Lue à l’envers : si \(G\) est une primitive de \(g\), alors \(G \circ u\) est une primitive de \(u' \times (g \circ u)\). Chaque ligne du tableau 1 donne ainsi une ligne « composée ». C’est l’objectif « calculer une primitive en utilisant les fonctions de la forme \((v' \circ u) \times u'\) ».

Exemples du polycopié. Une primitive de \(e^{2x}\) sur \(\R\) est \(\frac{e^{2x}}{2}\) ; une primitive de \(\cos(3x)\) est \(\frac{\sin(3x)}{3}\) ; une primitive de \(\frac{2x}{x^2 + 1}\) est \(\ln(x^2 + 1)\).

Cas à savoir par réflexe (TD 3, question 3a) : pour \(a \neq 0\), une primitive de \(\sin(ax + b)\) est \(-\frac{1}{a}\cos(ax + b)\), une primitive de \(\cos(ax + b)\) est \(\frac{1}{a}\sin(ax + b)\), une primitive de \(e^{ax + b}\) est \(\frac{1}{a}e^{ax + b}\). Ainsi \(\sin(2x) \to -\frac{\cos(2x)}{2}\), \(\cos\left(\frac{x}{2}\right) \to 2\sin\left(\frac{x}{2}\right)\), \(e^{6x - 7} \to \frac{e^{6x-7}}{6}\).

Pièges
  • On divise par \(a\) quand on cherche une primitive de \(e^{ax}\) ; on multiplie quand on dérive. Diviser par \(\frac{1}{2}\), c’est multiplier par 2 : \(\cos\left(\frac{x}{2}\right) \to 2\sin\left(\frac{x}{2}\right)\).
  • \(\frac{u'}{\sqrt{u}}\) a pour primitive \(2\sqrt{u}\), pas \(\sqrt{u}\) : la ligne du tableau a un 2 au dénominateur.
  • Le \(u'\) doit être présent en facteur. Sans lui, la ligne ne s’applique pas : \(\frac{1}{x^2 + 1}\) n’a pas pour primitive \(\ln(x^2 + 1)\), mais \(\arctan(x)\).

Reconnaître la forme et ajuster la constante

Méthode « sans intégration par parties ni changement de variable »
  1. Repère \(u\) : ce qui est « à l’intérieur » (sous la racine, au dénominateur, dans l’exposant, dans le cosinus).
  2. Calcule \(u'\) et compare-le au facteur restant. S’il est là à une constante près, c’est gagné.
  3. Fais apparaître \(u'\) exactement, en compensant devant : \(x = \frac{1}{2} \times 2x\).
  4. Lis la ligne du tableau 2, puis vérifie en dérivant.
Rédaction modèle exercices types du Moodle, exercice 2

1. \(f(x) = \dfrac{2x - 1}{\sqrt{x^2 - x + 1}}\). Soit \(u(x) = x^2 - x + 1\) ; \(u'(x) = 2x - 1\), donc \(f = \dfrac{u'}{\sqrt{u}}\).on nomme u, on écrit la forme Une primitive de \(f\) sur \(\R\) est \(F(x) = 2\sqrt{u(x)} = 2\sqrt{x^2 - x + 1}\).

\(e^{2x}\) oui, \(e^{x^2}\) non

Le TD 3 pose la question : « savez-vous calculer une primitive de \(x \mapsto e^{2x}\) ? de \(x \mapsto e^{x^2}\) ? ». Pour \(e^{2x}\), \(u' = 2\) est une constante : on compense, \(\frac{e^{2x}}{2}\). Pour \(e^{x^2}\), il faudrait le facteur \(u' = 2x\), qui n’est pas une constante : on ne peut pas le fabriquer. Cette fonction a des primitives (elle est continue), mais aucune ne s’écrit avec les fonctions usuelles. En revanche \(x\,e^{x^2}\) se traite : \(\frac{1}{2}e^{x^2}\).

Aux contrôles et aux examens

La première question d’intégrales est presque toujours une primitive de ce type, avec la consigne « sans intégration par parties ni changement de variable » :

  • Contrôle de cours d’octobre 2022 : \(\displaystyle\int_0^1 x\sqrt{x^2 + 1}\,dx\) (\(u = x^2 + 1\), forme \(\frac{1}{2}u'u^{1/2}\)).
  • Contrôle de novembre 2022 : \(\displaystyle\int_0^1 \frac{2x^3 + 1}{(x^4 + 2x + 1)^3}\,dx\) (\(u = x^4 + 2x + 1\), forme \(\frac{1}{2}\cdot\frac{u'}{u^3}\)).
  • Contrôle de novembre 2021 : \(\displaystyle\int_0^1 (x^2 + 1)\sqrt{x^3 + 3x + 1}\,dx\) (\(u = x^3 + 3x + 1\), forme \(\frac{1}{3}u'u^{1/2}\)).
  • Examen d’octobre 2024 : \(\displaystyle\int_0^1 \frac{2x + 2}{2x^2 + 4x + 1}\,dx\) (forme \(\frac{1}{2}\cdot\frac{u'}{u}\)). Janvier 2023 : \(\displaystyle\int_1^2 (x - 1)\sqrt{x - 1}\,dx\) (puissance \(\frac{3}{2}\)).

Les calculs complets sont dans l’entraînement ; le passage de la primitive à l’intégrale est au cours 2, partie 5.
