Proving that a sequence converges without knowing its limit.

Until now, a limit was something you computed. The theorems in this lesson guarantee that a limit exists without giving it: an increasing sequence that is bounded above converges, and two adjacent sequences have the same limit. Subsequences are mostly used the other way round: two subsequences with different limits, and the sequence diverges.

Monotonic sequences: the monotone convergence theorem

Proposition convergent or monotonic sequences
  1. Every convergent sequence is bounded.
  2. Every sequence that is increasing and bounded above is convergent.
  3. Every sequence that is decreasing and bounded below is convergent.
  4. Every increasing sequence that is not bounded above tends to \(+\infty\).
  5. Every decreasing sequence that is not bounded below tends to \(-\infty\).

A monotonic sequence therefore always has a limit, finite or infinite: the only question is whether it is bounded on the right side.

  • The theorem says the limit exists. It does not say what it equals.
  • If \((u_n)\) is increasing and bounded above by \(M\), its limit \(\ell\) satisfies \(\ell \leq M\): an upper bound is not the limit. Moreover \(u_n \leq \ell\) for every \(n\).
  • “Increasing and bounded below” gives nothing: \((n)\) is increasing, bounded below by 0, and diverges.
Method showing that a sequence converges by monotonicity
  1. Monotonicity: sign of \(u_{n+1} - u_n\), or induction (lesson 4, part 3).
  2. Bound on the right side: bounded above if increasing, bounded below if decreasing. Often by induction.
  3. Conclude by quoting the theorem: “the sequence is increasing and bounded above, hence it converges”.
  4. If the limit is asked for: pass to the limit in the recurrence relation (lesson 6), then rule out the impossible values using the bounds.
Model answer Moodle model exercise

Show that the sequence defined by \(u_0 = 0\) and \(\forall n \in \N,\ u_{n+1} = \dfrac{1 + u_n^2}{3}\) converges.

\(u_1 = \frac{1}{3}\), \(u_2 = \frac{10}{27}\). All the terms are defined and positive.

Increasing, by induction on “\(u_n \lt u_{n+1}\)”. \(u_0 \lt u_1\). If \(u_n \lt u_{n+1}\), since the terms are positive, \(u_n^2 \lt u_{n+1}^2\), hence \(\dfrac{1 + u_n^2}{3} \lt \dfrac{1 + u_{n+1}^2}{3}\), that is, \(u_{n+1} \lt u_{n+2}\).squaring is increasing on the positives

Bounded above by 1, by induction. \(u_0 \leq 1\). If \(u_n \leq 1\), then \(u_n^2 \leq 1\) and \(u_{n+1} \leq \frac{2}{3} \leq 1\).

The sequence is increasing and bounded above: it converges.we quote the theorem

Going all the way. The limit \(\ell\) satisfies \(\ell = \dfrac{1 + \ell^2}{3}\), that is, \(\ell^2 - 3\ell + 1 = 0\): \(\ell = \dfrac{3 \pm \sqrt{5}}{2}\). Since \(\ell \leq 1\), \(\ell = \dfrac{3 - \sqrt{5}}{2} \approx 0.38\).

Tutorial 4, exercise 3.5. \(u_n = \displaystyle\sum_{k=0}^{n} \frac{1}{k!}\). Increasing: \(u_{n+1} - u_n = \frac{1}{(n+1)!} \gt 0\). By induction, \(k! \geq 2^{k-1}\) for \(k \geq 1\) (since \((k+1)! = (k+1)\,k! \geq 2 \times 2^{k-1}\)). Hence \(u_n \leq 1 + \displaystyle\sum_{k=1}^{n} \frac{1}{2^{k-1}} = 1 + 2\left(1 - \frac{1}{2^n}\right) \leq 3\). Increasing and bounded above by 3: it converges, and \(u_2 = 2.5 \leq \ell \leq 3\). (Its limit is the number \(e\).)

  • “Bounded above by 3, so it tends to 3”: false. The theorem does not give the limit.
  • Forgetting one of the two ingredients: monotonicity and the bound.

Adjacent sequences

Definition adjacent sequences

Two sequences \((u_n)\) and \((v_n)\) are adjacent if:

  1. \((u_n)\) is increasing;
  2. \((v_n)\) is decreasing;
  3. \(\displaystyle\lim_{n \to +\infty} (v_n - u_n) = 0\).
Theorem adjacent sequences

Let \((u_n)\) and \((v_n)\) be two adjacent sequences. Then they converge to the same limit \(\ell\), and (with \((u_n)\) increasing and \((v_n)\) decreasing):

\[\forall n \in \N,\quad u_n \leq u_{n+1} \leq \ell \leq v_{n+1} \leq v_n.\]
Proof the “Proofs to know” sheet

1. Let \(w_n = v_n - u_n\). For every \(n\), \(w_{n+1} - w_n = (v_{n+1} - v_n) + (u_n - u_{n+1})\). Both brackets are negative or zero, so \((w_n)\) is decreasing.

\((w_n)\) is decreasing and tends to 0, so it is nonnegative: \(\forall n \in \N,\ w_n \geq 0\), that is, \(v_n \geq u_n\).

Since \((u_n)\) is increasing and \((v_n)\) is decreasing: \(\forall n \in \N,\ u_0 \leq u_n \leq v_n \leq v_0\).

\((u_n)\) is increasing and bounded above by \(v_0\): it converges to a real number \(\ell\). \((v_n)\) is decreasing and bounded below by \(u_0\): it converges to a real number \(\ell'\).

Finally \(\ell' - \ell = \lim v_n - \lim u_n = \lim (v_n - u_n) = 0\), so \(\ell = \ell'\).

2. \((u_n)\) is increasing and tends to \(\ell\), so \((u_n - \ell)\) is increasing and tends to 0: it is nonpositive, that is, \(u_n \leq \ell\). Likewise \(v_n \geq \ell\). Hence \(u_n \leq u_{n+1} \leq \ell \leq v_{n+1} \leq v_n\).

Method “show that the sequences are adjacent”
  1. State the definition (the question often asks for it: “after recalling the definition”).
  2. Sign of \(u_{n+1} - u_n\): positive.
  3. Sign of \(v_{n+1} - v_n\): negative. This is the tricky computation: same denominator, then simplify.
  4. \(\lim (v_n - u_n) = 0\).
  5. Conclude, then use the result: both sequences converge to the same limit, and \(u_n \leq \ell \leq v_n\) for every \(n\).
Model answer January 2024 exam, exercise 2 (6 points)

For \(n \geq 2\): \(u_n = \displaystyle\sum_{k=0}^{n} \frac{1}{k!}\) and \(v_n = u_n + \dfrac{1}{n!}\).

\((u_n)\) and \((v_n)\) are adjacent if \((u_n)\) is increasing, \((v_n)\) is decreasing and \(\lim (v_n - u_n) = 0\).the definition first

\(u_{n+1} - u_n = \dfrac{1}{(n+1)!} \geq 0\): \((u_n)\) is increasing.

\(v_{n+1} - v_n = \dfrac{1}{(n+1)!} + \dfrac{1}{(n+1)!} - \dfrac{1}{n!} = \dfrac{2 - (n + 1)}{(n+1)!} = \dfrac{1 - n}{(n+1)!}\). Since \(n \geq 2\), \(v_{n+1} - v_n \leq 0\): \((v_n)\) is decreasing.1/n! = (n+1)/(n+1)!

\(v_n - u_n = \dfrac{1}{n!} \to 0\). The two sequences are adjacent.

So they converge to the same limit: \((u_n)\) converges. And every convergent sequence is bounded: \((u_n)\) is bounded above.questions 2 and 3 of the paper

Tutorial 4, exercise 3.8. \(u_n = \displaystyle\sum_{k=1}^{n} \frac{1}{k^2}\), \(v_n = u_n + \frac{1}{n}\). \(u_{n+1} - u_n = \frac{1}{(n+1)^2} \gt 0\). \(v_{n+1} - v_n = \dfrac{1}{(n+1)^2} + \dfrac{1}{n+1} - \dfrac{1}{n} = \dfrac{n + n(n+1) - (n+1)^2}{n(n+1)^2} = -\dfrac{1}{n(n+1)^2}\), negative. \(v_n - u_n = \frac{1}{n} \to 0\). Adjacent.

Tutorial 4, exercise 3.9: approximating the limit. \(u_n = \displaystyle\sum_{k=1}^{n-1} \frac{1}{k^2(k+1)^2}\), \(v_n = u_n + \frac{1}{3n^2}\). We find \(u_{n+1} - u_n = \frac{1}{n^2(n+1)^2} \gt 0\) and \(v_{n+1} - v_n = \dfrac{3 + n^2 - (n+1)^2}{3n^2(n+1)^2} = \dfrac{2 - 2n}{3n^2(n+1)^2} \leq 0\). Since \(u_n \leq \ell \leq v_n\), the error is at most \(v_n - u_n = \frac{1}{3n^2}\): it drops below \(0.01\) as soon as \(n^2 \geq \frac{100}{3}\), that is, \(n = 6\). Then \(u_6 \approx 0.2883 \leq \ell \leq v_6 \approx 0.2976\): \(\ell \approx 0.29\) to within \(0.01\).

Traps
  • Forgetting the third condition, or showing only that \(u_n \leq v_n\).
  • Factorial mistake: \(\dfrac{1}{n!} = \dfrac{n + 1}{(n+1)!}\).
  • The decrease of \((v_n)\) may hold only from some rank on (here \(n \geq 2\)): that is enough, but you have to say so.

Subsequences

Definition subsequence

Let \((u_n)\) be a sequence. A subsequence of \((u_n)\) is any sequence of the form \((u_{\varphi(n)})\), where \(\varphi\) is a strictly increasing map from \(\N\) to \(\N\).

You keep some of the terms, in order, without going back. The most useful ones: \((u_{2n})\) (even ranks), \((u_{2n+1})\) (odd ranks), \((u_{3n})\), \((u_{n+1})\).

Proposition and corollary

If \(u_n \to \ell\), then every subsequence of \((u_n)\) converges to \(\ell\).

Corollary. If \((u_n)\) has a divergent subsequence, or two subsequences converging to different limits, then \((u_n)\) diverges.

Result to know Tutorial 4, exercise 4.10: “you are allowed to use it”
\[u_n \xrightarrow[n \to +\infty]{} \ell \iff \left(u_{2n} \xrightarrow[n \to +\infty]{} \ell \ \text{ and } \ u_{2n+1} \xrightarrow[n \to +\infty]{} \ell\right).\]

Even and odd ranks cover all the ranks: that is why the equivalence is true.

\(u_n = \sin\left(\dfrac{n\pi}{3}\right)\). \(u_{3n} = \sin(n\pi) = 0\): the sequence \((u_{3n})\) is zero, it converges to 0.

\(u_{6n+1} = \sin\left(2n\pi + \dfrac{\pi}{3}\right) = \dfrac{\sqrt{3}}{2}\): \((u_{6n+1})\) converges to \(\dfrac{\sqrt{3}}{2}\).

\((u_n)\) has two subsequences converging to different limits: by the course, it diverges.we quote the corollary

Showing that a sequence converges January 2024 exam, exercise 6

\(u_n = \dfrac{1}{n}\displaystyle\sum_{k=0}^{n-1} (-1)^k\) for \(n \in \N^*\). Geometric sum with common ratio \(-1\): \(u_n = \dfrac{1 - (-1)^n}{2n}\).

So \(u_{2n} = 0\) and \(u_{2n+1} = \dfrac{2}{4n + 2} = \dfrac{1}{2n + 1}\). The two subsequences converge to the same limit 0: \((u_n)\) converges to 0.

Tutorial 4, exercise 4.11: the harmonic series diverges. \(h_n = \displaystyle\sum_{k=1}^{n} \frac{1}{k}\) is increasing. \(h_{2n} - h_n = \displaystyle\sum_{k=n+1}^{2n} \frac{1}{k} \geq n \times \frac{1}{2n} = \frac{1}{2}\). If \((h_n)\) converged to \(\ell\), so would \((h_{2n})\), and \(h_{2n} - h_n \to 0\): absurd. \((h_n)\) is increasing and does not converge, so it is not bounded above: it tends to \(+\infty\).

Exercise 4.12. \(a_n = \displaystyle\sum_{k=1}^{n} \frac{(-1)^k}{k}\). \(a_{2n+2} - a_{2n} = \frac{1}{2n+2} - \frac{1}{2n+1} \lt 0\): \((a_{2n})\) decreases. \(a_{2n+3} - a_{2n+1} = \frac{1}{2n+2} - \frac{1}{2n+3} \gt 0\): \((a_{2n+1})\) increases. \(a_{2n} - a_{2n+1} = \frac{1}{2n+1} \to 0\). The two subsequences are adjacent, so they have the same limit: \((a_n)\) converges.

Traps
  • A single convergent subsequence proves nothing about \((u_n)\).
  • To conclude that the sequence converges, you need subsequences that cover all the ranks and have the same limit.
  • \(u_{2n+1}\) is obtained by replacing \(n\) with \(2n + 1\) everywhere: \(\frac{1 - (-1)^{2n+1}}{2(2n+1)} = \frac{2}{4n+2}\).

The Bolzano-Weierstrass theorem

Theorem Bolzano-Weierstrass

From every bounded sequence, you can extract a convergent subsequence.

This is what remains true of the false converse “bounded, hence convergent”: a bounded sequence does not necessarily converge, but one of its subsequences does.

  • \(((-1)^n)\) is bounded and diverges; \((u_{2n})\) is constant equal to 1, hence convergent.
  • \((\cos(n))\) is bounded: it has a convergent subsequence, even though we cannot write it down.
  • \((n)\) is not bounded: none of its subsequences converges, the theorem does not apply.

\(u_n = \displaystyle\sum_{k=n}^{2n-1} \frac{1}{k}\) for \(n \in \N^*\).

\(u_{n+1} - u_n = \dfrac{1}{2n} + \dfrac{1}{2n+1} - \dfrac{1}{n} = \dfrac{1}{2n+1} - \dfrac{1}{2n} \lt 0\): the sequence is strictly decreasing.two terms come in, one goes out

The sum has \(n\) terms, each between \(\dfrac{1}{2n-1}\) and \(\dfrac{1}{n}\): \(\dfrac{n}{2n-1} \leq u_n \leq 1\). Since \(\dfrac{n}{2n-1} \geq \dfrac{1}{2}\), the sequence is bounded below by \(\frac{1}{2}\) and bounded above by 1.
