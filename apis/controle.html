Pas au contrôle

MiMos des semaines du 23 et du 30 novembre

  • Suites récurrentes \(u_{n+1} = f(u_n)\) : points fixes, tableau de variations.

Ces trois modules sont pour le DM du 7 décembre et l’examen final. Conséquence pratique : lundi, on ne peut pas te demander de conclure « croissante et majorée donc convergente ». Une limite se justifie par le calcul, les opérations, une comparaison ou les gendarmes.

Cas limite : la fiche « Démonstrations à connaître » est un module à part, non cité. Ses trois premières démonstrations portent sur des modules au programme : voir plus bas.

Intégrales

  • \(\displaystyle\int_a^b f(x)\,dx = \left[F(x)\right]_a^b = F(b) - F(a)\)
  • \(x \mapsto \displaystyle\int_a^x f(t)\,dt\) est la primitive de \(f\) qui s’annule en \(a\)
  • Chasles : \(\displaystyle\int_a^b = \int_a^c + \int_c^b\) ; \(\displaystyle\int_b^a = -\int_a^b\)
  • paire : \(\displaystyle\int_{-a}^{a} f = 2\int_0^a f\) ; impaire : \(0\)
  • si \(f \leq g\) sur \([a, b]\) : \(\displaystyle\int_a^b f \leq \int_a^b g\)
  • valeur moyenne : \(\dfrac{1}{b - a}\displaystyle\int_a^b f(x)\,dx\)
  • rectangles, \(f\) monotone : \(A_{n,i} \leq \displaystyle\int_a^b f \leq A_{n,s}\)

Les deux techniques

  • IPP. \(f\), \(g\) de classe \(C^1\) sur \([a, b]\) : \(\displaystyle\int_a^b f g' = \left[fg\right]_a^b - \int_a^b f'g\)
  • Changement de variable. \(\varphi\) bijection \(C^1\) : \(\displaystyle\int_{\varphi(a)}^{\varphi(b)} f(x)\,dx = \int_a^b f(\varphi(t))\varphi'(t)\,dt\)
  • on change la fonction, le \(dx\) et les bornes
  • \(\arctan(0) = 0\), \(\arctan\frac{1}{\sqrt{3}} = \frac{\pi}{6}\), \(\arctan(1) = \frac{\pi}{4}\), \(\arctan(\sqrt{3}) = \frac{\pi}{3}\)

Suites géométriques

  • \(u_{n+1} = q\,u_n\) ; \(u_n = u_0\,q^n = u_{n_0}q^{n - n_0}\)
  • \(u_0 + \cdots + u_n = u_0\dfrac{1 - q^{n+1}}{1 - q}\) si \(q \neq 1\) ; \((n + 1)u_0\) si \(q = 1\)
  • \(q \gt 1\) : \(q^n \to +\infty\) ; \(q = 1\) : \(1\) ; \(|q| \lt 1\) : \(0\) ; \(q \leq -1\) : pas de limite
  • \((q^n)\) converge \(\iff -1 \lt q \leq 1\)
  • si \(\left|\frac{u_{n+1}}{u_n}\right| \lt \ell \lt 1\) à partir d’un rang : \(u_n \to 0\)
  • \(u_{n+1} = au_n + b\) : point fixe \(\ell\), \((u_n - \ell)\) géométrique de raison \(a\)

Théorèmes à énoncer

  • Gendarmes. Si, à partir d’un certain rang, \(u_n \leq v_n \leq w_n\), et si \((u_n)\) et \((w_n)\) convergent vers une même limite \(\ell\), alors \((v_n)\) converge vers \(\ell\).
  • Comparaison. Si \(u_n \leq v_n\) pour tout \(n\) : \(u_n \to +\infty \Rightarrow v_n \to +\infty\) ; \(v_n \to -\infty \Rightarrow u_n \to -\infty\).
  • Unicité de la limite.
  • Convergente \(\Rightarrow\) bornée ; la réciproque est fausse : \(((-1)^n)\).
Cours 4, partie 6 →

Limites : les réflexes

  • formes indéterminées : \(\infty - \infty\), \(0 \times \infty\), \(\frac{\infty}{\infty}\), \(\frac{0}{0}\)
  • factoriser par le terme dominant
  • \(\frac{\ln n}{n} \to 0\), \(\frac{n^k}{e^n} \to 0\), \(\frac{e^n}{n^k} \to +\infty\)
  • bornée \(\times\) (tend vers 0) \(\to 0\)
  • \(u_n \gt 0\) pour tout \(n\) donne seulement \(\ell \geq 0\)
  • \(u_n \to 0 \iff |u_n| \to 0\)

Démonstrations possibles

  • IPP : dérivée du produit, puis on intègre. Demandée en octobre 2022. Cours 3, partie 1
  • bornée \(\iff \exists M,\ \forall n,\ |u_n| \leq M\). Cours 4, partie 2
  • convergente \(\Rightarrow\) bornée (\(\varepsilon = 1\), inégalité triangulaire). Partie 6
  • théorème des gendarmes (\(N = \max(N_1, N_2)\)). Partie 6

Cours 3 : primitives et intégrales 6 points

  1. Compléter : donner une primitive \(F\) de chaque fonction \(f\) (sans se soucier du domaine de définition) : \(\dfrac{1}{x^2}\) ; \(e^{-3x}\) ; \(\cos(2x)\) ; \(\dfrac{x}{x^2 + 1}\) ; \(\dfrac{1}{\sqrt{x}}\) ; \(\dfrac{1}{1 + x^2}\). (2 points)
  2. Entourer les formules vraies (une formule fausse entourée retire des points). \(f\) et \(g\) sont continues sur \(\R\), \(F\) est une primitive de \(f\), \(a \lt b\). (1,5 point)
    1. \(\displaystyle\int_a^b f(x)\,dx = F(a) - F(b)\)
    2. si \(f\) est paire, \(\displaystyle\int_{-a}^{a} f(x)\,dx = 0\)
    3. une primitive de \(u'e^u\) est \(e^u\)
    4. \(\displaystyle\int_a^b f(x)g(x)\,dx = \int_a^b f(x)\,dx \times \int_a^b g(x)\,dx\)
    5. \(\displaystyle\int_b^a f(x)\,dx = -\int_a^b f(x)\,dx\)
    6. une primitive de \(\dfrac{u'}{u^2}\) est \(-\dfrac{1}{u}\)
  3. À l’aide d’une représentation graphique, déterminer \(\displaystyle\int_{-1}^{3} (2 - x)\,dx\). (1 point)
  4. En partageant \([0, 2]\) en 4 intervalles de même longueur, donner un encadrement de \(\displaystyle\int_0^2 x^2\,dx\) par la méthode des rectangles. (1,5 point)

Cours 3 : intégration par parties et changement de variable 4 points

  1. Énoncer le théorème d’intégration par parties avec ses hypothèses, puis calculer \(I = \displaystyle\int_0^1 (x + 2)e^{-x}\,dx\). (2 points)
  2. Calculer \(K = \displaystyle\int_1^4 \frac{dx}{\sqrt{x}\left(1 + \sqrt{x}\right)}\) en posant \(t = \sqrt{x}\). (2 points)

Cours 4 : introduction aux suites 4 points

  1. Soit \((u_n)\) une suite réelle. Donner la définition mathématique (avec les quantificateurs) de : (a) \((u_n)\) est majorée ; (b) \((u_n)\) est strictement décroissante ; (c) \((u_n)\) converge vers \(\ell \in \R\). (1,5 point)
  2. Donner un exemple d’une suite (non constante) : (a) bornée et non convergente ; (b) décroissante et minorée par 2 (justifier brièvement) ; (c) tendant vers \(+\infty\) sans être croissante. (1,5 point)
  3. Mettre le symbole \(\Rightarrow\), \(\Leftarrow\) ou \(\Leftrightarrow\) à la place des pointillés. (1 point)
    1. \((u_n)\) converge \(\ \ldots\ \) \((u_n)\) est bornée
    2. \((u_n)\) est croissante \(\ \ldots\ \) \(\forall n \in \N,\ u_{n+1} - u_n \geq 0\)
    3. \(u_n \to 0\) \(\ \ldots\ \) \(|u_n| \to 0\)
    4. \((u_n)\) n’est pas majorée \(\ \ldots\ \) \(u_n \to +\infty\)

Cours 4 : limites 3,5 points

  1. Les suites suivantes sont-elles convergentes ? Si oui, donner la limite. Justifier. (2,5 points)
    1. \(a_n = \dfrac{3n^2 - n}{2n^2 + 5}\)
    2. \(b_n = \dfrac{(-1)^n}{n}\) (\(n \geq 1\))
    3. \(c_n = n^2 - 3^n\)
    4. \(d_n = \sqrt{n + 1} - \sqrt{n}\)
  2. Énoncer le théorème des gendarmes. (1 point)

Cours 4 : exemples remarquables 2,5 points

  1. Soit \((u_n)\) géométrique de premier terme \(u_0 = 3\) et de raison \(\frac{1}{2}\). Donner \(u_n\) en fonction de \(n\), la limite de \((u_n)\), et calculer \(S = u_0 + u_1 + u_2 + u_3 + u_4\). (1,25 point)
  2. Soit \((u_n)\) définie par \(u_0 = 0\) et \(u_{n+1} = \dfrac{u_n + 6}{3}\). Déterminer \(\ell\) tel que \((u_n - \ell)\) soit géométrique, puis exprimer \(u_n\) en fonction de \(n\) et donner sa limite. (1,25 point)

Cours 3 : primitives et intégrales

  1. \(-\dfrac{1}{x}\) ; \(-\dfrac{e^{-3x}}{3}\) ; \(\dfrac{\sin(2x)}{2}\) ; \(\dfrac{1}{2}\ln(x^2 + 1)\) ; \(2\sqrt{x}\) ; \(\arctan(x)\). Six cases : un tiers de point chacune.
  2. Vraies : (c), (e), (f). (a) est fausse : c’est \(F(b) - F(a)\). (b) est fausse : pour une fonction paire on double, c’est pour une fonction impaire que l’intégrale est nulle. (d) est fausse : l’intégrale d’un produit n’est pas le produit des intégrales.
  3. La droite \(y = 2 - x\) passe par \((-1, 3)\), coupe l’axe en \(x = 2\) et arrive en \((3, -1)\). Au-dessus de l’axe sur \([-1, 2]\) : triangle \(\frac{3 \times 3}{2} = 4{,}5\). En dessous sur \([2, 3]\) : triangle \(\frac{1 \times 1}{2} = 0{,}5\). Donc \(\displaystyle\int_{-1}^{3} (2 - x)\,dx = 4{,}5 - 0{,}5 = 4\).
  4. \(x \mapsto x^2\) est continue, positive et croissante sur \([0, 2]\) ; largeur \(0{,}5\). Rectangles inférieurs : \(0{,}5 \times (0^2 + 0{,}5^2 + 1^2 + 1{,}5^2) = 1{,}75\). Rectangles supérieurs : \(0{,}5 \times (0{,}5^2 + 1^2 + 1{,}5^2 + 2^2) = 3{,}75\). Donc \(1{,}75 \leq \displaystyle\int_0^2 x^2\,dx \leq 3{,}75\) (valeur exacte \(\frac{8}{3}\)).

Cours 3 : intégration par parties et changement de variable

  1. Soient \(f\) et \(g\) de classe \(C^1\) sur \([a, b]\) ; alors \(\displaystyle\int_a^b f(x)g'(x)\,dx = \left[f(x)g(x)\right]_a^b - \int_a^b f'(x)g(x)\,dx\) (1 point, dont l’hypothèse). Ici \(u(x) = x + 2\), \(u'(x) = 1\), \(v'(x) = e^{-x}\), \(v(x) = -e^{-x}\) : \(I = \left[-(x + 2)e^{-x}\right]_0^1 + \displaystyle\int_0^1 e^{-x}\,dx = \left(-\frac{3}{e} + 2\right) + \left(1 - \frac{1}{e}\right)\), soit \(I = 3 - \dfrac{4}{e}\).
  2. \(t = \sqrt{x}\) : \(x = t^2\), \(dx = 2t\,dt\) ; \(x = 1 \Rightarrow t = 1\), \(x = 4 \Rightarrow t = 2\). \(K = \displaystyle\int_1^2 \frac{2t\,dt}{t(1 + t)} = 2\int_1^2 \frac{dt}{1 + t} = 2\left[\ln(1 + t)\right]_1^2 = 2(\ln 3 - \ln 2)\), soit \(K = 2\ln\dfrac{3}{2}\). Un demi-point pour \(dx\), un demi-point pour les bornes.

Cours 4 : introduction aux suites

  1. (a) \(\exists M \in \R,\ \forall n \in \N,\ u_n \leq M\). (b) \(\forall n \in \N,\ u_{n+1} \lt u_n\). (c) \(\forall \varepsilon \gt 0,\ \exists n_\varepsilon \in \N,\ \forall n \in \N,\ \left(n \geq n_\varepsilon \Rightarrow |u_n - \ell| \lt \varepsilon\right)\).
  2. (a) \(u_n = (-1)^n\). (b) \(u_n = 2 + \dfrac{1}{n + 1}\) : \(\frac{1}{n + 1} \gt 0\) donc \(u_n \geq 2\), et \(\frac{1}{n + 2} \lt \frac{1}{n + 1}\) donc \(u_{n+1} \lt u_n\). (c) \(u_n = n + 2(-1)^n\) : \(u_n \geq n - 2\), et \(u_0 = 2 \gt u_1 = -1\).
  3. (a) \(\Rightarrow\) (la réciproque est fausse : \(((-1)^n)\)). (b) \(\Leftrightarrow\) (c’est la définition). (c) \(\Leftrightarrow\). (d) \(\Leftarrow\) : une suite qui tend vers \(+\infty\) n’est pas majorée, mais \((n(1 + (-1)^n))\) n’est pas majorée sans tendre vers \(+\infty\).

Cours 4 : limites

  1. (a) \(a_n = \dfrac{3 - \frac{1}{n}}{2 + \frac{5}{n^2}} \to \dfrac{3}{2}\) : convergente. (b) \(-\dfrac{1}{n} \leq b_n \leq \dfrac{1}{n}\) et les deux suites tendent vers 0 : par le théorème des gendarmes, \(b_n \to 0\), convergente. (c) \(c_n = 3^n\left(\dfrac{n^2}{3^n} - 1\right)\) ; par croissances comparées \(\dfrac{n^2}{3^n} \to 0\), donc \(c_n \to -\infty\) : divergente. (d) \(d_n = \dfrac{(n + 1) - n}{\sqrt{n + 1} + \sqrt{n}} = \dfrac{1}{\sqrt{n + 1} + \sqrt{n}} \to 0\) : convergente.
  2. Soient \((u_n)\), \((v_n)\), \((w_n)\) trois suites réelles telles que, à partir d’un certain rang, \(u_n \leq v_n \leq w_n\), et telles que \((u_n)\) et \((w_n)\) convergent vers une même limite \(\ell \in \R\). Alors \((v_n)\) converge vers \(\ell\).

Cours 4 : exemples remarquables

  1. \(u_n = \dfrac{3}{2^n}\) ; \(\left|\frac{1}{2}\right| \lt 1\) donc \(u_n \to 0\) ; \(S = 3 \times \dfrac{1 - \left(\frac{1}{2}\right)^5}{1 - \frac{1}{2}} = 6 \times \dfrac{31}{32} = \dfrac{93}{16}\) (cinq termes : exposant 5).
  2. Point fixe : \(\ell = \dfrac{\ell + 6}{3} \iff \ell = 3\). \(v_n = u_n - 3\) : \(v_{n+1} = \dfrac{u_n + 6}{3} - 3 = \dfrac{u_n - 3}{3} = \dfrac{1}{3}v_n\), géométrique de raison \(\frac{1}{3}\), avec \(v_0 = -3\). Donc \(u_n = 3 - \dfrac{3}{3^n}\) et \(u_n \to 3\).
