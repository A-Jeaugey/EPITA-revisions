Recto · Primitives et intégrales

cours 3 du Moodle, en entier · cours 1 à 3 du site

Au contrôle

  • Remplir un tableau de primitives ; calculer une intégrale « sans IPP ni changement de variable ».
  • Une intégrale par un calcul d’aires ; un encadrement par la méthode des rectangles.
  • Énoncer l’IPP avec ses hypothèses, la démontrer (octobre 2022), l’appliquer.
  • Un changement de variable, toujours donné.

Primitive

  • \(F\) primitive de \(f\) sur \(I\) : \(F\) dérivable sur \(I\) et \(F' = f\).
  • Toute fonction continue sur un intervalle a des primitives.
  • Deux primitives diffèrent d’une constante : \(F + c\).
  • Une seule primitive prend une valeur donnée en un point donné.

Reconnaître la forme

  • Nommer \(u\), calculer \(u'\), comparer : il manque souvent une constante.
  • \(\frac{x}{x^2+1} = \frac{1}{2}\cdot\frac{u'}{u}\) : primitive \(\frac{1}{2}\ln(x^2+1)\).
  • \(x\sqrt{x^2+1} = \frac{1}{2}u'u^{1/2}\) : primitive \(\frac{1}{3}(x^2+1)^{3/2}\).
  • \(\tan x = -\frac{u'}{u}\) avec \(u = \cos x\) : primitive \(-\ln|\cos x|\).
  • Vérifier en dérivant.

Intégrale et aire

  • \(f \geq 0\) : \(\int_a^b f\) est l’aire sous la courbe, en unités d’aire.
  • \(f \leq 0\) : \(\int_a^b f = -\) aire. Signe quelconque : + au-dessus, − en dessous.
  • Par aires : triangle \(\frac{b \times h}{2}\), trapèze \(\frac{(B+b)h}{2}\), demi-disque \(\frac{\pi r^2}{2}\).
  • Variable muette : \(\int_a^b f(x)\,dx = \int_a^b f(t)\,dt\).

Méthode des rectangles

  • \(n\) intervalles de largeur \(h = \frac{b-a}{n}\).
  • \(f\) croissante : bord gauche = rectangles inférieurs, bord droit = supérieurs (l’inverse si décroissante).
  • \(f\) monotone : \(A_{n,i} \leq \int_a^b f \leq A_{n,s}\), et les deux tendent vers l’intégrale.
  • \(\int_0^1 x^2\,dx\), \(n = 5\) : \(0{,}24 \leq I \leq 0{,}44\).

Propriétés

  • \(\int_a^a f = 0\) ; \(\int_b^a f = -\int_a^b f\).
  • Chasles : \(\int_a^b f = \int_a^c f + \int_c^b f\).
  • Paire : \(\int_{-a}^{a} f = 2\int_0^a f\). Impaire : \(\int_{-a}^{a} f = 0\).
  • Linéarité : \(\int (\alpha f + \beta g) = \alpha\int f + \beta\int g\).
  • \(f \leq g \Rightarrow \int_a^b f \leq \int_a^b g\) ; \(f \leq M \Rightarrow \int_a^b f \leq M(b-a)\).
  • Valeur moyenne : \(\frac{1}{b-a}\int_a^b f(x)\,dx\).

Théorème fondamental

  • \(f\) continue : \(x \mapsto \int_a^x f(t)\,dt\) est la primitive de \(f\) qui s’annule en \(a\).
  • \(\int_a^b f(x)\,dx = \left[F(x)\right]_a^b = F(b) - F(a)\).

Intégration par parties

  • \(f\), \(g\) de classe \(C^1\) sur \([a,b]\) : \(\int_a^b fg' = \left[fg\right]_a^b - \int_a^b f'g\).
  • Preuve : \((fg)' = f'g + fg'\), on intègre, et \(\int_a^b (fg)' = \left[fg\right]_a^b\).
  • Polynôme \(\times\) (\(e^{kx}\), \(\cos\), \(\sin\)) : dériver le polynôme.
  • \(\ln\) : dériver \(\ln\) ; \(\ln x = 1 \times \ln x\).
  • \(e^x\sin x\) : deux IPP, l’intégrale revient.

Changement de variable

  • \(\varphi\) bijection \(C^1\) : \(\int_{\varphi(a)}^{\varphi(b)} f(x)\,dx = \int_a^b f(\varphi(t))\varphi'(t)\,dt\).
  • 1. poser ; 2. exprimer \(x\) ; 3. \(dx = \varphi'(t)\,dt\) ; 4. changer les bornes ; 5. tout réécrire.
  • \(t = \sqrt{x+2}\) : \(x = t^2 - 2\), \(dx = 2t\,dt\).
  • \(\arctan 0 = 0\), \(\arctan\frac{1}{\sqrt{3}} = \frac{\pi}{6}\), \(\arctan 1 = \frac{\pi}{4}\), \(\arctan\sqrt{3} = \frac{\pi}{3}\).

Pièges

  • Primitive de \(\sin\) : \(-\cos\). De \(\frac{1}{x^2}\) : \(-\frac{1}{x}\), pas un logarithme.
  • \(F(a) - F(b)\) au lieu de \(F(b) - F(a)\).
  • Une aire est positive ; une intégrale peut être négative.
  • IPP : oublier le crochet, ou l’hypothèse \(C^1\).
  • Changement de variable : bornes non changées, \(dx\) remplacé par \(dt\) sans facteur.
  • Paire : on double. Impaire : zéro.

Verso · Suites

Au contrôle

  • Définitions « avec les quantificateurs » : bornée, croissante, convergente (2022, 2023).
  • « Donner un exemple de suite… », parfois à justifier.
  • « Convergente ? Si oui, donner la limite. »
  • Condition sur \(q\) pour que \((q^n)\) converge (2022).

Bornes

  • Majorée : \(\exists M \in \R,\ \forall n \in \N,\ u_n \leq M\).
  • Minorée : \(\exists m \in \R,\ \forall n \in \N,\ m \leq u_n\).
  • Bornée : majorée et minorée \(\iff \exists M,\ \forall n,\ |u_n| \leq M\).

Monotonie

  • Croissante : \(\forall n \in \N,\ u_{n+1} \geq u_n\) (strictement : \(\gt\)).
  • Monotone : croissante ou décroissante. Stationnaire : constante à partir d’un rang.
  • Méthodes : signe de \(u_{n+1} - u_n\) ; \(\frac{u_{n+1}}{u_n}\) comparé à 1 si \(u_n \gt 0\) ; variations de \(f\) ; récurrence.

Limites : définitions

  • \(u_n \to \ell\) : \(\forall \varepsilon \gt 0,\ \exists n_\varepsilon \in \N,\ \forall n \geq n_\varepsilon,\ |u_n - \ell| \lt \varepsilon\).
  • \(u_n \to +\infty\) : \(\forall A \in \R,\ \exists n_0 \in \N,\ \forall n \geq n_0,\ u_n \gt A\).
  • Divergente : ne converge pas (limite infinie ou pas de limite).
  • La limite est unique. \(u_n \to 0 \iff |u_n| \to 0\).
  • \(u_n \gt 0\) pour tout \(n\) : seulement \(\ell \geq 0\).

Opérations, formes indéterminées

  • Limites finies : somme, produit, inverse (si \(\ell' \neq 0\)).
  • Indéterminées : \(\infty - \infty\), \(0 \times \infty\), \(\frac{\infty}{\infty}\), \(\frac{0}{0}\).
  • Factoriser par le terme dominant ; quantité conjuguée pour les racines.
  • \(\frac{\ln n}{n} \to 0\), \(\frac{n^k}{e^n} \to 0\), \(\frac{e^n}{n^k} \to +\infty\), \(\frac{a^n}{n!} \to 0\).

Comparaison, gendarmes

  • \(u_n \leq v_n\) : \(u_n \to +\infty \Rightarrow v_n \to +\infty\) ; \(v_n \to -\infty \Rightarrow u_n \to -\infty\).
  • Gendarmes : \(u_n \leq v_n \leq w_n\) à partir d’un rang, \((u_n)\) et \((w_n)\) de même limite \(\ell\) : \(v_n \to \ell\).
  • Bornée \(\times\) (tend vers 0) tend vers 0 : \(\frac{\sin n}{n} \to 0\).

Démonstrations

  • Bornée \(\iff |u_n| \leq M\) : \(\Leftarrow\) \(-M \leq u_n \leq M\) ; \(\Rightarrow\) \(M = \max(|m|, |K|)\).
  • Convergente \(\Rightarrow\) bornée : \(\varepsilon = 1\), \(|u_n| \leq |u_n - \ell| + |\ell| \lt 1 + |\ell|\) pour \(n \geq N\) ; \(M = \max(|u_0|, \ldots, |u_{N-1}|, 1 + |\ell|)\).
  • Gendarmes : \(\varepsilon \gt 0\), \(N_1\) pour \((u_n)\), \(N_2\) pour \((w_n)\), \(N = \max(N_1, N_2)\) : \(\ell - \varepsilon \lt u_n \leq v_n \leq w_n \lt \ell + \varepsilon\).

Suites géométriques

  • \(u_{n+1} = q\,u_n\) ; \(u_n = u_0 q^n = u_{n_0}q^{n-n_0}\).
  • \(u_0 + \cdots + u_n = u_0\frac{1 - q^{n+1}}{1 - q}\) (\(q \neq 1\)) ; \((n+1)u_0\) si \(q = 1\).
  • \(q \gt 1\) : \(+\infty\) ; \(q = 1\) : 1 ; \(|q| \lt 1\) : 0 ; \(q \leq -1\) : pas de limite.
  • \((q^n)\) converge \(\iff -1 \lt q \leq 1\).
  • Arithmétique : \(u_n = u_0 + nr\), somme \((n+1)\frac{u_0 + u_n}{2}\).

Arithmético-géométrique

  • \(u_{n+1} = au_n + b\) : point fixe \(\ell = a\ell + b\).
  • \(v_n = u_n - \ell\) est géométrique de raison \(a\).
  • \(u_n = \ell + (u_0 - \ell)a^n\) ; si \(|a| \lt 1\), \(u_n \to \ell\).
  • \(u_{n+1} = \frac{u_n + 4}{5}\), \(u_0 = 5\) : \(u_n = 1 + \frac{4}{5^n}\).

Critère du quotient

  • \(u_n \neq 0\) et \(\left|\frac{u_{n+1}}{u_n}\right| \lt \ell \lt 1\) à partir d’un rang : \(u_n \to 0\).
  • Si \(\frac{u_{n+1}}{u_n} \to 0\), alors \(u_n \to 0\).
  • \(\ell\) est fixe : « quotient \(\lt 1\) » ne suffit pas (\(1 + \frac{1}{n}\)).

Exemples à donner

bornée, non convergente\((-1)^n\)
ni croissante ni décroissante\((-1)^n\)
majorée par 3\(3 - n\)
strict. croissante, bornée\(\frac{n}{n+1}\)
strict. croissante, convergente\(-\frac{1}{n+1}\)
non constante, tend vers 2\(2 + \frac{1}{n+1}\)
tend vers \(+\infty\), non croissante\(n + 2(-1)^n\)
non majorée, pas de limite \(+\infty\)\(n(1 + (-1)^n)\)
ni majorée ni minorée\((-1)^n n\)

Pièges

  • « \(\forall n,\ \exists M\) » : l’ordre est faux, \(M\) vient d’abord.
  • Divergente ne veut pas dire « tend vers l’infini ».
  • Bornée n’implique pas convergente ; convergente implique bornée.
  • « Converge \(\iff |q| \lt 1\) » oublie \(q = 1\).
  • Somme géométrique : exposant = nombre de termes.
  • Quotient comparé à 1 : seulement pour des termes positifs.

  • Suites récurrentes \(u_{n+1} = f(u_n)\).
  • Comparaisons de Landau : \(o\), \(O\), \(\sim\).
