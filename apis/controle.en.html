Integrals

  • \(\displaystyle\int_a^b f(x)\,dx = \left[F(x)\right]_a^b = F(b) - F(a)\)
  • \(x \mapsto \displaystyle\int_a^x f(t)\,dt\) is the primitive of \(f\) that vanishes at \(a\)
  • Chasles: \(\displaystyle\int_a^b = \int_a^c + \int_c^b\); \(\displaystyle\int_b^a = -\int_a^b\)
  • even: \(\displaystyle\int_{-a}^{a} f = 2\int_0^a f\); odd: \(0\)
  • if \(f \leq g\) on \([a, b]\): \(\displaystyle\int_a^b f \leq \int_a^b g\)
  • mean value: \(\dfrac{1}{b - a}\displaystyle\int_a^b f(x)\,dx\)
  • rectangles, \(f\) monotonic: \(A_{n,i} \leq \displaystyle\int_a^b f \leq A_{n,s}\)

The two techniques

  • IBP. \(f\), \(g\) of class \(C^1\) on \([a, b]\): \(\displaystyle\int_a^b f g' = \left[fg\right]_a^b - \int_a^b f'g\)
  • Change of variable. \(\varphi\) a \(C^1\) bijection: \(\displaystyle\int_{\varphi(a)}^{\varphi(b)} f(x)\,dx = \int_a^b f(\varphi(t))\varphi'(t)\,dt\)
  • you change the function, the \(dx\) and the bounds
  • \(\arctan(0) = 0\), \(\arctan\frac{1}{\sqrt{3}} = \frac{\pi}{6}\), \(\arctan(1) = \frac{\pi}{4}\), \(\arctan(\sqrt{3}) = \frac{\pi}{3}\)
Lesson 3 →

Geometric sequences

  • \(u_{n+1} = q\,u_n\); \(u_n = u_0\,q^n = u_{n_0}q^{n - n_0}\)
  • \(u_0 + \cdots + u_n = u_0\dfrac{1 - q^{n+1}}{1 - q}\) if \(q \neq 1\); \((n + 1)u_0\) if \(q = 1\)
  • \(q \gt 1\): \(q^n \to +\infty\); \(q = 1\): \(1\); \(|q| \lt 1\): \(0\); \(q \leq -1\): no limit
  • \((q^n)\) converges \(\iff -1 \lt q \leq 1\)
  • if \(\left|\frac{u_{n+1}}{u_n}\right| \lt \ell \lt 1\) from some rank on: \(u_n \to 0\)
  • \(u_{n+1} = au_n + b\): fixed point \(\ell\), \((u_n - \ell)\) geometric with common ratio \(a\)

Theorems to state

  • Squeeze theorem. If, from some rank on, \(u_n \leq v_n \leq w_n\), and if \((u_n)\) and \((w_n)\) converge to the same limit \(\ell\), then \((v_n)\) converges to \(\ell\).
  • Comparison. If \(u_n \leq v_n\) for all \(n\): \(u_n \to +\infty \Rightarrow v_n \to +\infty\); \(v_n \to -\infty \Rightarrow u_n \to -\infty\).
  • Uniqueness of the limit.
  • Convergent \(\Rightarrow\) bounded; the converse is false: \(((-1)^n)\).

Limits: the reflexes

  • indeterminate forms: \(\infty - \infty\), \(0 \times \infty\), \(\frac{\infty}{\infty}\), \(\frac{0}{0}\)
  • factor out the dominant term
  • \(\frac{\ln n}{n} \to 0\), \(\frac{n^k}{e^n} \to 0\), \(\frac{e^n}{n^k} \to +\infty\)
  • bounded \(\times\) (tends to 0) \(\to 0\)
  • \(u_n \gt 0\) for all \(n\) only gives \(\ell \geq 0\)
  • \(u_n \to 0 \iff |u_n| \to 0\)

Possible proofs

  • IBP: derivative of the product, then integrate. Asked in October 2022. Lesson 3, part 1

  • convergent \(\Rightarrow\) bounded (\(\varepsilon = 1\), triangle inequality). Part 6

Course 3: primitives and integrals 6 points

  1. Complete: give a primitive \(F\) of each function \(f\) (without worrying about the domain of definition): \(\dfrac{1}{x^2}\); \(e^{-3x}\); \(\cos(2x)\); \(\dfrac{x}{x^2 + 1}\); \(\dfrac{1}{\sqrt{x}}\); \(\dfrac{1}{1 + x^2}\). (2 points)
  2. Circle the true formulas (circling a false formula removes points). \(f\) and \(g\) are continuous on \(\R\), \(F\) is a primitive of \(f\), \(a \lt b\). (1.5 points)
    1. \(\displaystyle\int_a^b f(x)\,dx = F(a) - F(b)\)
    2. if \(f\) is even, \(\displaystyle\int_{-a}^{a} f(x)\,dx = 0\)
    3. a primitive of \(u'e^u\) is \(e^u\)
    4. \(\displaystyle\int_a^b f(x)g(x)\,dx = \int_a^b f(x)\,dx \times \int_a^b g(x)\,dx\)
    5. \(\displaystyle\int_b^a f(x)\,dx = -\int_a^b f(x)\,dx\)
    6. a primitive of \(\dfrac{u'}{u^2}\) is \(-\dfrac{1}{u}\)
  3. Using a graph, determine \(\displaystyle\int_{-1}^{3} (2 - x)\,dx\). (1 point)
  4. Splitting \([0, 2]\) into 4 intervals of the same length, give bounds for \(\displaystyle\int_0^2 x^2\,dx\) by the rectangle method. (1.5 points)

Course 3: integration by parts and change of variable 4 points

  1. State the integration by parts theorem with its hypotheses, then compute \(I = \displaystyle\int_0^1 (x + 2)e^{-x}\,dx\). (2 points)
  2. Compute \(K = \displaystyle\int_1^4 \frac{dx}{\sqrt{x}\left(1 + \sqrt{x}\right)}\) by setting \(t = \sqrt{x}\). (2 points)

Course 4: introduction to sequences 4 points

  1. Let \((u_n)\) be a real sequence. Give the mathematical definition (with quantifiers) of: (a) \((u_n)\) is bounded above; (b) \((u_n)\) is strictly decreasing; (c) \((u_n)\) converges to \(\ell \in \R\). (1.5 points)
  2. Give an example of a (non-constant) sequence: (a) bounded and not convergent; (b) decreasing and bounded below by 2 (justify briefly); (c) tending to \(+\infty\) without being increasing. (1.5 points)
  3. Put the symbol \(\Rightarrow\), \(\Leftarrow\) or \(\Leftrightarrow\) in place of the dots. (1 point)
    1. \((u_n)\) converges \(\ \ldots\ \) \((u_n)\) is bounded
    2. \((u_n)\) is increasing \(\ \ldots\ \) \(\forall n \in \N,\ u_{n+1} - u_n \geq 0\)
    3. \(u_n \to 0\) \(\ \ldots\ \) \(|u_n| \to 0\)
    4. \((u_n)\) is not bounded above \(\ \ldots\ \) \(u_n \to +\infty\)

Course 4: limits 3.5 points

  1. Are the following sequences convergent? If so, give the limit. Justify. (2.5 points)
    1. \(a_n = \dfrac{3n^2 - n}{2n^2 + 5}\)
    2. \(b_n = \dfrac{(-1)^n}{n}\) (\(n \geq 1\))
    3. \(c_n = n^2 - 3^n\)
    4. \(d_n = \sqrt{n + 1} - \sqrt{n}\)
  2. State the squeeze theorem. (1 point)

Course 4: remarkable examples 2.5 points

  1. Let \((u_n)\) be geometric with first term \(u_0 = 3\) and common ratio \(\frac{1}{2}\). Give \(u_n\) as a function of \(n\), the limit of \((u_n)\), and compute \(S = u_0 + u_1 + u_2 + u_3 + u_4\). (1.25 points)
  2. Let \((u_n)\) be defined by \(u_0 = 0\) and \(u_{n+1} = \dfrac{u_n + 6}{3}\). Find \(\ell\) such that \((u_n - \ell)\) is geometric, then express \(u_n\) as a function of \(n\) and give its limit. (1.25 points)

Course 3: primitives and integrals

  1. \(-\dfrac{1}{x}\); \(-\dfrac{e^{-3x}}{3}\); \(\dfrac{\sin(2x)}{2}\); \(\dfrac{1}{2}\ln(x^2 + 1)\); \(2\sqrt{x}\); \(\arctan(x)\). Six boxes: one third of a point each.
  2. True: (c), (e), (f). (a) is false: it is \(F(b) - F(a)\). (b) is false: for an even function you double, it is for an odd function that the integral is zero. (d) is false: the integral of a product is not the product of the integrals.
  3. The line \(y = 2 - x\) passes through \((-1, 3)\), crosses the axis at \(x = 2\) and ends at \((3, -1)\). Above the axis on \([-1, 2]\): triangle \(\frac{3 \times 3}{2} = 4.5\). Below it on \([2, 3]\): triangle \(\frac{1 \times 1}{2} = 0.5\). So \(\displaystyle\int_{-1}^{3} (2 - x)\,dx = 4.5 - 0.5 = 4\).
  4. \(x \mapsto x^2\) is continuous, positive and increasing on \([0, 2]\); width \(0.5\). Lower rectangles: \(0.5 \times (0^2 + 0.5^2 + 1^2 + 1.5^2) = 1.75\). Upper rectangles: \(0.5 \times (0.5^2 + 1^2 + 1.5^2 + 2^2) = 3.75\). So \(1.75 \leq \displaystyle\int_0^2 x^2\,dx \leq 3.75\) (exact value \(\frac{8}{3}\)).

Course 3: integration by parts and change of variable

  1. Let \(f\) and \(g\) be of class \(C^1\) on \([a, b]\); then \(\displaystyle\int_a^b f(x)g'(x)\,dx = \left[f(x)g(x)\right]_a^b - \int_a^b f'(x)g(x)\,dx\) (1 point, including the hypothesis). Here \(u(x) = x + 2\), \(u'(x) = 1\), \(v'(x) = e^{-x}\), \(v(x) = -e^{-x}\): \(I = \left[-(x + 2)e^{-x}\right]_0^1 + \displaystyle\int_0^1 e^{-x}\,dx = \left(-\frac{3}{e} + 2\right) + \left(1 - \frac{1}{e}\right)\), that is \(I = 3 - \dfrac{4}{e}\).
  2. \(t = \sqrt{x}\): \(x = t^2\), \(dx = 2t\,dt\); \(x = 1 \Rightarrow t = 1\), \(x = 4 \Rightarrow t = 2\). \(K = \displaystyle\int_1^2 \frac{2t\,dt}{t(1 + t)} = 2\int_1^2 \frac{dt}{1 + t} = 2\left[\ln(1 + t)\right]_1^2 = 2(\ln 3 - \ln 2)\), that is \(K = 2\ln\dfrac{3}{2}\). Half a point for \(dx\), half a point for the bounds.

Course 4: introduction to sequences

  1. (a) \(\exists M \in \R,\ \forall n \in \N,\ u_n \leq M\). (b) \(\forall n \in \N,\ u_{n+1} \lt u_n\). (c) \(\forall \varepsilon \gt 0,\ \exists n_\varepsilon \in \N,\ \forall n \in \N,\ \left(n \geq n_\varepsilon \Rightarrow |u_n - \ell| \lt \varepsilon\right)\).
  2. (a) \(u_n = (-1)^n\). (b) \(u_n = 2 + \dfrac{1}{n + 1}\): \(\frac{1}{n + 1} \gt 0\) so \(u_n \geq 2\), and \(\frac{1}{n + 2} \lt \frac{1}{n + 1}\) so \(u_{n+1} \lt u_n\). (c) \(u_n = n + 2(-1)^n\): \(u_n \geq n - 2\), and \(u_0 = 2 \gt u_1 = -1\).
  3. (a) \(\Rightarrow\) (the converse is false: \(((-1)^n)\)). (b) \(\Leftrightarrow\) (it is the definition). (c) \(\Leftrightarrow\). (d) \(\Leftarrow\): a sequence that tends to \(+\infty\) is not bounded above, but \((n(1 + (-1)^n))\) is not bounded above without tending to \(+\infty\).

Course 4: limits

  1. (a) \(a_n = \dfrac{3 - \frac{1}{n}}{2 + \frac{5}{n^2}} \to \dfrac{3}{2}\): convergent. (b) \(-\dfrac{1}{n} \leq b_n \leq \dfrac{1}{n}\) and both sequences tend to 0: by the squeeze theorem, \(b_n \to 0\), convergent. (c) \(c_n = 3^n\left(\dfrac{n^2}{3^n} - 1\right)\); by comparative growth \(\dfrac{n^2}{3^n} \to 0\), so \(c_n \to -\infty\): divergent. (d) \(d_n = \dfrac{(n + 1) - n}{\sqrt{n + 1} + \sqrt{n}} = \dfrac{1}{\sqrt{n + 1} + \sqrt{n}} \to 0\): convergent.
  2. Let \((u_n)\), \((v_n)\), \((w_n)\) be three real sequences such that, from some rank on, \(u_n \leq v_n \leq w_n\), and such that \((u_n)\) and \((w_n)\) converge to the same limit \(\ell \in \R\). Then \((v_n)\) converges to \(\ell\).

Course 4: remarkable examples

  1. \(u_n = \dfrac{3}{2^n}\); \(\left|\frac{1}{2}\right| \lt 1\) so \(u_n \to 0\); \(S = 3 \times \dfrac{1 - \left(\frac{1}{2}\right)^5}{1 - \frac{1}{2}} = 6 \times \dfrac{31}{32} = \dfrac{93}{16}\) (five terms: exponent 5).
  2. Fixed point: \(\ell = \dfrac{\ell + 6}{3} \iff \ell = 3\). \(v_n = u_n - 3\): \(v_{n+1} = \dfrac{u_n + 6}{3} - 3 = \dfrac{u_n - 3}{3} = \dfrac{1}{3}v_n\), geometric with common ratio \(\frac{1}{3}\), with \(v_0 = -3\). So \(u_n = 3 - \dfrac{3}{3^n}\) and \(u_n \to 3\).
