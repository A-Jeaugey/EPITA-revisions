\(u_{n+1} = f(u_n)\): the function decides everything.

A recursive sequence is read from the function \(f\) that takes you from one term to the next. A stable interval guarantees that the sequence is well defined and bounded, the variations of \(f\) give the monotonicity, and the fixed points are the only possible limits. The write-up always follows the same plan.

Part 1 “General facts” module · Tutorial 4 ex. 6.15

A well-defined sequence: the stable interval

Definition recursive sequence, stable interval

A recursive sequence is defined by its first term \(u_0\) and a relation \(\forall n \in \N,\ u_{n+1} = f(u_n)\).

An interval \(I\) is stable under \(f\) if \(f(I) \subset I\): for every \(x \in I\), \(f(x) \in I\).

Property

If \(I\) is stable under \(f\) and \(u_0 \in I\), then the sequence is well defined and \(\forall n \in \N,\ u_n \in I\).

The proof is a one-line induction: if \(u_n \in I\), then \(u_{n+1} = f(u_n) \in I\). This is exactly what the papers have you write: “show by induction that \(\forall n \in \N,\ 1 \lt u_n \lt 2\)”. A bounded stable interval gives a bounded sequence.

Reading it on a graph. Draw the curve of \(f\) and the line \(y = x\). Start from \(u_0\) on the x-axis, go up to the curve (height \(u_1\)), move horizontally to the line \(y = x\) to carry \(u_1\) over to the x-axis, and start again.

  • Check that \(f(u_n)\) exists: a square root, a quotient or a logarithm imposes an interval.

Fixed points: the only possible limits

Definition fixed point

A fixed point of \(f\) is a real number \(\ell\) such that \(f(\ell) = \ell\). If \(u_0\) is a fixed point, the sequence is constant.

Theorem limit of a recursive sequence

Let \((u_n)\) be defined by \(u_{n+1} = f(u_n)\), with \(f\) continuous on \(I\). If \((u_n)\) converges to a real number \(\ell \in I\), then

\[\ell = f(\ell).\]

Why: \(u_{n+1} \to \ell\) (subsequence), and \(f(u_n) \to f(\ell)\) by continuity; so both sides of \(u_{n+1} = f(u_n)\) have the same limit.

The theorem does not say that the sequence converges. It says: if it converges, it is to a fixed point. You first prove convergence (lesson 5), then solve \(\ell = f(\ell)\), then choose among the solutions using the bounds or the monotonicity.

Model answer January 2024 exam, exercise 5, question 1 (b)

\(u_0 = 1\), \(u_{n+1} = \dfrac{u_n}{u_n + 8}\), and we have shown \(u_n \gt 0\). “Suppose that \((u_n)\) converges to a real number \(\ell\). What are the possible values of \(\ell\)?”

Let \(f : x \mapsto \dfrac{x}{x + 8}\). \(f\) is continuous on \(\R_+\), so \(\ell = f(\ell)\).continuity, then ℓ = f(ℓ)

\(\ell = \dfrac{\ell}{\ell + 8} \iff \ell^2 + 8\ell = \ell \iff \ell(\ell + 7) = 0\). If the sequence converges, it is to 0 or to \(-7\).

Later in the exercise: \(u_n \gt 0\) for every \(n\) gives \(\ell \geq 0\), so \(\ell = 0\).the bounds rule out −7

Traps
  • Solving \(\ell = f(\ell)\) and concluding “so the sequence converges to \(\ell\)”: the proof of convergence is missing.
  • Forgetting the word “continuous”: it is the hypothesis that lets you pass to the limit.
  • Keeping a fixed point that is incompatible with the bounds of the sequence.

Part 3 “General facts” module: \(f\) monotonic

The monotonicity of the sequence

Properties

Let \(I\) be an interval stable under \(f\) and \(u_0 \in I\).

  1. If \(f\) is increasing on \(I\), then \((u_n)\) is monotonic: increasing if \(u_1 \geq u_0\), decreasing if \(u_1 \leq u_0\).
  2. If \(f\) is decreasing on \(I\), then \((u_{2n})\) and \((u_{2n+1})\) are monotonic, in opposite directions.
  3. In every case, \(u_{n+1} - u_n = f(u_n) - u_n\): the sign of \(g(x) = f(x) - x\) on \(I\) gives the monotonicity.

Why 1. By induction: if \(u_n \leq u_{n+1}\), then, since \(f\) is increasing, \(f(u_n) \leq f(u_{n+1})\), that is, \(u_{n+1} \leq u_{n+2}\). The order of the first two terms propagates.

Why 2. \(u_{n+2} = f(f(u_n))\) and \(f \circ f\) is increasing: apply 1 to the terms of even ranks, then of odd ranks.

Model answer January 2025 exam, exercise 5, question 1

\(u_0 = \dfrac{3}{2}\), \(u_{n+1} = 1 + \dfrac{1}{4}u_n^2\). Study the monotonicity (“try to factor”).

\(u_{n+1} - u_n = \dfrac{u_n^2}{4} - u_n + 1 = \dfrac{u_n^2 - 4u_n + 4}{4} = \dfrac{(u_n - 2)^2}{4} \geq 0\).a perfect-square identity

For every \(n\), \(u_{n+1} - u_n \geq 0\): the sequence is increasing.

Traps
  • The sign of \(f(x) - x\) depends on the interval: you first need to know where the \(u_n\) are.
  • \(f\) decreasing: the sequence is in general not monotonic, it oscillates around the fixed point.

Part 4 Tutorial 4 ex. 6.16

The complete study, depending on \(u_0\)

Method studying \(u_{n+1} = f(u_n)\)
  1. Fixed points: solve \(f(x) = x\).
  2. Variations of \(f\): table of variations, with the values at the fixed points.
  3. Stable interval containing \(u_0\), bounded by the fixed points: induction on “\(u_n \in I\)”.
  4. Monotonicity: sign of \(f(x) - x\) on \(I\), factored using the fixed points.
  5. Convergence: increasing and bounded above, or decreasing and bounded below. Otherwise: monotonic and not convergent, hence an infinite limit.
  6. Limit: a fixed point (\(f\) continuous), compatible with the bounds and the monotonicity.
Model answer Tutorial 4, exercise 6.16: \(f(x) = \frac{x^2 + 3}{4}\)

1. For every real \(x\), \(f(x) \geq \frac{3}{4} \gt 0\). So \(\forall n \in \N^*,\ u_n = f(u_{n-1}) \gt 0\).

2. \(f(x) = x \iff x^2 - 4x + 3 = 0 \iff (x - 1)(x - 3) = 0\). Fixed points: 1 and 3. If \(u_0\) equals 1 or 3, the sequence is constant.

3. \(f'(x) = \frac{x}{2}\): \(f\) decreases on \(]-\infty, 0]\), increases on \([0, +\infty[\), with \(f(0) = \frac{3}{4}\), \(f(1) = 1\), \(f(3) = 3\).

4. Let \(u_0 \in [0, 1[\). (a) By induction: if \(0 \leq u_n \lt 1\), since \(f\) is strictly increasing on \([0, 1]\), \(f(0) \leq f(u_n) \lt f(1)\), that is, \(\frac{3}{4} \leq u_{n+1} \lt 1\).[0, 1[ is stable

(b) \(u_{n+1} - u_n = \dfrac{u_n^2 - 4u_n + 3}{4} = \dfrac{(u_n - 1)(u_n - 3)}{4}\). On \([0, 1[\), both factors are negative: \(u_{n+1} - u_n \gt 0\). The sequence is strictly increasing.factored using the fixed points

(c) Increasing and bounded above by 1: it converges to \(\ell\). \(f\) is continuous, so \(\ell \in \{1, 3\}\); and \(\ell \leq 1\). So \(\ell = 1\).

5. Let \(u_0 \gt 3\). By induction \(u_n \gt 3\) (\(f\) increasing, \(f(3) = 3\)). Both factors are positive: the sequence is strictly increasing. If it converged, its limit would be 1 or 3; but \(\ell \geq u_0 \gt 3\): impossible. Increasing and not convergent, it is not bounded above: \(u_n \to +\infty\).argument by contradiction

6. Let \(u_0 \in\ ]1, 3[\). By induction \(1 \lt u_n \lt 3\). The factors have opposite signs: the sequence is strictly decreasing, bounded below by 1, hence convergent; \(\ell \leq u_0 \lt 3\), so \(\ell = 1\).

Part 5 Tutorial 4 ex. 6.17 · January 2024 and 2025 exams

Heron’s method, and the exam exercises

Model answer Tutorial 4, exercise 6.17: approximating \(\sqrt{a}\)

\(a \gt 0\), \(f(x) = \dfrac{1}{2}\left(x + \dfrac{a}{x}\right)\) on \(\R_+^*\), \(u_0 \gt 0\), \(u_{n+1} = f(u_n)\).

1. If \(u_n \gt 0\), then \(u_{n+1} = \frac{1}{2}\left(u_n + \frac{a}{u_n}\right) \gt 0\): by induction, the sequence is well defined and strictly positive.

2. \(f(x) = x \iff \dfrac{a}{x} = x \iff x^2 = a \iff x = \sqrt{a}\) (since \(x \gt 0\)). If \(u_0 = \sqrt{a}\), the sequence is constant.

3. \(f'(x) = \dfrac{1}{2}\left(1 - \dfrac{a}{x^2}\right)\): \(f\) decreases on \(]0, \sqrt{a}]\), increases on \([\sqrt{a}, +\infty[\), and its minimum is \(f(\sqrt{a}) = \sqrt{a}\). So \(\forall x \gt 0,\ f(x) \geq \sqrt{a}\), and \(\forall n \in \N^*,\ u_n \geq \sqrt{a}\).the minimum of f bounds the sequence below

4. \(u_{n+1} - u_n = \dfrac{1}{2}\left(\dfrac{a}{u_n} - u_n\right) = \dfrac{a - u_n^2}{2u_n}\). For \(n \geq 1\), \(u_n \geq \sqrt{a}\) so \(a - u_n^2 \leq 0\): the sequence is decreasing from rank 1 on.

5. Decreasing and bounded below by \(\sqrt{a}\): it converges to \(\ell \geq \sqrt{a} \gt 0\). \(f\) is continuous on \(\R_+^*\), so \(\ell = f(\ell)\), hence \(\ell = \sqrt{a}\).

In numbers, with \(a = 2\) and \(u_0 = 1\): \(u_1 = 1.5\), \(u_2 \approx 1.41667\), \(u_3 \approx 1.414216\), for \(\sqrt{2} \approx 1.414214\). The number of correct decimals roughly doubles at each step.

Model answer January 2025 exam, exercise 5 (4.5 points)

\(u_0 = \dfrac{3}{2}\), \(u_{n+1} = 1 + \dfrac{1}{4}u_n^2\). We saw (part 3): \(u_{n+1} - u_n = \dfrac{(u_n - 2)^2}{4} \geq 0\), the sequence is increasing.

Induction on “\(1 \lt u_n \lt 2\)”. \(u_0 = \frac{3}{2}\). If \(1 \lt u_n \lt 2\), then \(1 \lt u_n^2 \lt 4\), so \(\frac{1}{4} \lt \frac{u_n^2}{4} \lt 1\) and \(\frac{5}{4} \lt u_{n+1} \lt 2\); in particular \(1 \lt u_{n+1} \lt 2\).

Conclusion. Increasing and bounded above by 2: the sequence converges to \(\ell\). \(x \mapsto 1 + \frac{x^2}{4}\) is continuous, so \(\ell = 1 + \dfrac{\ell^2}{4} \iff (\ell - 2)^2 = 0\). So \(\ell = 2\).

Model answer January 2024 exam, exercise 5 (10 points): the auxiliary sequence

\(u_0 = 1\), \(u_{n+1} = \dfrac{u_n}{u_n + 8}\). Part 1: \(u_n \gt 0\) by induction; \(u_{n+1} - u_n = -\dfrac{u_n(u_n + 7)}{u_n + 8} \leq 0\); decreasing and bounded below by 0, hence convergent, to 0 (see part 2).

Part 2: \(v_n = 1 + \dfrac{7}{u_n}\). \(v_{n+1} = 1 + \dfrac{7(u_n + 8)}{u_n} = 8 + \dfrac{56}{u_n} = 8\left(1 + \dfrac{7}{u_n}\right) = 8v_n\): geometric with common ratio 8, \(v_0 = 8\), so \(v_n = 8^{n+1}\).we make vₙ appear

Hence \(u_n = \dfrac{7}{v_n - 1} = \dfrac{7}{8^{n+1} - 1}\), which indeed tends to 0.

In the exam
  • The questions follow the plan: positivity or bounds by induction, “possible values of \(\ell\)”, monotonicity, “is it convergent? give its limit”.
  • Monotonicity is done through the sign of \(u_{n+1} - u_n\), to be factored.
  • Often a geometric auxiliary sequence then gives \(u_n\) as a function of \(n\) (lesson 4, part 7).
