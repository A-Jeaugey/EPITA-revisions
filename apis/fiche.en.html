Front · Primitives and integrals

Moodle course 3, in full · lessons 1 to 3 of the site

In the course test

  • Fill in a table of primitives; compute an integral “without IBP or change of variable”.
  • An integral by computing areas; bounds by the rectangle method.
  • State IBP with its hypotheses, prove it (October 2022), apply it.
  • A change of variable, always given.

Primitive

  • \(F\) is a primitive of \(f\) on \(I\): \(F\) is differentiable on \(I\) and \(F' = f\).
  • Every continuous function on an interval has primitives.
  • Two primitives differ by a constant: \(F + c\).
  • Exactly one primitive takes a given value at a given point.

Recognising the form

  • Name \(u\), compute \(u'\), compare: a constant is often missing.
  • \(\frac{x}{x^2+1} = \frac{1}{2}\cdot\frac{u'}{u}\): primitive \(\frac{1}{2}\ln(x^2+1)\).
  • \(x\sqrt{x^2+1} = \frac{1}{2}u'u^{1/2}\): primitive \(\frac{1}{3}(x^2+1)^{3/2}\).
  • \(\tan x = -\frac{u'}{u}\) with \(u = \cos x\): primitive \(-\ln|\cos x|\).
  • Check by differentiating.

Integral and area

  • \(f \geq 0\): \(\int_a^b f\) is the area under the curve, in area units.
  • \(f \leq 0\): \(\int_a^b f = -\) area. Any sign: + above, − below.
  • By areas: triangle \(\frac{b \times h}{2}\), trapezium \(\frac{(B+b)h}{2}\), half-disc \(\frac{\pi r^2}{2}\).
  • Dummy variable: \(\int_a^b f(x)\,dx = \int_a^b f(t)\,dt\).

Rectangle method

  • \(n\) intervals of width \(h = \frac{b-a}{n}\).
  • \(f\) increasing: left edge = lower rectangles, right edge = upper rectangles (the opposite if decreasing).
  • \(f\) monotonic: \(A_{n,i} \leq \int_a^b f \leq A_{n,s}\), and both tend to the integral.
  • \(\int_0^1 x^2\,dx\), \(n = 5\): \(0.24 \leq I \leq 0.44\).

Properties

  • \(\int_a^a f = 0\); \(\int_b^a f = -\int_a^b f\).
  • Chasles: \(\int_a^b f = \int_a^c f + \int_c^b f\).
  • Even: \(\int_{-a}^{a} f = 2\int_0^a f\). Odd: \(\int_{-a}^{a} f = 0\).
  • Linearity: \(\int (\alpha f + \beta g) = \alpha\int f + \beta\int g\).
  • \(f \leq g \Rightarrow \int_a^b f \leq \int_a^b g\); \(f \leq M \Rightarrow \int_a^b f \leq M(b-a)\).
  • Mean value: \(\frac{1}{b-a}\int_a^b f(x)\,dx\).

Fundamental theorem

  • \(f\) continuous: \(x \mapsto \int_a^x f(t)\,dt\) is the primitive of \(f\) that vanishes at \(a\).
  • \(\int_a^b f(x)\,dx = \left[F(x)\right]_a^b = F(b) - F(a)\).

Integration by parts

  • \(f\), \(g\) of class \(C^1\) on \([a,b]\): \(\int_a^b fg' = \left[fg\right]_a^b - \int_a^b f'g\).
  • Proof: \((fg)' = f'g + fg'\), integrate, and \(\int_a^b (fg)' = \left[fg\right]_a^b\).
  • Polynomial \(\times\) (\(e^{kx}\), \(\cos\), \(\sin\)): differentiate the polynomial.
  • \(\ln\): differentiate \(\ln\); \(\ln x = 1 \times \ln x\).
  • \(e^x\sin x\): two IBPs, the integral comes back.

Change of variable

  • \(\varphi\) a \(C^1\) bijection: \(\int_{\varphi(a)}^{\varphi(b)} f(x)\,dx = \int_a^b f(\varphi(t))\varphi'(t)\,dt\).
  • 1. set; 2. express \(x\); 3. \(dx = \varphi'(t)\,dt\); 4. change the bounds; 5. rewrite everything.
  • \(t = \sqrt{x+2}\): \(x = t^2 - 2\), \(dx = 2t\,dt\).
  • \(\arctan 0 = 0\), \(\arctan\frac{1}{\sqrt{3}} = \frac{\pi}{6}\), \(\arctan 1 = \frac{\pi}{4}\), \(\arctan\sqrt{3} = \frac{\pi}{3}\).

Traps

  • Primitive of \(\sin\): \(-\cos\). Of \(\frac{1}{x^2}\): \(-\frac{1}{x}\), not a logarithm.
  • \(F(a) - F(b)\) instead of \(F(b) - F(a)\).
  • An area is positive; an integral can be negative.
  • IBP: forgetting the bracket, or the \(C^1\) hypothesis.
  • Change of variable: bounds not changed, \(dx\) replaced by \(dt\) without a factor.
  • Even: double. Odd: zero.

Back · Sequences

Moodle course 4: introduction, limits, remarkable examples · lesson 4 of the site

In the course test

  • Definitions “with quantifiers”: bounded, increasing, convergent (2022, 2023).
  • “Give an example of a sequence…”, sometimes to justify.
  • “Is it convergent? If so, give the limit.”
  • Condition on \(q\) for \((q^n)\) to converge (2022).

Bounds

  • Bounded above: \(\exists M \in \R,\ \forall n \in \N,\ u_n \leq M\).
  • Bounded below: \(\exists m \in \R,\ \forall n \in \N,\ m \leq u_n\).
  • Bounded: bounded above and below \(\iff \exists M,\ \forall n,\ |u_n| \leq M\).

Monotonicity

  • Increasing: \(\forall n \in \N,\ u_{n+1} \geq u_n\) (strictly: \(\gt\)).
  • Monotonic: increasing or decreasing. Stationary: constant from some rank on.
  • Methods: sign of \(u_{n+1} - u_n\); \(\frac{u_{n+1}}{u_n}\) compared to 1 if \(u_n \gt 0\); variations of \(f\); induction.

Limits: definitions

  • \(u_n \to \ell\): \(\forall \varepsilon \gt 0,\ \exists n_\varepsilon \in \N,\ \forall n \geq n_\varepsilon,\ |u_n - \ell| \lt \varepsilon\).
  • \(u_n \to +\infty\): \(\forall A \in \R,\ \exists n_0 \in \N,\ \forall n \geq n_0,\ u_n \gt A\).
  • Divergent: does not converge (infinite limit or no limit).
  • The limit is unique. \(u_n \to 0 \iff |u_n| \to 0\).
  • \(u_n \gt 0\) for all \(n\): only \(\ell \geq 0\).

Operations, indeterminate forms

  • Finite limits: sum, product, inverse (if \(\ell' \neq 0\)).
  • Indeterminate: \(\infty - \infty\), \(0 \times \infty\), \(\frac{\infty}{\infty}\), \(\frac{0}{0}\).
  • Factor out the dominant term; conjugate expression for roots.
  • \(\frac{\ln n}{n} \to 0\), \(\frac{n^k}{e^n} \to 0\), \(\frac{e^n}{n^k} \to +\infty\), \(\frac{a^n}{n!} \to 0\).

Comparison, squeeze theorem

  • \(u_n \leq v_n\): \(u_n \to +\infty \Rightarrow v_n \to +\infty\); \(v_n \to -\infty \Rightarrow u_n \to -\infty\).
  • Squeeze theorem: \(u_n \leq v_n \leq w_n\) from some rank on, \((u_n)\) and \((w_n)\) with the same limit \(\ell\): \(v_n \to \ell\).
  • Bounded \(\times\) (tends to 0) tends to 0: \(\frac{\sin n}{n} \to 0\).

Proofs

  • Bounded \(\iff |u_n| \leq M\): \(\Leftarrow\) \(-M \leq u_n \leq M\); \(\Rightarrow\) \(M = \max(|m|, |K|)\).
  • Convergent \(\Rightarrow\) bounded: \(\varepsilon = 1\), \(|u_n| \leq |u_n - \ell| + |\ell| \lt 1 + |\ell|\) for \(n \geq N\); \(M = \max(|u_0|, \ldots, |u_{N-1}|, 1 + |\ell|)\).
  • Squeeze theorem: \(\varepsilon \gt 0\), \(N_1\) for \((u_n)\), \(N_2\) for \((w_n)\), \(N = \max(N_1, N_2)\): \(\ell - \varepsilon \lt u_n \leq v_n \leq w_n \lt \ell + \varepsilon\).

Geometric sequences

  • \(u_{n+1} = q\,u_n\); \(u_n = u_0 q^n = u_{n_0}q^{n-n_0}\).
  • \(u_0 + \cdots + u_n = u_0\frac{1 - q^{n+1}}{1 - q}\) (\(q \neq 1\)); \((n+1)u_0\) if \(q = 1\).
  • \(q \gt 1\): \(+\infty\); \(q = 1\): 1; \(|q| \lt 1\): 0; \(q \leq -1\): no limit.
  • \((q^n)\) converge \(\iff -1 \lt q \leq 1\).
  • Arithmetic: \(u_n = u_0 + nr\), sum \((n+1)\frac{u_0 + u_n}{2}\).

Arithmetic-geometric

  • \(u_{n+1} = au_n + b\): fixed point \(\ell = a\ell + b\).
  • \(v_n = u_n - \ell\) is geometric with common ratio \(a\).
  • \(u_n = \ell + (u_0 - \ell)a^n\); if \(|a| \lt 1\), \(u_n \to \ell\).
  • \(u_{n+1} = \frac{u_n + 4}{5}\), \(u_0 = 5\): \(u_n = 1 + \frac{4}{5^n}\).

Ratio criterion

  • \(u_n \neq 0\) and \(\left|\frac{u_{n+1}}{u_n}\right| \lt \ell \lt 1\) from some rank on: \(u_n \to 0\).
  • If \(\frac{u_{n+1}}{u_n} \to 0\), then \(u_n \to 0\).
  • \(\ell\) is fixed: “ratio \(\lt 1\)” is not enough (\(1 + \frac{1}{n}\)).

not bounded above, no limit \(+\infty\)\(n(1 + (-1)^n)\)
neither bounded above nor below\((-1)^n n\)

Traps

  • “\(\forall n,\ \exists M\)”: the order is wrong, \(M\) comes first.
  • Divergent does not mean “tends to infinity”.
  • Bounded does not imply convergent; convergent implies bounded.
  • “Converges \(\iff |q| \lt 1\)” forgets \(q = 1\).
  • Geometric sum: exponent = number of terms.
  • Ratio compared to 1: only for positive terms.
