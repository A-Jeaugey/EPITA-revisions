One function per file: answers/name.c defines it, includes/name.h declares it between header guards, and the .c includes its own header.

includes/sum_gold.h 
#ifndef SUM_GOLD_H
#define SUM_GOLD_H

#include <stdio.h>

int sum_gold(const int purses[], size_t len);

#endif
answers/sum_gold.c 
#include "../includes/sum_gold.h"

int sum_gold(const int purses[], size_t len)
{
    int total = 0;
    for (size_t i = 0; i < len; i++)
    {
        total += purses[i];
    }
    return total;
}

The #include path follows the given skeleton. <stdio.h> in the header provides size_t to the prototype.

The rules of the statements
  • If the statement and the skeleton or the moulinette disagree, the statement is right (tell the assistant).
  • The code must compile: otherwise, no grade. The command: gcc -Wall -Wextra -Werror -std=c99.
  • The given prototypes must be followed strictly: name, return type, types and order of the parameters.
  • Remove your personal tests: the moulinette brings its own main. A main in answers/ breaks the linking.
  • Only what is allowed (headers, keywords) can be used. In practical 1: <stdio.h> only, so no ready-made strlen or strcmp.
  • The .gitignore is mandatory, before the first hand-in (executables, *.o, *.out, *~…).
  • A yes / no function returns exactly 0 or 1. A printf output is copied character for character, final newline included.

During the practical

The routine, function by function

It avoids silly zeros: a misplaced file, a forgotten test, a warning.

  1. Read the instructions and the examples in full: they fix the edge cases (empty array, empty string, negative value, “at most” or “strictly”).
  2. Create includes/name.h (header guards and copied prototype) and answers/name.c (which includes the header).
  3. Write the edge cases first, then the loop. Array: for (size_t i = 0; i < len; i++). String: for (size_t i = 0; s[i] != '\0'; i++).
  4. Test in a main.c of your own, outside answers/, with the statement's examples: gcc -Wall -Wextra -Werror -std=c99 main.c answers/name.c -o test.
  5. Compare your output with the statement's, character by character.
  6. git add the two files, commit, an archi-* tag if you doubt the file tree, then push --follow-tags. Hand in often: a partial hand-in is better than nothing.
Checked with gcc

The traps of the day

Each one is shown, with the real gcc message, in the courses.

Does not compile with the practicals' options
  • Unused variable or parameter. Course 1
  • int i compared to a size_t (len, strlen, sizeof). Course 2
  • size_t i … i >= 0 in a backward loop. Course 2
  • sizeof on an array received as a parameter. Course 2
  • a == b between two char arrays. Course 3
  • A char as an array index. Course 3
  • case without break, = in an if, non-void function without a final return, wrong printf format. Course 1
Compiles, but wrong
  • i <= len: one cell too many, undefined behavior. Course 2
  • Maximum initialized to 0 with negative values; empty array forgotten.
  • -1 returned in an else on the first iteration instead of after the loop.
  • String copy without the final '\0'; destination too small.
  • '0' mistaken for '\0'; lowercase conversion without checking that it is a lowercase letter.
  • Modifying a string literal (char *s = "…"): crash.
  • Uninitialized sum or counter.

Arrays

answers/sum_gold.c

fundamentals

Returns the sum of the len purses of the array purses. If len is 0, returns 0.

Prototype
int sum_gold(const int purses[], size_t len);
Example
int purses[] = {12, 5, 30};
printf("%d\n", sum_gold(purses, 3));
printf("%d\n", sum_gold(purses, 2));
printf("%d\n", sum_gold(purses, 0));
Output
47
17
0
Solution
int sum_gold(const int purses[], size_t len)
{
    int total = 0;
    for (size_t i = 0; i < len; i++)
    {
        total += purses[i];
    }
    return total;
}

The case len == 0 does not need separate handling: the loop does not run and total is 0. You do have to initialize it, though.

answers/richest_member.c

fundamentals

Returns the index of the richest member of the array gold. In case of a tie, the first one. If len is 0, returns -1. Amounts can be negative (debts).

Prototype
int richest_member(const int gold[], size_t len);
Example
int gold[] = {40, 95, 12, 95};
int debts[] = {-3, -1, -7};
printf("%d\n", richest_member(gold, 4));
printf("%d\n", richest_member(debts, 3));
printf("%d\n", richest_member(gold, 0));
Output
1
1
-1
Hint

Keep the index of the best one, not its value. Start from index 0 (never from a value 0, because of the debts) and only replace with a strict > to keep the first one.

Solution
int richest_member(const int gold[], size_t len)
{
    if (len == 0)
    {
        return -1;
    }
    size_t best = 0;
    for (size_t i = 1; i < len; i++)
    {
        if (gold[i] > gold[best])
        {
            best = i;
        }
    }
    return best;
}

answers/count_above.c

fundamentals

Returns the number of members whose level is strictly greater than threshold.

Prototype
int count_above(const int levels[], size_t len, int threshold);
Example
int levels[] = {3, 10, 7, 10, 1};
printf("%d\n", count_above(levels, 5, 6));
printf("%d\n", count_above(levels, 5, 10));
printf("%d\n", count_above(levels, 5, 0));
Output
3
0
5
Solution
int count_above(const int levels[], size_t len, int threshold)
{
    int count = 0;
    for (size_t i = 0; i < len; i++)
    {
        if (levels[i] > threshold)
        {
            count++;
        }
    }
    return count;
}

“Strictly”: >, hence 0 for the threshold 10.

answers/find_last.c

fundamentals

Returns the index of the last occurrence of badge in badges, or -1 if it is not there.

Prototype
int find_last(const int badges[], size_t len, int badge);
Example
int badges[] = {7, 3, 7, 9};
printf("%d\n", find_last(badges, 4, 7));
printf("%d\n", find_last(badges, 4, 9));
printf("%d\n", find_last(badges, 4, 4));
Output
2
3
-1
Hint

Loop backward to stop at the first one found, without the size_t i >= 0 trap (course 2, part 2). Another solution: loop forward and remember the last index seen.

Solution
int find_last(const int badges[], size_t len, int badge)
{
    for (size_t i = len; i > 0; i--)
    {
        if (badges[i - 1] == badge)
        {
            return i - 1;
        }
    }
    return -1;
}

answers/is_ranked.c

fundamentals

A ranking is valid if the scores are strictly decreasing. Returns 1 if it is valid, 0 otherwise. An array of 0 or 1 scores is valid.

Prototype
int is_ranked(const int scores[], size_t len);
Example
int a[] = {90, 75, 40};
int b[] = {90, 90, 40};
printf("%d\n", is_ranked(a, 3));
printf("%d\n", is_ranked(b, 3));
printf("%d\n", is_ranked(b, 1));
printf("%d\n", is_ranked(a, 0));
Output
1
0
1
1
Solution
int is_ranked(const int scores[], size_t len)
{
    for (size_t i = 1; i < len; i++)
    {
        if (scores[i] >= scores[i - 1])
        {
            return 0;
        }
    }
    return 1;
}

Each cell is compared with the previous one, starting from index 1: never a cell -1, and arrays of 0 or 1 cells do not enter the loop.

answers/pay_tax.c

fundamentals

Removes tax coins from each member, in the array itself. A fortune never goes below 0. A negative tax is treated as 0.

Prototype
void pay_tax(int gold[], size_t len, int tax);
Example
int gold[] = {50, 8, 0, 10};
pay_tax(gold, 4, 10);
printf("%d %d %d %d\n", gold[0], gold[1], gold[2], gold[3]);
pay_tax(gold, 4, -5);
printf("%d %d %d %d\n", gold[0], gold[1], gold[2], gold[3]);
Output
40 0 0 0
40 0 0 0
Solution
void pay_tax(int gold[], size_t len, int tax)
{
    if (tax < 0)
    {
        tax = 0;
    }
    for (size_t i = 0; i < len; i++)
    {
        gold[i] -= tax;
        if (gold[i] < 0)
        {
            gold[i] = 0;
        }
    }
}

No const: the function modifies the array, and the caller sees the new values (the array is not copied).

answers/rotate_left.c

fundamentals

Rotates the queue one step to the left: each element moves forward one cell and the first one goes to the end. Does nothing if len is 0.

Prototype
void rotate_left(int queue[], size_t len);
Example
int queue[] = {1, 2, 3, 4};
rotate_left(queue, 4);
printf("%d %d %d %d\n", queue[0], queue[1], queue[2], queue[3]);
rotate_left(queue, 4);
printf("%d %d %d %d\n", queue[0], queue[1], queue[2], queue[3]);
Output
2 3 4 1
3 4 1 2
Hint

Set the first one aside, shift the others to the left, then put it in the last cell. Watch out for len - 1 when len is 0: with a size_t, it gives a huge number.

Solution
void rotate_left(int queue[], size_t len)
{
    if (len == 0)
    {
        return;
    }
    int first = queue[0];
    for (size_t i = 0; i + 1 < len; i++)
    {
        queue[i] = queue[i + 1];
    }
    queue[len - 1] = first;
}

answers/best_row.c

proficiencies

Each row of grid contains a team's earnings over 3 quests. Returns the index of the row whose sum is the largest (the first one in case of a tie), or -1 if rows is 0.

Prototype
int best_row(int grid[][3], size_t rows);
Example
int grid[3][3] = {
    {1, 2, 3},
    {9, 0, 0},
    {4, 4, 4}
};
printf("%d\n", best_row(grid, 3));
printf("%d\n", best_row(grid, 2));
printf("%d\n", best_row(grid, 0));
Output
2
1
-1
Solution
int best_row(int grid[][3], size_t rows)
{
    if (rows == 0)
    {
        return -1;
    }
    size_t best = 0;
    int best_sum = grid[0][0] + grid[0][1] + grid[0][2];
    for (size_t r = 1; r < rows; r++)
    {
        int sum = 0;
        for (size_t c = 0; c < 3; c++)
        {
            sum += grid[r][c];
        }
        if (sum > best_sum)
        {
            best_sum = sum;
            best = r;
        }
    }
    return best;
}

Row sums: 6, 9 and 12. With rows = 2, only the first two count.

Strings

answers/tag_length.c

fundamentals

Returns the number of characters of tag, not counting the '\0'. <string.h> is not allowed.

Prototype
size_t tag_length(const char *tag);
Example
printf("%zu\n", tag_length("guild"));
printf("%zu\n", tag_length(""));
printf("%zu\n", tag_length("a b"));
Output
5
0
3
Solution
size_t tag_length(const char *tag)
{
    size_t len = 0;
    while (tag[len] != '\0')
    {
        len++;
    }
    return len;
}

The space is a character like any other. Printing a size_t: %zu.

answers/count_vowels.c

fundamentals

Returns the number of vowels (a e i o u, lowercase or uppercase) in str.

Prototype
int count_vowels(const char *str);
Example
printf("%d\n", count_vowels("Guild Master"));
printf("%d\n", count_vowels("RHYTHM"));
printf("%d\n", count_vowels("AEIOU aeiou"));
Output
4
0
10
Solution
int count_vowels(const char *str)
{
    int count = 0;
    for (size_t i = 0; str[i] != '\0'; i++)
    {
        char c = str[i];
        if (c >= 'A' && c <= 'Z')
        {
            c = c - 'A' + 'a';
        }
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u')
        {
            count++;
        }
    }
    return count;
}

The character is lowercased in a copy (c): the string, being const, is not modified.

answers/capitalize_words.c

fundamentals

Capitalizes the first letter of each word of str, in place. A word starts at the beginning of the string or right after a space. The other characters do not change.

Prototype
void capitalize_words(char *str);
Example
char a[] = "the iron guild";
char b[] = "  two  spaces";
char c[] = "42 rats";
capitalize_words(a);
capitalize_words(b);
capitalize_words(c);
printf("[%s]\n[%s]\n[%s]\n", a, b, c);
Output
[The Iron Guild]
[  Two  Spaces]
[42 Rats]
Solution
void capitalize_words(char *str)
{
    for (size_t i = 0; str[i] != '\0'; i++)
    {
        int starts_word = (i == 0 || str[i - 1] == ' ');
        if (starts_word && str[i] >= 'a' && str[i] <= 'z')
        {
            str[i] = str[i] - 'a' + 'A';
        }
    }
}

i == 0 is tested first: thanks to the ||, str[i - 1] is never read when i is 0. In “42 rats”, the word “42” starts with a digit, which does not change.

answers/same_member.c

proficiencies

Returns 1 if a and b are the same name ignoring case, 0 otherwise.

Prototype
int same_member(const char *a, const char *b);
Example
printf("%d\n", same_member("Arthur", "aRTHUR"));
printf("%d\n", same_member("Arthur", "Arthu"));
printf("%d\n", same_member("Ada", "Ida"));
printf("%d\n", same_member("", ""));
Output
1
0
0
1
Hint

Like my_strcmp (course 3, part 4): move forward while both strings continue and the characters, lowercased, are equal. At the end, both strings must end together.

Solution
int same_member(const char *a, const char *b)
{
    size_t i = 0;
    while (a[i] != '\0' && b[i] != '\0')
    {
        char x = a[i];
        char y = b[i];
        if (x >= 'A' && x <= 'Z')
        {
            x = x - 'A' + 'a';
        }
        if (y >= 'A' && y <= 'Z')
        {
            y = y - 'A' + 'a';
        }
        if (x != y)
        {
            return 0;
        }
        i++;
    }
    return a[i] == b[i];
}

The last test is 1 only if both strings have ended ('\0' on both sides): “Arthur” against “Arthu” compares 'r' with '\0'.

answers/count_words.c

proficiencies

Returns the number of words in str. Words are separated by one or more spaces; there may be some at the beginning and at the end.

Prototype
int count_words(const char *str);
Example
printf("%d\n", count_words("join the guild"));
printf("%d\n", count_words("  many   spaces  here "));
printf("%d\n", count_words(""));
printf("%d\n", count_words("solo"));
Output
3
3
0
1
Hint

Counting the spaces does not work (several spaces in a row). Count the starts of words instead: a character that is not a space while you were not inside a word.

Solution
int count_words(const char *str)
{
    int count = 0;
    int in_word = 0;
    for (size_t i = 0; str[i] != '\0'; i++)
    {
        if (str[i] == ' ')
        {
            in_word = 0;
        }
        else if (!in_word)
        {
            in_word = 1;
            count++;
        }
    }
    return count;
}

answers/is_valid_tag.c

proficiencies

A guild handle is valid if it is between 1 and 12 characters long, starts with a lowercase letter, and contains only lowercase letters, digits and '_'. Returns 1 if it is valid, 0 otherwise.

Prototype
int is_valid_tag(const char *tag);
Example
printf("%d\n", is_valid_tag("arthur_42"));
printf("%d\n", is_valid_tag("42arthur"));
printf("%d\n", is_valid_tag(""));
printf("%d\n", is_valid_tag("Arthur"));
printf("%d\n", is_valid_tag("twelve_chars"));
printf("%d\n", is_valid_tag("thirteen_char"));
Output
1
0
0
0
1
0
Solution
int is_valid_tag(const char *tag)
{
    if (tag[0] < 'a' || tag[0] > 'z')
    {
        return 0;
    }
    size_t i = 1;
    while (tag[i] != '\0')
    {
        char c = tag[i];
        int ok = (c >= 'a' && c <= 'z') || (c >= '0' && c <= '9') || c == '_';
        if (!ok || i >= 12)
        {
            return 0;
        }
        i++;
    }
    return 1;
}

The empty string is rejected by the first test ('\0' is not a lowercase letter). A 13th character is at index 12: i >= 12 rejects it.

answers/parse_gold.c

proficiencies

Converts an amount written in digits, like "250", to an integer. Returns -1 if the string is empty or contains anything other than a digit.

Prototype
int parse_gold(const char *str);
Example
printf("%d\n", parse_gold("250"));
printf("%d\n", parse_gold("007"));
printf("%d\n", parse_gold("12a"));
printf("%d\n", parse_gold(""));
printf("%d\n", parse_gold("-5"));
Output
250
7
-1
-1
-1
Hint

Read from left to right: value = value * 10 + digit, with digit = str[i] - '0'.

Solution
int parse_gold(const char *str)
{
    if (str[0] == '\0')
    {
        return -1;
    }
    int value = 0;
    for (size_t i = 0; str[i] != '\0'; i++)
    {
        if (str[i] < '0' || str[i] > '9')
        {
            return -1;
        }
        value = value * 10 + (str[i] - '0');
    }
    return value;
}

“250”: 0 × 10 + 2 = 2, then 2 × 10 + 5 = 25, then 25 × 10 + 0 = 250.
