Characters, then a zero.

C has no “string” type. A string is an array of char whose end is marked by a special character, '\0'. All the functions on strings move forward cell by cell until this zero: if it is missing, they carry on into the neighboring memory.

Part 1 Lecture 2: From Arrays to Strings, The Null Terminator

A char array that ends with '\0'

Definition

A string is an array of char ended by the null character '\0' (code 0), which means “end of the string”. Every string is an array of char; an array of char without '\0' is not a string.

char a[] = {'H', 'i', '\0'};   // a string
char b[] = "Hello";            // '\0' added for you
char c[] = {'H', 'i'};         // NOT a string

printf("%s\n", a);
printf("%s\n", b);
printf("%zu %zu\n", sizeof(b), strlen(b));
printf("%c%c\n", c[0], c[1]);  // fine: char by char

$ ./nul
Hi
Hello
6 5
Hi
To remember
  • In double quotes, "Hello", the final '\0' is added automatically.
  • printf("%s", s) prints the characters up to the '\0'. Without it (the array c), it carries on into the neighboring memory: undefined behavior.
  • sizeof counts the cells of the array, '\0' included; strlen (from <string.h>) counts the characters before the '\0'.
  • To store n characters, you need n + 1 cells.
  • 'a' is a character (a char); "a" is a string of 2 cells: 'a' then '\0'.
In a prototype: char s[] or char *s

As a parameter, const char s[] and const char *s mean the same thing: the function receives the address of the start of the string. The practical statements write char *; in both cases, you read the characters with s[i]. The star will be explained with pointers.

Part 2 Lecture 2: Computing a String Length

Looping through a string, characters are numbers

You do not know the length in advance: you move forward as long as the current cell is not '\0'. That is exactly what strlen does, and you must know how to rewrite it when only <stdio.h> is allowed.

#include <stdio.h>

size_t my_strlen(const char *s)
{
    size_t i = 0;
    while (s[i] != '\0')
    {
        i++;
    }
    return i;
}

int count_char(const char *s, char c)
{
    int count = 0;
    for (size_t i = 0; s[i] != '\0'; i++)
    {
        if (s[i] == c)
        {
            count++;
        }
    }
    return count;
}

int main(void)
{
    printf("%zu\n", my_strlen("robot"));
    printf("%zu\n", my_strlen(""));
    printf("%d\n", count_char("banana", 'a'));
    return 0;
}

$ ./strlen
5
0
3

Letters and digits follow one another: you compute with the characters themselves, without learning the codes.

char c = 'g';
char d = '7';

printf("%c\n", c - 'a' + 'A');   // to upper case
printf("%d\n", d - '0');         // digit value
printf("%d\n", c - 'a');         // rank in alphabet
printf("%c\n", 'a' + 25);

Traps
  • The stopping condition is s[i] != '\0', not i < sizeof(s): in a function, sizeof does not give the size of the string.
  • strlen returns a size_t: for (int i = 0; i < strlen(s); i++) does not compile (signed / unsigned comparison, as in course 2).
  • A char as an array index (count[s[i]]) does not compile: error: array subscript has type 'char'. Cast it: count[(unsigned char)s[i]].
  • '0' (the character, code 48) is not '\0' (the end, code 0).

Part 3 the classic loops of the practicals

Modifying a string in place

A string stored in an array (char s[] = "…") is modified cell by cell, and the function that receives it modifies the caller's (like an array). You never touch the '\0'.

#include <stdio.h>

void to_upper(char *s)
{
    for (size_t i = 0; s[i] != '\0'; i++)
    {
        if (s[i] >= 'a' && s[i] <= 'z')
        {
            s[i] = s[i] - 'a' + 'A';
        }
    }
}

void reverse_string(char *s)
{
    size_t len = 0;
    while (s[len] != '\0')
    {
        len++;
    }
    for (size_t i = 0; i < len / 2; i++)
    {
        char tmp = s[i];
        s[i] = s[len - 1 - i];
        s[len - 1 - i] = tmp;
    }
}

void replace_char(char *s, char old, char new_char)
{
    for (size_t i = 0; s[i] != '\0'; i++)
    {
        if (s[i] == old)
        {
            s[i] = new_char;
        }
    }
}

int main(void)
{
    char name[] = "Ada Lovelace 1815";
    char word[] = "stressed";
    char path[] = "a-b-c";

    to_upper(name);
    reverse_string(word);
    replace_char(path, '-', '/');
    printf("%s\n%s\n%s\n", name, word, path);
    return 0;
}

$ ./inplace
ADA LOVELACE 1815
desserts
a/b/c
A string literal cannot be modified

char s[] = "hello"; creates an array of your own, which can be modified. char *s = "hello"; designates the string literal itself, which is read-only: modifying it compiles, then crashes.

#include <stdio.h>

int main(void)
{
    char *s = "hello";
    s[0] = 'H';
    printf("%s\n", s);
    return 0;
}

$ ./literal
Segmentation fault (core dumped)
Traps
  • Uppercase: only if it is a lowercase letter. Spaces, digits and capitals stay as they are.
  • Reversing: compute the length first, swap up to len / 2, and do not move the '\0' (it stays at s[len]).

Part 4 Lecture 2: Comparing Strings, The Three Big Rules

Comparing, copying

== between two strings compares their addresses, not their contents. Two different arrays that contain "cat" are never at the same address. gcc even refuses to compare two arrays:

#include <stdio.h>

int main(void)
{
    char a[] = "cat";
    char b[] = "cat";

    if (a == b)
    {
        printf("same\n");
    }
    return 0;
}

$ gcc -Wall -Wextra -Werror -std=c99 cmp.c
cmp.c:8:11: error: comparison between two arrays [-Werror=array-compare]
cc1: all warnings being treated as errors
strcmp (from <string.h>)

strcmp(a, b) is 0 if the two strings are equal, a negative number if a comes before b in code order, positive otherwise. So you test strcmp(a, b) == 0, and never if (strcmp(a, b)) for “equal”.

Rewritten with <stdio.h> only, the comparison, the copy and the palindrome test:

#include <stdio.h>

int my_strcmp(const char *a, const char *b)
{
    size_t i = 0;
    while (a[i] != '\0' && a[i] == b[i])
    {
        i++;
    }
    return a[i] - b[i];
}

void my_strcpy(char *dest, const char *src)    // dest must be large enough
{
    size_t i = 0;
    while (src[i] != '\0')
    {
        dest[i] = src[i];
        i++;
    }
    dest[i] = '\0';
}

int is_palindrome(const char *s)
{
    size_t len = 0;
    while (s[len] != '\0')
    {
        len++;
    }
    for (size_t i = 0; i < len / 2; i++)
    {
        if (s[i] != s[len - 1 - i])
        {
            return 0;
        }
    }
    return 1;
}

int main(void)
{
    char copy[16];

    printf("%d\n", my_strcmp("cat", "cat") == 0);
    printf("%d\n", my_strcmp("cat", "dog") < 0);
    printf("%d\n", my_strcmp("cats", "cat") > 0);
    my_strcpy(copy, "kayak");
    printf("%s %d\n", copy, is_palindrome(copy));
    printf("%d %d\n", is_palindrome("robot"), is_palindrome(""));
    return 0;
}

$ ./cmpcopy
1
1
1
kayak 1
0 1
Traps
  • The copy must write the final '\0', after the loop. Without it, copy is not a string.
  • The destination must have at least length + 1 cells.
  • my_strcmp also stops when a ends: "cats" against "cat" compares 's' with '\0'.

Part 5 Lecture 2: Reading a Line Safely, Tiny Challenge

Reading a line: fgets

fgets(array, size, stdin)
  • Reads a line typed on the keyboard (stdin) into the array, never exceeding size - 1 characters (it keeps one cell for '\0'). You pass sizeof(line).
  • Returns NULL if there is nothing left to read: you test for it.
  • Keeps the final '\n' if there is room: you must remove it before comparing.
#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[64];

    printf("Spell: ");
    if (fgets(line, sizeof(line), stdin) == NULL)
    {
        return 1;
    }

    size_t n = strlen(line);
    if (n > 0 && line[n - 1] == '\n')
    {
        line[n - 1] = '\0';
    }

    if (strcmp(line, "fireball") == 0)
    {
        printf("Boom! (%zu letters)\n", strlen(line));
    }
    else
    {
        printf("Nothing happens.\n");
    }
    return 0;
}

$ echo "fireball" | ./fgets
Spell: Boom! (8 letters)
