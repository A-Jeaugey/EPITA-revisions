Le format des TP 1 et 2

Ce que la moulinette attend

Le TP noté est probablement le « 102p03 » des modalités d'évaluation : il suit le format des deux premiers TP. Le sujet du jour fera foi s'il diffère.

Arborescence sur le modèle du TP 2 
epita-prepa-computer-science-prog-102-p-03-2031-prenom.nom
├── nom_du_sujet
│   ├── answers
│   │   ├── sum_gold.c
│   │   └── count_vowels.c
│   └── includes
│       ├── sum_gold.h
│       └── count_vowels.h
├── .gitignore
└── README

Une fonction par fichier : answers/nom.c la définit, includes/nom.h la déclare entre des gardes, et le .c inclut son propre en-tête.

includes/sum_gold.h 
#ifndef SUM_GOLD_H
#define SUM_GOLD_H

#include <stdio.h>

int sum_gold(const int purses[], size_t len);

#endif
answers/sum_gold.c 
#include "../includes/sum_gold.h"

int sum_gold(const int purses[], size_t len)
{
    int total = 0;
    for (size_t i = 0; i < len; i++)
    {
        total += purses[i];
    }
    return total;
}

Le chemin de l'#include suit le squelette fourni. <stdio.h> dans l'en-tête donne size_t au prototype.

Les règles des sujets
  • En cas de désaccord entre le sujet et le squelette ou la moulinette, le sujet a raison (signale-le à l'assistant).
  • Le code doit compiler : sinon, aucune note. La commande : gcc -Wall -Wextra -Werror -std=c99.
  • Les prototypes donnés sont à respecter strictement : nom, type de retour, types et ordre des paramètres.
  • Retire tes tests personnels : la moulinette apporte son propre main. Un main dans answers/ empêche l'édition de liens.
  • Seul ce qui est autorisé (en-têtes, mots-clés) peut servir. Au TP 1 : <stdio.h> seulement, donc pas de strlen ni de strcmp tout faits.
  • Le .gitignore est obligatoire, avant le premier rendu (exécutables, *.o, *.out, *~…).
  • Une fonction oui / non renvoie exactement 0 ou 1. Une sortie printf se recopie au caractère près, retour à la ligne final compris.

$ git status

  • Un tag submit-* rend le travail (aux TP 1 et 2 : 3 par semaine). Chaque tag a un nom unique : submit-1, submit-2…

Pendant le TP

La routine, fonction par fonction

Elle évite les zéros bêtes : un fichier mal placé, un test oublié, un avertissement.

  1. Lis la consigne et les exemples en entier : ils fixent les cas limites (tableau vide, chaîne vide, valeur négative, « au plus » ou « strictement »).
  2. Crée includes/nom.h (gardes et prototype recopié) et answers/nom.c (qui inclut l'en-tête).
  3. Écris les cas limites d'abord, puis la boucle. Tableau : for (size_t i = 0; i < len; i++). Chaîne : for (size_t i = 0; s[i] != '\0'; i++).
  4. Teste dans un main.c à toi, hors de answers/, avec les exemples du sujet : gcc -Wall -Wextra -Werror -std=c99 main.c answers/nom.c -o test.
  5. Compare ta sortie à celle du sujet, caractère par caractère.
  6. git add des deux fichiers, commit, tag archi-* si tu as un doute sur l'arborescence, puis push --follow-tags. Rends souvent : un rendu partiel vaut mieux que rien.
Vérifiés avec gcc

Les pièges du jour

Chacun est montré, avec le vrai message de gcc, dans les cours.

Ne compile pas avec les options des TP
  • Variable ou paramètre inutilisé. Cours 1
  • int i comparé à un size_t (len, strlen, sizeof). Cours 2
  • size_t i … i >= 0 dans une boucle à l'envers. Cours 2
  • sizeof sur un tableau reçu en paramètre. Cours 2
  • a == b entre deux tableaux de char. Cours 3
  • Un char comme indice de tableau. Cours 3
  • case sans break, = dans un if, fonction non void sans return final, format printf faux. Cours 1
Compile, mais faux
  • i <= len : une case de trop, comportement indéfini. Cours 2
  • Maximum initialisé à 0 avec des valeurs négatives ; tableau vide oublié.
  • -1 renvoyé dans un else au premier tour au lieu d'après la boucle.
  • Copie de chaîne sans le '\0' final ; destination trop petite.
  • '0' pris pour '\0' ; minuscule convertie sans tester que c'en est une.
  • Modifier une chaîne littérale (char *s = "…") : plantage.
  • Somme ou compteur non initialisé.
TP blanc · « The Guild Ledger »

Quinze fonctions au format de la moulinette

Des exercices écrits pour le site, au niveau et dans la forme des TP 1 et 2 : consigne, prototype, exemple et sortie exacte. Seul <stdio.h> est autorisé. Chaque corrigé a été compilé avec les options des TP et sa sortie comparée à celle annoncée.

Les tableaux

answers/sum_gold.c

fondamental

Renvoie la somme des len bourses du tableau purses. Si len vaut 0, renvoie 0.

Prototype
int sum_gold(const int purses[], size_t len);
Exemple
int purses[] = {12, 5, 30};
printf("%d\n", sum_gold(purses, 3));
printf("%d\n", sum_gold(purses, 2));
printf("%d\n", sum_gold(purses, 0));
Sortie
47
17
0
Corrigé
int sum_gold(const int purses[], size_t len)
{
    int total = 0;
    for (size_t i = 0; i < len; i++)
    {
        total += purses[i];
    }
    return total;
}

Le cas len == 0 n'a pas besoin d'être traité à part : la boucle ne tourne pas et total vaut 0. Il faut en revanche l'initialiser.

answers/richest_member.c

fondamental

Renvoie l'indice du membre le plus riche du tableau gold. En cas d'égalité, le premier. Si len vaut 0, renvoie -1. Les montants peuvent être négatifs (dettes).

Prototype
int richest_member(const int gold[], size_t len);
Exemple
int gold[] = {40, 95, 12, 95};
int debts[] = {-3, -1, -7};
printf("%d\n", richest_member(gold, 4));
printf("%d\n", richest_member(debts, 3));
printf("%d\n", richest_member(gold, 0));
Sortie
1
1
-1
Indice

Garde l'indice du meilleur, pas sa valeur. Pars de l'indice 0 (jamais d'une valeur 0, à cause des dettes) et ne remplace qu'avec > strict pour garder le premier.

Corrigé
int richest_member(const int gold[], size_t len)
{
    if (len == 0)
    {
        return -1;
    }
    size_t best = 0;
    for (size_t i = 1; i < len; i++)
    {
        if (gold[i] > gold[best])
        {
            best = i;
        }
    }
    return best;
}

answers/find_last.c

fondamental

Renvoie l'indice de la dernière occurrence de badge dans badges, ou -1 s'il n'y figure pas.

Prototype
int find_last(const int badges[], size_t len, int badge);
Exemple
int badges[] = {7, 3, 7, 9};
printf("%d\n", find_last(badges, 4, 7));
printf("%d\n", find_last(badges, 4, 9));
printf("%d\n", find_last(badges, 4, 4));
Sortie
2
3
-1
Indice

Parcours à l'envers pour s'arrêter à la première trouvée, sans le piège du size_t i >= 0 (cours 2, partie 2). Autre solution : parcours à l'endroit en retenant le dernier indice vu.

Corrigé
int find_last(const int badges[], size_t len, int badge)
{
    for (size_t i = len; i > 0; i--)
    {
        if (badges[i - 1] == badge)
        {
            return i - 1;
        }
    }
    return -1;
}

answers/is_ranked.c

fondamental

Un classement est valide si les scores sont strictement décroissants. Renvoie 1 s'il est valide, 0 sinon. Un tableau de 0 ou 1 score est valide.

Prototype
int is_ranked(const int scores[], size_t len);
Exemple
int a[] = {90, 75, 40};
int b[] = {90, 90, 40};
printf("%d\n", is_ranked(a, 3));
printf("%d\n", is_ranked(b, 3));
printf("%d\n", is_ranked(b, 1));
printf("%d\n", is_ranked(a, 0));
Sortie
1
0
1
1
Corrigé
int is_ranked(const int scores[], size_t len)
{
    for (size_t i = 1; i < len; i++)
    {
        if (scores[i] >= scores[i - 1])
        {
            return 0;
        }
    }
    return 1;
}

On compare chaque case à la précédente, en partant de l'indice 1 : jamais de case -1, et les tableaux de 0 ou 1 case ne passent pas dans la boucle.

answers/pay_tax.c

fondamental

Retire tax pièces à chaque membre, dans le tableau lui-même. Une fortune ne descend jamais sous 0. Une taxe négative est traitée comme 0.

Prototype
void pay_tax(int gold[], size_t len, int tax);
Exemple
int gold[] = {50, 8, 0, 10};
pay_tax(gold, 4, 10);
printf("%d %d %d %d\n", gold[0], gold[1], gold[2], gold[3]);
pay_tax(gold, 4, -5);
printf("%d %d %d %d\n", gold[0], gold[1], gold[2], gold[3]);
Sortie
40 0 0 0
40 0 0 0
Corrigé
void pay_tax(int gold[], size_t len, int tax)
{
    if (tax < 0)
    {
        tax = 0;
    }
    for (size_t i = 0; i < len; i++)
    {
        gold[i] -= tax;
        if (gold[i] < 0)
        {
            gold[i] = 0;
        }
    }
}

Pas de const : la fonction modifie le tableau, et l'appelant voit les nouvelles valeurs (le tableau n'est pas copié).

answers/rotate_left.c

fondamental

Fait tourner la file d'attente d'un cran vers la gauche : chaque élément avance d'une case et le premier passe à la fin. Ne fait rien si len vaut 0.

Prototype
void rotate_left(int queue[], size_t len);
Exemple
int queue[] = {1, 2, 3, 4};
rotate_left(queue, 4);
printf("%d %d %d %d\n", queue[0], queue[1], queue[2], queue[3]);
rotate_left(queue, 4);
printf("%d %d %d %d\n", queue[0], queue[1], queue[2], queue[3]);
Sortie
2 3 4 1
3 4 1 2
Indice

Mets le premier de côté, décale les autres vers la gauche, puis pose-le dans la dernière case. Attention à len - 1 quand len vaut 0 : avec un size_t, cela donne un nombre immense.

Corrigé
void rotate_left(int queue[], size_t len)
{
    if (len == 0)
    {
        return;
    }
    int first = queue[0];
    for (size_t i = 0; i + 1 < len; i++)
    {
        queue[i] = queue[i + 1];
    }
    queue[len - 1] = first;
}

answers/best_row.c

approfondi

Chaque ligne de grid contient les gains d'une équipe sur 3 quêtes. Renvoie l'indice de la ligne dont la somme est la plus grande (la première en cas d'égalité), ou -1 si rows vaut 0.

Prototype
int best_row(int grid[][3], size_t rows);
Exemple
int grid[3][3] = {
    {1, 2, 3},
    {9, 0, 0},
    {4, 4, 4}
};
printf("%d\n", best_row(grid, 3));
printf("%d\n", best_row(grid, 2));
printf("%d\n", best_row(grid, 0));
Sortie
2
1
-1
Corrigé
int best_row(int grid[][3], size_t rows)
{
    if (rows == 0)
    {
        return -1;
    }
    size_t best = 0;
    int best_sum = grid[0][0] + grid[0][1] + grid[0][2];
    for (size_t r = 1; r < rows; r++)
    {
        int sum = 0;
        for (size_t c = 0; c < 3; c++)
        {
            sum += grid[r][c];
        }
        if (sum > best_sum)
        {
            best_sum = sum;
            best = r;
        }
    }
    return best;
}

Sommes des lignes : 6, 9 et 12. Avec rows = 2, seules les deux premières comptent.

Les chaînes

answers/tag_length.c

fondamental

Renvoie le nombre de caractères de tag, sans compter le '\0'. <string.h> n'est pas autorisé.

Prototype
size_t tag_length(const char *tag);
Exemple
printf("%zu\n", tag_length("guild"));
printf("%zu\n", tag_length(""));
printf("%zu\n", tag_length("a b"));
Sortie
5
0
3
Corrigé
size_t tag_length(const char *tag)
{
    size_t len = 0;
    while (tag[len] != '\0')
    {
        len++;
    }
    return len;
}

L'espace est un caractère comme un autre. Affichage d'un size_t : %zu.

answers/count_vowels.c

fondamental

Renvoie le nombre de voyelles (a e i o u, minuscules ou majuscules) de str.

Prototype
int count_vowels(const char *str);
Exemple
printf("%d\n", count_vowels("Guild Master"));
printf("%d\n", count_vowels("RHYTHM"));
printf("%d\n", count_vowels("AEIOU aeiou"));
Sortie
4
0
10
Corrigé
int count_vowels(const char *str)
{
    int count = 0;
    for (size_t i = 0; str[i] != '\0'; i++)
    {
        char c = str[i];
        if (c >= 'A' && c <= 'Z')
        {
            c = c - 'A' + 'a';
        }
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u')
        {
            count++;
        }
    }
    return count;
}

On passe le caractère en minuscule dans une copie (c) : la chaîne, en const, n'est pas modifiée.

answers/capitalize_words.c

fondamental

Met en majuscule la première lettre de chaque mot de str, sur place. Un mot commence au début de la chaîne ou juste après une espace. Les autres caractères ne changent pas.

Prototype
void capitalize_words(char *str);
Exemple
char a[] = "the iron guild";
char b[] = "  two  spaces";
char c[] = "42 rats";
capitalize_words(a);
capitalize_words(b);
capitalize_words(c);
printf("[%s]\n[%s]\n[%s]\n", a, b, c);
Sortie
[The Iron Guild]
[  Two  Spaces]
[42 Rats]
Corrigé
void capitalize_words(char *str)
{
    for (size_t i = 0; str[i] != '\0'; i++)
    {
        int starts_word = (i == 0 || str[i - 1] == ' ');
        if (starts_word && str[i] >= 'a' && str[i] <= 'z')
        {
            str[i] = str[i] - 'a' + 'A';
        }
    }
}

i == 0 est testé en premier : grâce au ||, str[i - 1] n'est jamais lu quand i vaut 0. Dans « 42 rats », le mot « 42 » commence par un chiffre, qui ne change pas.

answers/same_member.c

approfondi

Renvoie 1 si a et b sont le même nom sans tenir compte des majuscules, 0 sinon.

Prototype
int same_member(const char *a, const char *b);
Exemple
printf("%d\n", same_member("Arthur", "aRTHUR"));
printf("%d\n", same_member("Arthur", "Arthu"));
printf("%d\n", same_member("Ada", "Ida"));
printf("%d\n", same_member("", ""));
Sortie
1
0
0
1
Indice

Comme my_strcmp (cours 3, partie 4) : avance tant que les deux chaînes continuent et que les caractères, mis en minuscule, sont égaux. À la fin, les deux chaînes doivent se terminer ensemble.

Corrigé
int same_member(const char *a, const char *b)
{
    size_t i = 0;
    while (a[i] != '\0' && b[i] != '\0')
    {
        char x = a[i];
        char y = b[i];
        if (x >= 'A' && x <= 'Z')
        {
            x = x - 'A' + 'a';
        }
        if (y >= 'A' && y <= 'Z')
        {
            y = y - 'A' + 'a';
        }
        if (x != y)
        {
            return 0;
        }
        i++;
    }
    return a[i] == b[i];
}

Le dernier test vaut 1 seulement si les deux chaînes sont finies ('\0' des deux côtés) : « Arthur » contre « Arthu » compare 'r' à '\0'.

answers/count_words.c

approfondi

Renvoie le nombre de mots de str. Les mots sont séparés par une ou plusieurs espaces ; il peut y en avoir au début et à la fin.

int count_words(const char *str);
Exemple
printf("%d\n", count_words("join the guild"));

3
3
0
1
Indice

Compter les espaces ne marche pas (plusieurs espaces à la suite). Compte plutôt les débuts de mot : un caractère qui n'est pas une espace alors qu'on n'était pas dans un mot.

Corrigé
int count_words(const char *str)
{

    int in_word = 0;
    for (size_t i = 0; str[i] != '\0'; i++)

        if (str[i] == ' ')
        {
            in_word = 0;
        }
        else if (!in_word)
        {
            in_word = 1;
            count++;
        }
    }
    return count;
}

answers/is_valid_tag.c

approfondi

Un pseudo de guilde est valide s'il fait entre 1 et 12 caractères, commence par une lettre minuscule, et ne contient que des lettres minuscules, des chiffres et '_'. Renvoie 1 s'il est valide, 0 sinon.

Prototype
int is_valid_tag(const char *tag);
Exemple
printf("%d\n", is_valid_tag("arthur_42"));
printf("%d\n", is_valid_tag("42arthur"));
printf("%d\n", is_valid_tag(""));
printf("%d\n", is_valid_tag("Arthur"));
printf("%d\n", is_valid_tag("twelve_chars"));
printf("%d\n", is_valid_tag("thirteen_char"));
Sortie
1
0
0
0
1
0
Corrigé
int is_valid_tag(const char *tag)
{
    if (tag[0] < 'a' || tag[0] > 'z')
    {
        return 0;
    }
    size_t i = 1;
    while (tag[i] != '\0')
    {
        char c = tag[i];
        int ok = (c >= 'a' && c <= 'z') || (c >= '0' && c <= '9') || c == '_';
        if (!ok || i >= 12)
        {
            return 0;
        }
        i++;
    }
    return 1;
}

La chaîne vide est rejetée par le premier test ('\0' n'est pas une minuscule). Un 13ᵉ caractère se trouve à l'indice 12 : i >= 12 le refuse.

answers/parse_gold.c

approfondi

Convertit en entier un montant écrit en chiffres, comme "250". Renvoie -1 si la chaîne est vide ou contient autre chose qu'un chiffre.

Prototype
int parse_gold(const char *str);
Exemple
printf("%d\n", parse_gold("250"));
printf("%d\n", parse_gold("007"));
printf("%d\n", parse_gold("12a"));
printf("%d\n", parse_gold(""));
printf("%d\n", parse_gold("-5"));
Sortie
250
7
-1
-1
-1
Indice

Lis de gauche à droite : value = value * 10 + chiffre, avec chiffre = str[i] - '0'.

Corrigé
int parse_gold(const char *str)
{
    if (str[0] == '\0')
    {
        return -1;
    }
    int value = 0;
    for (size_t i = 0; str[i] != '\0'; i++)
    {
        if (str[i] < '0' || str[i] > '9')
        {
            return -1;
        }
        value = value * 10 + (str[i] - '0');
    }
    return value;
}

« 250 » : 0 × 10 + 2 = 2, puis 2 × 10 + 5 = 25, puis 25 × 10 + 0 = 250.
