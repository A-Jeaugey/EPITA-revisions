Une rangée de cases côte à côte.

Un tableau, c'est un nombre fixe de cases du même type, rangées l'une après l'autre en mémoire, numérotées à partir de 0. Le C ne vérifie jamais que l'indice est valide, et une fonction ne connaît pas la taille du tableau qu'on lui passe : il faut la lui donner.

Les trois règles du CM
  • Indices valides : de 0 à longueur - 1.
  • Tableau en paramètre : on passe le tableau et sa longueur.
  • Chaîne : un tableau de char qui finit par '\0' (cours 3).

Partie 1 CM 2 : Arrays in One Sentence, Declaration, Indexing

Déclarer, initialiser, indexer

Définition

Un tableau est une rangée de cases de taille fixe, toutes du même type, placées les unes après les autres en mémoire (contiguës). On accède à une case par son indice, qui commence à 0.

int a[5];                    // 5 cases, uninitialized
int b[5] = {3, 1, 4, 1, 5};  // initialized
int c[] = {3, 1, 4, 1, 5};   // size deduced: 5
int d[5] = {0};              // every case is 0
int e[5] = {7, 8};           // 7, 8, then 0, 0, 0
En mémoire int b[5] = {3, 1, 4, 1, 5};
[0][1][2][3][4]
31415

b[0] vaut 3 (la première case), b[4] vaut 5 (la cinquième et dernière). Pour une longueur n, les indices valides vont de 0 à n − 1.

int b[5] = {3, 1, 4, 1, 5};
int e[5] = {7, 8};

b[2] = 42;
printf("%d %d %d\n", b[0], b[2], b[4]);
printf("%d %d %d\n", e[1], e[2], e[4]);

$ ./index
3 42 5
8 0 0
Pièges
  • Un tableau local non initialisé contient des valeurs indéterminées. Pour partir de zéros : = {0}.
  • La taille ne change pas : pas d'append comme en Python.
  • On ne copie pas un tableau avec = : on recopie case par case dans une boucle.

Partie 2 CM 2 : Looping Through an Array

Parcourir un tableau : size_t et sizeof

#include <stdio.h>

int main(void)
{
    int a[] = {3, 1, 4, 1, 5};
    size_t n = sizeof(a) / sizeof(a[0]);

    printf("n = %zu\n", n);
    for (size_t i = 0; i < n; i++)
    {
        printf("a[%zu] = %d\n", i, a[i]);
    }
    return 0;
}

$ ./loop
n = 5
a[0] = 3
a[1] = 1
a[2] = 4
a[3] = 1
a[4] = 5
Les outils
  • sizeof donne une taille en octets. sizeof(a) vaut 20 (5 cases de 4 octets) et sizeof(a[0]) vaut 4 : leur quotient est le nombre de cases.
  • size_t est le type des tailles et des indices : un entier sans signe (jamais négatif). Il s'affiche avec %zu. Il est défini dans <stdio.h> (et <stddef.h>).
  • La division par sizeof(a[0]) ne marche que là où le tableau est déclaré, pas dans une fonction qui le reçoit (partie 4).
Deux erreurs de type qui ne compilent pas

Un indice int comparé à un size_t : signé contre non signé, refusé par -Wextra -Werror. Prends un size_t i quand la borne est un size_t.

#include <stdio.h>

int main(void)
{
    int a[] = {1, 2, 3};
    for (int i = 0; i < sizeof(a) / sizeof(a[0]); i++)
    {
        printf("%d\n", a[i]);
    }
    return 0;
}

$ gcc -Wall -Wextra -Werror -std=c99 loop.c
loop.c:6:23: error: comparison of integer expressions of different signedness: 'int' and 'long unsigned int' [-Werror=sign-compare]
cc1: all warnings being treated as errors

Une boucle à l'envers avec size_t : i >= 0 est toujours vrai pour un entier sans signe (après 0 vient un très grand nombre).

#include <stdio.h>

int main(void)
{
    int a[] = {1, 2, 3};
    for (size_t i = 2; i >= 0; i--)
    {
        printf("%d\n", a[i]);
    }
    return 0;
}

$ gcc -Wall -Wextra -Werror -std=c99 rev.c
rev.c:6:26: error: comparison of unsigned expression in '>= 0' is always true [-Werror=type-limits]
cc1: all warnings being treated as errors

À l'envers, la bonne forme part de n et lit la case i - 1 :

int a[] = {1, 2, 3};
size_t n = 3;

for (size_t i = n; i > 0; i--)
{
    printf("%d ", a[i - 1]);
}
printf("\n");

$ ./backward
3 2 1

Partie 3 CM 2 : Will it work?, Arrays and Memory

Sortir des bornes

Le C ne vérifie pas les indices. Lire ou écrire a[3] dans un tableau de 3 cases compile sans un mot de gcc, même avec -Wall -Wextra -Werror. À l'exécution, c'est un comportement indéfini : le programme peut sembler marcher, planter, ou corrompre en silence d'autres variables rangées juste à côté.

#include <stdio.h>

int main(void)
{
    int a[3] = {10, 20, 30};

    for (int i = 0; i <= 3; i++)
    {
        printf("a[%d] = %d\n", i, a[i]);
    }
    return 0;
}
L'erreur classique : <= au lieu de <

Le dernier tour lit a[3], la case après le tableau. Ce qui s'affiche est imprévisible.

[0][1][2][3]
102030?

Les cases étant contiguës, l'accès par indice est très rapide ; c'est aussi pour cela qu'un débordement touche directement la mémoire voisine.

Pour déboguer : AddressSanitizer

Compile avec -fsanitize=address -g : le programme s'arrête au premier accès hors du tableau et donne la ligne fautive.

$ gcc -Wall -Wextra -Werror -std=c99 -fsanitize=address -g oob.c -o oob
$ ./oob
==677==ERROR: AddressSanitizer: stack-buffer-overflow on address 0x7f7ec310002c
READ of size 4 at 0x7f7ec310002c thread T0
    #0 0x5592102b23dc in main oob.c:9

Sortie réelle de ce programme, adresses abrégées. À retirer avant de rendre : la commande des TP n'a pas cette option.

Partie 4 CM 2 : Arrays as Function Parameters, sum_array

Passer un tableau à une fonction

Ce qu'il faut savoir
  • La fonction reçoit le tableau, pas sa taille : on la passe en second paramètre, de type size_t.
  • Le tableau n'est pas copié : si la fonction modifie une case, l'appelant voit la modification. Ce n'est pas comme un int (cours 1, partie 6).
  • const int a[] annonce que la fonction ne modifiera pas le tableau ; écrire dedans ne compile plus.
#include <stdio.h>

void fill(int a[], size_t len, int value)
{
    for (size_t i = 0; i < len; i++)
    {
        a[i] = value;
    }
}

int main(void)
{
    int x[] = {1, 2, 3, 4};

    fill(x, 4, 10);
    for (size_t i = 0; i < 4; i++)
    {
        printf("x[%zu] = %d\n", i, x[i]);
    }
    return 0;
}

$ ./fill
x[0] = 10
x[1] = 10
x[2] = 10
x[3] = 10
sizeof dans la fonction : refusé

Dans la fonction, a n'est plus qu'une adresse : sizeof(a) donnerait la taille d'une adresse (8 octets), pas celle du tableau. gcc le refuse.

#include <stdio.h>

size_t count(const int a[])
{
    return sizeof(a) / sizeof(a[0]);
}

int main(void)
{
    int a[] = {1, 2, 3};
    printf("%zu\n", count(a));
    return 0;
}

$ gcc -Wall -Wextra -Werror -std=c99 count.c
count.c:5:18: error: 'sizeof' on array function parameter 'a' will return size of 'const int *' [-Werror=sizeof-array-argument]
cc1: all warnings being treated as errors

Les algorithmes qui reviennent dans tous les sujets. Ceux qui lisent sans modifier prennent un const int a[] :

#include <stdio.h>

int sum_array(const int a[], size_t len)
{
    int sum = 0;
    for (size_t i = 0; i < len; i++)
    {
        sum += a[i];
    }
    return sum;
}

int max_array(const int a[], size_t len)    // len must be at least 1
{
    int best = a[0];
    for (size_t i = 1; i < len; i++)
    {
        if (a[i] > best)
        {
            best = a[i];
        }
    }
    return best;
}

int count_value(const int a[], size_t len, int value)
{
    int count = 0;
    for (size_t i = 0; i < len; i++)
    {
        if (a[i] == value)
        {
            count++;
        }
    }
    return count;
}

int index_of(const int a[], size_t len, int value)
{
    for (size_t i = 0; i < len; i++)
    {
        if (a[i] == value)
        {
            return i;    // first occurrence
        }
    }
    return -1;           // not found
}

int main(void)
{
    int a[] = {3, 1, 4, 1, 5};
    int neg[] = {-7, -2, -9};

    printf("sum = %d\n", sum_array(a, 5));
    printf("max = %d\n", max_array(a, 5));
    printf("max = %d\n", max_array(neg, 3));
    printf("count of 1 = %d\n", count_value(a, 5, 1));
    printf("index of 4 = %d\n", index_of(a, 5, 4));
    printf("index of 8 = %d\n", index_of(a, 5, 8));
    return 0;
}

$ ./algos
sum = 14
max = 5
max = -2
count of 1 = 2
index of 4 = 2
index of 8 = -1
Modifier sur place : inverser

On échange la première et la dernière case, puis la deuxième et l'avant-dernière… jusqu'au milieu. Un échange passe par une variable temporaire.

#include <stdio.h>

void reverse_array(int a[], size_t len)
{
    for (size_t i = 0; i < len / 2; i++)
    {
        int tmp = a[i];
        a[i] = a[len - 1 - i];
        a[len - 1 - i] = tmp;
    }
}

int main(void)
{
    int a[] = {1, 2, 3, 4, 5};

    reverse_array(a, 5);
    for (size_t i = 0; i < 5; i++)
    {
        printf("%d ", a[i]);
    }
    printf("\n");
    return 0;
}

$ ./reverse
5 4 3 2 1
Pièges
  • Maximum : partir de a[0], pas de 0 (avec des valeurs toutes négatives, 0 serait faux). Traite à part le tableau vide si l'énoncé le prévoit.
  • Recherche : return dès qu'on trouve, et -1 après la boucle, pas dans un else à l'intérieur.
  • Inversion : s'arrêter à len / 2, sinon on ré-échange tout et le tableau revient comme avant.
  • Modifier un const int a[] ne compile pas : error: assignment of read-only location.

Partie 5 CM 2 : Two-Dimensional Arrays, Traversing a 2D Array

Les tableaux à deux dimensions

int grid[2][3] : 2 lignes de 3 colonnes. grid[ligne][colonne], chaque indice partant de 0. En mémoire, les lignes sont rangées l'une après l'autre.

int grid[2][3] = {{1, 2, 3}, {4, 5, 6}};
col 0col 1col 2
ligne 0123
ligne 1456 = grid[1][2]

En mémoire :

123456

On parcourt avec deux boucles imbriquées : les lignes dehors, les colonnes dedans. Pour passer une grille à une fonction, le nombre de colonnes doit figurer dans le paramètre ; seul le nombre de lignes peut manquer et se passe à part.

#include <stdio.h>

int count_walls(int map[][4], size_t rows)
{
    int walls = 0;
    for (size_t r = 0; r < rows; r++)
    {
        for (size_t c = 0; c < 4; c++)
        {
            if (map[r][c] == 1)
            {
                walls++;
            }
        }
    }
    return walls;
}

int main(void)
{
    int map[3][4] = {
        {1, 1, 1, 1},
        {1, 0, 0, 1},
        {1, 1, 0, 1}
    };

    for (size_t r = 0; r < 3; r++)
    {
        for (size_t c = 0; c < 4; c++)
        {
            printf("%d ", map[r][c]);
        }
        printf("\n");
    }
    printf("walls = %d\n", count_walls(map, 3));
    return 0;
}

$ ./grid
1 1 1 1
1 0 0 1
1 1 0 1
walls = 9
Pièges
  • L'ordre est [ligne][colonne] : grid[1][2] est à la ligne 1, colonne 2.
  • Les deux boucles ont leurs propres bornes : lignes jusqu'au nombre de lignes, colonnes jusqu'au nombre de colonnes.
  • Le printf("\n") de fin de ligne se place entre les deux boucles, pas dans la boucle intérieure.
