A row of cells side by side.

An array is a fixed number of cells of the same type, stored one after another in memory, numbered from 0. C never checks that the index is valid, and a function does not know the size of the array you pass it: you have to give it.

Part 1 Lecture 2: Arrays in One Sentence, Declaration, Indexing

Declaring, initializing, indexing

Definition

An array is a row of cells of fixed size, all of the same type, placed one after another in memory (contiguous). You access a cell by its index, which starts at 0.

int a[5];                    // 5 cases, uninitialized
int b[5] = {3, 1, 4, 1, 5};  // initialized
int c[] = {3, 1, 4, 1, 5};   // size deduced: 5
int d[5] = {0};              // every case is 0
int e[5] = {7, 8};           // 7, 8, then 0, 0, 0
In memory int b[5] = {3, 1, 4, 1, 5};
[0][1][2][3][4]
31415

b[0] is 3 (the first cell), b[4] is 5 (the fifth and last). For a length n, the valid indices go from 0 to n − 1.

int b[5] = {3, 1, 4, 1, 5};
int e[5] = {7, 8};

b[2] = 42;
printf("%d %d %d\n", b[0], b[2], b[4]);
printf("%d %d %d\n", e[1], e[2], e[4]);

$ ./index
3 42 5
8 0 0
Traps
  • An uninitialized local array holds indeterminate values. To start from zeros: = {0}.
  • The size does not change: no append as in Python.
  • You do not copy an array with =: you copy it cell by cell in a loop.

Part 2 Lecture 2: Looping Through an Array

Looping through an array: size_t and sizeof

#include <stdio.h>

int main(void)
{
    int a[] = {3, 1, 4, 1, 5};
    size_t n = sizeof(a) / sizeof(a[0]);

    printf("n = %zu\n", n);
    for (size_t i = 0; i < n; i++)
    {
        printf("a[%zu] = %d\n", i, a[i]);
    }
    return 0;
}

$ ./loop
n = 5
a[0] = 3
a[1] = 1
a[2] = 4
a[3] = 1
a[4] = 5
The tools
  • sizeof gives a size in bytes. sizeof(a) is 20 (5 cells of 4 bytes) and sizeof(a[0]) is 4: their quotient is the number of cells.
  • size_t is the type of sizes and indices: an unsigned integer (never negative). It is printed with %zu. It is defined in <stdio.h> (and <stddef.h>).
  • Dividing by sizeof(a[0]) only works where the array is declared, not in a function that receives it (part 4).
Two type errors that do not compile

An int index compared to a size_t: signed against unsigned, rejected by -Wextra -Werror. Use a size_t i when the bound is a size_t.

#include <stdio.h>

int main(void)
{
    int a[] = {1, 2, 3};
    for (int i = 0; i < sizeof(a) / sizeof(a[0]); i++)
    {
        printf("%d\n", a[i]);
    }
    return 0;
}

$ gcc -Wall -Wextra -Werror -std=c99 loop.c
loop.c:6:23: error: comparison of integer expressions of different signedness: 'int' and 'long unsigned int' [-Werror=sign-compare]
cc1: all warnings being treated as errors

A backward loop with size_t: i >= 0 is always true for an unsigned integer (after 0 comes a very large number).

#include <stdio.h>

int main(void)
{
    int a[] = {1, 2, 3};
    for (size_t i = 2; i >= 0; i--)
    {
        printf("%d\n", a[i]);
    }
    return 0;
}

$ gcc -Wall -Wextra -Werror -std=c99 rev.c
rev.c:6:26: error: comparison of unsigned expression in '>= 0' is always true [-Werror=type-limits]
cc1: all warnings being treated as errors

Backward, the right form starts from n and reads cell i - 1:

int a[] = {1, 2, 3};
size_t n = 3;

for (size_t i = n; i > 0; i--)
{
    printf("%d ", a[i - 1]);
}
printf("\n");

$ ./backward
3 2 1

Part 3 Lecture 2: Will it work?, Arrays and Memory

Going out of bounds

C does not check indices. Reading or writing a[3] in a 3-cell array compiles without a word from gcc, even with -Wall -Wextra -Werror. At run time, it is undefined behavior: the program may seem to work, crash, or silently corrupt other variables stored right next to it.

#include <stdio.h>

int main(void)
{
    int a[3] = {10, 20, 30};

    for (int i = 0; i <= 3; i++)
    {
        printf("a[%d] = %d\n", i, a[i]);
    }
    return 0;
}
The classic mistake: <= instead of <

The last iteration reads a[3], the cell after the array. What is printed is unpredictable.

[0][1][2][3]
102030?

Since the cells are contiguous, access by index is very fast; that is also why an overflow directly touches the neighboring memory.

To debug: AddressSanitizer

Compile with -fsanitize=address -g: the program stops at the first access outside the array and gives the faulty line.

$ gcc -Wall -Wextra -Werror -std=c99 -fsanitize=address -g oob.c -o oob
$ ./oob
==677==ERROR: AddressSanitizer: stack-buffer-overflow on address 0x7f7ec310002c
READ of size 4 at 0x7f7ec310002c thread T0
    #0 0x5592102b23dc in main oob.c:9

Part 4 Lecture 2: Arrays as Function Parameters, sum_array

Passing an array to a function

What you need to know
  • The function receives the array, not its size: you pass it as a second parameter, of type size_t.
  • The array is not copied: if the function changes a cell, the caller sees the change. This is not like an int (course 1, part 6).
  • const int a[] announces that the function will not modify the array; writing into it no longer compiles.
#include <stdio.h>

void fill(int a[], size_t len, int value)
{
    for (size_t i = 0; i < len; i++)
    {
        a[i] = value;
    }
}

int main(void)
{
    int x[] = {1, 2, 3, 4};

    fill(x, 4, 10);
    for (size_t i = 0; i < 4; i++)
    {
        printf("x[%zu] = %d\n", i, x[i]);
    }
    return 0;
}

$ ./fill
x[0] = 10
x[1] = 10
x[2] = 10
x[3] = 10
sizeof inside the function: rejected

Inside the function, a is only an address: sizeof(a) would give the size of an address (8 bytes), not that of the array. gcc rejects it.

#include <stdio.h>

size_t count(const int a[])
{
    return sizeof(a) / sizeof(a[0]);
}

int main(void)
{
    int a[] = {1, 2, 3};
    printf("%zu\n", count(a));
    return 0;
}

$ gcc -Wall -Wextra -Werror -std=c99 count.c
count.c:5:18: error: 'sizeof' on array function parameter 'a' will return size of 'const int *' [-Werror=sizeof-array-argument]
cc1: all warnings being treated as errors

The algorithms that come back in every exam. Those that read without modifying take a const int a[]:

#include <stdio.h>

int sum_array(const int a[], size_t len)
{
    int sum = 0;
    for (size_t i = 0; i < len; i++)
    {
        sum += a[i];
    }
    return sum;
}

int max_array(const int a[], size_t len)    // len must be at least 1
{
    int best = a[0];
    for (size_t i = 1; i < len; i++)
    {
        if (a[i] > best)
        {
            best = a[i];
        }
    }
    return best;
}

int count_value(const int a[], size_t len, int value)
{
    int count = 0;
    for (size_t i = 0; i < len; i++)
    {
        if (a[i] == value)
        {
            count++;
        }
    }
    return count;
}

int index_of(const int a[], size_t len, int value)
{
    for (size_t i = 0; i < len; i++)
    {
        if (a[i] == value)
        {
            return i;    // first occurrence
        }
    }
    return -1;           // not found
}

int main(void)
{
    int a[] = {3, 1, 4, 1, 5};
    int neg[] = {-7, -2, -9};

    printf("sum = %d\n", sum_array(a, 5));
    printf("max = %d\n", max_array(a, 5));
    printf("max = %d\n", max_array(neg, 3));
    printf("count of 1 = %d\n", count_value(a, 5, 1));
    printf("index of 4 = %d\n", index_of(a, 5, 4));
    printf("index of 8 = %d\n", index_of(a, 5, 8));
    return 0;
}

$ ./algos
sum = 14
max = 5
max = -2
count of 1 = 2
index of 4 = 2
index of 8 = -1
Modifying in place: reversing

You swap the first and the last cell, then the second and the second to last… up to the middle. A swap goes through a temporary variable.

#include <stdio.h>

void reverse_array(int a[], size_t len)
{
    for (size_t i = 0; i < len / 2; i++)
    {
        int tmp = a[i];
        a[i] = a[len - 1 - i];
        a[len - 1 - i] = tmp;
    }
}

int main(void)
{
    int a[] = {1, 2, 3, 4, 5};

    reverse_array(a, 5);
    for (size_t i = 0; i < 5; i++)
    {
        printf("%d ", a[i]);
    }
    printf("\n");
    return 0;
}

$ ./reverse
5 4 3 2 1
Traps
  • Maximum: start from a[0], not from 0 (with all-negative values, 0 would be wrong). Handle the empty array separately if the statement mentions it.
  • Search: return as soon as you find it, and -1 after the loop, not in an else inside it.
  • Reversal: stop at len / 2, otherwise everything is swapped back and the array returns to how it was.
  • Modifying a const int a[] does not compile: error: assignment of read-only location.

Part 5 Lecture 2: Two-Dimensional Arrays, Traversing a 2D Array

Two-dimensional arrays

int grid[2][3]: 2 rows of 3 columns. grid[row][column], each index starting at 0. In memory, the rows are stored one after another.

int grid[2][3] = {{1, 2, 3}, {4, 5, 6}};
col 0col 1col 2
row 0123
row 1456 = grid[1][2]

In memory:

123456

You traverse it with two nested loops: rows outside, columns inside. To pass a grid to a function, the number of columns must appear in the parameter; only the number of rows can be left out and is passed separately.

#include <stdio.h>

int count_walls(int map[][4], size_t rows)
{
    int walls = 0;
    for (size_t r = 0; r < rows; r++)
    {
        for (size_t c = 0; c < 4; c++)
        {
            if (map[r][c] == 1)
            {
                walls++;
            }
        }
    }
    return walls;
}

int main(void)
{
    int map[3][4] = {
        {1, 1, 1, 1},
        {1, 0, 0, 1},
        {1, 1, 0, 1}
    };

    for (size_t r = 0; r < 3; r++)
    {
        for (size_t c = 0; c < 4; c++)
        {
            printf("%d ", map[r][c]);
        }
        printf("\n");
    }
    printf("walls = %d\n", count_walls(map, 3));
    return 0;
}

$ ./grid
1 1 1 1
1 0 0 1
1 1 0 1
walls = 9
Traps
  • The order is [row][column]: grid[1][2] is in row 1, column 2.
  • The two loops have their own bounds: rows up to the number of rows, columns up to the number of columns.
  • The end-of-row printf("\n") goes between the two loops, not inside the inner loop.
