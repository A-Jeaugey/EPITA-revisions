Des caractères, puis un zéro.

Le C n'a pas de type « chaîne ». Une chaîne, c'est un tableau de char dont la fin est marquée par un caractère spécial, '\0'. Toutes les fonctions sur les chaînes avancent case par case jusqu'à ce zéro : s'il manque, elles continuent dans la mémoire d'à côté.

Partie 1 CM 2 : From Arrays to Strings, The Null Terminator

Un tableau de char qui finit par '\0'

Définition

Une chaîne de caractères est un tableau de char terminé par le caractère nul '\0' (le code 0), qui veut dire « fin de la chaîne ». Toute chaîne est un tableau de char ; un tableau de char sans '\0' n'est pas une chaîne.

char a[] = {'H', 'i', '\0'};   // a string
char b[] = "Hello";            // '\0' added for you
char c[] = {'H', 'i'};         // NOT a string

printf("%s\n", a);
printf("%s\n", b);
printf("%zu %zu\n", sizeof(b), strlen(b));
printf("%c%c\n", c[0], c[1]);  // fine: char by char

$ ./nul
Hi
Hello
6 5
Hi
À retenir
  • Entre guillemets, "Hello", le '\0' final est ajouté tout seul.
  • printf("%s", s) affiche les caractères jusqu'au '\0'. Sans lui (le tableau c), il continue dans la mémoire d'à côté : comportement indéfini.
  • sizeof compte les cases du tableau, '\0' compris ; strlen (de <string.h>) compte les caractères avant le '\0'.
  • Pour ranger n caractères, il faut n + 1 cases.
  • 'a' est un caractère (un char) ; "a" est une chaîne de 2 cases : 'a' puis '\0'.
Dans un prototype : char s[] ou char *s

En paramètre, const char s[] et const char *s veulent dire la même chose : la fonction reçoit l'adresse du début de la chaîne. Les sujets de TP écrivent char * ; dans les deux cas, on lit les caractères avec s[i]. L'étoile sera expliquée avec les pointeurs.

Partie 2 CM 2 : Computing a String Length

Parcourir une chaîne, les caractères sont des nombres

On ne connaît pas la longueur à l'avance : on avance tant que la case courante n'est pas '\0'. C'est exactement ce que fait strlen, qu'il faut savoir réécrire quand seul <stdio.h> est autorisé.

#include <stdio.h>

size_t my_strlen(const char *s)
{
    size_t i = 0;
    while (s[i] != '\0')
    {
        i++;
    }
    return i;
}

int count_char(const char *s, char c)
{
    int count = 0;
    for (size_t i = 0; s[i] != '\0'; i++)
    {
        if (s[i] == c)
        {
            count++;
        }
    }
    return count;
}

int main(void)
{
    printf("%zu\n", my_strlen("robot"));
    printf("%zu\n", my_strlen(""));
    printf("%d\n", count_char("banana", 'a'));
    return 0;
}

$ ./strlen
5
0
3

Les lettres et les chiffres se suivent : on calcule avec les caractères eux-mêmes, sans apprendre les codes.

char c = 'g';
char d = '7';

printf("%c\n", c - 'a' + 'A');   // to upper case
printf("%d\n", d - '0');         // digit value
printf("%d\n", c - 'a');         // rank in alphabet
printf("%c\n", 'a' + 25);

$ ./ascii
G
7
6
z
Pièges
  • La condition d'arrêt est s[i] != '\0', pas i < sizeof(s) : dans une fonction, sizeof ne donne pas la taille de la chaîne.
  • strlen renvoie un size_t : for (int i = 0; i < strlen(s); i++) ne compile pas (comparaison signé / non signé, comme au cours 2).
  • Un char comme indice de tableau (count[s[i]]) ne compile pas : error: array subscript has type 'char'. Convertis : count[(unsigned char)s[i]].
  • '0' (le caractère, code 48) n'est pas '\0' (la fin, code 0).

Partie 3 les parcours classiques des TP

Modifier une chaîne sur place

Une chaîne rangée dans un tableau (char s[] = "…") se modifie case par case, et la fonction qui la reçoit modifie celle de l'appelant (comme un tableau). On ne touche jamais au '\0'.

#include <stdio.h>

void to_upper(char *s)
{
    for (size_t i = 0; s[i] != '\0'; i++)
    {
        if (s[i] >= 'a' && s[i] <= 'z')
        {
            s[i] = s[i] - 'a' + 'A';
        }
    }
}

void reverse_string(char *s)
{
    size_t len = 0;
    while (s[len] != '\0')
    {
        len++;
    }
    for (size_t i = 0; i < len / 2; i++)
    {
        char tmp = s[i];
        s[i] = s[len - 1 - i];
        s[len - 1 - i] = tmp;
    }
}

void replace_char(char *s, char old, char new_char)
{
    for (size_t i = 0; s[i] != '\0'; i++)
    {
        if (s[i] == old)
        {
            s[i] = new_char;
        }
    }
}

int main(void)
{
    char name[] = "Ada Lovelace 1815";
    char word[] = "stressed";
    char path[] = "a-b-c";

    to_upper(name);
    reverse_string(word);
    replace_char(path, '-', '/');
    printf("%s\n%s\n%s\n", name, word, path);
    return 0;
}

$ ./inplace
ADA LOVELACE 1815
desserts
a/b/c
Une chaîne littérale ne se modifie pas

char s[] = "hello"; crée un tableau à toi, modifiable. char *s = "hello"; désigne la chaîne littérale elle-même, en lecture seule : la modifier compile, puis plante.

#include <stdio.h>

int main(void)
{
    char *s = "hello";
    s[0] = 'H';
    printf("%s\n", s);
    return 0;
}

$ ./literal
Segmentation fault (core dumped)
Pièges
  • Majuscule : seulement si c'est une minuscule. Les espaces, chiffres et majuscules restent tels quels.
  • Inverser : calculer la longueur d'abord, échanger jusqu'à len / 2, et ne pas déplacer le '\0' (il reste en s[len]).

Partie 4 CM 2 : Comparing Strings, The Three Big Rules

Comparer, copier

== entre deux chaînes compare leurs adresses, pas leur contenu. Deux tableaux différents qui contiennent "cat" ne sont jamais à la même adresse. gcc refuse d'ailleurs de comparer deux tableaux :

#include <stdio.h>

int main(void)
{
    char a[] = "cat";
    char b[] = "cat";

    if (a == b)
    {
        printf("same\n");
    }
    return 0;
}

$ gcc -Wall -Wextra -Werror -std=c99 cmp.c
cmp.c:8:11: error: comparison between two arrays [-Werror=array-compare]
cc1: all warnings being treated as errors
strcmp (de <string.h>)

strcmp(a, b) vaut 0 si les deux chaînes sont égales, un nombre négatif si a vient avant b dans l'ordre des codes, positif sinon. On teste donc strcmp(a, b) == 0, et jamais if (strcmp(a, b)) pour « égales ».

Réécrites avec <stdio.h> seulement, la comparaison, la copie et le test de palindrome :

#include <stdio.h>

int my_strcmp(const char *a, const char *b)
{
    size_t i = 0;
    while (a[i] != '\0' && a[i] == b[i])
    {
        i++;
    }
    return a[i] - b[i];
}

void my_strcpy(char *dest, const char *src)    // dest must be large enough
{
    size_t i = 0;
    while (src[i] != '\0')
    {
        dest[i] = src[i];
        i++;
    }
    dest[i] = '\0';
}

int is_palindrome(const char *s)
{
    size_t len = 0;
    while (s[len] != '\0')
    {
        len++;
    }
    for (size_t i = 0; i < len / 2; i++)
    {
        if (s[i] != s[len - 1 - i])
        {
            return 0;
        }
    }
    return 1;
}

int main(void)
{
    char copy[16];

    printf("%d\n", my_strcmp("cat", "cat") == 0);
    printf("%d\n", my_strcmp("cat", "dog") < 0);
    printf("%d\n", my_strcmp("cats", "cat") > 0);
    my_strcpy(copy, "kayak");
    printf("%s %d\n", copy, is_palindrome(copy));
    printf("%d %d\n", is_palindrome("robot"), is_palindrome(""));
    return 0;
}

$ ./cmpcopy
1
1
1
kayak 1
0 1
Pièges
  • La copie doit écrire le '\0' final, après la boucle. Sans lui, copy n'est pas une chaîne.
  • La destination doit avoir au moins longueur + 1 cases.
  • my_strcmp s'arrête aussi quand a se termine : "cats" contre "cat" compare 's' à '\0'.

Partie 5 CM 2 : Reading a Line Safely, Tiny Challenge

Lire une ligne : fgets

fgets(tableau, taille, stdin)
  • Lit une ligne tapée au clavier (stdin) dans le tableau, sans jamais dépasser taille - 1 caractères (il garde une case pour '\0'). On passe sizeof(line).
  • Renvoie NULL s'il n'y a plus rien à lire : on le teste.
  • Garde le '\n' final s'il y a la place : il faut l'enlever avant de comparer.
#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[64];

    printf("Spell: ");
    if (fgets(line, sizeof(line), stdin) == NULL)
    {
        return 1;
    }

    size_t n = strlen(line);
    if (n > 0 && line[n - 1] == '\n')
    {
        line[n - 1] = '\0';
    }

    if (strcmp(line, "fireball") == 0)
    {
        printf("Boom! (%zu letters)\n", strlen(line));
    }
    else
    {
        printf("Nothing happens.\n");
    }
    return 0;
}

$ echo "fireball" | ./fgets
Spell: Boom! (8 letters)

strcmp(a, b)0 si égales, négatif ou positif sinon
fgets(buf, size, stdin)(de <stdio.h>) buf, ou NULL en fin d'entrée
