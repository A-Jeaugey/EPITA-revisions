Le partiel 1 de physique sur une page

À relire la veille et le matin de l’épreuve. Chaque titre de case renvoie à la partie du cours correspondante.

Méthodes détaillées

Au partiel

Écrit, réponses sur le sujet, ni calculatrice ni document (1 h en 2022). QCM de cours, puis 2 ou 3 exercices. Résultat littéral, puis application numérique avec l’unité ; g = 10 m·s⁻² si l’énoncé le dit.

Cadre de l’étude

Système (point matériel M) · référentiel terrestre supposé galiléen · repère (O, ux, uy), uy vers le haut · t = 0 au départ, conditions initiales OM(0), v(0).

Cartésiennes

OM = xux + yuy v = dOMdt = ẋux + ẏuy a = dvdt = ẍux + ÿuy ‖v‖ = √ẋ² + ẏ²

ux, uy fixes. v tangent à la trajectoire. ddtcos(ωt) = −ω sin(ωt).

Nature du mouvement

Uniforme : ‖v‖ constante. v · a > 0 accéléré, < 0 décéléré, = 0 (a ≠ 0) : seule la direction change. Rectiligne uniforme : a = 0 ; circulaire uniforme : a ≠ 0.

Intégrer

v(t) = ∫a dt + C1, C1 = v(0) ; x(t) = ∫v dt + C2, C2 = x(0).

a constant : v = at + v0, x = 12at² + v0t + x0. Distance parcourue = x(t) − x(0).

Trajectoire

Élimine t (tire-le de x(t)) ou utilise cos² + sin² = 1. Donne la nature : (x − a)² + (y − b)² = R² cercle ; x²A² + y²B² = 1 ellipse ; parabole ; segment (bornes).

Tir depuis O

x = v0 cosα · t y = v0 sinα · t − 12gt² y(x) = −g2v0² cos²αx² + x tanα (+ h)

Sommet : vy = 0, tS = v0 sinαg, yS = v0² sin²α2g, xS = v0² sinα cosαg. Impact : y(tP) = 0, tP = 2tS, xP = v0² sin2αg. Lâcher de h : t = √2hg.

Forces

Poids P = mg (vertical, bas) · réaction R ⊥ support · tension T le long du fil · frottement fluide f = −αv · gravitation F = −Gm1m2d²u12 (attractive) · quantité de mouvement p = mv. Unité : N = kg·m·s⁻².

Lois de Newton

1re (inertie) : ΣF = 0 ⇔ repos ou mouvement rectiligne uniforme. 2e : ΣF = dpdt = ma (référentiel galiléen). 3e : F1→2 = −F2→1.

Exploiter la 2e loi

  1. Cadre, bilan des forces, schéma.
  2. ΣF = ma en vecteurs, puis projection en colonnes.
  3. Intégrer avec les conditions initiales.

Pente (ux vers le bas de la pente) : P = (mg sinα ; −mg cosα), R = mg cosα. Chute libre : a = −g, indépendante de m.

Travail, puissance

WA→B = F · AB = F · AB · cosθ (J) : moteur > 0, résistant < 0, nul si F ⊥ déplacement. W(P) = mg(zA − zB). Frottement constant : −f · AB. Puissance P = F · v (W).

Énergies

Ec = 12mv² Ep = mgz EM = Ec + Ep

TEC : ΔEc = ΣWA→B. Forces conservatives seules : EM constante. Frottements : EM diminue. Chute de h : v = √2gh. Vitesse entre deux points → énergie ; durée → 2e loi.

Base polaire

ur = cosθux + sinθuy uθ = −sinθux + cosθuy durdt = θ̇uθ duθdt = −θ̇ur

r = OM > 0, x = r cosθ, y = r sinθ. Base mobile, tournée de +90°.

Vitesse, accélération

OM = rur v = ṙur + rθ̇uθ a = (r̈ − rθ̇²)ur + (2ṙθ̇ + rθ̈)uθ

Mouvement circulaire

r = R : v = Rθ̇uθ, a = −Rθ̇²ur + Rθ̈uθ. Uniforme (θ̇ = ω, θ̈ = 0) : v = Rω, a = −Rω²ur = −v²Rur (centripète), période T = 2πω. Cylindriques : OM = rur + zuz.

Unités, calcul

km/h ÷ 3,6 = m·s⁻¹ (90 → 25). J = N·m ; W = J·s⁻¹ ; ω en rad·s⁻¹. sin30° = 12, cos30° = √32 ≈ 0,87, cos45° = √22 ≈ 0,71. Vérifie l’homogénéité.

Pièges

  • OM = xux + yuy, jamais x + y ; OM = rur, sans θuθ.
  • Norme = racine des carrés ; composante signée ≠ norme.
  • « x diminue » ≠ décéléré : regarde v · a.
  • Constantes d’intégration ; plus de t dans y(x) ; t = 0 n’est pas l’impact.
  • Sommet : v = v0 cosαux ≠ 0.
  • Sinus ou cosinus : le côté adjacent à l’angle prend le cosinus.
  • Sens de l’axe → signe de g et du poids.
  • Dériver ur : θ̇uθ, pas 0.
