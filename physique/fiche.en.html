Detailed methods

In the midterm

Written, answers on the paper, no calculator, no documents (1 h in 2022). Lecture MCQ, then 2 or 3 exercises. Literal result, then the numerical value with its unit; g = 10 m·s⁻² if the paper says so.

Study framework

System (material point M) · terrestrial reference frame, assumed Galilean · coordinate system (O, ux, uy), uy upwards · t = 0 at the start, initial conditions OM(0), v(0).

Cartesian coordinates

OM = xux + yuy v = dOMdt = ẋux + ẏuy a = dvdt = ẍux + ÿuy ‖v‖ = √ẋ² + ẏ²

ux, uy fixed. v tangent to the trajectory. ddtcos(ωt) = −ω sin(ωt).

Nature of motion

Uniform: ‖v‖ constant. v · a > 0 accelerated, < 0 decelerated, = 0 (a ≠ 0): only the direction changes. Uniform rectilinear: a = 0; uniform circular: a ≠ 0.

Integrate

v(t) = ∫a dt + C1, C1 = v(0); x(t) = ∫v dt + C2, C2 = x(0).

Constant a: v = at + v0, x = 12at² + v0t + x0. Distance travelled = x(t) − x(0).

Trajectory

Eliminate t (get it from x(t)) or use cos² + sin² = 1. Name the curve: (x − a)² + (y − b)² = R² circle; x²A² + y²B² = 1 ellipse; parabola; segment (ends).

Projectile from O

x = v0 cosα · t y = v0 sinα · t − 12gt² y(x) = −g2v0² cos²αx² + x tanα (+ h)

Apex: vy = 0, tS = v0 sinαg, yS = v0² sin²α2g, xS = v0² sinα cosαg. Impact: y(tP) = 0, tP = 2tS, xP = v0² sin2αg. Released from h: t = √2hg.

Forces

Weight W = mg (vertical, down) · surface reaction R ⊥ surface · tension T along the string · fluid friction f = −αv · gravity F = −Gm1m2d²u12 (attractive) · momentum p = mv. Unit: N = kg·m·s⁻².

Newton’s laws

First (inertia): ΣF = 0 ⇔ at rest or uniform rectilinear motion. Second: ΣF = dpdt = ma (Galilean frame). Third: F1→2 = −F2→1.

Using the second law

  1. Framework, forces involved, force diagram.
  2. ΣF = ma with vectors, then project in columns.
  3. Integrate with the initial conditions.

Slope (ux down the slope): W = (mg sinα; −mg cosα), R = mg cosα. Free fall: a = −g, whatever m.

Work, power

WA→B = F · AB = F · AB · cosθ (J): driving > 0, resisting < 0, zero if F ⊥ displacement. Weight: WA→B = mg(zA − zB). Constant friction: −f · AB. Power P = F · v (W).

Energy

Ek = 12mv² Ep = mgz EM = Ek + Ep

Work-kinetic energy theorem: ΔEk = ΣWA→B. Conservative forces only: EM constant. Friction: EM decreases. Fall from h: v = √2gh. Speed between two points → energy; duration → second law.

Polar basis

ur = cosθux + sinθuy uθ = −sinθux + cosθuy durdt = θ̇uθ duθdt = −θ̇ur

r = OM > 0, x = r cosθ, y = r sinθ. Moving basis, turned by +90° (anti-clockwise).

Velocity, acceleration

OM = rur v = ṙur + rθ̇uθ a = (r̈ − rθ̇²)ur + (2ṙθ̇ + rθ̈)uθ

Circular motion

r = R: v = Rθ̇uθ, a = −Rθ̇²ur + Rθ̈uθ. Uniform (θ̇ = ω, θ̈ = 0): v = Rω, a = −Rω²ur = −v²Rur (centripetal), period T = 2πω. Cylindrical: OM = rur + zuz.

Units, arithmetic

km/h ÷ 3.6 = m·s⁻¹ (90 → 25). J = N·m; W = J·s⁻¹; ω in rad·s⁻¹. sin30° = 12, cos30° = √32 ≈ 0.87, cos45° = √22 ≈ 0.71. Check the dimensions.

Traps

  • OM = xux + yuy, never x + y; OM = rur, with no θuθ.
  • Norm = root of the squares; signed component ≠ norm.
  • “x decreases” ≠ decelerated: look at v · a.
  • Integration constants; no t left in y(x); t = 0 is not the impact.
  • Apex: v = v0 cosαux ≠ 0.
  • Sine or cosine: the side adjacent to the angle takes the cosine.
  • Direction of the axis → sign of g and of the weight.
  • Weight W (vector) ≠ work WA→B (number).
  • Differentiating ur gives θ̇uθ, not 0.
