1Method 1

Classify the operations of a signature

  1. Find the defined types: those in types (or sort). Everything else (uses) is predefined.
  2. No argument? It is a constant (emptylist : → list).
  3. Result of a defined type? Internal operation.
  4. Predefined result and at least one argument of a defined type? Observer.
Trap

In the iterative list, box is a defined type too: access : list × integer → box is an internal operation, contents : box → element an observer.

Out loud as in writing

Justify with the rule: “top is an observer: its argument is a stack (defined type) and its result an element (predefined type).”

2Method 2

Find the preconditions

  1. Try the edge cases on each argument: empty list or stack, rank 0, rank beyond the length, missing element.
  2. Does the result make sense? If not, the operation is partial: write op(…) is-defined-iaoi … with the operations of the type (λ ≠ emptylist, isempty(s) = false, 1 ≤ k ≤ length(λ)).
  3. Otherwise, write “none” and say why in one line: the marker expects an answer, even an empty one.

Partial

last : list → element: the empty list has no last element.

last(λ) is-defined-iaoi λ ≠ emptylist

Total

concatenate : list × list → list: joining an empty list is no problem at all.

preconditions: none

Bounds trap

For an insertion, the rank can be length(λ) + 1 (insert at the end); for a deletion or an access, it stops at length(λ).

3Method 3

Write the axioms of an operation on a recursive list

A recursive list is either emptylist or cons(e, λ). So every operation is defined in two families of cases, and the cons case calls the operation again on the shorter list λ.

  1. Write the profile and look for the preconditions (method 2).
  2. emptylist case: what does the operation give on the empty list? One axiom.
  3. cons(e, λ) case: what do you do with the first element e, given the result on λ? If the answer depends on e, write one axiom per case, with the condition before ⇒.
  4. Check: each case has an axiom, the conditions do not overlap, both sides have the same type, the recursive call is on λ.
  5. End with with: the type of each variable.

Example: number of occurrences

types
    list
uses
    element, integer
operations
    nbocc : list x element → integer
preconditions
    none: the empty list contains x zero times
axioms
    nbocc(emptylist, x) = 0
    e = x ⇒ nbocc(cons(e, λ), x) = nbocc(λ, x) + 1
    e ≠ x ⇒ nbocc(cons(e, λ), x) = nbocc(λ, x)
with
    list λ
    element e, x

Example: adding at the end

operations
    addlast : list x element → list
axioms
    addlast(emptylist, x) = cons(x, emptylist)
    addlast(cons(e, λ), x) = cons(e, addlast(λ, x))
with
    list λ
    element e, x
The template

An operation that “keeps or drops” each element depending on a condition (deleting some elements, filtering) always follows the same template: condition(e) ⇒ op(cons(e, λ), …) = op(λ, …) to drop it, not condition(e) ⇒ op(cons(e, λ), …) = cons(e, op(λ, …)) to keep it.

In the exam

October 2023: concatenate. October 2024: deletegreater (delete the elements strictly greater than a given element). Both follow this template: see the solutions.

4Method 4

Write the axioms of an operation on an iterative list

An iterative list is described by its length and by its i-th element for each rank. So to define a new internal operation, you give the length of the result, then the nth element of the result rank by rank, range by range.

  1. Preconditions on the ranks (method 2).
  2. Draw the list before and after, with the ranks above it. Find the ranges: unchanged ranks, new rank(s), shifted ranks.
  3. Length of the result: one axiom.
  4. One axiom per range: the condition on i, then the rank to read in λ (i, i − 1, i + 1…).
  5. Test the boundaries on your drawing: the first and the last rank of each range.

Example: doubling the element at rank k

operations
    double : list x integer → list
preconditions
    double(λ, k) is-defined-iaoi 1 ≤ k ≤ length(λ)
axioms
    length(double(λ, k)) = length(λ) + 1
    1 ≤ i ≤ k ⇒ nth(double(λ, k), i) = nth(λ, i)
    i = k + 1 ⇒ nth(double(λ, k), i) = nth(λ, k)
    k + 1 < i ≤ length(λ) + 1 ⇒ nth(double(λ, k), i) = nth(λ, i - 1)
with
    list λ
    integer i, k
Check on a drawing

λ = {a, b, c}, k = 2: result {a, b, b, c}. Ranks 1 and 2: unchanged. Rank 3: a copy of rank 2. Rank 4: you read rank 4 − 1 = 3 of λ, which is c. The length goes from 3 to 4.

In the exam

The 2017 and 2021 papers asked for an operation on the iterative list (modify): same method, see practice.

5Method 5

Apply a mystery operation

You get an unknown operation, given only by its axioms, a list and some arguments: you must find the resulting list. Do not guess what the operation does: compute.

  1. Precondition: do the arguments satisfy it? If not, the result is undefined.
  2. Length: substitute into the length axiom. Now you know how many slots to fill.
  3. Rank by rank: for each i, find the axiom whose condition is true, and read the rank it gives in λ.
  4. Check: the length you found matches, and the result makes sense (a deleted range, a sublist…).
Write the table

On your scratch paper: one row “rank i”, one row “rank read in λ”, one row “value”. An offset error shows up at once.

6Method 6

Reduce a term with the axioms

  1. Read the term from the inside out: the starting structure is in the middle.
  2. Look for a piece with the exact shape of an axiom’s left-hand side (pop(push(…)), first(cons(…))…). Match the variables, replace.
  3. Conditional axiom (queue, set): first compute the condition (isempty(q), x ∈ s), then choose the axiom.
  4. Partial operation on an empty structure: the term is undefined, stop there.
7Method 7

Answer the course questions

Course questions are marked word for word: use the exact vocabulary of the course sheets. They came up in 2019, 2021, 2022 and 2023, for 4 to 6 points. The answers below are those of the answer keys (for 2019, the official English answer key).

8Method 8

Write up your paper

  • Answer on the exam paper, in the boxes provided: anything outside them is not marked (instructions of October 2024).
  • Use a pen: a pencil answer is not marked. The presentation is marked.
  • Keep the order of the course: preconditions, then axioms, then with. Write the keywords.
  • One line per axiom. Align the ⇒ if you can: the marker reads faster.
  • Use the names from the paper (emptylist or empty-list, λ, λ2) and declare every variable in with.
9Method 9

The traps that cost points

Check before handing in
  • A precondition invented on a total operation, or forgotten on a partial one.
  • A missing case: emptylist, a range of ranks, the equality e = x.
  • Overlapping conditions (two axioms for the same case): inconsistent axioms.
  • A reversed rank shift: after an insertion you read i − 1, after a deletion i + 1.
  • The two sides of an axiom with different types (top(…) = s).
  • “Observer” confused with “returns a boolean”.
  • Stack and queue swapped: the stack gives back the last one in, the queue the first one.
