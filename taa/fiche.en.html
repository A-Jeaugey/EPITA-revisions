Méthodes détaillées

À l’examen

Écrit sur le sujet : 30 min et 10 points en octobre 2024 ; 1 h annoncée cette année. On y retrouve des questions de cours, des axiomes à écrire pour une nouvelle opération sur une liste, une opération « mystère » à appliquer à une liste.

Réponds dans les cadres, au stylo : la présentation est notée.

Type abstrait

Définition = une signature (types + opérations) + un système d’axiomes.

Mots-clés, dans l’ordre : types · utilise · opérations · préconditions · axiomes · avec.

Signature

Opération = nom + profil : types des arguments × … → type du résultat.

Infixe : _^_ : entier × entier → entier, s’écrit 4^2.

Constante : aucun argument ; elle retourne un type défini (pilevide : → pile).

Hiérarchie

Type défini : nouveau, dans types. Type prédéfini : existe déjà, dans utilise.

Opération interne : résultat de type défini.

Observateur : au moins un argument de type défini et résultat de type prédéfini.

Préconditions

Domaine des opérations partielles : op(x) est-défini-ssi condition. Structure vide, rang hors bornes…

Opération totale : aucune précondition, et dis-le (ex. concaténer).

Opération auxiliaire : sert à écrire le domaine d’une autre (est-présent pour rechercher).

Axiomes

On applique les observateurs aux opérations internes. Un axiome = égalité de deux termes du même type, éventuellement sous condition condition ⇒ t1 = t2.

Consistance : pas d’axiomes contradictoires. Complétude : assez d’axiomes pour calculer tout terme défini.

avec : le type de chaque variable.

Liste récursive

types
    liste, place
utilise
    élément
opérations
    listevide : → liste
         cons : élément x liste → liste
          fin : liste → liste
         tête : liste → place
      contenu : place → élément
      premier : liste → élément
         succ : place → place
préconditions
    fin(λ), tête(λ), premier(λ) : λ ≠ listevide
axiomes
    premier(λ) = contenu(tête(λ))
    fin(cons(e, λ)) = λ
    premier(cons(e, λ)) = e
    succ(tête(λ)) = tête(fin(λ))

{e1, e2, e3} = cons(e1, cons(e2, cons(e3, listevide))).

Nouvelle opération récursive

  1. Un axiome pour listevide, un (ou plusieurs, avec conditions sur e) pour cons(e, λ).
  2. Le cas cons rappelle l’opération sur λ : la liste raccourcit à chaque fois.
  3. Préconditions seulement si la liste vide n’a pas de sens.

concaténer(listevide, λ2) = λ2
concaténer(cons(e, λ), λ2) = cons(e, concaténer(λ, λ2))

Liste itérative

opérations
       accès : liste x entier → place
        ième : liste x entier → élément
    longueur : liste → entier
   supprimer : liste x entier → liste
     insérer : liste x entier x élément → liste
préconditions
    accès(λ, k), supprimer(λ, k) : λ ≠ listevide
                         & 1 ≤ k ≤ longueur(λ)
    insérer(λ, k, e) : 1 ≤ k ≤ longueur(λ) + 1
axiomes
    longueur(listevide) = 0
    longueur(supprimer(λ, k)) = longueur(λ) - 1
    longueur(insérer(λ, k, e)) = longueur(λ) + 1
    1 ≤ i < k ⇒ ième(supprimer(λ, k), i) = ième(λ, i)
    k ≤ i ≤ longueur(λ) - 1 ⇒ … = ième(λ, i + 1)
    1 ≤ i < k ⇒ ième(insérer(λ, k, e), i) = ième(λ, i)
    k = i ⇒ ième(insérer(λ, k, e), i) = e
    k < i ≤ longueur(λ) + 1 ⇒ … = ième(λ, i - 1)
    contenu(accès(λ, k)) = ième(λ, k)
    succ(accès(λ, k)) = accès(λ, k + 1)

Opération mystère

  1. Vérifie la précondition avec les arguments donnés (sinon : indéfini).
  2. Calcule la longueur du résultat.
  3. Pour chaque rang i, trouve son cas et lis le rang indiqué dans λ (i + y − x + 1…).
  4. Contrôle les bords : premier rang, dernier rang, liste vide.

Pile · LIFO

types
    pile
opérations
    pilevide : → pile
     empiler : pile x élément → pile
     dépiler : pile → pile
      sommet : pile → élément
     estvide : pile → booléen
préconditions
    dépiler(p), sommet(p) : estvide(p) = Faux
axiomes
    dépiler(empiler(p, e)) = p
    sommet(empiler(p, e)) = e
    estvide(pilevide) = Vrai
    estvide(empiler(p, e)) = Faux

File · FIFO

préconditions
    défiler(f), premier(f) : estvide(f) = Faux
axiomes
    estvide(f) = Vrai ⇒ premier(enfiler(f, e)) = e
    estvide(f) = Faux ⇒ premier(enfiler(f, e)) = premier(f)
    estvide(f) = Vrai ⇒ défiler(enfiler(f, e)) = filevide
    estvide(f) = Faux ⇒
            défiler(enfiler(f, e)) = enfiler(défiler(f), e)
    estvide(filevide) = Vrai
    estvide(enfiler(f, e)) = Faux

Le premier entré est le plus enfoui dans le terme : il faut des conditions.

Ensembles

x ∈ ensemblevide = faux ; x = y ⇒ (x ∈ ajouter(y, e)) = vrai ; x ≠ y ⇒ (x ∈ ajouter(y, e)) = (x ∈ e).

card : + 1 seulement si l’élément ajouté était absent. choisir(e) : défini si e ≠ ensemblevide.

Multi-ensemble : nboccurrences : élément × multiensemble → entier ; card(ajouter(x, me)) = card(me) + 1.

Réécrire un terme

Cherche un morceau qui a la forme exacte du côté gauche d’un axiome, remplace-le, recommence. Vérifie les conditions ⇒ ; une opération partielle hors domaine rend le terme indéfini.

sommet(dépiler(empiler(empiler(pilevide, a), b))) → sommet(empiler(pilevide, a)) → a.

Pièges

  • Observateur ≠ « renvoie un booléen » : sommet, longueur, contenu sont des observateurs.
  • Inventer une précondition sur une opération totale, ou oublier celle d’une opération partielle.
  • Oublier un cas (listevide, ou une des zones de rangs) : axiomes incomplets.
  • Décalage de rang : après insérer, on lit i − 1 ; après supprimer, i + 1.
  • Deux côtés d’un axiome de types différents.
  • Pile et file : LIFO contre FIFO.
