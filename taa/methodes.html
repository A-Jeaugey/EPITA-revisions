1Méthode 1

Classer les opérations d’une signature

  1. Repère les types définis : ceux de types (ou sorte). Tout le reste (utilise) est prédéfini.
  2. Aucun argument ? C’est une constante (listevide : → liste).
  3. Résultat de type défini ? Opération interne.
  4. Résultat prédéfini et au moins un argument de type défini ? Observateur.
Piège

Dans la liste itérative, place est aussi un type défini : accès : liste × entier → place est une opération interne, contenu : place → élément un observateur.

À l’oral comme à l’écrit

Justifie avec la règle : « sommet est un observateur : son argument est une pile (type défini) et son résultat un élément (type prédéfini). »

2Méthode 2

Trouver les préconditions

  1. Essaie les cas limites sur chaque argument : liste ou pile vide, rang 0, rang au-delà de la longueur, élément absent.
  2. Le résultat a-t-il un sens ? Si non, l’opération est partielle : écris op(…) est-défini-ssi … avec les opérations du type (λ ≠ listevide, estvide(p) = Faux, 1 ≤ k ≤ longueur(λ)).
  3. Sinon, écris « aucune » et dis pourquoi en une ligne : le correcteur attend une réponse, même vide.

Partielle

dernier : liste → élément : la liste vide n’a pas de dernier élément.

dernier(λ) est-défini-ssi λ ≠ listevide

Totale

concaténer : liste × liste → liste : coller une liste vide ne pose aucun problème.

préconditions : aucune

Piège des bornes

Pour une insertion, le rang peut valoir longueur(λ) + 1 (insérer à la fin) ; pour une suppression ou un accès, il s’arrête à longueur(λ).

3Méthode 3

Écrire les axiomes d’une opération sur une liste récursive

Une liste récursive est soit listevide, soit cons(e, λ). Toute opération se définit donc en deux familles de cas, et le cas cons rappelle l’opération sur la liste plus courte λ.

  1. Écris le profil et cherche les préconditions (méthode 2).
  2. Cas listevide : que vaut l’opération sur la liste vide ? Un axiome.
  3. Cas cons(e, λ) : que fais-tu de la tête e, sachant le résultat sur λ ? Si la réponse dépend de e, écris un axiome par cas, avec la condition avant ⇒.
  4. Vérifie : chaque cas a un axiome, les conditions ne se chevauchent pas, les deux côtés ont le même type, l’appel récursif porte sur λ.
  5. Termine par avec : le type de chaque variable.

Exemple : nombre d’occurrences

types
    liste
utilise
    élément, entier
opérations
    nbocc : liste x élément → entier
préconditions
    aucune : la liste vide contient 0 fois x
axiomes
    nbocc(listevide, x) = 0
    e = x ⇒ nbocc(cons(e, λ), x) = nbocc(λ, x) + 1
    e ≠ x ⇒ nbocc(cons(e, λ), x) = nbocc(λ, x)
avec
    liste λ
    élément e, x

Exemple : ajouter en queue

opérations
    ajout-queue : liste x élément → liste
axiomes
    ajout-queue(listevide, x) = cons(x, listevide)
    ajout-queue(cons(e, λ), x) = cons(e, ajout-queue(λ, x))
avec
    liste λ
    élément e, x
Le gabarit

Une opération qui « garde ou jette » chaque élément selon une condition (supprimer certains éléments, filtrer) suit toujours le même gabarit : condition(e) ⇒ op(cons(e, λ), …) = op(λ, …) pour jeter, non condition(e) ⇒ op(cons(e, λ), …) = cons(e, op(λ, …)) pour garder.

À l’examen

Octobre 2023 : concaténer. Octobre 2024 : supprime-sup (supprimer les éléments strictement supérieurs à un élément donné). Les deux suivent ce gabarit : voir les corrigés.

4Méthode 4

Écrire les axiomes d’une opération sur une liste itérative

Une liste itérative se décrit par sa longueur et par son i-ème élément pour chaque rang. Pour définir une nouvelle opération interne, on donne donc longueur du résultat, puis ième du résultat rang par rang, en zones.

  1. Préconditions sur les rangs (méthode 2).
  2. Dessine la liste avant et après, rangs au-dessus. Repère les zones : rangs inchangés, rang(s) nouveau(x), rangs décalés.
  3. Longueur du résultat : un axiome.
  4. Un axiome par zone : la condition sur i, puis le rang à lire dans λ (i, i − 1, i + 1…).
  5. Teste les frontières sur ton dessin : le premier et le dernier rang de chaque zone.

Exemple : doubler l’élément de rang k

opérations
    doubler : liste x entier → liste
préconditions
    doubler(λ, k) est-défini-ssi 1 ≤ k ≤ longueur(λ)
axiomes
    longueur(doubler(λ, k)) = longueur(λ) + 1
    1 ≤ i ≤ k ⇒ ième(doubler(λ, k), i) = ième(λ, i)
    i = k + 1 ⇒ ième(doubler(λ, k), i) = ième(λ, k)
    k + 1 < i ≤ longueur(λ) + 1 ⇒ ième(doubler(λ, k), i) = ième(λ, i - 1)
avec
    liste λ
    entier i, k
Vérification sur un dessin

λ = {a, b, c}, k = 2 : résultat {a, b, b, c}. Rangs 1 et 2 : inchangés. Rang 3 : copie du rang 2. Rang 4 : on lit le rang 4 − 1 = 3 de λ, c’est c. La longueur passe de 3 à 4.

À l’examen

Les sujets 2017 et 2021 demandaient une opération sur la liste itérative (modifier) : même méthode, voir l’entraînement.

5Méthode 5

Appliquer une opération mystère

On te donne une opération inconnue par ses seuls axiomes, une liste et des arguments : il faut la liste résultante. Ne devine pas ce que fait l’opération, calcule.

  1. Précondition : les arguments la respectent-ils ? Sinon, le résultat est indéfini.
  2. Longueur : remplace dans l’axiome de longueur. Tu sais combien de cases remplir.
  3. Rang par rang : pour chaque i, trouve l’axiome dont la condition est vraie, et lis le rang indiqué dans λ.
  4. Contrôle : la longueur trouvée correspond, et le résultat a un sens (un intervalle supprimé, une sous-liste…).
Écris le tableau

Sur le brouillon : une ligne « rang i », une ligne « rang lu dans λ », une ligne « valeur ». Une erreur de décalage se voit tout de suite.

S’entraîner avec le générateur d’opérations mystère

6Méthode 6

Réduire un terme avec les axiomes

  1. Lis le terme de l’intérieur vers l’extérieur : la structure de départ est au centre.
  2. Cherche un morceau qui a la forme exacte d’un côté gauche d’axiome (dépiler(empiler(…)), premier(cons(…))…). Associe les variables, remplace.
  3. Axiome conditionnel (file, ensemble) : calcule d’abord la condition (estvide(f), x ∈ e), puis choisis l’axiome.
  4. Opération partielle sur une structure vide : le terme est indéfini, arrête-toi.

8Méthode 8

Rédiger la copie

  • Réponds sur le sujet, dans les cadres prévus : ce qui est en dehors n’est pas corrigé (consigne d’octobre 2024).
  • Au stylo : une réponse au crayon de papier n’est pas corrigée. La présentation est notée.
  • Garde l’ordre du cours : préconditions, puis axiomes, puis avec. Écris les mots-clés.
  • Une ligne par axiome. Aligne les ⇒ si tu peux, le correcteur lit plus vite.
  • Utilise les noms du sujet (listevide ou liste-vide, λ, λ2) et déclare chaque variable dans avec.
9Méthode 9

Les pièges qui coûtent des points

À vérifier avant de rendre
  • Une précondition inventée sur une opération totale, ou oubliée sur une opération partielle.
  • Un cas manquant : listevide, une zone de rangs, l’égalité e = x.
  • Des conditions qui se chevauchent (deux axiomes pour le même cas) : axiomes inconsistants.
  • Un décalage de rang inversé : après insertion on lit i − 1, après suppression i + 1.
  • Les deux côtés d’un axiome de types différents (sommet(…) = p).
  • « Observateur » confondu avec « renvoie un booléen ».
  • Pile et file inversées : la pile rend le dernier entré, la file le premier.
