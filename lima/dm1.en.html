Implementations

  • Static = array; dynamic = records linked by pointers.
  • Recursive list in an array: array + head index. Add: increment, then write; remove: decrement (the value stays in the cell).
  • Iterative list in an array: array + length. Access to the k-th element is immediate; insertion / deletion: shifts, at most n − 1 assignments, worst case at the 1st position.
  • Linked: the list is the pointer to the 1st record; empty = null. cons: allocate, val ← e, suiv ← L, L ← new.
  • Iterative linked list: k-th element by following k − 1 links; no shift; to delete, keep the previous one, then free the memory.
  • Recursive lists: everything in constant time in both implementations.

Linear searches

  • Associative: criterion on the key value only. Positive (successful): key present; negative (unsuccessful): absent.
  • We count the comparisons of x with the elements.
  • Unsorted: negative n always; positive n in the worst case, n / 2 on average.
  • Sorted: we stop as soon as we go past x; n in the worst case, n / 2 on average, positive and negative alike.
  • Self-adjusting: aggressive (to the head), soft (one place), reasonable (several places). Not on a sorted list; the aggressive one is costly in a contiguous list.
  • Everything is O(n).

Python (Tutorial 1)

  • Indices from 0 to len(L) - 1; nth(λ, k) = L[k - 1].
  • range(n) : 0 … n − 1 ; range(a, b) : a … b − 1.
  • L.append(x) adds at the end and returns None.
  • Interrupted traversal: while i < len(L) and L[i] != x, index test first.
  • Histogram: H = [0] * 256, H[ord(c)] += 1.
  • A tuple is immutable: L[i] = (k, v), not L[i][1] = v.
  • M = L does not copy the list.

The mistakes that cost you

Six traps

Re-read just before
  1. Copying the bounds of an algorithm (1 to length) into Python (0 to len(L) - 1).
  2. Believing that a negative search on an unsorted list costs n / 2 on average: it is n, always.
  3. Mixing up the variants: aggressive = to the head, soft = by one place.
  4. Applying self-adjusting search to a sorted list: forbidden.
  5. cons in the wrong order: new↑.suiv ← L before L ← new.
  6. Inserting into an array: shift starting from the end; the worst case is the first position.
