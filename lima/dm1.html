Implémentations

  • Statique = tableau ; dynamique = enregistrements chaînés par pointeurs.
  • Liste récursive en tableau : tableau + indice de tête. Ajouter : incrémenter puis écrire ; supprimer : décrémenter (la valeur reste dans la case).
  • Liste itérative en tableau : tableau + longueur. Accès au k-ième immédiat ; insertion / suppression : décalages, au plus n − 1 affectations, pire cas en 1re place.
  • Chaînée : la liste est le pointeur sur le 1er enregistrement ; vide = nul. cons : allouer, val ← e, suiv ← L, L ← new.
  • Chaînée itérative : k-ième en suivant k − 1 liens ; pas de décalage ; pour supprimer, garder le précédent, puis libérer.
  • Récursives : tout en temps constant dans les deux implémentations.
Cours 1 →

Recherches séquentielles

  • Associative : critère sur la seule valeur de la clé. Positive : clé présente ; négative : absente.
  • On compte les comparaisons de x avec les éléments.
  • Non triée : négative n toujours ; positive n au pire, n / 2 en moyenne.
  • Triée : on s’arrête dès qu’on dépasse x ; n au pire, n / 2 en moyenne, positive comme négative.
  • Auto-adaptative : agressive (en tête), molle (une place), raisonnable (plusieurs places). Pas sur liste triée ; l’agressive est coûteuse en contigu.
  • Tout est en O(n).
Cours 2 →

Python (TD 1)

  • Indices de 0 à len(L) - 1 ; ième(λ, k) = L[k - 1].
  • range(n) : 0 … n − 1 ; range(a, b) : a … b − 1.
  • L.append(x) ajoute à la fin et renvoie None.
  • Parcours interrompu : while i < len(L) and L[i] != x, test d’indice en premier.
  • Histogramme : H = [0] * 256, H[ord(c)] += 1.
  • Un tuple est immuable : L[i] = (k, v), pas L[i][1] = v.
  • M = L ne copie pas la liste.
Cours 2, partie 6 →
Les erreurs qui coûtent

Six pièges

À relire juste avant
  1. Recopier les bornes d’un algo (1 à longueur) en Python (0 à len(L) - 1).
  2. Croire qu’une recherche négative sur liste non triée coûte n / 2 en moyenne : c’est n, toujours.
  3. Confondre les variantes : agressive = en tête, molle = d’une place.
  4. Appliquer l’auto-adaptative à une liste triée : interdit.
  5. cons dans le mauvais ordre : new↑.suiv ← L avant L ← new.
  6. Insérer dans un tableau : décaler en partant de la fin ; le pire cas est la première place.
