À relire la veille et le matin de l’épreuve. Chaque titre de case renvoie à la partie du cours correspondante. Les formules du B1 (cinématique, forces, énergie) sont sur la fiche du B1.

Méthodes détaillées

À l’examen

Écrit, réponses sur le sujet, ni calculatrice ni document. Souvent un QCM, puis 2 ou 3 exercices : un mouvement en polaires ou sur un cercle, un exercice de 2e loi et d’énergie sur une trajectoire circulaire, et de la statique (moments, absente du cours de cette année). Nouveau cette année : oscillateurs et ondes, au verso.

Base polaire

ur = cosθux + sinθuy uθ = −sinθux + cosθuy durdt = θ̇uθ duθdt = −θ̇ur

r = OM > 0, x = r cosθ, y = r sinθ. Base mobile, tournée de +90°.

Vitesse, accélération

OM = rur v = ṙur + rθ̇uθ a = (r̈ − rθ̇²)ur + (2ṙθ̇ + rθ̈)uθ

Mouvement circulaire

r = R : v = Rθ̇uθ, a = −Rθ̇²ur + Rθ̈uθ. Uniforme (θ̇ = ω, θ̈ = 0) : v = Rω, a = −Rω²ur = −v²Rur (centripète), période T = 2πω. Cylindriques : OM = rur + zuz.

2e loi sur un cercle

Sur le rayon : forces vers le centre − forces vers l’extérieur = mv²R. Sur la tangente : ΣFθ = mRθ̈ = m dv/dt. Pas de « force centripète » dans le bilan.

Réaction d’un support

Dessus d’une sphère (θ depuis le sommet) : N = m(g cosθ − v²/R). Fond d’une cuvette : N = m(g cosθ + v²/R). Sans frottement, la réaction ne travaille pas.

Énergie, puis réaction

Depuis le sommet, sans vitesse : v² = 2gR(1 − cosθ), donc N = mg(3 cosθ − 2). Décollage quand N = 0 : cosθ = 2/3 (≈ 48°).

Looping

Hauteur de M au-dessus du bas : R + R sinθ. N = mg(2h/R − 2 − 3 sinθ). Faire le tour : h ≥ 5R/2, soit v² ≥ gR au sommet.

Frottement, Frenet

Frottement constant sur un arc : W = −fRΔθ (radians), ΔEm = W(f).

Sur un cercle : uT = uθ, uN = −ur, aT = dv/dt, aN = v²/R > 0, s = Rθ.

Rappels du B1

ΣF = ma. ΔEc = ΣW. W(P) = mg(zA − zB). Sans frottement, EM se conserve.

Pièges

  • Pas de terme en uθ dans OM ; duθ/dt = −θ̇ur.
  • Uniforme ≠ accélération nulle.
  • Sur un cercle, N ≠ mg cosθ.
  • Hauteur : R(1 − cosθ) sous le sommet.
  • C’est la réaction qui s’annule au décollage.
  • Arc Rθ, pas corde ; 10 g = 0,01 kg.

Verso · oscillateurs et ondes

Force de rappel

F = −k(ℓ − ℓ0) u

u : de l’attache vers la masse. Origine à la position de repos : F = −kx ux. Étiré : la force tire vers l’attache.

Oscillateur harmonique

ẍ + ω0² x = 0 ω0 = √(k/m) x = A cos ω0t + B sin ω0t, A = x0, B = v0/ω0

Ou Xm cos(ω0t + φ), Xm = √(x0² + (v0/ω0)²).

Période, énergie

T0 = 2π/ω0 = 2π√(m/k), indépendante de l’amplitude. Epe = ½kx² EM = ½kXm² vmax = ω0Xm

vmax au passage à l’équilibre ; v = 0 aux extrémités.

Ressort vertical

Axe z vers le haut, O à l’attache : ze = −(ℓ0 + mg/k). Avec Z = z − ze : Z̈ + ω0²Z = 0, même ω0. L’amplitude se compte depuis l’équilibre.

Pendule simple

θ̈ + (g/l) sin θ = 0 T = mg cos θ + mlθ̇²

Petits angles (radians) : T0 = 2π√(l/g), θ = θ0 cos ω0t. Ep = mgl(1 − cos θ), Ec = ½ml²θ̇².

Frottement fluide

ẍ + ẋ/τ + ω0²x = 0 τ = m/α λ = 1/(2τ)

λ < ω0 : pseudo-périodique, e−λt(A cos ωt + B sin ωt), ω = √(ω0² − λ²). λ = ω0 : critique, (A + Bt)e−ω0t. λ > ω0 : apériodique.

Signal, onde

f = 1/T λ = c/f = cT

Onde : perturbation qui se propage sans transport de matière ; c dépend du milieu. s = f(t − x/c) vers les x croissants. Audible : 20 Hz à 20 kHz.

OPPM, déphasage

s = A cos(ωt − kx + φ) ω = 2πf k = 2π/λ = ω/c

Δφ = φ2 − φ1 = −ωΔt (retard : négatif). 0 : en phase ; π : opposition ; π/2 : quadrature. Chemin en plus δ : Δφ = 2πδ/λ.

Ondes stationnaires

s = 2A sin(ωt) sin(kx)

Nœuds tous les λ/2. Corde fixée aux deux bouts : λn = 2L/n, fn = nc/(2L), n ≥ 1. Tuyau fermé-ouvert : fn = (2n + 1)c/(4L).

Pièges

  • B = v0/ω0, pas v0.
  • √(m/k) et √(l/g) dans les périodes, pas l’inverse.
  • sin θ ≈ θ en radians.
  • Amplitude ×2 : énergie ×4.
  • λ = c/f, nœuds à λ/2.
