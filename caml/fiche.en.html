Recursion, conditionals, pattern matching

# let rec fact n =
    if n = 0 then
      1
    else
      n * fact (n-1) ;;
val fact : int -> int = <fun>
# let sign = function
      0 -> 0
    | n when n > 0 -> 1
    | _ -> -1 ;;
val sign : int -> int = <fun>

let rec for every recursive function. if always has an else, of the same type. let f = function … is the same as let f x = match x with …. Patterns are tried in order; when adds a condition; _ matches everything.

Exceptions

  • invalid_arg "…" → Invalid_argument: an invalid parameter (rank ≤ 0, k < 0, list empty from the start). Tested once, in the wrapper, before the traversal.
  • failwith "…" → Failure: the computation fails on the way (list too short, element not found). In the case that reveals it, often [].
  • Type string -> 'a: fits in any branch. Constructor and message: those of the examples (Invalid_arg is a typo).

e :: lstat least one element
[e]exactly one (e :: [])

(a, b) :: lstlist of pairs
l :: otherslist of lists (l is a list)
(e1 :: l1, e2 :: l2)two lists: 4 cases with ([], []), (lst, []), ([], lst)

Wrapper · accumulator

# let nth i lst =
    if i <= 0 then
      invalid_arg "nth: i <= 0"
    else
      let rec get i = function
          [] -> failwith "nth: list too short"
        | e :: l ->
            if i = 1 then
              e
            else
              get (i-1) l
      in
        get i lst ;;
val nth : int -> 'a list -> 'a = <fun>
# let reverse lst =
    let rec rev acc = function
        [] -> acc
      | e :: l -> rev (e :: acc) l
    in
      rev [] lst ;;
val reverse : 'a list -> 'a list = <fun>
# reverse [1; 2; 3] ;;
- : int list = [3; 2; 1]

Pure recursion first: an accumulator reverses the order, use it only when the statement lends itself to it.

Higher-order functions, written by hand

# let rec map f = function
      [] -> []
    | e :: l -> f e :: map f l ;;
val map : ('a -> 'b) -> 'a list -> 'b list = <fun>
# let rec filter p = function
      [] -> []
    | e :: l ->
        if p e then
          e :: filter p l
        else
          filter p l ;;
val filter : ('a -> bool) -> 'a list -> 'a list = <fun>
# let rec for_all p = function
      [] -> true
    | e :: l -> p e && for_all p l ;;
val for_all : ('a -> bool) -> 'a list -> bool = <fun>
# let rec exists p = function
      [] -> false
    | e :: l -> p e || exists p l ;;
val exists : ('a -> bool) -> 'a list -> bool = <fun>
# let rec process_list f init = function
      [] -> init
    | e :: l -> f e (process_list f init l) ;;
val process_list : ('a -> 'b -> 'b) -> 'b -> 'a list -> 'b = <fun>
# let rec fold_left f a = function
      [] -> a
    | e :: l -> fold_left f (f a e) l ;;
val fold_left : ('a -> 'b -> 'a) -> 'a -> 'b list -> 'a = <fun>
# filter (function x -> x > 0) [-1; 2; 0; 5] ;;
- : int list = [2; 5]
# fold_left (function acc -> function e -> e :: acc) [] [1; 2; 3] ;;
- : int list = [3; 2; 1]

The function parameter is called (p e) and passed on at each recursive call. process_list (tutorial) is fold_right.

Optimising

  • A recursive call whose result is used twice: let m = maximum lst in (otherwise 2n calls).
  • Stop as soon as the answer is known: && and || do not evaluate their second operand if the first is enough; sorted list: stop as soon as you go past.
  • Test the parameters once (wrapper). Add with ::; @ copies its left-hand list.

Traps

  • let rec forgotten: Error: Unbound value fact.
  • fact n-1 = (fact n) - 1: endless loop. Write fact (n-1), f (-1).
  • [e; lst]: two elements. The general case is e :: lst.
  • :: puts one element in front of a list; [1; 2] :: [3] is rejected.
  • | y -> matches everything: it is a new variable. To compare: | z when z = y ->.
  • match inside a match: in brackets.
  • not a = b = (not a) = b; use =, <>, never ==.
  • Examples on int and char: no 0 nor + on the elements.
  • Caml writes 4., not 4.0.
