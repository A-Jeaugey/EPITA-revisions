Conversions

To base 10

Sum of products digit × baseposition; position 0 just left of the point. 28.2816 = 32 + 8 + 0.125 + 0.03125 = 40.15625.

From base 10

  • Integer part: successive divisions, remainders read from the last to the first.
  • Fractional part: successive multiplications, integer parts read from the first to the last; carry on with the fractional part only.
  • n digits asked for: stop, without rounding. 40.3510 → 10 1000.0101 12; 141.310 → 8D.4C16 (not 4D).

Base 2 ↔ base 16

Groups of 4 bits from the point; pad with 0s on the left of the integer part and on the right of the fractional part: 1011 1011.1011 012 = BB.B416. One hexadecimal digit = exactly 4 bits.

Written operations

  • Addition: 1 + 1 = 10 (0 carry 1); 1 + 1 + 1 = 11; four 1s = 100, a carry over two columns.
  • Subtraction: top digit too small → it gains 2, the bottom digit of the next column gains 1.
  • Multiplication: one partial product per 1 of the multiplier, shifted by its position; add the partial products.
  • Division: 1 in the quotient if the remainder contains the divisor, 0 otherwise; each digit brought down gives a digit of the quotient. Papers: final remainder 0.
  • Hexadecimal addition: each column in decimal (A = 10 … F = 15), then in base 16: 3 + 10 + 6 = 19 = 1316, write down 3, carry 1. Three terms: a carry of up to 2.
  • Check: go back to decimal. 76316 + FAA16 + 5B616 = 1CC316.

8-bit words: positive from 00 to 7F, negative from 80 to FF.

Two’s complement

  • One’s complement: invert each bit. Two’s complement: one’s complement + 1.
  • Shortcut: from right to left, keep up to the first 1 included, invert the rest.
  • Encoding −x: x in binary on n bits, then its two’s complement: 17 = 00010001 → −17 = 11101111.
  • Decoding: MSB 0 → as an unsigned number; MSB 1 → negative, its absolute value is its two’s complement: 10111101 → 01000011 = 67 → −67.
  • −128 = 10000000 on 8 bits: its two’s complement gives the same word back.
  • Sign extension: replicate the sign bit to the left. 10001101 → 1111 1111 1000 1101.

Overflow, the 8-bit table

  • Always write the 8-bit word obtained (the carry or borrow that goes out is left out).
  • Unsigned: ERROR if the true result is out of 0 … 255: carry out of an addition, first < second in a subtraction.
  • Signed: ERROR if the true result is out of −128 … 127. With the signs: only P + P = N, N + N = P, P − N = N, N − P = P.

IEEE 754: encoding (single)

  1. S = 0 if positive.
  2. The number in binary, then normalized: 1.… × 2e.
  3. E = e + 127, on 8 bits (leading zeros).
  4. M = digits after the point, padded on the right up to 23 bits.

0.0937510 = 0.0001 12 = 1.12 × 2−4; E = 123.

0.0937500111101110000000000000000000000

IEEE 754: decoding (double)

  1. First 3 hexadecimal digits → S (1 bit) and E (11 bits); if the 1st digit < 8, E = those three digits.
  2. M = the last 13 digits (52 bits).
  3. E = 7FF: ∞ or NaN; E = 0: 0 or denormalized; otherwise 1.M × 2E − 1023.
  4. k × 2n: point moved up to the last 1, odd k.

2844 0000 0000 0000: E = 28416 = 644, 1.012 × 2644 − 1023 = 5 × 2−381.

000A 8000 0000 0000 → 21 × 2−1027 (denormalized); 7FF0 0001 0000 0000 → NaN.

BCD, Gray, ASCII

  • BCD: each decimal digit on 4 bits: 3,768 = 0011 0111 0110 1000BCD.
  • Gray (reflected binary code): a single bit changes from one number to the next, unweighted code. From 0 to 15:

0000 0001 0011 0010 0110 0111 0101 0100 1100 1101 1111 1110 1010 1011 1001 1000

  • ASCII: ‘0’ = 3016 = 48, ‘A’ = 4116 = 65, ‘a’ = 6116 = 97.

Never asked at the exam; on the syllabus of Moodle test 2.

Traps

  • Rounding instead of truncating; multiplying the whole product instead of its fractional part.
  • Fractional part grouped from the right (BB.2D instead of BB.B4); inner zeros lost (DC.81 → ….1000 0001).
  • A hexadecimal digit written in decimal (13 instead of D); a column total left in decimal.
  • A 0 forgotten in the quotient; partial products shifted wrongly.
  • A carry mistaken for a signed overflow; the binary word left empty when there is an overflow.
  • IEEE: a forgotten bias (127 / 1023); E without its leading zeros; the hidden 1 stored; a denormalized number with 2−1023 instead of 2−1022; an even k.
  • In English: a decimal point and a comma between thousands (3,129 = three thousand one hundred and twenty-nine).
