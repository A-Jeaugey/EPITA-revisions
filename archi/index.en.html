The instructions printed on the papers

  • Answer on the worksheet.10 papers out of 10The answers go in the boxes of the paper. A blank frame at the end is there if you run out of space.
  • Do not show any calculation unless you are explicitly asked.2023, 2024, 2025Conversions, 8-bit table, IEEE 754: only the result counts; the conversion instructions say it again (“Write down the result only (do not show any calculation)”). Do your working on scrap paper.
  • Show all calculations.9 papers out of 10The one exception: the written operations. Write each operation in the grid, digit by digit; for the division, the partial remainders; for the multiplication, one partial product per 1 of the multiplier. See methods 4 to 7.
  • If an overflow occurs, write down ‘ERROR’ instead of the decimal value.8-bit tableThe binary result is always written; ERROR only goes in the decimal column concerned (method 8).
  • Do not use a pencil or red ink.2023, 2024, 2025Use a pen, as in the other subjects.

“n digits after the point”: truncate

The successive multiplications stop at the number of digits asked for, without rounding. All five times rounding would have given something else, the answer key truncated: 141.310 → 8D.4C16 in 2018, not 8D.4D. This is not the IEEE 754 rule, which rounds to nearest.
