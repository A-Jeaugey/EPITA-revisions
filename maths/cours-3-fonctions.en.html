Every \(x\) has an image, not always the other way round.

A function associates a single image with each element of its input set. This lesson shows you how to find the image of a set and its reverse image, how to prove that a function is injective, surjective or bijective, and then how to change its sets so that it becomes so. In the October 2024 OBM exam, these questions are worth 10 points out of 40; in the 2023 LE exam, 8 points out of 20.

Part 1 notes p. 19 · ex. 4.14

Function, graph, arrow diagram

A function turns each element of a set \(E\) into an element of a set \(F\). This is what a Caml function does: it takes an argument and returns a result, always exactly one.

Definition function, mapping

Let \(E\) and \(F\) be two sets. A function (or mapping: the two words are synonyms in this class) \(f : E \to F\) associates with every element \(x\) of \(E\) a unique element \(f(x)\) of \(F\):

\[\forall x \in E,\ \exists !\, y \in F,\ y = f(x).\]
  • \(E\) is the input set, \(F\) the output set.
  • \(f(x)\) is the image of \(x\). If \(y = f(x)\), \(x\) is a pre-image of \(y\).
  • \(F^E\) denotes the set of all functions from \(E\) to \(F\) (\(\R^\R\): the functions from \(\R\) to \(\R\)).
Definition graph

The graph of \(f : E \to F\) is the set \(G_f = \{(x, f(x)),\ x \in E\}\), a subset of \(E \times F\). For a function from \(\R\) to \(\R\), it is the curve with equation \(y = f(x)\).

Method is it a function?
  1. On an arrow diagram: exactly one arrow leaves each element of \(E\). An element with no arrow, or with two arrows: it is not a function.
  2. The elements of \(F\) may receive any number of arrows: none, one or several.
  3. For a formula: check that \(f(x)\) exists for every \(x\) in the input set.

How many functions? Each element of the input set chooses its image freely. From \(\ent{1}{4}\) to \(\ent{1}{5}\), there are 5 choices for each of the 4 elements: \(5^4 = 625\) functions. In general, \(\card(F^E) = \card(F)^{\card(E)}\): these are the \(p\)-tuples of lesson 5.

Model answer exercise 4.14

Figure 2 does not define a function from \(E\) to \(F\): the element \(d\) has two images, 2 and 3.the faulty element

However, a function associates with each \(x \in E\) a unique image \(f(x) \in F\).

Trap: forgetting the input set
  • \(x \mapsto \frac{1}{x}\) is not a function from \(\R\) to \(\R\): 0 has no image. It is one from \(\R^*\) to \(\R\). Likewise, \(x \mapsto \sqrt{x}\) goes from \(\R^+\) to \(\R\).
  • An element of the output set with no pre-image does not stop \(f\) from being a function: only the input set is checked.

Image and reverse image of a set

You know the image of an element. It extends to sets: \(f(A)\) is not “\(f\) applied to the set \(A\)”, it is the set of all the values that \(f\) takes on \(A\).

Definition to write out: asked in 2022, 2023 and 2024

Let \(f : E \to F\), \(A \subset E\) and \(B \subset F\).

  • The image (direct image) of \(A\) under \(f\): \(f(A) = \{f(x),\ x \in A\} = \{y \in F,\ \exists x \in A,\ y = f(x)\}\). It is a subset of \(F\).
  • The reverse image (preimage) of \(B\): \(f^{-1}(B) = \{x \in E,\ f(x) \in B\}\). It is a subset of \(E\).

In other words: \(y \in f(A) \Leftrightarrow \exists x \in A,\ y = f(x)\) and \(x \in f^{-1}(B) \Leftrightarrow f(x) \in B\).

\(f^{-1}(B)\) exists for every function, even when the inverse function \(f^{-1}\) does not exist (part 5). Same notation, different meaning: here you take the reverse image of a set.

Method finite sets
  1. \(f(A)\): write the image of each element of \(A\), then remove the repetitions.
  2. \(f^{-1}(B)\): go through the whole of \(E\) and keep the \(x\) whose image is in \(B\). If none does, \(f^{-1}(B) = \varnothing\).

Example (exercise 4.15). \(f(a) = f(b) = 2\), \(f(c) = 3\), \(f(d) = 5\). Then \(f(\{a, b, c\}) = \{2, 3\}\), \(f(\{a, b, c, d\}) = \{2, 3, 5\}\), \(f^{-1}(\{2, 3\}) = \{a, b, c\}\) and \(f^{-1}(\{1, 5\}) = \{d\}\): 1 has no pre-image, it contributes nothing.

2022 midterm, exercise 2.2. \(f : \ent{1}{4} \to \ent{10}{14}\), \(f(1) = 10\), \(f(2) = f(3) = 11\), \(f(4) = 13\). Then \(f(\ent{1}{4}) = \{10, 11, 13\}\), \(f(\{3\}) = \{11\}\), \(f^{-1}(\{10, 11\}) = \{1, 2, 3\}\) and \(f^{-1}(\{12\}) = \varnothing\).

OBM exam 2024, exercise 2.2. \(E = \{2, 3, 4\}\), \(F = \{1, 2, 3\}\) and \(f : E \times F \to \N\), \((x, y) \mapsto x + y\). The table of values gives \(f(E \times F) = \{3, 4, 5, 6, 7\}\), \(f(\{(2, 2), (4, 3)\}) = \{4, 7\}\), \(f^{-1}(\{1\}) = \varnothing\) (a sum is at least \(2 + 1 = 3\)) and \(f^{-1}(\{6\}) = \{(3, 3), (4, 2)\}\).

Model answer LE exam 2023, exercise 3

1. \(f(A) = \{f(x),\ x \in A\}\) and \(f^{-1}(B) = \{x \in E,\ f(x) \in B\}\).the exact sets

2. A function \(f : \{a, b, c, d\} \to \ent{1}{5}\) with \(f(\{a, b\}) = \{1, 2\}\), \(f^{-1}(\{5\}) = \varnothing\) and \(f^{-1}(\{2\}) = \{b, c\}\): \(f(a) = 1\), \(f(b) = f(c) = 2\), \(f(d) = 4\).

Check: \(b\) and \(c\) are the only elements with image 2, \(\{f(a), f(b)\} = \{1, 2\}\) and no element has image 5.read the three conditions again

Three functions work (\(f(d)\) is 1, 3 or 4: enumeration of the 625 functions). One is enough, but it must satisfy all three conditions at once, and every element must have an image.

Trap: sets, not numbers
  • \(f(\{3\}) = \{11\}\) is a set; \(f(3) = 11\) is a number. Keep the braces.
  • \(f^{-1}(\{y\})\) can be empty (\(y\) has no pre-image) or contain several elements.
  • In general \(f(f^{-1}(B)) \neq B\) and \(f^{-1}(f(A)) \neq A\). With \(f(x) = x^2\) on \(\R\): \(f^{-1}(f([0, 1])) = f^{-1}([0, 1]) = [-1, 1]\), and \(f(f^{-1}([-1, 1])) = f([-1, 1]) = [0, 1]\).

Images of intervals by the basic functions

For a function from \(\R\) to \(\R\), you cannot list the images one by one. You read the image of an interval on the table of variations: on a piece where \(f\) is strictly monotonic, the image goes from one end to the other.

Theorem admitted: continuous function on an interval

If \(f\) is continuous and strictly increasing on \([a, b]\), then \(f([a, b]) = [f(a), f(b)]\). If it is strictly decreasing, \(f([a, b]) = [f(b), f(a)]\). An open or infinite end of the interval gives an open end, equal to the limit of \(f\).

Method images of intervals
  1. Draw the graph (on your draft) or make the table of variations on the input set.
  2. \(f(A)\): cut \(A\) into pieces where \(f\) is strictly monotonic; on each one, the image goes from the value (or limit) at one end to the one at the other end. Put the pieces together.
  3. Closed bracket if the value is reached at a point of \(A\), open otherwise.
  4. \(f^{-1}(B)\): solve “\(f(x) \in B\)” piece by piece, without leaving the input set.

  • \(\ln(\{0\})\) makes no sense: 0 is not in the input set. Writing \(\varnothing\) is another answer, to be justified.

Injectivity

Definition injective

\(f : E \to F\) is injective if two elements with the same image are equal:

\[\forall (x, x') \in E^2,\ f(x) = f(x') \Rightarrow x = x'.\]

By contrapositive, this is the same as \(\forall (x, x') \in E^2,\ x \neq x' \Rightarrow f(x) \neq f(x')\): distinct elements always have distinct images. Each element of \(F\) has at most one pre-image.

Negation: \(f\) is not injective \(\Leftrightarrow \exists (x, x') \in E^2,\ f(x) = f(x') \land x \neq x'\).

Arrow diagram

No element of \(F\) receives two arrows.

Graph

Every horizontal line meets the curve at most once.

Method prove, disprove
  1. To prove it: “Let \(x, x' \in E\) such that \(f(x) = f(x')\).” Compute until you get \(x = x'\).
  2. To disprove it: give two precise numbers, distinct, with the same image, and compute their images.
Model answer seminar notes

Let us show that \(f : \R \to \R\), \(x \mapsto 2x + 1\) is injective.

Let \(x_1, x_2 \in \R\) such that \(f(x_1) = f(x_2)\). Then \(2x_1 + 1 = 2x_2 + 1\), so \(2x_1 = 2x_2\), so \(x_1 = x_2\).down to x₁ = x₂

Hence \(f\) is injective.

Model answer exercise 6.26, a fraction

Let \(f(x) = \frac{x + 1}{2x + 3}\) on \(I = \R \setminus \{-\frac{3}{2}\}\). Let \(x, x' \in I\) such that \(f(x) = f(x')\).

Then \((x + 1)(2x' + 3) = (x' + 1)(2x + 3)\), that is \(2xx' + 3x + 2x' + 3 = 2xx' + 3x' + 2x + 3\).cross-multiply

What remains is \(x = x'\): \(f\) is injective on \(I\).

Model answer not injective: LE exam 2023

\(g(x) = |x - 1|\): \(g(0) = g(2) = 1\) and \(0 \neq 2\).two precise numbers

Two distinct elements have the same image: \(g\) is not injective.

Theorem strict monotonicity

If \(f\) is strictly monotonic on an interval \(I\), then \(f\) is injective on \(I\).

Proof: let \(x \neq x'\) in \(I\), say \(x < x'\). If \(f\) is strictly increasing, \(f(x) < f(x')\), so \(f(x) \neq f(x')\). The same holds if it is strictly decreasing.

Finite sets (exercise 5.20). An injective function from \(E\) to \(F\) sends the elements of \(E\) to elements that are all different: you need \(\card(E) \leq \card(F)\). From \(\ent{1}{4}\) to \(\ent{1}{5}\), there are 120 of them (the arrangements of lesson 5); from \(\ent{1}{4}\) to \(\ent{1}{3}\), none.

Trap: the wrong implication
  • “\(x = x' \Rightarrow f(x) = f(x')\)” is true for every function: it is not injectivity. The direction is \(f(x) = f(x') \Rightarrow x = x'\).
  • “\(f\) is increasing so it is injective” is false: a constant function is increasing. You need strictly increasing.
  • Examples do not prove injectivity: \(f(1) \neq f(2)\) says nothing about the other pairs.

Surjectivity, bijectivity, inverse function

Definition surjective

\(f : E \to F\) is surjective if every element of \(F\) has at least one pre-image:

\[\forall y \in F,\ \exists x \in E,\ y = f(x).\]

In other words, \(f(E) = F\). Negation: \(\exists y \in F,\ \forall x \in E,\ f(x) \neq y\).

Arrow diagram

Each element of \(F\) receives at least one arrow.

Graph

Every horizontal line \(y = b\), with \(b \in F\), meets the curve at least once.

Method prove surjectivity
  1. On your draft: for \(y \in F\), solve \(f(x) = y\) for the unknown \(x\).
  2. On your paper: “Let \(y \in F\). Set \(x = \dots\)”; check that \(x \in E\), then that \(f(x) = y\).
  3. To disprove it: a precise \(y\) of \(F\) with no pre-image, with the reason.
Model answer seminar notes

Let us show that \(f : \R \to \R\), \(x \mapsto x^3\) is surjective.

Let \(y \in \R\). Set \(x = \sqrt[3]{y}\): \(x \in \R\) and \(f(x) = (\sqrt[3]{y})^3 = y\).set it, check it

Every real number has a pre-image: \(f\) is surjective.

Model answer not surjective

\(f : \R \to \R\), \(x \mapsto x^2\). For every \(x \in \R\), \(x^2 \geq 0\): the equation \(x^2 = -1\) has no solution.

\(-1\) has no pre-image: \(f\) is not surjective.a precise element of F

Definition bijective

\(f\) is bijective if it is both injective and surjective. Equivalently (exercise 5.24):

\[\forall y \in F,\ \exists !\, x \in E,\ y = f(x).\]

The existence of \(x\) is surjectivity; its uniqueness is injectivity. Every element of \(F\) has exactly one pre-image.

Theorem accepted without proof (seminar, ex. 5.24)

\(f : E \to F\) is bijective if and only if there exists \(g : F \to E\) such that \(\forall x \in E,\ g \circ f(x) = x\) and \(\forall y \in F,\ f \circ g(y) = y\). This \(g\) is unique: it is the inverse function \(f^{-1}\), and

\[\big(y = f(x) \text{ and } x \in E\big) \Leftrightarrow \big(x = f^{-1}(y) \text{ and } y \in F\big).\]

The graphs of \(f\) and \(f^{-1}\) are symmetric with respect to the line \(y = x\). Examples: \(\exp : \R \to ]0, +\infty[\) and \(\ln\); \(x \mapsto x^2\) from \(\R^+\) to \(\R^+\) and \(\sqrt{\ }\).

Model answer exercise 6.26: a bijection and its inverse

\(f(x) = \frac{x + 1}{2x + 3}\) on \(I = \R \setminus \{-\frac{3}{2}\}\). Let \(y \in \R \setminus \{\frac{1}{2}\}\). For \(x \in I\): \(f(x) = y \Leftrightarrow x + 1 = y(2x + 3) \Leftrightarrow x(1 - 2y) = 3y - 1 \Leftrightarrow x = \frac{1 - 3y}{2y - 1}\).y ≠ 1/2

This \(x\) is in \(I\) (otherwise \(f(x)\) would not be defined) and \(f\left(\frac{1 - 3y}{2y - 1}\right) = y\): it exists and it is unique.

And \(\frac{1}{2}\) has no pre-image: \(\frac{x + 1}{2x + 3} = \frac{1}{2}\) gives \(2x + 2 = 2x + 3\), which is impossible. So \(f\) is bijective from \(I\) to \(\R \setminus \{\frac{1}{2}\}\), with \(f^{-1}(y) = \frac{1 - 3y}{2y - 1}\).

Trap: surjectivity depends on the output set
  • The same formula \(x^2\) is surjective onto \(\R^+\) and not onto \(\R\): always write both sets.
  • \(f^{-1}(\{y\})\) (a set, always defined) is not \(f^{-1}(y)\) (a number, only if \(f\) is bijective).
  • Between two finite sets, a bijection needs the same cardinal: from \(\ent{1}{4}\) to \(\ent{1}{5}\), there is none.

Changing the sets to make it injective, surjective, bijective

Injectivity depends on the input set, surjectivity on the output set. A question came up in 2020, 2022, 2023 and 2024: “if not, find two intervals \(I\) and \(J\) such that \(f : I \to J\) is injective (surjective)”.

Method restricting
  1. Injective: shrink the input set to an interval \(I\) where \(f\) is strictly monotonic (read on the table of variations). The output set can stay \(\R\).
  2. Surjective: keep the input set and replace the output set by the image \(J = f(E)\).
  3. Bijective: both at once, \(f : I \to f(I)\) with \(f\) strictly monotonic and continuous on the interval \(I\).
Model answer LE exam 2023, exercise 3.3c-d

(c) \(g(0) = g(2) = 1\) and \(0 \neq 2\): \(g\) is not injective. On \(I_1 = [1, +\infty[\), \(g(x) = x - 1\) is strictly increasing: \(g : I_1 \to J_1 = \R\) is injective.the reason

(d) For every \(x\), \(g(x) \geq 0\): \(-2\) has no pre-image, \(g\) is not surjective. Since \(g(\R) = [0, +\infty[\), \(g : I_2 = \R \to J_2 = \R^+\) is surjective.

  • Always give \(I\) and \(J\), with the reason (“strictly increasing on \(I\)”, “\(g(\R) = [1, +\infty[\)”).

  • In the 2024 OBM exam, \(I\) and \(J\) had to contain at least two elements, and the function had to be injective and not surjective: check the “not” part too.

Composition

Definition composition

Let \(f : E \to F\) and \(g : F \to G\). The composition \(g \circ f : E \to G\) is defined by \((g \circ f)(x) = g(f(x))\): apply \(f\) first, then \(g\).

It only exists if the images of \(f\) lie in the input set of \(g\) (here, the output set of \(f\) is the input set of \(g\)).

Example (exercise 5.23.1). \(f(x) = x^2\), \(g(x) = x + 1\), \(h(x) = \cos x\):

\((f \circ f)(x) = x^4\), \(\quad\) \((f \circ g)(x) = (x + 1)^2 = x^2 + 2x + 1\), \(\quad\) \((g \circ f)(x) = x^2 + 1\),
\((g \circ g)(x) = x + 2\), \(\quad\) \((g \circ h)(x) = \cos x + 1\), \(\quad\) \((h \circ g)(x) = \cos(x + 1)\).

\(g \circ f \neq f \circ g\) in general: \((f \circ g)(1) = 4\) but \((g \circ f)(1) = 2\).

Exercise 5.23.2. With \(f(x) = 2x\), \(g(x) = -2x\) and \(h(x) = x^2\): \((h \circ f)(x) = (h \circ g)(x) = 4x^2\), although \(f \neq g\). You cannot “cancel” \(h\): \(h\) is not injective.

Exercise 5.23.3. \(f : [0, 1] \to \R\) and \(g : \R \to \R^+\): \(g \circ f\) and \(g \circ g\) exist; \(f \circ g\) and \(f \circ f\) do not, because \(\R^+\) and \(\R\) are not included in \([0, 1]\).

Exercise 5.23.4: decomposing. \(x \mapsto e^{\sqrt{x^2 + 1}}\) is \(\exp \circ \sqrt{\ } \circ u\) with \(u(x) = x^2 + 1\): read from the inside out.

2018 midterm, exercise 6. \(f : \R^2 \to \R\), \((x, y) \mapsto xy\) and \(g : \R \to \R^2\), \(x \mapsto (x, x^2)\): \(f \circ g(x) = x \cdot x^2 = x^3\) and \(g \circ f(x, y) = (xy, x^2y^2)\).

Theorem exercise 5.25 ★, 2022 midterm

Let \(f : E \to F\) and \(g : F \to G\). If \(f\) and \(g\) are injective, \(g \circ f\) is injective. If \(f\) and \(g\) are surjective, \(g \circ f\) is surjective. So the composition of two bijections is a bijection.

Model answer official 2022 correction, exercise 2.4

Assume \(f\) and \(g\) are injective. We want to show that \(\forall (x, x') \in E^2,\ g \circ f(x) = g \circ f(x') \Rightarrow x = x'\).the goal, written

Let \((x, x') \in E^2\) such that \(g \circ f(x) = g \circ f(x')\). Then \(g(f(x)) = g(f(x'))\). Since \(g\) is injective, \(f(x) = f(x')\). This implies \(x = x'\) because \(f\) is injective.

Assume \(f\) and \(g\) are surjective. Let \(y \in G\). As \(g\) is surjective, \(\exists z \in F\) such that \(y = g(z)\). Since \(z \in F\) and \(f\) is surjective from \(E\) to \(F\), \(\exists x \in E\) such that \(z = f(x)\).

Thus \(y = g(z) = g(f(x)) = g \circ f(x)\): \(y\) has a pre-image under \(g \circ f\).

Trap: the reading order
  • \(g \circ f\) reads “\(g\) composed with \(f\)” but applies from right to left: \(f\) first. \((f \circ g)(x) = f(g(x))\).
  • Before composing, check that the composition exists (exercise 5.23.3).
  • \(h \circ f = h \circ g\) does not imply \(f = g\).

Definition parity, periodicity

Let \(f\) be defined on \(D\), with \(-x \in D\) for every \(x \in D\). \(f\) is even if \(\forall x \in D,\ f(-x) = f(x)\) (axis of symmetry: the \(y\)-axis), odd if \(\forall x \in D,\ f(-x) = -f(x)\) (centre of symmetry: the origin). \(f\) is \(T\)-periodic if \(\forall x \in D,\ x + T \in D\) and \(f(x + T) = f(x)\).

Exercise 5.22: \(\sin(4x)\) is \(\frac{\pi}{2}\)-periodic (\(\sin(4x + 2\pi) = \sin(4x)\)) and odd; it is enough to study it on \([0, \frac{\pi}{4}]\).

To know rules (handout)
  • \(|ab| = |a||b|\), \(|a + b| \leq |a| + |b|\) (triangle inequality), \(\sqrt{a^2} = |a|\).
  • \(e^{a + b} = e^a e^b\), \(e^{-a} = \frac{1}{e^a}\), \(e^a > 0\): an exponential never vanishes.
  • For \(a, b > 0\): \(\ln(ab) = \ln a + \ln b\), \(\ln\frac{1}{a} = -\ln a\), \(\ln(a^n) = n \ln a\). And \(e^y = x \Leftrightarrow y = \ln x\) for \(x > 0\).
Definition arctan (exercise 5.24)

\(\tan\) is continuous and strictly increasing from \(]-\frac{\pi}{2}, \frac{\pi}{2}[\) to \(\R\), with limits \(-\infty\) and \(+\infty\): it is bijective. Its inverse function is \(\arctan : \R \to ]-\frac{\pi}{2}, \frac{\pi}{2}[\), strictly increasing, odd, with derivative \(\arctan'(y) = \frac{1}{1 + y^2}\) (because \(\tan' = 1 + \tan^2\)).

Values: \(\arctan 0 = 0\), \(\arctan 1 = \frac{\pi}{4}\), \(\arctan \sqrt{3} = \frac{\pi}{3}\), \(\arctan\frac{1}{\sqrt{3}} = \frac{\pi}{6}\), \(\arctan(-1) = -\frac{\pi}{4}\).

Good to know

arctan has never come up in the 2016 to 2024 exams: only a derivative of \(\arctan \circ \arctan\) in 2019, in an analysis part that is no longer in the syllabus of this exam. Remember the definition, the values and the derivative, without spending more time on it.

Trap: the false formulas
  • \((a + b)^2 \neq a^2 + b^2\), \(\sqrt{a + b} \neq \sqrt{a} + \sqrt{b}\), \(\ln(a + b) \neq \ln a + \ln b\), \(\frac{1}{a + b} \neq \frac{1}{a} + \frac{1}{b}\): test with \(a = b = 1\).
  • \(\ln(a^n) = n \ln a\) requires \(a > 0\): the handout states it “for \(a \in \R\)”, which is a mistake (\(\ln(-1)\) does not exist).
  • \(\arctan(\tan \pi) = 0\), not \(\pi\): \(\arctan(\tan x) = x\) only for \(x \in ]-\frac{\pi}{2}, \frac{\pi}{2}[\).
