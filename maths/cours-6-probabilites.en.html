Part 1 summary sheet “Probability space” § 1.1 · ex. 1.2

Random experiment, sample set, events

A random experiment is an experiment whose outcome cannot be predicted with certainty: rolling a dice, drawing a hand of cards, picking a student at random. Each possible result is an outcome, written \(\omega\). In this lesson, there are only finitely many outcomes.

Definition sample set, event
  • The sample set (or sample space) \(\Omega\) is the set of all outcomes. It is finite: \(\Omega = \{\omega_1, \ldots, \omega_n\}\).
  • An event is a subset of \(\Omega\): \(A \subset \Omega\). We say that \(A\) occurs when the outcome obtained belongs to \(A\).
  • An elementary event contains only one outcome: it is a singleton \(\{\omega\}\).
  • \(\mathcal{P}(\Omega)\), the power set of \(\Omega\), is the set of all events. \(\Omega\) is the certain event, \(\varnothing\) the impossible event.

Events are sets: they are combined with the operations of lesson 2. Each operation has its sentence. In the table, we roll a dice: \(\Omega = \ent{1}{6}\), \(A\) “getting an even number” \(= \{2, 4, 6\}\) and \(B\) “getting at least 4” \(= \{4, 5, 6\}\).

Definition incompatible events, partition
  • \(A\) and \(B\) are incompatible (mutually exclusive, disjoint) if \(A \cap B = \varnothing\).
  • \(A_1, \ldots, A_p\) are pairwise disjoint if \(A_i \cap A_j = \varnothing\) for all \(i \neq j\).
  • They form a partition of \(\Omega\) (mutually exclusive collectively exhaustive events) if they are pairwise disjoint and their union is \(\Omega\): \(\Omega = A_1 \sqcup A_2 \sqcup \cdots \sqcup A_p\). Each outcome then belongs to one and only one \(A_i\). The symbol \(\sqcup\) denotes a union of disjoint sets.
  • For any event \(A\), \((A, \overline{A})\) is a partition of \(\Omega\): it is the one used in total probability exercises (part 7).

Type !(A|B): the region outside both circles, “neither \(A\) nor \(B\)”. Then type !A & !B: the same regions. This is De Morgan’s law, \(\overline{A \cup B} = \overline{A} \cap \overline{B}\) (lesson 2).

Example (ex. 1.2): describing the sample set. A box contains 5 red and 6 white marbles. To get equally likely outcomes, number the marbles from 1 to 11 (the red ones from 1 to 5). The form of \(\Omega\) depends on the way of drawing (lesson 5).

  • “\(\Omega = \{R, R, R, W, \ldots\}\)” is not a set: an element appears only once in a set. And the sample set \(\{R, W\}\) does not give equally likely outcomes (5 red, 6 white). Number identical objects.
  • Incompatible is not complementary. \(A\) and \(\overline{A}\) are incompatible and their union is \(\Omega\). “Getting 1” and “getting 2” are incompatible without being complementary.

Part 2 summary sheet “Probability space” § 1.2 · ex. 1.1

Probability function, probability space

Definition probability function, probability space

Let \(\Omega\) be a finite set. A probability function on \(\Omega\) is a function \(\P : \mathcal{P}(\Omega) \to [0, 1]\) that satisfies the two axioms:

  1. \(\P(\Omega) = 1\);
  2. for any pair of disjoint events \((A, B) \in [\mathcal{P}(\Omega)]^2\), \(\P(A \sqcup B) = \P(A) + \P(B)\).

The 3-tuple \((\Omega, \mathcal{P}(\Omega), \P)\) is a probability space.

Exercises 2 (ex. 1.1) start from the three Kolmogorov’s axioms: \(f(\Omega) = 1\), \(f(A) \geq 0\) for every \(A\), and additivity for two disjoint events. It is the same thing: with these three axioms, one proves that \(f\) takes its values in \([0, 1]\) (part 3). Such an \(f\) is called a probability function, and \((\Omega, \mathcal{P}(\Omega), f)\) a probability space.

Theorem a probability function is determined by the singletons

If \(\Omega = \{\omega_1, \ldots, \omega_n\}\), for any event \(A\):

\[\P(A) = \sum_{\omega \in A} \P(\{\omega\}).\]

Conversely, numbers \(p_1, \ldots, p_n\) that are non-negative and add up to 1 define one and only one probability function on \(\Omega\) such that \(\P(\{\omega_i\}) = p_i\) for every \(i\). The first statement is proved in part 3 (property 2).

Method defining a probability function, or checking that you have one
  1. Give the probability \(p_i\) of each outcome \(\omega_i\).
  2. Check that each \(p_i\) is non-negative and that \(p_1 + \cdots + p_n = 1\).
  3. The probability of an event is the sum of the probabilities of its outcomes.

  • A probability is never negative and never greater than 1: always check that your results are consistent.

Part 3 theorems and proofs § 1 · ex. 1.1

Properties of a probability function, with proofs

You know these properties well, you have seen them before. The purpose here is to see that they can be proved using the two axioms only. The Moodle document “Theorems and proofs” gives them, written as below: lecture questions may ask for them.

Proposition properties of a probability function

Let \((\Omega, \mathcal{P}(\Omega), \P)\) be a probability space.

  1. \(\P(\varnothing) = 0\).
  2. If \(\Omega = \{\omega_1, \omega_2, \ldots, \omega_n\}\), the values \(\P(\{\omega_1\}), \P(\{\omega_2\}), \ldots, \P(\{\omega_n\})\) enable one to define the function \(\P\).
  3. \(\forall (A, B) \in [\mathcal{P}(\Omega)]^2,\ \P(A) = \P(A \setminus B) + \P(A \cap B)\).
  4. \(\forall (A, B) \in [\mathcal{P}(\Omega)]^2,\ \P(A \cup B) + \P(A \cap B) = \P(A) + \P(B)\).
Proof you have to know Theorems and proofs, § 1

From the definition of a probability function, we know that: (i) \(\P(\Omega) = 1\); (ii) for all \((A, B) \in [\mathcal{P}(\Omega)]^2\) such that \(A \cap B = \varnothing\), \(\P(A \sqcup B) = \P(A) + \P(B)\). Now, let us prove the four properties.

1. For any set \(A \in \mathcal{P}(\Omega)\), we have \(A \cap \varnothing = \varnothing\). Thus, by using the second axiom satisfied by the function \(\P\), we get:

\[\P(A \sqcup \varnothing) = \P(A) + \P(\varnothing).\]

However, \(A \sqcup \varnothing = A\). Hence \(\P(A) = \P(A) + \P(\varnothing)\), which implies: \(\P(\varnothing) = 0\).

2. We have to show that for all \(A \in \mathcal{P}(\Omega)\), the value of \(\P(A)\) can be determined. Let \(A \in \mathcal{P}(\Omega)\). Since \(\Omega\) is a finite set, \(A \subset \Omega\) is a finite set too. We can hence enumerate its elements and write \(A\) with the form

\[A = \{x_1, x_2, \ldots, x_p\} \quad \text{with} \quad \card(A) = p.\]

Thus, \(A\) can be expressed as the disjoint union \(A = \{x_1\} \sqcup \{x_2\} \sqcup \cdots \sqcup \{x_p\}\). By using the second axiom satisfied by the function \(\P\), we get:

\[\P(A) = \P(\{x_1\}) + \P(\{x_2\}) + \cdots + \P(\{x_p\}).\]

3. Let \((A, B) \in [\mathcal{P}(\Omega)]^2\). \(A\) can be written as the disjoint union \(A = (A \setminus B) \sqcup (A \cap B)\). Thus,

\[\P(A) = \P(A \setminus B) + \P(A \cap B).\]

4. Let \((A, B) \in [\mathcal{P}(\Omega)]^2\). The set \(A \cup B\) can be written as the disjoint union \(A \cup B = (A \setminus B) \sqcup (A \cap B) \sqcup (B \setminus A)\). We hence get:

\[\P(A \cup B) = \P(A \setminus B) + \P(A \cap B) + \P(B \setminus A).\]

Furthermore, using property 3,

\[\begin{cases} \P(A) = \P(A \setminus B) + \P(A \cap B) \\ \P(B) = \P(B \setminus A) + \P(A \cap B) \end{cases}\]

By summing these two relations, we get:

\[\P(A) + \P(B) = \underbrace{\P(A \setminus B) + \P(A \cap B) + \P(B \setminus A)}_{\P(A \cup B)} + \P(A \cap B).\]

Thus, \(\P(A \cup B) + \P(A \cap B) = \P(A) + \P(B)\).

Two points of wording
  • In property 3, the document writes “Let \(A \in \mathcal{P}(\Omega)\)” without introducing \(B\). Write “Let \((A, B) \in [\mathcal{P}(\Omega)]^2\)”.
  • In properties 2 and 4, axiom (ii) is used with more than two sets. This is allowed: step by step (by induction), it extends to any finite family of pairwise disjoint events.
Theorem other consequences of the axioms (ex. 1.1)

For any events \(A\), \(B\), \(C\):

  • \(\P(\overline{A}) = 1 - \P(A)\);
  • \(0 \leq \P(A) \leq 1\);
  • if \(A \subset B\): \(\P(B \setminus A) = \P(B) - \P(A)\) and \(\P(A) \leq \P(B)\) (a probability function is increasing);
  • inclusion-exclusion formula (property 4 rewritten): \(\P(A \cup B) = \P(A) + \P(B) - \P(A \cap B)\);
  • with three events: \(\P(A \cup B \cup C) = \P(A) + \P(B) + \P(C) - \P(A \cap B) - \P(A \cap C) - \P(B \cap C) + \P(A \cap B \cap C)\).
Proof of the first three points

\(\Omega = A \sqcup \overline{A}\), hence \(1 = \P(\Omega) = \P(A) + \P(\overline{A})\), so \(\P(\overline{A}) = 1 - \P(A)\).

If \(A \subset B\), then \(B = A \sqcup (B \setminus A)\), hence \(\P(B) = \P(A) + \P(B \setminus A)\). Since \(\P(B \setminus A) \geq 0\), we get \(\P(A) \leq \P(B)\). With \(B = \Omega\): \(\P(A) \leq \P(\Omega) = 1\).

Example (MCQ of 29 September 2025). In a group of 42 students, 30 study English (\(A\)), 25 study Chinese (\(C\)), and each of them studies at least one of the two languages: \(\P(A \cup C) = 1\). We pick a student at random. By inclusion-exclusion:

\(\P(A \cap C) = \P(A) + \P(C) - \P(A \cup C) = \frac{30}{42} + \frac{25}{42} - 1 = \frac{13}{42}\)

13 students study both languages.

Model answer lecture question

Let us prove that \(\P(\overline{A}) = 1 - \P(A)\). Let \(A \in \mathcal{P}(\Omega)\).

\(A \cap \overline{A} = \varnothing\) and \(A \sqcup \overline{A} = \Omega\).disjoint: we may add

By the second axiom, \(\P(A) + \P(\overline{A}) = \P(\Omega) = 1\), hence \(\P(\overline{A}) = 1 - \P(A)\).

Trap: subtracting without an inclusion
  • \(\P(A \setminus B) = \P(A) - \P(B)\) is false in general: it is \(\P(A) - \P(A \cap B)\) (property 3). On the dice, with \(A\) “even” and \(B\) “at least 4”: \(\P(A \setminus B) = \P(\{2\}) = \frac{1}{6}\), but \(\P(A) - \P(B) = \frac{1}{2} - \frac{1}{2} = 0\).
  • \(\P(B \setminus A) = \P(B) - \P(A)\) requires \(A \subset B\). In inclusion-exclusion, do not forget \(- \P(A \cap B)\).

Equiprobability: counting to compute

Definition equiprobability

There is equiprobability when all outcomes have the same probability, \(\frac{1}{\card(\Omega)}\). We also say that \(\P\) is the uniform distribution on \(\Omega\). Then, for any event \(A\):

\[\P(A) = \frac{\card(A)}{\card(\Omega)} = \frac{\text{number of positive cases}}{\text{number of possible cases}}.\]

This is property 2 of part 3: \(\P(A)\) is the sum of \(\card(A)\) terms, all equal to \(\frac{1}{\card(\Omega)}\). Computing a probability becomes a counting problem (lesson 5).

Method computing under equiprobability
  1. Describe \(\Omega\): does order matter? is there replacement? (lesson 5).
  2. Justify equiprobability with the wording: “fair dice”, “at random”, “cannot be distinguished by touch”.
  3. Count \(\card(\Omega)\) and \(\card(A)\) with the same model: subsets with subsets, lists with lists.
  4. Divide and simplify. For “at least one”, use the complement: \(\P(A) = 1 - \P(\overline{A})\).

Poincaré’s dice (ex. 1.3). We roll two indistinguishable dice: does “getting at least one 6” have probability \(\frac{11}{36}\) or \(\frac{6}{21}\)? Even if they look the same, the dice are two distinct objects: imagine them with different colours. The 36 pairs are equally likely, 11 of them contain a 6: \(\P = \frac{11}{36}\). The computation \(\frac{6}{21}\) assumes that the 21 unordered pairs are equally likely. This is wrong: the pair \(\{5, 6\}\) comes from two 2-tuples, \((5, 6)\) and \((6, 5)\), whereas the pair \(\{6, 6\}\) comes from only one.

Birthdays (ex. 1.4). With \(N\) persons and 365 equally likely days, the complement of “at least two persons have the same birthday” is “the \(N\) days are distinct”: \(\P = 1 - \frac{A_{365}^{N}}{365^N}\). From \(N = 23\) on, this probability exceeds \(\frac{1}{2}\) (\(\approx 0.507\)).

Model answer ex. 2.5, at least one ace

An outcome is a 5-card hand, that is, a 5-element subset of the 32-card deck: \(\card(\Omega) = \binom{32}{5} = 201\,376\).

The hand is picked at random: there is equiprobability.say it

Let \(A\) be “the hand contains at least one ace”. Its complement \(\overline{A}\) is “no ace”: the 5 cards are taken among the 28 cards that are not aces, hence \(\card(\overline{A}) = \binom{28}{5} = 98\,280\).

Thus \(\P(A) = 1 - \P(\overline{A}) = 1 - \frac{98\,280}{201\,376} = \frac{1\,841}{3\,596} \approx 0.512\).

Trap: outcomes that are not equally likely
  • Indistinguishable dice: count 2-tuples, not unordered pairs (\(\frac{11}{36}\), not \(\frac{6}{21}\)).
  • “At least one ace” is not \(4 \times \binom{31}{4}\) (one ace, then any 4 cards): a hand with two aces is counted twice. Use the complement.
  • “An integer between 0 and 20”: there are 21 of them. \(\P(\text{at least } 10) = \frac{11}{21}\), not \(\frac{1}{2}\) (MCQ of 6 October 2025).

Conditional probability, chain rule, probability trees

Knowing that \(B\) occurred changes the chances of \(A\): only the outcomes in \(B\) are left. A fair dice gives an even number: the probability that it is a 6 is no longer \(\frac{1}{6}\). Three outcomes are left, 2, 4 and 6: it is \(\frac{1}{3}\).

Definition conditional probability

Let \(A\) and \(B\) be two events, with \(\P(B) \neq 0\). The conditional probability of \(A\) given \(B\) is

\[\P(A \mid B) = \frac{\P(A \cap B)}{\P(B)}.\]

It is also written \(\P_B(A)\), in particular on trees.

\(\P(\{6\} \mid \{2, 4, 6\}) = \frac{\P(\{6\})}{\P(\{2, 4, 6\})} = \frac{1/6}{1/2} = \frac{1}{3}\)
Theorem given \(B\), we still have a probability function

If \(\P(B) \neq 0\), the mapping \(A \mapsto \P(A \mid B)\) is a probability function on \(\Omega\). In particular \(\P(\overline{A} \mid B) = 1 - \P(A \mid B)\).

Proof: \(\P(\Omega \mid B) = \frac{\P(B)}{\P(B)} = 1\); if \(A_1\) and \(A_2\) are disjoint, \((A_1 \sqcup A_2) \cap B = (A_1 \cap B) \sqcup (A_2 \cap B)\), and we divide by \(\P(B)\).

Theorem chain rule (intersection of events)

When the conditional probabilities are defined:

\[\P(A \cap B) = \P(A \mid B)\,\P(B) = \P(B \mid A)\,\P(A),\]
\[\P(A_1 \cap A_2 \cap \cdots \cap A_n) = \P(A_1)\,\P(A_2 \mid A_1)\,\P(A_3 \mid A_1 \cap A_2) \cdots \P(A_n \mid A_1 \cap \cdots \cap A_{n-1}).\]

The first line is the definition, multiplied by the denominator. The summary sheet writes the second one in reverse order, from \(A_n\) to \(A_1\).

Example (“Probability Exercises”, ex. 4). An urn contains 5 red balls and 3 blue balls. Two balls are drawn without replacement. \(R_1\): “the 1st one is red”, \(R_2\): “the 2nd one is red”. Given \(R_1\), 7 balls are left, 4 of them red: \(\P(R_2 \mid R_1) = \frac{4}{7}\).

\(\P(R_1 \cap R_2) = \P(R_1)\,\P(R_2 \mid R_1) = \frac{5}{8} \times \frac{4}{7} = \frac{5}{14}\)
Method the probability tree
  1. First level: a partition, for example \(A\) and \(\overline{A}\), with their probabilities.
  2. After the branch \(A\), write the probabilities given \(A\): \(\P(B \mid A)\) and \(\P(\overline{B} \mid A)\). The branches leaving one node add up to 1.
  3. The probability of a path is the product of its branches: it is the probability of the intersection, \(\P(A \cap B) = \P(A)\,\P(B \mid A)\).
  4. The probability of an event is the sum of the paths that lead to it (part 7).

The second draw depends on the first one: given \(\overline{R_1}\), 5 red balls out of 7 are left. The tool also gives \(\P(R_2) = \frac{5}{8}\): the second ball is red with the same probability as the first one.

Example (ex. 3.12, ANAC points). 60% of the students get points with sport (\(S\)), 50% with communication activities (\(C\)), and one third of the students doing sport also do communication activities: \(\P(C \mid S) = \frac{1}{3}\).

\(\P(S \cap C) = \P(C \mid S)\,\P(S) = \frac{1}{3} \times \frac{3}{5} = \frac{1}{5}\)
\(\P(S \cup C) = \P(S) + \P(C) - \P(S \cap C) = \frac{3}{5} + \frac{1}{2} - \frac{1}{5} = \frac{9}{10}\)
\(\P(\overline{S} \cap \overline{C}) = 1 - \P(S \cup C) = 1 - \frac{9}{10} = \frac{1}{10}\)

10% of the students get no point.

Model answer “Conditional Probability”, ex. 4

We draw 2 cards successively, without replacement, from a 52-card deck. \(A\): “the first card is a heart”, \(B\): “the second card is a heart”.

Given \(A\), 51 cards are left, 12 of them hearts, picked at random: \(\P(B \mid A) = \frac{12}{51} = \frac{4}{17}\).the new sample set

Hence \(\P(A \cap B) = \P(B \mid A)\,\P(A) = \frac{4}{17} \times \frac{1}{4} = \frac{1}{17}\).

Trap: \(\P(A \mid B)\) is not \(\P(B \mid A)\)
  • In a 52-card deck: \(\P(\text{king} \mid \text{heart}) = \frac{1}{13}\), but \(\P(\text{heart} \mid \text{king}) = \frac{1}{4}\). Always divide by the probability of what is known, the event after the bar.
  • The official solution of 2019 (ex. 7) computes \(\P_B(A) = \frac{0.3}{0.7}\): it divides by \(\P(A)\). With \(\P(B) = 0.4\), \(\P_B(A) = \frac{0.3}{0.4} = \frac{3}{4}\).
  • “Given” is not “and”: “a student attends tutoring and passes” is \(\P(S \cap V)\), “given that he attends tutoring, he passes” is \(\P(V \mid S)\).

Part 6 summary sheet § 1.2 · ex. 3.7 · “Conditional Probability”, part A

Independence

Definition independent events

Two events \(A\) and \(B\) are independent if

\[\P(A \cap B) = \P(A)\,\P(B).\]

Then, if \(\P(B) \neq 0\), \(\P(A \mid B) = \P(A)\), and if \(\P(A) \neq 0\), \(\P(B \mid A) = \P(B)\): knowing that one occurred does not alter the chances of the other.

Theorem independence and complements

If \(A\) and \(B\) are independent, then \(A\) and \(\overline{B}\) are independent, and so are \(\overline{A}\) and \(\overline{B}\).

Proof “Conditional Probability”, ex. 2

Assume that \(A\) and \(B\) are independent. By property 3 of part 3, \(\P(A) = \P(A \setminus B) + \P(A \cap B)\), and \(A \setminus B = A \cap \overline{B}\). Hence

\[\P(A \cap \overline{B}) = \P(A) - \P(A \cap B) = \P(A) - \P(A)\,\P(B) = \P(A)\big(1 - \P(B)\big) = \P(A)\,\P(\overline{B}).\]

\(A\) and \(\overline{B}\) are independent. Apply this result to the pair \((\overline{B}, A)\), which is independent: \(\overline{B}\) and \(\overline{A}\) are independent.

Definition mutual independence

\(A\), \(B\), \(C\) are mutually independent if they are pairwise independent and \(\P(A \cap B \cap C) = \P(A)\,\P(B)\,\P(C)\). Pairwise is not enough.

Counterexample (sheet, ex. 2). Toss a fair coin twice: \(A\) “first toss is heads”, \(B\) “second toss is heads”, \(C\) “both tosses give the same result”. Each has probability \(\frac{1}{2}\), and each intersection of two of them is one 2-tuple out of four, with probability \(\frac{1}{4} = \frac{1}{2} \times \frac{1}{2}\): they are pairwise independent. But \(A \cap B \cap C = \{(H, H)\}\) and \(\P(A \cap B \cap C) = \frac{1}{4}\), whereas \(\P(A)\,\P(B)\,\P(C) = \frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}\): they are not mutually independent.

Model answer ex. 3.7

The number is picked at random in \(\ent{1}{20}\): equiprobability. \(A = \{2, 4, \ldots, 20\}\) (10 elements), \(B = \{5, 10, 15, 20\}\), \(A \cap B = \{10, 20\}\).

(a) \(A \cap B \neq \varnothing\): \(A\) and \(B\) are not incompatible.one common element is enough

(b) \(\P(A)\,\P(B) = \frac{10}{20} \times \frac{4}{20} = \frac{1}{10}\) and \(\P(A \cap B) = \frac{2}{20} = \frac{1}{10}\): equal, so \(A\) and \(B\) are independent.

In \(\ent{1}{21}\): \(\P(A \cap B) = \frac{2}{21} = \frac{42}{441}\) and \(\frac{42}{441} \neq \frac{40}{441}\) \(= \P(A)\,\P(B)\): they are no longer independent.

Midterm, October 2019, ex. 7 (2 points). With the 8-sided dice of part 2: \(\P(A \cap B) = \P(\{2, 4\}) = 0.1 + 0.2 = 0.3\), but \(\P(A)\,\P(B) = 0.7 \times 0.4 = 0.28\). \(A\) and \(B\) are not independent, and not incompatible either (\(\P(A \cap B) \neq 0\)).

Two dice (sheet, ex. 1). \(A\) “the first dice is even”, \(B\) “the sum is 7”, \(C\) “the sum is 8”. \(\P(A \cap B) = \frac{3}{36} = \frac{1}{12}\) \(= \frac{1}{2} \times \frac{1}{6}\): independent. \(\P(A \cap C) = \frac{3}{36} = \frac{1}{12}\), but \(\P(A)\,\P(C) = \frac{1}{2} \times \frac{5}{36} = \frac{5}{72}\): not independent.

Trap: three confusions
  • Independent is not incompatible, nor the other way round. To prove independence, compute \(\P(A \cap B)\) and \(\P(A)\,\P(B)\) and compare them.
  • Independence depends on \(\P\): the same “even” and “multiple of 5” are independent in \(\ent{1}{20}\), not in \(\ent{1}{21}\).
  • Draws without replacement are not independent. With two cards drawn without replacement, \(\P(B \mid A) = \frac{4}{17}\) whereas \(\P(B) = \frac{1}{4}\). With replacement, \(\P(B \mid A) = \frac{1}{4} = \P(B)\): independent.

Law of total probability

We often know the chances of \(A\) in each case (with tutoring, without tutoring) and the proportion of each case. The law of total probability puts the pieces back together.

Theorem law of total probability

Let \((B_1, \ldots, B_n)\) be a partition of \(\Omega\) (mutually exclusive collectively exhaustive events) with \(\P(B_i) \neq 0\) for every \(i\), and \(A\) an event. Then

\[\P(A) = \sum_{i=1}^{n} \P(A \cap B_i) = \sum_{i=1}^{n} \P(A \mid B_i)\,\P(B_i).\]

With the partition \((B, \overline{B})\): \(\P(A) = \P(A \mid B)\,\P(B) + \P(A \mid \overline{B})\,\P(\overline{B})\).

Proof ex. 3.8: “Which statement is given by the law of total probability? Prove it”

Let \(A \in \mathcal{P}(\Omega)\). Since \((B_1, \ldots, B_n)\) is a partition of \(\Omega\), \(\Omega = B_1 \sqcup \cdots \sqcup B_n\). Hence, since \(\cap\) distributes over \(\cup\),

\[A = A \cap \Omega = (A \cap B_1) \cup (A \cap B_2) \cup \cdots \cup (A \cap B_n).\]

This union is disjoint: for \(i \neq j\), \((A \cap B_i) \cap (A \cap B_j) \subset B_i \cap B_j = \varnothing\). By additivity of \(\P\) (extended to \(n\) pairwise disjoint events),

\[\P(A) = \P(A \cap B_1) + \cdots + \P(A \cap B_n).\]

Finally, for every \(i\), \(\P(B_i) \neq 0\) and, by definition of conditional probability, \(\P(A \cap B_i) = \P(A \mid B_i)\,\P(B_i)\). Hence \(\P(A) = \sum_{i=1}^{n} \P(A \mid B_i)\,\P(B_i)\).

A typo in the summary sheet

The French summary sheet “Probabilités conditionnelles” (p. 2) writes the last term \(\P(A \cap B_n)\,\P(B_n)\). Read \(\P(A \mid B_n)\,\P(B_n)\), as in the sum \(\sum \P(A \mid B_i)\,\P(B_i)\) on the same line.

DP exam, October 2023, ex. 4. The probability that a student attends maths tutoring (\(S\)) is 10%. If he attends, he passes the maths unit (\(V\)) with probability 80%; otherwise, 30%. Results as simplified fractions.

Model answer official solution, DP exam 2023, ex. 4.1 and 4.2

1. \(\P(S) = 0.1\), \(\P(V \mid S) = 0.8\), \(\P(V \mid \overline{S}) = 0.3\).translate first

2. Since \(\{S, \overline{S}\}\) is a partition of \(\Omega\), we have \(V = (V \cap S) \cup (V \cap \overline{S})\) (disjoint union).state the partition

Bayes’ formula, the “threshold” question

The wording gives \(\P(A \mid B)\) (the test is positive for 95% of sick people); the question asks for \(\P(B \mid A)\) (you test positive: what is the risk of being sick?). Bayes’ formula turns the conditional probability around.

Theorem Bayes’ formula

If \(\P(A) \neq 0\) and \(\P(B) \neq 0\):

\[\P(B \mid A) = \frac{\P(A \mid B)\,\P(B)}{\P(A)}.\]

If \((B_1, \ldots, B_n)\) is a partition of \(\Omega\) with \(\P(B_i) \neq 0\), for every \(k \in \ent{1}{n}\):

\[\P(B_k \mid A) = \frac{\P(A \mid B_k)\,\P(B_k)}{\sum_{i=1}^{n} \P(A \mid B_i)\,\P(B_i)}.\]
Proof

By definition, \(\P(B \mid A) = \frac{\P(A \cap B)}{\P(A)}\), and by the chain rule, \(\P(A \cap B) = \P(A \mid B)\,\P(B)\): replace the numerator. With a partition, also replace the denominator \(\P(A)\) using the law of total probability (part 7).

The medical test (“Conditional Probability”, ex. 7, figure 1). \(\P(M) = \frac{1}{100}\), \(\P(T \mid M) = \frac{95}{100}\), \(\P(T \mid \overline{M}) = \frac{10}{100}\).

\(\P(T) = \P(T \mid M)\,\P(M) + \P(T \mid \overline{M})\,\P(\overline{M}) = \frac{95}{100} \times \frac{1}{100} + \frac{10}{100} \times \frac{99}{100} = \frac{217}{2\,000}\)
\(\P(M \mid T) = \frac{\P(T \mid M)\,\P(M)}{\P(T)} = \frac{19/2\,000}{217/2\,000} = \frac{19}{217} \approx 0.088\)

Less than 9%: the disease is rare, and healthy people are so numerous that their 10% of false positives outnumber the true positives. Out of 2,000 persons:

40% of the students learn their maths lecture (\(C\)). They pass the year (\(V\)) with probability 80%, the others with 20%.

1. \(\P(C) = \frac{2}{5}\), \(\P(V \mid C) = \frac{4}{5}\), \(\P(V \mid \overline{C}) = \frac{1}{5}\).

2. \(\{C, \overline{C}\}\) is a partition of \(\Omega\), hence \(\P(V) = \P(V \mid C)\,\P(C) + \P(V \mid \overline{C})\,\P(\overline{C}) = \frac{4}{5} \times \frac{2}{5} + \frac{1}{5} \times \frac{3}{5} = \frac{11}{25}\).

Trap: what Bayes turns around
  • \(\P(T \mid M) = 95\,\%\) does not give \(\P(M \mid T)\): here \(\P(M \mid T) = \frac{19}{217}\). First write “We look for \(\P(\ldots \mid \ldots)\)”: what is known goes after the bar.
  • The denominator in Bayes’ formula is the probability of what is known, \(\P(A)\), computed with the law of total probability.
  • Threshold question: \(p\) is a probability, so \(p \in [0, 1]\). If you find \(p \geq 1.2\), no proportion works: say so. End with a sentence (“at least 90%”).
