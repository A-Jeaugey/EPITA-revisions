Connecteurs

  • \(P \Rightarrow Q\) n’est fausse que si \(P\) vraie et \(Q\) fausse ; \((P \Rightarrow Q) \iff (\neg P \lor Q)\).
  • \(\neg(P \land Q) \iff \neg P \lor \neg Q\) ; \(\neg(P \lor Q) \iff \neg P \land \neg Q\) (De Morgan).
  • \(\neg(P \Rightarrow Q) \iff P \land \neg Q\) : ce n’est pas une implication.
  • Contraposée \(\neg Q \Rightarrow \neg P\) : équivalente. Réciproque \(Q \Rightarrow P\) : non.
  • \(P \Rightarrow Q\) : \(P\) condition suffisante pour \(Q\), \(Q\) condition nécessaire pour \(P\). On place ⇒ du petit ensemble de vérité vers le grand.

Quantificateurs

  • \(\neg(\forall x \in E, P(x)) \iff \exists x \in E, \neg P(x)\) ; \(\neg(\exists x \in E, P(x)) \iff \forall x \in E, \neg P(x)\). Ensembles gardés.
  • \(\leq\) se nie en \(>\) ; \(m \leq f(x) \leq M\) en \(f(x) < m\) ou \(f(x) > M\).
  • L’ordre compte : \(\forall x\, \exists y,\ y > x\) vraie ; \(\exists y\, \forall x,\ y > x\) fausse.
  • Bornée : \(\exists (m, M) \in \R^2, \forall x \in \R, m \leq f(x) \leq M\). Majorée : \(\exists M \in \R, \forall x \in \R, f(x) \leq M\).
  • Constante : \(\exists c \in \R, \forall x \in \R, f(x) = c\). Périodique : \(\exists T \in \R^*, \forall x \in \R, f(x + T) = f(x)\).
  • Vrai ou faux : un \(\forall\) se prouve (« Soit \(x\) ») ou se réfute par un contre-exemple ; un \(\exists\) se prouve par un témoin.

Ensembles

  • \(\in\) : élément dans ensemble ; \(\subset\) : ensemble dans ensemble. \(\{3\} \subset \{1, 2, 3\}\), \(\{3\} \in \mathcal{P}(A)\), \(\varnothing \subset A\).
  • \(A \subset B \iff \forall x \in A, x \in B\) ; \(A = B\) : double inclusion.
  • \(\overline{A \cup B} = \overline{A} \cap \overline{B}\) ; \(\overline{A \cap B} = \overline{A} \cup \overline{B}\) ; \(A \setminus B = A \cap \overline{B}\).
  • \(\card(A \times B) = \card(A)\card(B)\) ; \(\card(\mathcal{P}(E)) = 2^{\card(E)}\) ; \(E \times F \neq F \times E\).
  • Crible : \(\card(A \cup B) =\) \(\card(A) + \card(B) - \card(A \cap B)\) ; à trois : \(+\card(A \cap B \cap C)\) après les trois intersections deux à deux.

Images

  • \(f(A) = \{f(x),\ x \in A\}\), soit \(\{y \in F,\ \exists x \in A,\ y = f(x)\}\) : une partie de \(F\).
  • \(f^{-1}(B) = \{x \in E,\ f(x) \in B\}\), partie de \(E\) : existe même si \(f\) n’est pas bijective ; peut être vide.
  • Intervalle : morceaux de stricte monotonie, borne fermée si atteinte : \(\exp(]0, \pi]) = ]1, e^{\pi}]\).
  • Résoudre dans le départ : sur \([-\pi, \pi]\), \(\sin^{-1}([0, 1])\) vaut \(\{-\pi\} \cup [0, \pi]\).

Injective, surjective

  • Injective : \(\forall (x, x') \in E^2,\ f(x) = f(x') \Rightarrow x = x'\). Non : \(f(a) = f(b)\) avec \(a \neq b\), chiffrés.
  • Surjective : \(\forall y \in F,\ \exists x \in E,\ y = f(x)\). Non : un \(y\) sans antécédent.
  • Bijective : \(\forall y \in F,\ \exists !\, x \in E,\ y = f(x)\).
  • Rendre injective : réduire le départ (stricte monotonie). Surjective : réduire l’arrivée à \(f(E)\).
  • Composée de deux injections : injection ; de deux surjections : surjection. \(h \circ f = h \circ g \not\Rightarrow f = g\).

Fonctions usuelles

  • \(\ln(ab) = \ln a + \ln b\), \(\ln(a^n) = n\ln a\) pour \(a, b > 0\) ; \(e^{a+b} = e^a e^b\), \(e^x > 0\).
  • \(\sqrt{a^2} = |a|\) ; \(|a + b| \leq |a| + |b|\) ; \(\cos\) paire, \(\sin\) impaire.
  • \(\tan' = 1 + \tan^2 = \frac{1}{\cos^2}\) ; \(\arctan : \R \to ]-\frac{\pi}{2}, \frac{\pi}{2}[\), \(\arctan'(y) = \frac{1}{1 + y^2}\).
  • \(\arctan 1 = \frac{\pi}{4}\), \(\arctan \sqrt{3} = \frac{\pi}{3}\), \(\arctan \frac{1}{\sqrt{3}} = \frac{\pi}{6}\).

Raisonnements

  • \(\forall x \in E, P(x)\) : « Soit \(x \in E\) fixé. » ; \(P \Rightarrow Q\) : « Supposons \(P\). » ; \(A \subset B\) : « Soit \(x \in A\) fixé. »
  • Contraposée : supposer \(\neg Q\), arriver à \(\neg P\). Absurde : supposer \(\neg P\), arriver à une contradiction.
  • Récurrence : \(\mathcal{P}(n)\) posée ; initialisation au bon rang ; hérédité \(\mathcal{P}(n) \Rightarrow \mathcal{P}(n+1)\) ; conclusion.
  • \(\sum_{k=1}^{n} k = \frac{n(n+1)}{2}\) ; \(\sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}\) ; \(\sum_{k=0}^{n} q^k = \frac{1 - q^{n+1}}{1 - q}\) si \(q \neq 1\).

Rédiger : les règles du séminaire

  • « Elles ont un rôle très important » (la prof, 19 octobre). OBM 2025 : « Rédiger en suivant les règles de rédaction vues en séminaire ».
  • La première ligne selon l’énoncé ; \(P \iff Q\) et \(A = B\) en deux temps annoncés.
  • On part des hypothèses, jamais de la conclusion ; un lien entre chaque ligne : alors, ainsi, or, d’où, donc.
  • On finit en recopiant ce qu’il fallait démontrer. Un « pour tout » faux : un contre-exemple chiffré.

Démonstrations à connaître

  • \(g \circ f\) injective : \(g(f(x)) = g(f(x'))\) donne \(f(x) = f(x')\), donc \(x = x'\).
  • \(g \circ f\) surjective : un antécédent de \(y\) par \(g\), puis un antécédent de celui-ci par \(f\).
  • \((\forall \varepsilon > 0, |a| \leq \varepsilon) \Rightarrow a = 0\) : contraposée, \(\varepsilon = \frac{|a|}{2}\).
  • \(n^2\) pair \(\Rightarrow\) \(n\) pair : contraposée, \(n = 2k + 1\) donne \(n^2 = 2(2k^2 + 2k) + 1\).
  • \(\sqrt{2}\) irrationnel : absurde avec \(\frac{p}{q}\) irréductible.

Pièges OBM

  • Négation qui change l’ensemble, ou \(\leq\) nié en \(<\).
  • « Croissante donc injective » : il faut strictement.
  • Surjective dépend de l’arrivée : \(x^2\) l’est sur \(\R^+\), pas sur \(\R\).
  • Antisymétrique n’est pas « non symétrique ».
  • \(\card(\{\varnothing\}) = 1\) ; une flèche manquante ou double : pas une fonction.

  • Anagrammes : \(\frac{n!}{k_1!\,k_2!\cdots}\). \(A_{10}^3 = 720\) mais \(\binom{10}{3} = 120\).

Coefficients binomiaux

  • \(\binom{n}{0} = \binom{n}{n} = 1\), \(\binom{n}{1} = n\) ; symétrie \(\binom{n}{k} = \binom{n}{n-k}\).
  • Pascal (\(1 \leq k \leq n\)) : \(\binom{n+1}{k} = \binom{n}{k-1} + \binom{n}{k}\).
  • Binôme : \((x + y)^n = \sum_{k=0}^{n} \binom{n}{k} x^{n-k} y^k\) ; \(\sum_{k=0}^{n} \binom{n}{k} = 2^n\).
  • Vandermonde : \(\sum_{i=0}^{k} \binom{p}{i}\binom{n}{k-i} = \binom{n+p}{k}\).
  • \(\binom{n}{p}\binom{p}{k} = \binom{n}{k}\binom{n-k}{p-k}\) (DP 2024) ; \(k\binom{n}{k} = n\binom{n-1}{k-1}\) (DP 2025).

Probabilités

  • \(\P : \mathcal{P}(\Omega) \to [0, 1]\), \(\P(\Omega) = 1\), \(\P(A \sqcup B) = \P(A) + \P(B)\) si \(A \cap B = \varnothing\).
  • \(\P(\varnothing) = 0\) ; \(\P(\overline{A}) = 1 - \P(A)\) ; \(\P(A \cup B) = \P(A) + \P(B) - \P(A \cap B)\).
  • Équiprobabilité : \(\P(A) = \frac{\card(A)}{\card(\Omega)}\).
  • \(\P(A \mid B) = \frac{\P(A \cap B)}{\P(B)}\) si \(\P(B) \neq 0\) ; \(\P(A \cap B) = \P(A \mid B)\P(B)\).
  • Indépendants : \(\P(A \cap B) = \P(A)\P(B)\). Incompatibles : \(A \cap B = \varnothing\). Ce n’est pas pareil.

Probabilités totales, Bayes

  • « Comme \(\{S, \overline{S}\}\) forme une partition de \(\Omega\), \(V = (V \cap S) \sqcup (V \cap \overline{S})\) » :
  • \(\P(V) = \P(V \mid S)\P(S) + \P(V \mid \overline{S})\P(\overline{S})\).
  • Bayes : \(\P(S \mid V) = \frac{\P(V \mid S)\P(S)}{\P(V)}\).
  • Seuil : \(\P(V) = ap + b(1 - p) \geq s \iff p \geq \frac{s - b}{a - b}\) (si \(a > b\)). DP 2023 : \(\frac{0{,}75 - 0{,}3}{0{,}8 - 0{,}3} = 0{,}9\).

Variables aléatoires

  • Loi : \(X(\Omega)\) et les \(\P(X = x_i)\), de somme 1.
  • \(\E(X) = \sum x_i \P(X = x_i)\) ; transfert : \(\E(f(X)) = \sum f(x_i)\P(X = x_i)\).
  • \(\mathrm{Var}(X) = \E((X - \E(X))^2)\), puis Koenig-Huygens : \(\mathrm{Var}(X) = \E(X^2) - (\E(X))^2\) ; \(\sigma(X) = \sqrt{\mathrm{Var}(X)}\).
  • \(\E(aX + b) = a\E(X) + b\) ; \(\mathrm{Var}(aX + b) = a^2\mathrm{Var}(X)\) ; \(\E(X + Y) = \E(X) + \E(Y)\).
  • \(X, Y\) indépendantes : \(\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)\).

Bernoulli, binomiale

  • Bernoulli(\(p\)) : \(X(\Omega) = \{0, 1\}\), \(\P(X = 1) = p\) ; \(\E = p\), \(\mathrm{Var} = p(1 - p)\).
  • \(Y = X_1 + \dots + X_n\), Bernoulli(\(p\)) indépendantes : \(Y \sim \mathcal{B}(n, p)\), \(Y(\Omega) = \ent{0}{n}\).
  • \(\P(Y = k) = \binom{n}{k} p^k (1 - p)^{n-k}\) ; somme 1 par le binôme ; \(\E(Y) = np\), \(\mathrm{Var}(Y) = np(1 - p)\).
  • DP 2024 : \(\mathcal{B}(20, \frac{3}{4})\), \(\E = 20 \times \frac{3}{4} = 15\), \(\mathrm{Var} = 20 \times \frac{3}{4} \times \frac{1}{4} = \frac{15}{4}\).
  • Uniforme sur \(\{1, \dots, n\}\) : \(\E = \frac{n+1}{2}\), \(\mathrm{Var} = \frac{n^2 - 1}{12}\).

Démonstrations à connaître

  • \(\E(aX + b)\) : transfert avec \(x \mapsto ax + b\), somme séparée, \(\sum \P(X = x_i) = 1\).
  • Koenig-Huygens : développer \((X - \E(X))^2\), linéarité, \(\E(X)\) constante.
  • \(\mathrm{Var}(aX + b)\) : \((aX + b) - \E(aX + b) = a(X - \E(X))\).
  • Probabilités totales : \(A = \bigsqcup (A \cap B_i)\), additivité.
  • \(\P(\varnothing) = 0\) : \(A = A \sqcup \varnothing\). \(\P(A) = \P(A \setminus B) + \P(A \cap B)\).
  • Pascal : les tirages contiennent la boule 1 ou non. \(\sum \binom{n}{k} = 2^n\) : parties par cardinal.

Pièges DP

  • Podium \(A_n^3\) contre vélos identiques \(\binom{n}{3}\) ; avec remise \(n^p\), pas \(p^n\).
  • « Au moins un » compté directement : doublons. Complémentaire.
  • \(\P(A \mid B)\) divise par \(\P(B)\) ; 1 % = 0,01.
  • \(\mathrm{Var} = \E(X^2) - (\E(X))^2\), avec un moins ; \(b\) disparaît de \(\mathrm{Var}(aX + b)\).
  • \(\P(Y = k)\) est un seul terme, pas une somme.
