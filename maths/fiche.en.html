Connectives

  • \(P \Rightarrow Q\) is false only if \(P\) is true and \(Q\) false; \((P \Rightarrow Q) \iff (\neg P \lor Q)\).
  • \(\neg(P \land Q) \iff \neg P \lor \neg Q\); \(\neg(P \lor Q) \iff \neg P \land \neg Q\) (De Morgan).
  • \(\neg(P \Rightarrow Q) \iff P \land \neg Q\): it is not an implication.
  • Contrapositive \(\neg Q \Rightarrow \neg P\): equivalent. Converse \(Q \Rightarrow P\): not.
  • \(P \Rightarrow Q\): \(P\) is a sufficient condition for \(Q\), \(Q\) a necessary condition for \(P\). ⇒ goes from the small truth set to the large one.

Quantifiers

  • \(\neg(\forall x \in E, P(x)) \iff \exists x \in E, \neg P(x)\); \(\neg(\exists x \in E, P(x)) \iff \forall x \in E, \neg P(x)\). Sets kept.
  • \(\leq\) is negated into \(>\); \(m \leq f(x) \leq M\) into \(f(x) < m\) or \(f(x) > M\).
  • Order matters: \(\forall x\, \exists y,\ y > x\) true; \(\exists y\, \forall x,\ y > x\) false.
  • Bounded: \(\exists (m, M) \in \R^2, \forall x \in \R, m \leq f(x) \leq M\). Upper bounded: \(\exists M \in \R, \forall x \in \R, f(x) \leq M\).
  • Constant: \(\exists c \in \R, \forall x \in \R, f(x) = c\). Periodic: \(\exists T \in \R^*, \forall x \in \R, f(x + T) = f(x)\).
  • True or false: a \(\forall\) is proved (“Let \(x\)”) or disproved by a counterexample; an \(\exists\) is proved by a witness.

Sets

  • \(\in\): element in a set; \(\subset\): set in a set. \(\{3\} \subset \{1, 2, 3\}\), \(\{3\} \in \mathcal{P}(A)\), \(\varnothing \subset A\).
  • \(A \subset B \iff \forall x \in A, x \in B\); \(A = B\): double inclusion.
  • \(\overline{A \cup B} = \overline{A} \cap \overline{B}\); \(\overline{A \cap B} = \overline{A} \cup \overline{B}\); \(A \setminus B = A \cap \overline{B}\).
  • \(\card(A \times B) = \card(A)\card(B)\); \(\card(\mathcal{P}(E)) = 2^{\card(E)}\); \(E \times F \neq F \times E\).
  • Inclusion-exclusion: \(\card(A \cup B) =\) \(\card(A) + \card(B) - \card(A \cap B)\); with three sets: \(+\card(A \cap B \cap C)\) after the three pairwise intersections.

Images

  • \(f(A) = \{f(x),\ x \in A\}\), that is \(\{y \in F,\ \exists x \in A,\ y = f(x)\}\): a subset of \(F\).
  • \(f^{-1}(B) = \{x \in E,\ f(x) \in B\}\), subset of \(E\): exists even if \(f\) is not bijective; may be empty.
  • Interval: pieces of strict monotonicity, closed endpoint if reached: \(\exp(]0, \pi]) = ]1, e^{\pi}]\).
  • Solve in the input set: on \([-\pi, \pi]\), \(\sin^{-1}([0, 1])\) is \(\{-\pi\} \cup [0, \pi]\).

Injective, surjective

  • Injective: \(\forall (x, x') \in E^2,\ f(x) = f(x') \Rightarrow x = x'\). Not: \(f(a) = f(b)\) with \(a \neq b\), with numbers.
  • Surjective: \(\forall y \in F,\ \exists x \in E,\ y = f(x)\). Not: a \(y\) with no pre-image.
  • Bijective: \(\forall y \in F,\ \exists !\, x \in E,\ y = f(x)\).
  • Make it injective: reduce the input set (strict monotonicity). Surjective: reduce the output set to \(f(E)\).
  • Composition of two injections: injection; of two surjections: surjection. \(h \circ f = h \circ g \not\Rightarrow f = g\).

Basic functions

  • \(\ln(ab) = \ln a + \ln b\), \(\ln(a^n) = n\ln a\) for \(a, b > 0\); \(e^{a+b} = e^a e^b\), \(e^x > 0\).
  • \(\sqrt{a^2} = |a|\); \(|a + b| \leq |a| + |b|\); \(\cos\) even, \(\sin\) odd.
  • \(\tan' = 1 + \tan^2 = \frac{1}{\cos^2}\); \(\arctan : \R \to ]-\frac{\pi}{2}, \frac{\pi}{2}[\), \(\arctan'(y) = \frac{1}{1 + y^2}\).
  • \(\arctan 1 = \frac{\pi}{4}\), \(\arctan \sqrt{3} = \frac{\pi}{3}\), \(\arctan \frac{1}{\sqrt{3}} = \frac{\pi}{6}\).

Reasoning

  • \(\forall x \in E, P(x)\): “Let \(x \in E\) be given.”; \(P \Rightarrow Q\): “Assume \(P\).”; \(A \subset B\): “Let \(x \in A\) be given.”
  • Contrapositive: assume \(\neg Q\), reach \(\neg P\). Contradiction: assume \(\neg P\), reach a contradiction.
  • Induction: \(\mathcal{P}(n)\) stated; base case at the right rank; induction step \(\mathcal{P}(n) \Rightarrow \mathcal{P}(n+1)\); conclusion.
  • \(\sum_{k=1}^{n} k = \frac{n(n+1)}{2}\); \(\sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}\); \(\sum_{k=0}^{n} q^k = \frac{1 - q^{n+1}}{1 - q}\) if \(q \neq 1\).

Writing a proof: the seminar’s rules

  • “They play a very important role” (your teacher, 19 October). OBM 2025: “Write it following the writing rules seen in the seminar”.
  • The first line set by the statement; \(P \iff Q\) and \(A = B\) in two announced steps.
  • Start from the hypotheses, never from the conclusion; a link between every two lines: then, so, but, hence, therefore.
  • End by copying out what had to be proved. A false “for all”: one counterexample with numbers.

Proofs to know

  • \(g \circ f\) injective: \(g(f(x)) = g(f(x'))\) gives \(f(x) = f(x')\), so \(x = x'\).
  • \(g \circ f\) surjective: a pre-image of \(y\) under \(g\), then a pre-image of that one under \(f\).
  • \((\forall \varepsilon > 0, |a| \leq \varepsilon) \Rightarrow a = 0\): contrapositive, \(\varepsilon = \frac{|a|}{2}\).
  • \(n^2\) even \(\Rightarrow\) \(n\) even: contrapositive, \(n = 2k + 1\) gives \(n^2 = 2(2k^2 + 2k) + 1\).
  • \(\sqrt{2}\) irrational: contradiction with \(\frac{p}{q}\) in lowest terms.

OBM traps

  • A negation that changes the set, or \(\leq\) negated into \(<\).
  • “Increasing so injective”: it must be strictly.
  • Surjectivity depends on the output set: \(x^2\) is surjective onto \(\R^+\), not onto \(\R\).
  • Antisymmetric does not mean “not symmetric”.
  • \(\card(\{\varnothing\}) = 1\); a missing or double arrow: not a function.

Binomial coefficients

  • \(\binom{n}{0} = \binom{n}{n} = 1\), \(\binom{n}{1} = n\); symmetry \(\binom{n}{k} = \binom{n}{n-k}\).
  • Pascal (\(1 \leq k \leq n\)): \(\binom{n+1}{k} = \binom{n}{k-1} + \binom{n}{k}\).

Probability

  • \(\P : \mathcal{P}(\Omega) \to [0, 1]\), \(\P(\Omega) = 1\), \(\P(A \sqcup B) = \P(A) + \P(B)\) if \(A \cap B = \varnothing\).
  • \(\P(\varnothing) = 0\); \(\P(\overline{A}) = 1 - \P(A)\); \(\P(A \cup B) = \P(A) + \P(B) - \P(A \cap B)\).
  • Equiprobability: \(\P(A) = \frac{\card(A)}{\card(\Omega)}\).
  • \(\P(A \mid B) = \frac{\P(A \cap B)}{\P(B)}\) if \(\P(B) \neq 0\); \(\P(A \cap B) = \P(A \mid B)\P(B)\).
  • Independent: \(\P(A \cap B) = \P(A)\P(B)\). Incompatible: \(A \cap B = \varnothing\). Not the same thing.

Total probability, Bayes

  • “Since \(\{S, \overline{S}\}\) is a partition of \(\Omega\), \(V = (V \cap S) \sqcup (V \cap \overline{S})\)”:
  • \(\P(V) = \P(V \mid S)\P(S) + \P(V \mid \overline{S})\P(\overline{S})\).
  • Bayes: \(\P(S \mid V) = \frac{\P(V \mid S)\P(S)}{\P(V)}\).
  • Threshold: \(\P(V) = ap + b(1 - p) \geq s \iff p \geq \frac{s - b}{a - b}\) (if \(a > b\)). DP 2023: \(\frac{0.75 - 0.3}{0.8 - 0.3} = 0.9\).

Random variables

  • Distribution: \(X(\Omega)\) and the \(\P(X = x_i)\), adding up to 1.
  • \(\E(X) = \sum x_i \P(X = x_i)\); transfer: \(\E(f(X)) = \sum f(x_i)\P(X = x_i)\).
  • \(\mathrm{Var}(X) = \E((X - \E(X))^2)\), then König-Huygens: \(\mathrm{Var}(X) = \E(X^2) - (\E(X))^2\); \(\sigma(X) = \sqrt{\mathrm{Var}(X)}\).
  • \(\E(aX + b) = a\E(X) + b\); \(\mathrm{Var}(aX + b) = a^2\mathrm{Var}(X)\); \(\E(X + Y) = \E(X) + \E(Y)\).
  • \(X, Y\) independent: \(\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)\).

Bernoulli, binomial

  • Bernoulli(\(p\)): \(X(\Omega) = \{0, 1\}\), \(\P(X = 1) = p\); \(\E = p\), \(\mathrm{Var} = p(1 - p)\).
  • \(Y = X_1 + \dots + X_n\), independent Bernoulli(\(p\)): \(Y \sim \mathcal{B}(n, p)\), \(Y(\Omega) = \ent{0}{n}\).
  • \(\P(Y = k) = \binom{n}{k} p^k (1 - p)^{n-k}\); sum 1 by the binomial theorem; \(\E(Y) = np\), \(\mathrm{Var}(Y) = np(1 - p)\).
  • DP 2024: \(\mathcal{B}(20, \frac{3}{4})\), \(\E = 20 \times \frac{3}{4} = 15\), \(\mathrm{Var} = 20 \times \frac{3}{4} \times \frac{1}{4} = \frac{15}{4}\).
  • Uniform on \(\{1, \dots, n\}\): \(\E = \frac{n+1}{2}\), \(\mathrm{Var} = \frac{n^2 - 1}{12}\).

Proofs to know

  • \(\E(aX + b)\): transfer with \(x \mapsto ax + b\), split the sum, \(\sum \P(X = x_i) = 1\).
  • König-Huygens: expand \((X - \E(X))^2\), linearity, \(\E(X)\) constant.
  • \(\mathrm{Var}(aX + b)\): \((aX + b) - \E(aX + b) = a(X - \E(X))\).
  • Total probability: \(A = \bigsqcup (A \cap B_i)\), additivity.
  • \(\P(\varnothing) = 0\): \(A = A \sqcup \varnothing\). \(\P(A) = \P(A \setminus B) + \P(A \cap B)\).
  • Pascal: the draws contain ball 1 or not. \(\sum \binom{n}{k} = 2^n\): subsets by cardinality.

DP traps

  • Podium \(A_n^3\) against identical bikes \(\binom{n}{3}\); with replacement \(n^p\), not \(p^n\).
  • “At least one” counted directly: duplicates. Use the complement.
  • \(\P(A \mid B)\) divides by \(\P(B)\); 1% = 0.01.
  • \(\mathrm{Var} = \E(X^2) - (\E(X))^2\), with a minus; \(b\) disappears from \(\mathrm{Var}(aX + b)\).
  • \(\P(Y = k)\) is a single term, not a sum.
