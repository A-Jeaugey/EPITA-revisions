Part 1 notes p. 9-10 · seminar 2.10

Sets, elements, the empty set, intervals

Numbers, functions, the outcomes of a random experiment: in maths, everything lives in sets. Between an object and a set, there is only one question: is the object in it or not?

Definition set, element, membership

A set is a collection of distinct objects, called its elements. We write \(x \in A\) (“\(x\) belongs to \(A\)”) when \(x\) is an element of \(A\), and \(x \notin A\) otherwise. For a given object \(x\), “\(x \in A\)” is a proposition: it is either true or false (lesson 1).

Two sets are equal when they have exactly the same elements. The order in which you write them and repetitions do not matter: \(\{1, 2, 3\} = \{3, 1, 2\} = \{1, 1, 2, 3\}\).

Definition empty set, usual sets
  • The empty set \(\varnothing\) has no element. For example \(\{x \in \R,\ x^2 + 1 = 0\} = \varnothing\).
  • \(\N = \{0, 1, 2, \dots\}\) (it contains 0), \(\Z\) the integers, \(\Q\) the rational numbers, \(\R\) the real numbers, \(\C\) the complex numbers: \(\N \subset \Z \subset \Q \subset \R \subset \C\).
  • A star removes 0: \(\N^* = \N \setminus \{0\}\), \(\R^* = \R \setminus \{0\}\). A sign keeps one side: \(\R^+ = [0, +\infty[\), \(\R^- = \,]{-\infty}, 0]\).
Definition intervals

For two real numbers \(a \leq b\): \([a, b] = \{x \in \R,\ a \leq x \leq b\}\), \(]a, b[\, = \{x \in \R,\ a < x < b\}\), and in the same way \([a, b[\) and \(]a, b]\); \([a, +\infty[\, = \{x \in \R,\ x \geq a\}\), \(]{-\infty}, b[\, = \{x \in \R,\ x < b\}\). A bracket turned outwards excludes the endpoint (French notation, used in the course); \(\pm\infty\) is never an included endpoint.

For two integers \(a \leq b\), the interval of integers is \(\ent{a}{b} = \{n \in \Z,\ a \leq n \leq b\}\). It has \(b - a + 1\) elements.

\(\ent{2}{6} = \{2, 3, 4, 5, 6\}\): \(\card(A) = 6 - 2 + 1 = 5\)
\(\{n \in \N,\ 4 \leq n < 9\} = \{4, 5, 6, 7, 8\} = \ent{4}{8}\)

Example (seminar 2.10). \(A = \{x \in \R,\ -1 < x < 10\}\) and \(B = \{n \in \N,\ n + 1 \leq 8\}\). We translate them: \(A = \,]{-1}, 10[\) is an interval of real numbers, \(B = \ent{0}{7}\) has only 8 elements. A common set \(S\) containing both is \(\R\), because \(B \subset \N \subset \R\).

Let us show that \(10 \notin A\), with \(A = \{x \in \R,\ -1 < x < 10\}\). We do have \(10 \in \R\), but \(10 < 10\) is false.test the condition

Trap: an interval of real numbers is not a list of integers
  • \([0, 3]\) contains infinitely many real numbers (\(1.5\), \(\sqrt{2}\)…); the integers from 0 to 3 form \(\ent{0}{3} = \{0, 1, 2, 3\}\).
  • In \(]2, 5]\), the endpoint 2 is excluded: \(2 \notin \,]2, 5]\), but \(5 \in \,]2, 5]\).
  • \(\{1, 1, 2\}\) has 2 elements, not 3: a set does not count repetitions.

Describing a set: in extension, in intention, in parametric form

Definition three ways to write a set
  • In extension (roster notation): the list of its elements in braces, \(\{1, 2, 3, 4\}\). Dots are allowed when the pattern is obvious: \(\{1, 3, 5, \dots, 19\}\).
  • In intention (set-builder notation, with a membership condition): \(\{x \in E,\ P(x)\}\), “the elements \(x\) of \(E\) such that \(P(x)\) holds”. Example: \(\{x \in \N,\ 1 \leq x \leq 4\}\).
  • In parametric form: \(\{f(t),\ t \in T\}\), “all the \(f(t)\) as \(t\) runs through \(T\)”. Example: \(\{2n,\ n \in \N\}\), the even natural numbers.

Inside the braces there is always either a list, or “variable \(\in\) set, condition”, or “expression, parameter \(\in\) set”.

Two ways, one set (seminar 2.9.2). \(E = \{n \in \N,\ \exists k \in \N,\ n = 2k\}\) is written in intention, \(F = \{2p,\ p \in \N\}\) in parametric form: both describe the even natural numbers, so \(E = F\).

What is not a set (seminar 2.8). \(E_1 = \{\forall x \in \R,\ \sin(x) = 0\}\) and \(E_2 = \{\exists x \in \R,\ \sin(x) = 0\}\) mean nothing: a proposition has been put inside the braces, with no variable and no set it runs through. The set of real numbers that make \(\sin\) equal to zero is \(\{x \in \R,\ \sin(x) = 0\}\) in intention and \(\{k\pi,\ k \in \Z\}\) in parametric form.

Model answer express a set in extension (seminar 2.9.1)

\(A = \{n \in \N,\ \sqrt{2} < n < 2\pi\}\). Bound the endpoints: \(1 < \sqrt{2} < 2\) since \(1 < 2 < 4\), and \(6 < 2\pi < 7\) since \(3 < \pi < 3.5\).no calculator

So the integers strictly between \(\sqrt{2}\) and \(2\pi\) are 2, 3, 4, 5 and 6: \(A = \{2, 3, 4, 5, 6\}\).

\(B = \{x \in [0, 20],\ \exists n \in \N,\ x = n^2\}\): these are the squares of natural numbers that are at most 20. Since \(5^2 = 25 > 20\), \(B = \{0, 1, 4, 9, 16\}\).

Trap: braces around a sentence
  • \(\{x^2 = 1\}\) is not a set: write \(\{x \in \R,\ x^2 = 1\}\), which is \(\{-1, 1\}\). The variable and the set it runs through are compulsory.
  • In a parametric form, the letter that varies is the one after the comma. \(\{2x + 1,\ x \in \N,\ 0 \leq k \leq 9\}\) (found in a student’s notes) mixes \(x\) and \(k\): write \(\{2k + 1,\ k \in \ent{0}{9}\}\).

Inclusion, equality, “∈ or ⊂?”, power set

Definition inclusion, equality

\(A\) is included in \(B\), written \(A \subset B\), when every element of \(A\) is an element of \(B\):

\[A \subset B \iff \forall x \in A,\ x \in B.\]

We also say that \(A\) is a subset (a part) of \(B\). Its negation: \(A \not\subset B \iff \exists x \in A,\ x \notin B\). Equality is a double inclusion: \(A = B \iff (A \subset B \text{ and } B \subset A)\).

Properties
  • \(\varnothing \subset A\) and \(A \subset A\) for every set \(A\).
  • Transitivity: if \(A \subset B\) and \(B \subset C\), then \(A \subset C\).
Definition power set

The power set of \(E\), written \(\mathcal{P}(E)\), is the set of all the subsets of \(E\): \(X \in \mathcal{P}(E) \iff X \subset E\). It always contains \(\varnothing\) and \(E\). Example: \(\mathcal{P}(\{1, 2\}) = \{\varnothing, \{1\}, \{2\}, \{1, 2\}\}\).

\(\mathcal{P}(\{1, 2, 3\}) = \{\varnothing, \{1\}, \{2\}, \{3\}, \{1, 2\}, \{1, 3\}, \{2, 3\}, \{1, 2, 3\}\}\)
\(\card\big(\mathcal{P}(\{1, 2, 3\})\big) = 8 = 2^3\) (seminar 3.12; the formula \(2^n\) is proved in part 7)
Method ∈ or ⊂: look at the type of both sides
  1. If the object on the left has the same type as the elements on the right (a number and a set of numbers), compare with \(\in\) or \(\notin\).
  2. If the object on the left is a set of objects of the same type as those on the right (a set of numbers and a set of numbers), compare with \(\subset\) or \(\not\subset\).
  3. In \(\mathcal{P}(A)\), the elements are sets: \(\{3\} \in \mathcal{P}(A)\), whereas \(\{3\} \subset A\) and \(3 \in A\).
Model answer 2024 OBM exam, exercise 1.4

\(A = \{(x, y, z) \in \R^3,\ x = y = z\}\) and \(B = \{(x, y, z) \in \R^3,\ 2x - y - z = 0\}\).

(a) \(A\) and \(B\) are subsets of \(\R^3\).

(b) Let us show that \(A \subset B\). Let \((x, y, z) \in A\).any element Then \(x = y = z\), so \(2x - y - z = 2x - x - x = 0\). Thus \((x, y, z) \in B\). Hence \(A \subset B\).

(c) No. \((1, 2, 0) \in B\) since \(2 \times 1 - 2 - 0 = 0\), but \((1, 2, 0) \notin A\) since \(1 \neq 2\). So \(B \not\subset A\).a counterexample with numbers

Trap: \(\{3\} \in\) or \(\subset\), \(\varnothing\) or \(\{\varnothing\}\)
  • “\(\{3\} \in \{1, 2, 3\}\)” is false (a student’s notes write it): \(3 \in \{1, 2, 3\}\) and \(\{3\} \subset \{1, 2, 3\}\). “\(3 \subset A\)” is badly written: 3 is not a set.
  • \(\varnothing\) has no element; \(\{\varnothing\}\) has one, the empty set. \(\varnothing \subset A\) is always true, \(\varnothing \in A\) almost never, \(\varnothing \in \mathcal{P}(A)\) always.

Intersection, union, complement, set difference

Definition the four operations
  • Intersection: \(A \cap B = \{x,\ x \in A \text{ and } x \in B\}\).
  • Union: \(A \cup B = \{x,\ x \in A \text{ or } x \in B\}\).
  • Complement of \(A \subset E\) in \(E\): \(\overline{A} = A^c = E \setminus A = \{x \in E,\ x \notin A\}\).
  • Set difference: \(A \setminus B = \{x \in A,\ x \notin B\}\) (“\(A\) minus \(B\)”).

\(A\) and \(B\) are disjoint when \(A \cap B = \varnothing\).

Worked example. In \(E = \ent{1}{10}\), take \(A = \{2, 4, 6, 8, 10\}\) (the even numbers) and \(B = \{3, 6, 9\}\) (the multiples of 3).

\(A \cap B = \{6\}\); \(A \cup B = \{2, 3, 4, 6, 8, 9, 10\}\)
\(\overline{A} = \{1, 3, 5, 7, 9\}\); \(A \setminus B = A \cap \overline{B} = \{2, 4, 8, 10\}\); \(B \setminus A = \{3, 9\}\)
Properties the same as for the connectors
  • \(\cap\) and \(\cup\) are commutative and associative: we write \(A \cap B \cap C\) without brackets.
  • \(A \cap B \subset A \subset A \cup B\); \(A \cup \overline{A} = E\) and \(A \cap \overline{A} = \varnothing\); \(\overline{\overline{A}} = A\).
  • \(A \subset B \iff A \cap B = A \iff A \cup B = B\).

Seminar 2.10, continued. With \(A = \,]{-1}, 10[\) and \(B = \ent{0}{7}\): \(B \subset A\), so \(A \cup B = A\) and \(A \cap B = B\). The complement of \(B\) in \(\Z\) is \(\{n \in \Z,\ n < 0 \text{ or } n \geq 8\}\): the “or” comes from negating “\(0 \leq n\) and \(n \leq 7\)” (De Morgan).

  • \(A \setminus B \neq B \setminus A\) in general: above, \(\{2, 4, 8, 10\}\) against \(\{3, 9\}\).
  • “Intersection” and “union” are for sets; for propositions we say “conjunction” and “disjunction”.

Computing with intervals, De Morgan’s laws, distributivity

Theorem De Morgan’s laws, distributivity

For \(A\), \(B\), \(C\) subsets of \(E\) (complements taken in \(E\)):

\[\overline{A \cup B} = \overline{A} \cap \overline{B} \qquad \overline{A \cap B} = \overline{A} \cup \overline{B}\]
\[A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\]
\[A \cup (B \cap C) = (A \cup B) \cap (A \cup C)\]

These are De Morgan’s laws and the distributive laws of lesson 1, translated into sets: “not (\(P\) or \(Q\))” is “not \(P\) and not \(Q\)”.

Proof first law, by equivalences

Let \(x \in E\). Translate each membership into a proposition, then apply De Morgan’s law of logic:

\[\begin{aligned} x \in \overline{A \cup B} &\iff \neg(x \in A \lor x \in B) \\ &\iff (x \notin A) \land (x \notin B) \\ &\iff x \in \overline{A} \cap \overline{B}. \end{aligned}\]

The two sets have exactly the same elements: \(\overline{A \cup B} = \overline{A} \cap \overline{B}\).

Proof second law, by double inclusion

\(\subset\): let \(x \in \overline{A \cap B}\). Then \(x \notin A \cap B\): \(x\) is not both in \(A\) and in \(B\). So \(x \notin A\) or \(x \notin B\), that is \(x \in \overline{A}\) or \(x \in \overline{B}\): \(x \in \overline{A} \cup \overline{B}\).

\(\supset\): let \(x \in \overline{A} \cup \overline{B}\). If \(x \in \overline{A}\), then \(x \notin A\), so \(x \notin A \cap B\) (since \(A \cap B \subset A\)). If \(x \in \overline{B}\), in the same way \(x \notin A \cap B\). In both cases, \(x \in \overline{A \cap B}\).

By double inclusion, \(\overline{A \cap B} = \overline{A} \cup \overline{B}\).

Proof distributivity
\[\begin{aligned} x \in A \cap (B \cup C) &\iff x \in A \land (x \in B \lor x \in C) \\ &\iff (x \in A \land x \in B) \lor (x \in A \land x \in C) \\ &\iff x \in (A \cap B) \cup (A \cap C). \end{aligned}\]

The second equivalence is the distributivity of “and” over “or” (lesson 1, part 2).

Method computing with intervals
  1. Draw the real line and one line per set, with its brackets.
  2. \(\cap\): keep what is on every line; \(\cup\): what is on at least one.
  3. Complement in \(\R\): the gaps, with the brackets turned round. \(\overline{[0, 3]} = \,]{-\infty}, 0[\, \cup \,]3, +\infty[\): 0 and 3 are in \([0, 3]\), so not in its complement.

  • The complement of \([0, 3]\) is neither \(]0, 3[\) nor \(]{-\infty}, 0] \cup [3, +\infty[\): the endpoints change sides.

Cartesian product and 2-tuples

Definition 2-tuple, Cartesian product

A 2-tuple (ordered pair) \((x, y)\) is an ordered pair: \((x, y) = (x', y') \iff (x = x' \text{ and } y = y')\). The Cartesian product of \(A\) and \(B\) is the set of 2-tuples:

\[A \times B = \{(a, b),\ a \in A,\ b \in B\}.\]

We write \(A^2 = A \times A\); \(\R^2\) is the plane, \(\R^3\) space. In the same way, \(A_1 \times \cdots \times A_n\) is the set of \(n\)-tuples \((a_1, \dots, a_n)\).

Cardinal, disjoint union, partition

Definition cardinal, disjoint union, partition
  • The cardinal (cardinality) of a finite set \(A\) is its number of elements, written \(\card(A)\), \(|A|\) or \(\#A\). \(\card(\varnothing) = 0\).
  • If \(A \cap B = \varnothing\), their union is written \(A \sqcup B\): it is a disjoint union.
  • A family \((A_i)_{i \in I}\) of subsets of \(E\) is a partition of \(E\) when: (1) each \(A_i\) is non-empty; (2) \(A_i \cap A_j = \varnothing\) for \(i \neq j\); (3) \(\bigcup_{i \in I} A_i = E\). Each element of \(E\) is then in one and only one \(A_i\).

The summary sheet on probability spaces does not require (1): in probability, a partition may contain the empty set.

Theorem cardinals (notes, summary sheet)
  • \(\card(A \sqcup B) = \card(A) + \card(B)\); if \((A_i)\) is a partition of \(E\), \(\card(E) = \sum_{i} \card(A_i)\).
  • If \(X \subset Y\): \(\card(Y \setminus X) = \card(Y) - \card(X)\), so \(\card(X) \leq \card(Y)\).
  • \(\card(A \times B) = \card(A) \times \card(B)\).
  • If \(\card(E) = n\), then \(\card\big(\mathcal{P}(E)\big) = 2^n\).
Proof \(\card(Y \setminus X)\), seminar 3.13.3

Since \(X \subset Y\), we have \(Y = X \sqcup (Y \setminus X)\): an element of \(Y\) is either in \(X\) or outside \(X\), never both. So \(\card(Y) = \card(X) + \card(Y \setminus X)\), hence \(\card(Y \setminus X) = \card(Y) - \card(X)\).

Proof \(\card(A \times B)\)

Sort the 2-tuples by their first coordinate: \(A \times B = \bigsqcup_{a \in A} \big(\{a\} \times B\big)\). These sets are pairwise disjoint (different first coordinates) and each one has \(\card(B)\) elements. There are \(\card(A)\) of them, so \(\card(A \times B) = \card(A) \times \card(B)\). This is the two-way table of part 6: \(\card(A)\) rows of \(\card(B)\) cells.

Proof \(\card \mathcal{P}(E) = 2^n\) (sheet 1, ex. 1.6)

Write \(E = \{x_1, \dots, x_n\}\). To a subset \(X \subset E\), associate the list \((\varepsilon_1, \dots, \varepsilon_n) \in \{0, 1\}^n\), where \(\varepsilon_i = 1\) if \(x_i \in X\) and \(\varepsilon_i = 0\) otherwise.

Two different subsets give two different lists (some \(x_i\) is in one and not in the other), and every list comes from a subset: \(X = \{x_i,\ \varepsilon_i = 1\}\). So the two sets have the same number of elements: \(\card \mathcal{P}(E) = \card\big(\{0, 1\}^n\big) = 2 \times \cdots \times 2 = 2^n\).

For \(n = 0\): \(\mathcal{P}(\varnothing) = \{\varnothing\}\) does have \(2^0 = 1\) element. Another proof, \(\sum_{k=0}^{n} \binom{n}{k} = 2^n\), is in lesson 5, part 8.

Trap: the cardinal of \(\{\varnothing\}\), a set or a number

The inclusion-exclusion formula

In \(\card(A) + \card(B)\), the elements of \(A \cap B\) are counted twice: once in \(A\), once in \(B\). We remove them once.

Theorem inclusion-exclusion formula

For finite sets \(A\), \(B\), \(C\):

\[\card(A \cup B) = \card(A) + \card(B) - \card(A \cap B)\]
\[\begin{aligned} & \card(A \cup B \cup C) \\ & = \card(A) + \card(B) + \card(C) \\ & \quad - \card(A \cap B) - \card(A \cap C) - \card(B \cap C) \\ & \quad + \card(A \cap B \cap C) \end{aligned}\]
Proof you have to know two sets, with a partition (2023 DP exam)

We have \(A \cup B = (A \setminus B) \cup B\), and this union is disjoint: an element of \(A \cup B\) is either in \(B\), or in \(A\) and outside \(B\).

So \(\card(A \cup B) = \card(A \setminus B) + \card(B)\). Now \(A = (A \setminus B) \sqcup (A \cap B)\) (part 7) gives \(\card(A \setminus B) = \card(A) - \card(A \cap B)\). Thus:

\[\card(A \cup B) = \card(A) - \card(A \cap B) + \card(B).\]
Proof three sets (sheet 1, ex. 1.4)

Write \(A \cup B \cup C = (A \cup B) \cup C\) and apply the formula for two sets:

\[\begin{aligned} \card(A \cup B \cup C) = {} & \card(A \cup B) + \card(C) \\ & - \card\big((A \cup B) \cap C\big). \end{aligned}\]

By distributivity (part 5), \((A \cup B) \cap C = (A \cap C) \cup (B \cap C)\), and \((A \cap C) \cap (B \cap C) = A \cap B \cap C\). The formula for two sets gives \(\card\big((A \cup B) \cap C\big) = \card(A \cap C) + \card(B \cap C) - \card(A \cap B \cap C)\).

Also replace \(\card(A \cup B)\) by \(\card(A) + \card(B) - \card(A \cap B)\): this gives the formula for three sets.

Example (weekly MCQ of 30 September 2024). 64 medals; \(A\) (gold or silver) has 42 of them, \(B\) (gold or bronze) 38. Every medal is in \(A\) or in \(B\), so \(\card(A \cup B) = 64\), and the gold medals form \(A \cap B\): \(\card(A \cap B) = 42 + 38 - 64 = 16\). That leaves \(42 - 16 = 26\) silver medals and \(38 - 16 = 22\) bronze ones.

Example with three sets. In \(E = \ent{1}{100}\), \(A\), \(B\), \(C\) are the multiples of 2, of 3, of 5. The intersections are the multiples of 6, 10, 15 and 30.

\(\card(A \cup B \cup C) = 50 + 33 + 20 - 16 - 10 - 6 + 3 = 74\)
That leaves \(\card\big(E \setminus (A \cup B \cup C)\big) = 100 - 74 = 26\) integers divisible neither by 2, nor by 3, nor by 5.

An EPITA class of 40 students: 25 speak English, 11 speak Spanish, 6 speak neither English nor Spanish. Let \(C\) be the class, \(E\) the students who speak English, \(S\) those who speak Spanish.name the sets

(a) \(\card(C) = 40\), \(\card(E) = 25\), \(\card(S) = 11\) and \(\card\big(C \setminus (E \cup S)\big) = 6\).

(b) Since \(E \cup S \subset C\), \(\card(E \cup S) = \card(C) - \card\big(C \setminus (E \cup S)\big)\) \(= 40 - 6 = 34\).

By the inclusion-exclusion formula, \(\card(E \cup S) = \card(E) + \card(S) - \card(E \cap S)\), so \(\card(E \cap S) = \card(E) + \card(S) - \card(E \cup S)\) \(= 25 + 11 - 34 = 2\).the formula, then the numbers

Two students speak both languages.

Trap: adding without subtracting
  • \(\card(A \cup B) = \card(A) + \card(B)\) only if \(A\) and \(B\) are disjoint. For the class: \(25 + 11 = 36 \neq 34\), because the 2 bilingual students are counted twice.
