Partie 1 notes p. 9-10 · séminaire 2.10

Ensembles, éléments, ensemble vide, intervalles

Les nombres, les fonctions, les issues d’une expérience aléatoire : en maths, tout est rangé dans des ensembles. Entre un objet et un ensemble, il n’y a qu’une question à se poser : l’objet est-il dedans ou pas ?

Définition ensemble, élément, appartenance

Un ensemble est une collection d’objets distincts, appelés ses éléments. On écrit \(x \in A\) (« \(x\) appartient à \(A\) ») quand \(x\) est un élément de \(A\), et \(x \notin A\) sinon. Pour un objet \(x\) donné, « \(x \in A\) » est une assertion : elle est vraie ou fausse (cours 1).

Deux ensembles sont égaux quand ils ont exactement les mêmes éléments. L’ordre d’écriture et les répétitions ne comptent pas : \(\{1, 2, 3\} = \{3, 1, 2\} = \{1, 1, 2, 3\}\).

Définition ensemble vide, ensembles usuels
  • L’ensemble vide \(\varnothing\) n’a aucun élément. Par exemple \(\{x \in \R,\ x^2 + 1 = 0\} = \varnothing\).
  • \(\N = \{0, 1, 2, \dots\}\) (il contient 0), \(\Z\) les entiers relatifs, \(\Q\) les rationnels, \(\R\) les réels, \(\C\) les complexes : \(\N \subset \Z \subset \Q \subset \R \subset \C\).
  • Une étoile retire 0 : \(\N^* = \N \setminus \{0\}\), \(\R^* = \R \setminus \{0\}\). Un signe garde un côté : \(\R^+ = [0, +\infty[\), \(\R^- = \,]{-\infty}, 0]\).
Définition intervalles

Pour deux réels \(a \leq b\) : \([a, b] = \{x \in \R,\ a \leq x \leq b\}\), \(]a, b[\, = \{x \in \R,\ a < x < b\}\), et de même \([a, b[\) et \(]a, b]\) ; \([a, +\infty[\, = \{x \in \R,\ x \geq a\}\), \(]{-\infty}, b[\, = \{x \in \R,\ x < b\}\). Un crochet tourné vers l’extérieur exclut la borne ; \(\pm\infty\) n’est jamais une borne incluse.

Pour deux entiers \(a \leq b\), l’intervalle d’entiers est \(\ent{a}{b} = \{n \in \Z,\ a \leq n \leq b\}\). Il a \(b - a + 1\) éléments.

\(\ent{2}{6} = \{2, 3, 4, 5, 6\}\) : \(\card(A) = 6 - 2 + 1 = 5\)
\(\{n \in \N,\ 4 \leq n < 9\} = \{4, 5, 6, 7, 8\} = \ent{4}{8}\)

Exemple (séminaire 2.10). \(A = \{x \in \R,\ -1 < x < 10\}\) et \(B = \{n \in \N,\ n + 1 \leq 8\}\). On les traduit : \(A = \,]{-1}, 10[\) est un intervalle de réels, \(B = \ent{0}{7}\) n’a que 8 éléments. L’ensemble de référence commun est \(\R\), car \(B \subset \N \subset \R\).

Piège : un intervalle de réels n’est pas une liste d’entiers
  • \([0, 3]\) contient une infinité de réels (\(1{,}5\), \(\sqrt{2}\)…) ; les entiers de 0 à 3 forment \(\ent{0}{3} = \{0, 1, 2, 3\}\).
  • Dans \(]2, 5]\), la borne 2 est exclue : \(2 \notin \,]2, 5]\), mais \(5 \in \,]2, 5]\).
  • \(\{1, 1, 2\}\) a 2 éléments, pas 3 : un ensemble ne compte pas les répétitions.

Décrire un ensemble : extension, compréhension, paramétrique

Définition trois façons d’écrire un ensemble
  • En extension : la liste de ses éléments entre accolades, \(\{1, 2, 3, 4\}\). Des points de suspension sont permis si la suite est évidente : \(\{1, 3, 5, \dots, 19\}\).
  • En compréhension (description conditionnelle) : \(\{x \in E,\ P(x)\}\), « les éléments \(x\) de \(E\) qui vérifient \(P(x)\) ». Exemple : \(\{x \in \N,\ 1 \leq x \leq 4\}\).
  • Sous forme paramétrique : \(\{f(t),\ t \in T\}\), « tous les \(f(t)\) quand \(t\) parcourt \(T\) ». Exemple : \(\{2n,\ n \in \N\}\), les entiers naturels pairs.

Entre les accolades, il y a toujours soit une liste, soit « variable \(\in\) ensemble, condition », soit « expression, paramètre \(\in\) ensemble ».

Deux écritures, un ensemble (séminaire 2.9.2). \(E = \{n \in \N,\ \exists k \in \N,\ n = 2k\}\) est en compréhension, \(F = \{2p,\ p \in \N\}\) est paramétrique : les deux décrivent les entiers naturels pairs, donc \(E = F\).

Ce qui n’est pas un ensemble (séminaire 2.8). \(E_1 = \{\forall x \in \R,\ \sin(x) = 0\}\) et \(E_2 = \{\exists x \in \R,\ \sin(x) = 0\}\) ne veulent rien dire : entre les accolades, on a mis une assertion, sans variable ni ensemble de départ. L’ensemble des réels qui annulent \(\sin\) s’écrit \(\{x \in \R,\ \sin(x) = 0\}\) en compréhension et \(\{k\pi,\ k \in \Z\}\) sous forme paramétrique.

Rédaction modèle écrire en extension (séminaire 2.9.1)

\(A = \{n \in \N,\ \sqrt{2} < n < 2\pi\}\). On encadre les bornes : \(1 < \sqrt{2} < 2\) car \(1 < 2 < 4\), et \(6 < 2\pi < 7\) car \(3 < \pi < 3{,}5\).sans calculatrice

Les entiers strictement compris entre \(\sqrt{2}\) et \(2\pi\) sont donc 2, 3, 4, 5 et 6 : \(A = \{2, 3, 4, 5, 6\}\).

\(B = \{x \in [0, 20],\ \exists n \in \N,\ x = n^2\}\) : ce sont les carrés d’entiers naturels au plus égaux à 20. Comme \(5^2 = 25 > 20\), \(B = \{0, 1, 4, 9, 16\}\).

Piège : des accolades autour d’une phrase
  • \(\{x^2 = 1\}\) n’est pas un ensemble : écris \(\{x \in \R,\ x^2 = 1\}\), qui vaut \(\{-1, 1\}\). La variable et son ensemble de départ sont obligatoires.
  • Dans une forme paramétrique, la lettre qui varie est celle qui suit la virgule. \(\{2x + 1,\ x \in \N,\ 0 \leq k \leq 9\}\) (écrit dans des notes d’élève) mélange \(x\) et \(k\) : écris \(\{2k + 1,\ k \in \ent{0}{9}\}\).

Inclusion, égalité, « ∈ ou ⊂ ? », ensemble des parties

Définition inclusion, égalité

\(A\) est inclus dans \(B\), noté \(A \subset B\), quand tout élément de \(A\) est un élément de \(B\) :

\[A \subset B \iff \forall x \in A,\ x \in B.\]

On dit aussi que \(A\) est une partie (un sous-ensemble) de \(B\). Sa négation : \(A \not\subset B \iff \exists x \in A,\ x \notin B\). L’égalité est une double inclusion : \(A = B \iff (A \subset B \text{ et } B \subset A)\).

Propriétés
  • \(\varnothing \subset A\) et \(A \subset A\) pour tout ensemble \(A\).
  • Transitivité : si \(A \subset B\) et \(B \subset C\), alors \(A \subset C\).
Définition ensemble des parties

L’ensemble des parties de \(E\), noté \(\mathcal{P}(E)\), est l’ensemble de tous les sous-ensembles de \(E\) : \(X \in \mathcal{P}(E) \iff X \subset E\). Il contient toujours \(\varnothing\) et \(E\). Exemple : \(\mathcal{P}(\{1, 2\}) = \{\varnothing, \{1\}, \{2\}, \{1, 2\}\}\).

\(\mathcal{P}(\{1, 2, 3\}) = \{\varnothing, \{1\}, \{2\}, \{3\}, \{1, 2\}, \{1, 3\}, \{2, 3\}, \{1, 2, 3\}\}\)
\(\card\big(\mathcal{P}(\{1, 2, 3\})\big) = 8 = 2^3\) (séminaire 2.12 ; la formule \(2^n\) est démontrée en partie 7)
Méthode ∈ ou ⊂ : regarde le type des deux côtés
  1. Si l’objet de gauche est du même type que les éléments de droite (un nombre et un ensemble de nombres), on compare par \(\in\) ou \(\notin\).
  2. Si l’objet de gauche est un ensemble d’objets du même type que ceux de droite (un ensemble de nombres et un ensemble de nombres), on compare par \(\subset\) ou \(\not\subset\).
  3. Dans \(\mathcal{P}(A)\), les éléments sont des ensembles : \(\{3\} \in \mathcal{P}(A)\), alors que \(\{3\} \subset A\) et \(3 \in A\).
Rédaction modèle examen OBM 2024, exercice 1.4

\(A = \{(x, y, z) \in \R^3,\ x = y = z\}\) et \(B = \{(x, y, z) \in \R^3,\ 2x - y - z = 0\}\).

(a) \(A\) et \(B\) sont des sous-ensembles de \(\R^3\).

(b) Montrons que \(A \subset B\). Soit \((x, y, z) \in A\).un élément quelconque Alors \(x = y = z\), donc \(2x - y - z = 2x - x - x = 0\). Ainsi \((x, y, z) \in B\). Donc \(A \subset B\).

(c) Non. \((1, 2, 0) \in B\) car \(2 \times 1 - 2 - 0 = 0\), mais \((1, 2, 0) \notin A\) car \(1 \neq 2\). Donc \(B \not\subset A\).un contre-exemple chiffré

Piège : \(\{3\} \in\) ou \(\subset\), \(\varnothing\) ou \(\{\varnothing\}\)
  • « \(\{3\} \in \{1, 2, 3\}\) » est faux (des notes d’élève l’écrivent) : on a \(3 \in \{1, 2, 3\}\) et \(\{3\} \subset \{1, 2, 3\}\). « \(3 \subset A\) » est mal écrit : 3 n’est pas un ensemble.
  • \(\varnothing\) n’a aucun élément ; \(\{\varnothing\}\) en a un, l’ensemble vide. \(\varnothing \subset A\) est toujours vrai, \(\varnothing \in A\) presque jamais, \(\varnothing \in \mathcal{P}(A)\) toujours.

Intersection, union, complémentaire, différence

Définition les quatre opérations
  • Intersection : \(A \cap B = \{x,\ x \in A \text{ et } x \in B\}\).
  • Union (réunion) : \(A \cup B = \{x,\ x \in A \text{ ou } x \in B\}\).
  • Complémentaire de \(A \subset E\) dans \(E\) : \(\overline{A} = A^c = E \setminus A = \{x \in E,\ x \notin A\}\).
  • Différence : \(A \setminus B = \{x \in A,\ x \notin B\}\) (« \(A\) privé de \(B\) »).

\(A\) et \(B\) sont disjoints quand \(A \cap B = \varnothing\).

Propriétés les mêmes que pour les connecteurs
  • \(\cap\) et \(\cup\) sont commutatives et associatives : on écrit \(A \cap B \cap C\) sans parenthèses.

  • \(A \subset B \iff A \cap B = A \iff A \cup B = B\).

Calculs sur des intervalles, lois de De Morgan, distributivité

Théorème lois de De Morgan, distributivité

Pour \(A\), \(B\), \(C\) des parties de \(E\) (complémentaires pris dans \(E\)) :

\[\overline{A \cup B} = \overline{A} \cap \overline{B} \qquad \overline{A \cap B} = \overline{A} \cup \overline{B}\]
\[A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\]
\[A \cup (B \cap C) = (A \cup B) \cap (A \cup C)\]

Ce sont les lois de De Morgan et les distributivités du cours 1, traduites en ensembles : « non (\(P\) ou \(Q\)) » est « non \(P\) et non \(Q\) ».

Démonstration première loi, par équivalences

Soit \(x \in E\). On traduit chaque appartenance en assertion, puis on applique De Morgan logique :

\[\begin{aligned} x \in \overline{A \cup B} &\iff \neg(x \in A \lor x \in B) \\ &\iff (x \notin A) \land (x \notin B) \\ &\iff x \in \overline{A} \cap \overline{B}. \end{aligned}\]

Les deux ensembles ont exactement les mêmes éléments : \(\overline{A \cup B} = \overline{A} \cap \overline{B}\).

Démonstration seconde loi, par double inclusion

\(\subset\) : soit \(x \in \overline{A \cap B}\). Alors \(x \notin A \cap B\) : \(x\) n’est pas à la fois dans \(A\) et dans \(B\). Donc \(x \notin A\) ou \(x \notin B\), c’est-à-dire \(x \in \overline{A}\) ou \(x \in \overline{B}\) : \(x \in \overline{A} \cup \overline{B}\).

\(\supset\) : soit \(x \in \overline{A} \cup \overline{B}\). Si \(x \in \overline{A}\), alors \(x \notin A\), donc \(x \notin A \cap B\) (car \(A \cap B \subset A\)). Si \(x \in \overline{B}\), de même \(x \notin A \cap B\). Dans les deux cas, \(x \in \overline{A \cap B}\).

Par double inclusion, \(\overline{A \cap B} = \overline{A} \cup \overline{B}\).

Démonstration distributivité
\[\begin{aligned} x \in A \cap (B \cup C) &\iff x \in A \land (x \in B \lor x \in C) \\ &\iff (x \in A \land x \in B) \lor (x \in A \land x \in C) \\ &\iff x \in (A \cap B) \cup (A \cap C). \end{aligned}\]

La deuxième équivalence est la distributivité de « et » sur « ou » (cours 1, partie 2).

Méthode calculer sur des intervalles
  1. Dessine la droite réelle et une ligne par ensemble, avec ses crochets.
  2. \(\cap\) : garde ce qui est sur toutes les lignes ; \(\cup\) : ce qui est sur au moins une.
  3. Complémentaire dans \(\R\) : les trous, crochets retournés. \(\overline{[0, 3]} = \,]{-\infty}, 0[\, \cup \,]3, +\infty[\) : 0 et 3 sont dans \([0, 3]\), donc pas dans son complémentaire.

Produit cartésien et couples

Définition couple, produit cartésien

Un couple \((x, y)\) est une paire ordonnée : \((x, y) = (x', y') \iff (x = x' \text{ et } y = y')\). Le produit cartésien de \(A\) et \(B\) est l’ensemble des couples :

\[A \times B = \{(a, b),\ a \in A,\ b \in B\}.\]

On note \(A^2 = A \times A\) ; \(\R^2\) est le plan, \(\R^3\) l’espace. De même \(A_1 \times \cdots \times A_n\) est l’ensemble des \(n\)-uplets \((a_1, \dots, a_n)\).

Exemple (séminaire 2.12). \(E = \{1, 2, 3\}\) et \(F = \{a, b\}\), où \(a\) et \(b\) sont des lettres. Un tableau à double entrée donne tous les couples, sans en oublier :

\(3\)\((3, a)\)\((3, b)\)
Tableau 2.6 — \(F \times E\) : les mêmes lettres, dans l’autre ordre

\(a\)\((a, 1)\)\((a, 2)\)\((a, 3)\)

\(\{(0, 0)\} \subset A \times B\), avec \(A = \{x \in \R,\ -1 < x < 10\}\) et \(B = \{n \in \N,\ n + 1 \leq 8\}\) : on a \(0 \in A\) car \(-1 < 0 < 10\), et \(0 \in B\) car \(0 + 1 \leq 8\). Donc \((0, 0) \in A \times B\), d’où \(\{(0, 0)\} \subset A \times B\).une coordonnée à la fois

Cardinal, union disjointe, partition

Définition cardinal, union disjointe, partition
  • Le cardinal d’un ensemble fini \(A\) est son nombre d’éléments, noté \(\card(A)\), \(|A|\) ou \(\#A\). \(\card(\varnothing) = 0\).
  • Si \(A \cap B = \varnothing\), on note \(A \sqcup B\) leur union : c’est une union disjointe.
  • Une famille \((A_i)_{i \in I}\) de parties de \(E\) est une partition de \(E\) quand : (1) chaque \(A_i\) est non vide ; (2) \(A_i \cap A_j = \varnothing\) pour \(i \neq j\) ; (3) \(\bigcup_{i \in I} A_i = E\). Chaque élément de \(E\) est alors dans un et un seul \(A_i\).

La fiche « Espaces probabilisés » n’exige pas (1) : en probabilités, une partition peut contenir l’ensemble vide.

Théorème cardinaux (notes, fiche de synthèse)
  • \(\card(A \sqcup B) = \card(A) + \card(B)\) ; si \((A_i)\) est une partition de \(E\), \(\card(E) = \sum_{i} \card(A_i)\).
  • Si \(X \subset Y\) : \(\card(Y \setminus X) = \card(Y) - \card(X)\), donc \(\card(X) \leq \card(Y)\).
  • \(\card(A \times B) = \card(A) \times \card(B)\).
  • Si \(\card(E) = n\), alors \(\card\big(\mathcal{P}(E)\big) = 2^n\).
Démonstration \(\card(Y \setminus X)\), séminaire 2.13.3

Comme \(X \subset Y\), on a \(Y = X \sqcup (Y \setminus X)\) : un élément de \(Y\) est soit dans \(X\), soit hors de \(X\), jamais les deux. Donc \(\card(Y) = \card(X) + \card(Y \setminus X)\), d’où \(\card(Y \setminus X) = \card(Y) - \card(X)\).

Démonstration \(\card(A \times B)\)

On range les couples selon leur première coordonnée : \(A \times B = \bigsqcup_{a \in A} \big(\{a\} \times B\big)\). Ces ensembles sont deux à deux disjoints (premières coordonnées différentes) et chacun a \(\card(B)\) éléments. Il y en a \(\card(A)\), donc \(\card(A \times B) = \card(A) \times \card(B)\). C’est le tableau à double entrée de la partie 6 : \(\card(A)\) lignes de \(\card(B)\) cases.

Démonstration \(\card \mathcal{P}(E) = 2^n\) (TD 1.6)

Notons \(E = \{x_1, \dots, x_n\}\). À une partie \(X \subset E\), on associe la liste \((\varepsilon_1, \dots, \varepsilon_n) \in \{0, 1\}^n\), où \(\varepsilon_i = 1\) si \(x_i \in X\) et \(\varepsilon_i = 0\) sinon.

Deux parties différentes donnent deux listes différentes (un \(x_i\) est dans l’une et pas dans l’autre), et chaque liste vient d’une partie : \(X = \{x_i,\ \varepsilon_i = 1\}\). Les deux ensembles ont donc autant d’éléments : \(\card \mathcal{P}(E) = \card\big(\{0, 1\}^n\big) = 2 \times \cdots \times 2 = 2^n\).

Pour \(n = 0\) : \(\mathcal{P}(\varnothing) = \{\varnothing\}\) a bien \(2^0 = 1\) élément. Une autre preuve, \(\sum_{k=0}^{n} \binom{n}{k} = 2^n\), est dans le cours 5, partie 8.

La formule du crible

Dans \(\card(A) + \card(B)\), les éléments de \(A \cap B\) sont comptés deux fois : une fois dans \(A\), une fois dans \(B\). On les retire une fois.

Théorème formule du crible (inclusion-exclusion)

Pour \(A\), \(B\), \(C\) finis :

\[\card(A \cup B) = \card(A) + \card(B) - \card(A \cap B)\]
\[\begin{aligned} & \card(A \cup B \cup C) \\ & = \card(A) + \card(B) + \card(C) \\ & \quad - \card(A \cap B) - \card(A \cap C) - \card(B \cap C) \\ & \quad + \card(A \cap B \cap C) \end{aligned}\]
Démonstration à connaître deux ensembles, par une partition (examen DP 2023)

On a \(A \cup B = (A \setminus B) \cup B\), et cette union est disjointe : un élément de \(A \cup B\) est soit dans \(B\), soit dans \(A\) et hors de \(B\).

Donc \(\card(A \cup B) = \card(A \setminus B) + \card(B)\). Or \(A = (A \setminus B) \sqcup (A \cap B)\) (partie 7) donne \(\card(A \setminus B) = \card(A) - \card(A \cap B)\). Ainsi :

\[\card(A \cup B) = \card(A) - \card(A \cap B) + \card(B).\]
Démonstration trois ensembles (TD 1.4)

On écrit \(A \cup B \cup C = (A \cup B) \cup C\) et on applique la formule à deux ensembles :

\[\begin{aligned} \card(A \cup B \cup C) = {} & \card(A \cup B) + \card(C) \\ & - \card\big((A \cup B) \cap C\big). \end{aligned}\]

Par distributivité (partie 5), \((A \cup B) \cap C = (A \cap C) \cup (B \cap C)\), et \((A \cap C) \cap (B \cap C) = A \cap B \cap C\). La formule à deux ensembles donne \(\card\big((A \cup B) \cap C\big) = \card(A \cap C) + \card(B \cap C) - \card(A \cap B \cap C)\).

On remplace aussi \(\card(A \cup B)\) par \(\card(A) + \card(B) - \card(A \cap B)\) : on obtient la formule à trois ensembles.

Exemple (QCM hebdomadaire du 30 septembre 2024). 64 médailles ; \(A\) (or ou argent) en compte 42, \(B\) (or ou bronze) 38. Toute médaille est dans \(A\) ou dans \(B\), donc \(\card(A \cup B) = 64\), et les médailles d’or forment \(A \cap B\) : \(\card(A \cap B) = 42 + 38 - 64 = 16\). Il reste \(42 - 16 = 26\) médailles d’argent et \(38 - 16 = 22\) de bronze.

Exemple à trois ensembles. Dans \(E = \ent{1}{100}\), \(A\), \(B\), \(C\) sont les multiples de 2, de 3, de 5. Les intersections sont les multiples de 6, 10, 15 et 30.

\(\card(A \cup B \cup C) = 50 + 33 + 20 - 16 - 10 - 6 + 3 = 74\)
Il reste \(\card\big(E \setminus (A \cup B \cup C)\big) = 100 - 74 = 26\) entiers divisibles ni par 2, ni par 3, ni par 5.
Rédaction modèle séminaire 2.13.6

Une classe de 40 élèves : 25 parlent anglais, 11 espagnol, 6 ni l’un ni l’autre. On note \(C\) la classe, \(A\) les anglophones, \(E\) les hispanophones.nommer les ensembles

(a) \(\card(C) = 40\), \(\card(A) = 25\), \(\card(E) = 11\) et \(\card\big(C \setminus (A \cup E)\big) = 6\).

(b) Comme \(A \cup E \subset C\), \(\card(A \cup E) = \card(C) - \card\big(C \setminus (A \cup E)\big)\) \(= 40 - 6 = 34\).

Deux élèves parlent les deux langues.

Piège : additionner sans retirer
  • \(\card(A \cup B) = \card(A) + \card(B)\) seulement si \(A\) et \(B\) sont disjoints. Pour la classe : \(25 + 11 = 36 \neq 34\), car les 2 bilingues sont comptés deux fois.
  • À trois ensembles, n’oublie pas \(+\,\card(A \cap B \cap C)\) : les éléments communs aux trois sont ajoutés 3 fois puis retirés 3 fois, il faut les rajouter une fois.
